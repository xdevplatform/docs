## Official SDKs (XDKs)

Client libraries for the X API v2, generated from the OpenAPI spec with auth, pagination, and streaming built in.

### Quick start

<Tabs>
  <Tab title="Python">
```bash
pip install xdk
```

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

for page in client.posts.search_recent(query="from:XDevelopers", max_results=10):
    if page.data:
        print(page.data[0].text)
    break
```

<Button href="/xdks/python/overview">Full Python guide</Button>
  </Tab>
  <Tab title="TypeScript">
```bash
npm install @xdevplatform/xdk
```

```typescript
import { Client } from '@xdevplatform/xdk';

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });
const userResponse = await client.users.getByUsername('XDevelopers');
console.log(userResponse.data?.username);
```

<Button href="/xdks/typescript/overview">Full TypeScript guide</Button>
  </Tab>
  <Tab title="Java">
```xml
<dependency>
  <groupId>com.x</groupId>
  <artifactId>xdk</artifactId>
  <version>0.1.2</version>
</dependency>
```

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

var response = client.users().getByUsername("XDevelopers");
System.out.println(response.getData());
```

<Button href="/xdks/java/overview">Full Java guide</Button>
  </Tab>
  <Tab title="C#">
```bash
dotnet add package XDevPlatform.Xdk
```

```csharp
using System;
using Xdk;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

var response = await client.Users.GetByUsernameAsync("XDevelopers");
Console.WriteLine(response.Data);
```
