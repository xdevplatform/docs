Paginated methods in the Python XDK return a lazy iterator that follows `meta.next_token` automatically across pages.

## Automatic pagination

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

all_posts = []
for page in client.posts.search_recent(
    query="python",
    max_results=100,
    tweet_fields=["created_at", "author_id"],
):
    if page.data:
        all_posts.extend(page.data)
        print(f"Fetched {len(page.data)} posts (total: {len(all_posts)})")
    if len(all_posts) >= 500:
        break  # Stop early without fetching additional pages
```

The iterator stops automatically when `meta.next_token` is absent.

## Manual pagination

To control each request yourself, pull a single page with `next(...)` and pass `pagination_token` on the next call:

```python
first_page = next(client.posts.search_recent(
    query="python",
    max_results=100,
))

next_token = first_page.meta.next_token if first_page.meta else None
if next_token:
    second_page = next(client.posts.search_recent(
        query="python",
        max_results=100,
        pagination_token=next_token,
    ))
    print(f"Second page: {len(second_page.data or [])} posts")
```
