Install the official **Python XDK** (`xdk`) from [PyPI](https://pypi.org/project/xdk/).

## Prerequisites

- **Python 3.8+** (CPython or PyPy)
- `pip` or `uv`

## Install from PyPI

<CodeGroup>

```bash pip
pip install xdk
```

```bash uv
uv add xdk
```

```bash poetry
poetry add xdk
```

</CodeGroup>

## Virtual Environment Setup (Recommended)

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install xdk
```

## Verify Installation

```python
import xdk
from xdk import Client

print(xdk.__version__)
```

## Install from Source

```bash
git clone https://github.com/xdevplatform/xdk-python.git
cd xdk-python
pip install -e ".[dev]"
```
