Install `xdk` from [PyPI](https://pypi.org/project/xdk/). Requires Python 3.8+.

<CodeGroup>

```bash pip
pip install xdk
```

```bash uv
uv add xdk
```

```bash poetry
poetry add xdk
```

</CodeGroup>

## Virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install xdk
```

## Verify

```python
import xdk

print(xdk.__version__)
```

## Install from source

```bash
git clone https://github.com/xdevplatform/xdk-python.git
cd xdk-python
pip install -e ".[dev]"
```
