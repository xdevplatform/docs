## Installation

```bash
pip install xdk
```

## `Client` Initialization

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])
```

<ResponseField name="bearer_token" type="Optional[str]">
  App-only OAuth 2.0 Bearer Token for public read and search endpoints.
</ResponseField>
<ResponseField name="access_token" type="Optional[str]">
  OAuth 2.0 user-context access token for endpoints acting on behalf of a user.
</ResponseField>
<ResponseField name="auth" type="Optional[OAuth1]">
  Configured `OAuth1` instance for OAuth 1.0a HMAC-SHA1 user-context signing.
</ResponseField>
<ResponseField name="base_url" type="str" default="https://api.x.com">
  Base URL for X API requests.
</ResponseField>
<ResponseField name="timeout" type="Optional[float]">
  Per-request HTTP timeout in seconds.
</ResponseField>
<ResponseField name="max_retries" type="int" default="0">
  Maximum retry attempts for transient network or 5xx failures.
</ResponseField>
