## `create`

<Badge color="green">POST</Badge> `/2/notes`

**Create a Community Note**

Creates a Community Note on a Post. With test_mode set to true, the note is only for testing and is not publicly visible.

```python
import os
from xdk import Client
from xdk.community_notes.models import CreateRequest

client = Client(access_token=os.environ["X_ACCESS_TOKEN"])

response = client.community_notes.create(
    body=CreateRequest(test_mode=True, post_id="1895000000000000000", info={"text": "Hello from XDK!", "classification": "misinformed_or_potentially_misleading", "misleading_tags": ["disputed_claim_as_fact"], "trustworthy_sources": True})
)
print(response)
```

### Parameters

<ResponseField name="body" type="CreateRequest" required>
  Request payload.
</ResponseField>

**Returns:** `CreateResponse`

## `evaluate`

<Badge color="green">POST</Badge> `/2/notes/evaluate`

**Evaluate a Community Note**

Evaluates the text of a proposed Community Note on a Post and returns its claim-opinion score.

```python

client = Client(access_token=os.environ["X_ACCESS_TOKEN"])

response = client.community_notes.evaluate(
    body=EvaluateRequest(post_id="1895000000000000000", note_text="example")

```
