## `create_by_conversation_id`

<Badge color="green">POST</Badge> `/2/dm_conversations/{dm_conversation_id}/messages`

**Create DM Message by Conversation ID**

Sends a new direct message to a specific conversation by its ID.

```python
import os
from xdk import Client
from xdk.direct_messages.models import CreateByConversationIdRequest

client = Client(access_token=os.environ["X_ACCESS_TOKEN"])

response = client.direct_messages.create_by_conversation_id(
    dm_conversation_id="1500000000000000000",
    body=CreateByConversationIdRequest(text="Hello from XDK!")
)
print(response)
```

### Parameters

<ResponseField name="dm_conversation_id" type="str" required>
  `dm_conversation_id` (path parameter).
</ResponseField>

<ResponseField name="body" type="CreateByConversationIdRequest" required>
  At least one of `text`, `attachments` is required.
</ResponseField>

**Returns:** `CreateByConversationIdResponse`

## `create_conversation`

<Badge color="green">POST</Badge> `/2/dm_conversations`

**Create DM Conversation**

Initiates a new direct message conversation with specified participants.

```python
import os
from xdk import Client
from xdk.direct_messages.models import CreateConversationRequest

client = Client(access_token=os.environ["X_ACCESS_TOKEN"])

response = client.direct_messages.create_conversation(
    body=CreateConversationRequest(conversation_type="Group", participant_ids=["2244994945"], message={"text": "Hello from XDK!"})
)
print(response)
```

### Parameters

<ResponseField name="body" type="CreateConversationRequest" required>
  Request payload.
</ResponseField>

**Returns:** `CreateConversationResponse`

## `dm_conversations_media_download`

<Badge color="blue">GET</Badge> `/2/dm_conversations/media/{dm_id}/{media_id}/{resource_id}`

**Download DM Media**

Downloads media attached to a legacy Direct Message. The requesting user must be a participant in the conversation containing the specified DM event. The response body contains raw binary bytes.

```python
import os
from xdk import Client

client = Client(access_token=os.environ["X_ACCESS_TOKEN"])

response = client.direct_messages.dm_conversations_media_download(
    dm_id="1895000000000000000",
    media_id="3_1895000000000000000",
    resource_id="1895000000000000000"
)
print(response)
```

### Parameters

<ResponseField name="dm_id" type="str" required>
  `dm_id` (path parameter).
</ResponseField>

<ResponseField name="media_id" type="str" required>
  `media_id` (path parameter).
</ResponseField>

<ResponseField name="resource_id" type="str" required>
  `resource_id` (path parameter).
</ResponseField>

**Returns:** `bytes`
