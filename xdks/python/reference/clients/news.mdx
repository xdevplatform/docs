| :--- | :--- | :--- | :--- |
| [`get`](#get) | `GET /2/news/{id}` | Standard | Get News Stories by ID |
| [`search`](#search) | `GET /2/news/search` | Standard | Search News |

## `get`

<Badge color="blue">GET</Badge> `/2/news/{id}`

**Get News Stories by ID**

Retrieves news story by its ID.

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

response = client.news.get(id="1895000000000000000")
print(response)
```

## `search`

<Badge color="blue">GET</Badge> `/2/news/search`

**Search News**

Retrieves a list of News stories matching the specified search query.

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

response = client.news.search(query="from:XDevelopers")
print(response)
```

### Parameters

</ResponseField>
