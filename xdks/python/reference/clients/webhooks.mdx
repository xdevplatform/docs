## `create`

<Badge color="green">POST</Badge> `/2/webhooks`

**Create Webhook**

Creates a new webhook configuration.

```python
import os
from xdk import Client
from xdk.webhooks.models import CreateRequest

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

response = client.webhooks.create(body=CreateRequest(url="https://example.com/webhook"))
print(response)
```

### Parameters

<ResponseField name="body" type="CreateRequest" required>
  Request payload.
</ResponseField>

**Returns:** `CreateResponse`

## `create_webhook_replay_job`

<Badge color="green">POST</Badge> `/2/webhooks/replay`

**Create Replay Job for Webhook**

Creates a replay job to retrieve events from up to the past 24 hours for all events delivered or attempted to be delivered to the webhook.

```python
import os
from xdk import Client
from xdk.webhooks.models import CreateWebhookReplayJobRequest

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

response = client.webhooks.create_webhook_replay_job(
    body=CreateWebhookReplayJobRequest(webhook_id="1234567890", from_date="example", to_date="example")
)
print(response)
```

### Parameters

<ResponseField name="body" type="CreateWebhookReplayJobRequest" required>
  Request payload.
</ResponseField>

**Returns:** `CreateWebhookReplayJobResponse`
