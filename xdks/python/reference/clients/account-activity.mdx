Access **Account Activity** endpoints via `client.account_activity` (`AccountActivityClient`).

## Methods

| Method | Endpoint | Behavior | Summary |
| :--- | :--- | :--- | :--- |
| [`create_subscription`](#create_subscription) | `POST /2/account_activity/webhooks/{webhook_id}/subscriptions/all` | Standard | Create Subscription |
| [`delete_subscription`](#delete_subscription) | `DELETE /2/account_activity/webhooks/{webhook_id}/subscriptions/{user_id}/all` | Standard | Delete Subscription |

## `create_subscription`

<Badge color="green">POST</Badge> `/2/account_activity/webhooks/{webhook_id}/subscriptions/all`

**Create Subscription**

Creates an Account Activity subscription for the user and the given webhook.

```python
import os
from xdk import Client
from xdk.account_activity.models import CreateSubscriptionRequest

client = Client(access_token=os.environ["X_ACCESS_TOKEN"])

response = client.account_activity.create_subscription(webhook_id="1234567890", body=CreateSubscriptionRequest())
print(response)
```

### Parameters

<ResponseField name="webhook_id" type="schemas.WebhookConfigId" required>
  `webhook_id` (path parameter).
</ResponseField>

<ResponseField name="body" type="CreateSubscriptionRequest" required>
  Request payload.
</ResponseField>

**Returns:** `CreateSubscriptionResponse`

## `delete_subscription`

<Badge color="red">DELETE</Badge> `/2/account_activity/webhooks/{webhook_id}/subscriptions/{user_id}/all`

**Delete Subscription**

Deletes an Account Activity subscription for the given webhook and user ID.

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

response = client.account_activity.delete_subscription(webhook_id="1234567890", user_id="2244994945")
print(response)
```

### Parameters

<ResponseField name="webhook_id" type="schemas.WebhookConfigId" required>
  `webhook_id` (path parameter).
</ResponseField>

<ResponseField name="user_id" type="schemas.UserId" required>
  `user_id` (path parameter).
</ResponseField>

**Returns:** `DeleteSubscriptionResponse`
