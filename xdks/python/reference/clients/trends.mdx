## `get_by_woeid`

<Badge color="blue">GET</Badge> `/2/trends/by/woeid/{woeid}`

**Get Trends by WOEID**

Retrieves trending topics for a specific location identified by its WOEID. `meta.location` describes that location: its `woeid` and `name`, and when they are known its `country`, `country_code`, `place_type` (`town`, `country` or `supername`) and `parent_id`, the WOEID of the place that contains it.

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

response = client.trends.get_by_woeid(woeid=1)
print(response)
```

</ResponseField>

  A comma separated list of Trend fields to display.

## `get_locations`

<Badge color="blue">GET</Badge> `/2/trends/locations`

**Get Trend Locations**

Retrieves every location that has trends. Each location has a WOEID to pass to `GET /2/trends/by/woeid/{woeid}`. The list is short and is returned whole, so the route takes no paging parameters.

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

response = client.trends.get_locations()
print(response)
```

### Parameters

<Expandable title="Optional keyword arguments (1)">

<ResponseField name="trend_location_fields" type={"List[Literal[\"country\", \"country_code\", \"name\", \"parent_id\", \"place_type\", \"woeid\"]]"}>
  A comma separated list of TrendLocation fields to display.
</ResponseField>

</Expandable>

**Returns:** `GetLocationsResponse`

## `get_personalized`

<Badge color="blue">GET</Badge> `/2/users/personalized_trends`

**Get Personalized Trends**

Retrieves personalized trending topics for the authenticated user.

```python
import os
from xdk import Client

client = Client(access_token=os.environ["X_ACCESS_TOKEN"])

response = client.trends.get_personalized()
print(response)
```

### Parameters

<Expandable title="Optional keyword arguments (1)">

<ResponseField name="personalized_trend_fields" type={"List[Literal[\"category\", \"post_count\", \"trend_name\", \"trending_since\"]]"}>
  A comma separated list of PersonalizedTrend fields to display.
</ResponseField>

</Expandable>

**Returns:** `GetPersonalizedResponse`
