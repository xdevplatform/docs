## `create_bot`

<Badge color="green">POST</Badge> `/2/bots`

**Create a Bot**

Creates a bot account in the calling app's project and returns its bearer token. Idempotent on handle: repeating the request for a handle that already names one of the project's bots returns that bot with a freshly minted token, revoking the previous one — safe to retry when a response was lost, since the replaced token was never seen. With an OAuth 2.0 user token, the user must be an admin of the project's developer account. On API Connect, where the request bills the user's own account, the bot is created in the user's project instead; its token is still minted for the calling app.

```python
import os
from xdk import Client
from xdk.bots.models import CreateBotRequest

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

response = client.bots.create_bot(body=CreateBotRequest(handle="example"))
print(response)
```

### Parameters

<ResponseField name="body" type="CreateBotRequest" required>
  Request payload.
</ResponseField>

**Returns:** `CreateBotResponse`

## `delete_bot`

<Badge color="red">DELETE</Badge> `/2/bots/{id}`

**Delete Bot**

Deletes a bot account from the calling app's project. With an OAuth 2.0 user token, the user must be an admin of the project's developer account. On API Connect, where the request bills the user's own account, the bot is deleted from the user's project instead.

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

response = client.bots.delete_bot(id="1895000000000000000")
print(response)
```

### Parameters

<ResponseField name="id" type="str" required>
  `id` (path parameter).
</ResponseField>

**Returns:** `DeleteBotResponse`

## `get`

<Badge color="blue">GET</Badge> `/2/bots`

**Get Bots**

Retrieves the bot accounts in the calling app's project. meta.max_bots is the most bots the project can have.

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

response = client.bots.get()
print(response)
```

## `revoke_bot_token`

<Badge color="red">DELETE</Badge> `/2/bots/{id}/token`

**Revoke Bot Token**

Revokes a bot's bearer token. The bot account is kept, and rotating its token mints a new one.

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

response = client.bots.revoke_bot_token(id="1895000000000000000")
print(response)
```

### Parameters

<ResponseField name="id" type="str" required>
  `id` (path parameter).
</ResponseField>

**Returns:** `RevokeBotTokenResponse`

## `rotate_bot_token`

<Badge color="green">POST</Badge> `/2/bots/{id}/token`

**Rotate Bot Token**

Mints a new bearer token for a bot and invalidates every token previously issued for it. The new token is returned only once.

```python
import os
from xdk import Client
from xdk.bots.models import RotateBotTokenRequest

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

response = client.bots.rotate_bot_token(
    id="1895000000000000000",
    body=RotateBotTokenRequest(scopes=["example"])
)
print(response)
```

### Parameters

<ResponseField name="id" type="str" required>
  `id` (path parameter).
</ResponseField>

<ResponseField name="body" type="RotateBotTokenRequest" required>
  Request payload.
</ResponseField>

**Returns:** `RotateBotTokenResponse`
