## `activity`

<Badge color="blue">GET</Badge> `/2/activity/stream` <Badge color="green">Streaming</Badge>

**Activity Stream**

Stream of X Activities

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

for event in client.stream.activity():
    print(event)
```

### Parameters

<Expandable title="Optional keyword arguments (3)">

<ResponseField name="backfill_minutes" type="int">
  The number of minutes of backfill requested.
</ResponseField>

<ResponseField name="start_time" type="str">
  YYYY-MM-DDTHH:mm:ssZ. The earliest UTC timestamp from which the activities will be provided.
</ResponseField>

<ResponseField name="end_time" type="str">
  YYYY-MM-DDTHH:mm:ssZ. The latest UTC timestamp from which the activities will be provided.
</ResponseField>

</Expandable>

**Returns:** `Generator[ActivityResponse, None, None]`

## `get_rules`

<Badge color="blue">GET</Badge> `/2/tweets/search/stream/rules` <Badge color="purple">Paginated</Badge>

**Get Stream Rules**

Returns the active filtered-stream rules for the authenticated app. Provide `ids` to fetch specific rules; omit it to list all rules.

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

for page in client.stream.get_rules():
    print(page.data)
```

### Parameters

<Expandable title="Optional keyword arguments (3)">

<ResponseField name="ids" type="List[str]">
  `ids` (query parameter).
</ResponseField>

<ResponseField name="max_results" type="int">
  `max_results` (query parameter).
</ResponseField>

<ResponseField name="pagination_token" type="str">
  A base32hex-encoded pagination token that decodes to 8 bytes.
</ResponseField>

</Expandable>

**Returns:** `Iterator[GetRulesResponse]`
