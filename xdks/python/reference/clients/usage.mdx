## `get`

<Badge color="blue">GET</Badge> `/2/usage/tweets`

**Get Usage**

Retrieves usage statistics for Posts over a specified number of days.

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

response = client.usage.get()
print(response)
```

### Parameters

<Expandable title="Optional keyword arguments (2)">

<ResponseField name="days" type="int">
  `days` (query parameter).
</ResponseField>

<ResponseField name="usage_fields" type={"List[Literal[\"cap_reset_day\", \"daily_client_app_usage\", \"daily_project_usage\", \"project_cap\", \"project_id\", \"project_usage\"]]"}>
  A comma separated list of Usage fields to display.
</ResponseField>

</Expandable>

## `get_credits`

<Badge color="blue">GET</Badge> `/2/usage/credits`

**Get Usage Credits**

Returns the payer's developer-platform credit balance in USD. total_balance is max(0, prepaid_balance + free_balance); prepaid_balance may be negative.

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

response = client.usage.get_credits()
print(response)
```

**Returns:** `GetCreditsResponse`
