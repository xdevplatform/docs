Access **Articles** endpoints via `client.articles` (`ArticlesClient`).

## Methods

| Method | Endpoint | Behavior | Summary |
| :--- | :--- | :--- | :--- |
| [`article_create_draft`](#article_create_draft) | `POST /2/articles/draft` | Standard | Create Draft Article |
| [`article_publish`](#article_publish) | `POST /2/articles/{article_id}/publish` | Standard | Publish Article |

## `article_create_draft`

<Badge color="green">POST</Badge> `/2/articles/draft`

**Create Draft Article**

Creates a new Article draft that can later be published.

```python
import os
from xdk import Client
from xdk.articles.models import ArticleCreateDraftRequest

client = Client(access_token=os.environ["X_ACCESS_TOKEN"])

response = client.articles.article_create_draft(
    body=ArticleCreateDraftRequest(title="example", content_state={"blocks": [{}], "entities": [{}]})
)
print(response)
```

### Parameters

<ResponseField name="body" type="ArticleCreateDraftRequest" required>
  Create a draft Article.
</ResponseField>

**Returns:** `ArticleCreateDraftResponse`

## `article_publish`

<Badge color="green">POST</Badge> `/2/articles/{article_id}/publish`

**Publish Article**

Publishes a draft Article, making it publicly visible.

```python
import os
from xdk import Client

client = Client(access_token=os.environ["X_ACCESS_TOKEN"])

response = client.articles.article_publish(article_id="1895000000000000000")
print(response)
```

### Parameters

<ResponseField name="article_id" type="str" required>
  `article_id` (path parameter).
</ResponseField>

**Returns:** `ArticlePublishResponse`
