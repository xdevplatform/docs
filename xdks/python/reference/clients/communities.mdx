## `get_by_id`

<Badge color="blue">GET</Badge> `/2/communities/{id}`

**Get Community by ID**

Retrieves details of a specific Community by its ID.

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

response = client.communities.get_by_id(id="1895000000000000000")
print(response)
```

## `search`

<Badge color="blue">GET</Badge> `/2/communities/search` <Badge color="purple">Paginated</Badge>

**Search Communities**

Retrieves a list of Communities matching the specified search query.

```python
import os
from xdk import Client

client = Client(access_token=os.environ["X_ACCESS_TOKEN"])

for page in client.communities.search(query="from:XDevelopers"):
    print(page.data)
```
