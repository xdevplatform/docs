## Methods

| Method | Endpoint | Behavior | Summary |
| :--- | :--- | :--- | :--- |
| [`create_jobs`](#create_jobs) | `POST /2/compliance/jobs` | Standard | Create Compliance Job |

## `create_jobs`

<Badge color="green">POST</Badge> `/2/compliance/jobs`

**Create Compliance Job**

Creates a new Compliance Job for the specified job type.

```python
import os
from xdk import Client
from xdk.compliance.models import CreateJobsRequest

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

response = client.compliance.create_jobs(body=CreateJobsRequest(type="tweets"))
print(response)
```

## `delete_jobs_by_id`

<Badge color="red">DELETE</Badge> `/2/compliance/jobs/{id}`

**Cancel Compliance Job**

Cancels a Compliance Job that has not finished processing; its status becomes failed and a new job of the same type can be created.

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

response = client.compliance.delete_jobs_by_id(id="1895000000000000000")
print(response)
```

**Download Compliance Job Results**
