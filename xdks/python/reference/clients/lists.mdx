## `add_member`

<Badge color="green">POST</Badge> `/2/lists/{id}/members`

**Add List Member**

Adds a User to a specific List by its ID.

```python
import os
from xdk import Client
from xdk.lists.models import AddMemberRequest

client = Client(access_token=os.environ["X_ACCESS_TOKEN"])

response = client.lists.add_member(
    id="1450000000000000000",
    body=AddMemberRequest(user_id="2244994945")
)
print(response)
```

### Parameters

<ResponseField name="id" type="schemas.ListId" required>
  `id` (path parameter).
</ResponseField>

<ResponseField name="body" type="AddMemberRequest" required>
  Request payload.
</ResponseField>

**Returns:** `AddMemberResponse`
