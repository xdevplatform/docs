Streaming methods on `client.stream` hold open an HTTP connection and yield events as they arrive.

## Filtered stream

Make sure you have added at least one rule before connecting to `client.stream.posts()`:

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

for event in client.stream.posts():
    if event.data:
        print(event.data)
```

### Using with `asyncio`

```python
import asyncio
import os
import threading
from xdk import Client

async def stream_posts_async(client: Client):
    queue = asyncio.Queue()
    loop = asyncio.get_running_loop()
    stop = threading.Event()

    def run_stream():
        for post in client.stream.posts():
            if stop.is_set():
                break
            asyncio.run_coroutine_threadsafe(queue.put(post), loop)
        asyncio.run_coroutine_threadsafe(queue.put(None), loop)

    threading.Thread(target=run_stream, daemon=True).start()

    while True:
        post = await queue.get()
        if post is None:
            break
        if post.data:
            print(post.data)
    stop.set()

async def main():
    client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])
    await stream_posts_async(client)

asyncio.run(main())
```

## Managing rules

Add rules:

```python
from xdk.stream.models import UpdateRulesRequest

request_body = UpdateRulesRequest(
    add=[{"value": "from:XDevelopers", "tag": "official_updates"}]
)
client.stream.update_rules(body=request_body)
```

Delete rules:

```python
from xdk.stream.models import UpdateRulesRequest

request_body = UpdateRulesRequest(
    delete={"ids": ["rule_id_1", "rule_id_2"]}
)
client.stream.update_rules(body=request_body)
```

List active rules:

```python
for page in client.stream.get_rules():
    if page.data:
        for rule in page.data:
            print(rule.id, rule.value, rule.tag)
    break
```

See [Build a Rule](/x-api/posts/filtered-stream/integrate/build-a-rule) for rule syntax and operators, and the [StreamClient reference](/xdks/python/reference/clients/stream) for all streaming methods.
