<Steps>
  <Step title="Install the SDK">
```bash
pip install xdk
```
  </Step>
  <Step title="Export your Bearer Token">
    Generate a **Bearer Token** in the [X Developer Console](https://console.x.com) and set it in your shell:

```bash
export X_BEARER_TOKEN="your_bearer_token_here"
```
  </Step>
  <Step title="Run a search">
    Save this as `quickstart.py`:

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

for page in client.posts.search_recent(query="from:XDevelopers", max_results=10):
    if page.data:
        print(page.data[0].text)
    else:
        print("No posts found.")
    break
```

    Run it:

```bash
python quickstart.py
```
  </Step>
</Steps>
