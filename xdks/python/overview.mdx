The **Python XDK** (`xdk`) is X's official Python client library for the X API v2, generated directly from the [official OpenAPI specification](https://api.x.com/2/openapi.json).

## Key Features

- **Authentication**: App-only Bearer Token, OAuth 2.0 User Context with PKCE and token refresh, and OAuth 1.0a HMAC-SHA1 signing.
- **Typed Models**: Pydantic v2 request and response models with open-enum forward compatibility.
- **Automatic Pagination**: Generator-based cursor iteration across multi-page endpoints without manual `pagination_token` loops.
- **Real-Time Streaming**: Persistent streaming iterators for Filtered Stream, Sample Streams, Firehose, Compliance, and Activity Stream.
- **Complete API Coverage**: 24 resource clients covering Posts, Users, Streams, Direct Messages, Chat, Spaces, Lists, Communities, Media, Webhooks, Trends, News, Usage, and more.

## Quick Example

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

for page in client.posts.search_recent(query="from:XDevelopers", max_results=10):
    if page.data:
        for post in page.data:
            print(post.id, post.text)
    break
```
