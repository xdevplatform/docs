`xdk` is the official Python SDK for the X API v2. It includes typed Pydantic models, OAuth 2.0 PKCE and OAuth 1.0a auth, cursor pagination, and streaming.

## Quick example

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])

for page in client.posts.search_recent(query="from:XDevelopers", max_results=10):
    if page.data:
        for post in page.data:
            print(post.id, post.text)
    break
```
