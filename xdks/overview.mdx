The **X Developer Kits (XDKs)** are the official client libraries for the X API v2. Every SDK is generated directly from the [official X API OpenAPI specification](https://api.x.com/2/openapi.json), keeping endpoint coverage, request/response models, authentication helpers, pagination, and streaming synchronized across languages.

<CardGroup cols={2}>
  <Card title="Python XDK" icon="python" href="/xdks/python/overview">

## Side-by-Side Quickstart

Look up `@XDevelopers` using an app-only Bearer Token in any of the four official XDKs:

<Tabs>
  <Tab title="Python">
```bash
pip install xdk
```

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])
response = client.users.get_by_username(
    username="XDevelopers",
    user_fields=["created_at", "public_metrics"],
)
print(response.data)
```
  </Tab>
  <Tab title="TypeScript">
```bash
npm install @xdevplatform/xdk
```

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });
const response = await client.users.getByUsername("XDevelopers", {
  userFields: ["created_at", "public_metrics"],
});
console.log(response.data);
```
  </Tab>
  <Tab title="Java">
```xml
<dependency>
  <groupId>com.x</groupId>
  <artifactId>xdk</artifactId>
  <version>0.1.2</version>
</dependency>
```

```java
import com.x.xdk.XClient;
import com.x.xdk.clients.UsersClient;
import java.util.List;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

var response = client.users().getByUsername(
    "XDevelopers",
    UsersClient.GetByUsernameOptions.builder()
        .userFields(List.of("created_at", "public_metrics"))
);
System.out.println(response.getData());
```
  </Tab>
  <Tab title="C#">
```bash
dotnet add package XDevPlatform.Xdk
```

```csharp
using System;
using System.Collections.Generic;
using Xdk;
using Xdk.Clients;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

var response = await client.Users.GetByUsernameAsync(
    "XDevelopers",
    new UsersClient.GetByUsernameOptions
    {
        UserFields = new List<string> { "created_at", "public_metrics" },
    });
Console.WriteLine(response.Data);
```
  </Tab>
</Tabs>

## Core Capabilities Across All 4 SDKs

- **Unified Resource Clients**: Every X API v2 tag maps to a dedicated sub-client (`posts`, `users`, `stream`, `direct_messages` / `directMessages` / `DirectMessages`, `spaces`, `lists`, `communities`, `chat`, `media`, `webhooks`, `compliance`, `trends`, `news`, `usage`, and more).
- **Complete Authentication Support**:
  - **Bearer Token** (app-only read, search, and filtered/sample streaming)
  - **OAuth 2.0 User Context with PKCE** (fine-grained scopes + refresh token rotation)
  - **OAuth 1.0a User Context** (HMAC-SHA1 request signing)
- **Native Pagination**:
  - Python yields pages lazily via standard `Iterator` generators (`for page in client.posts.search_recent(...):`).
  - TypeScript provides `Paginator`, `PostPaginator`, `UserPaginator`, and `EventPaginator` with `for await (...)`.
  - Java exposes `*Pages(...)` methods returning `Paginator<T>` (`Iterable<T>`).
  - C# exposes `*Pages(...)` methods returning `Paginator<T>` (`IAsyncEnumerable<T>`).
- **Resilient Real-Time Streaming**:
  - Incremental UTF-8 NDJSON frame decoding, heartbeat handling, and resource cleanup across Filtered Stream, Sample Streams, Firehose, Compliance Streams, and Activity Stream.

</Tip>
