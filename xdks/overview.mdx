The X Developer Kits (XDKs) are X's client libraries for the X API v2, generated from the [X API OpenAPI spec](https://api.x.com/2/openapi.json).

## Quickstart

Look up `@XDevelopers` with a Bearer Token:

<Tabs>
  <Tab title="Python">
```bash
pip install xdk
```

```python
import os
from xdk import Client

client = Client(bearer_token=os.environ["X_BEARER_TOKEN"])
response = client.users.get_by_username(
    username="XDevelopers",
    user_fields=["created_at", "public_metrics"],
)
print(response.data)
```
  </Tab>
  <Tab title="TypeScript">
```bash
npm install @xdevplatform/xdk
```

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });
const response = await client.users.getByUsername("XDevelopers", {
  userFields: ["created_at", "public_metrics"],
});
console.log(response.data);
```
  </Tab>
  <Tab title="Java">
```xml
<dependency>
  <groupId>com.x</groupId>
  <artifactId>xdk</artifactId>
  <version>0.1.2</version>
</dependency>
```

```java
import com.x.xdk.XClient;
import com.x.xdk.clients.UsersClient;
import java.util.List;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

var response = client.users().getByUsername(
    "XDevelopers",
    UsersClient.GetByUsernameOptions.builder()
        .userFields(List.of("created_at", "public_metrics"))
);
System.out.println(response.getData());
```
  </Tab>
  <Tab title="C#">
```bash
dotnet add package XDevPlatform.Xdk
```

```csharp
using System;
using System.Collections.Generic;
using Xdk;
using Xdk.Clients;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

var response = await client.Users.GetByUsernameAsync(
    "XDevelopers",
    new UsersClient.GetByUsernameOptions
    {
        UserFields = new List<string> { "created_at", "public_metrics" },
    });
Console.WriteLine(response.Data);
```

## What's included

- **Typed clients** — One sub-client per X API v2 resource (`posts`, `users`, `stream`, `direct_messages`, `spaces`, `lists`, `media`, `webhooks`, `chat`, and more).
- **Authentication** — Bearer Token, OAuth 2.0 with PKCE and token refresh, and OAuth 1.0a.
- **Pagination** — Cursor handling via Python generators, TypeScript `Paginator`, Java `Paginator<T>`, and C# `IAsyncEnumerable<T>`.
- **Streaming** — Live event streams for Filtered Stream, Sample Streams, Firehose, Compliance, and Activity.

<Tip>
For encrypted X Chat messages, see the [Chat XDK](/xchat/xchat-xdk) (Python, TypeScript, Java, C#, Go, and Rust).
</Tip>
