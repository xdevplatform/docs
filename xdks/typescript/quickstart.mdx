<Steps>
  <Step title="Install the package">
```bash
npm install @xdevplatform/xdk
```
  </Step>
  <Step title="Export your Bearer Token">
    Generate a **Bearer Token** in the [X Developer Console](https://console.x.com) and set it in your shell:

```bash
export X_BEARER_TOKEN="your_bearer_token_here"
```
  </Step>
  <Step title="Run your first script">
    Save this as `quickstart.ts` (or `quickstart.mjs` for JavaScript):

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const user = await client.users.getByUsername("XDevelopers", {
  userFields: ["created_at", "description", "public_metrics"],
});
console.log("User:", user.data);

const posts = await client.posts.searchRecent("from:XDevelopers", {
  maxResults: 10,
  tweetFields: ["created_at", "public_metrics"],
});
console.log("Recent posts:", posts.data);
```

    Run it with `npx tsx quickstart.ts` or `node quickstart.mjs`.
  </Step>
</Steps>
