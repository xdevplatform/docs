The **TypeScript XDK** (`@xdevplatform/xdk`) is X's official TypeScript and JavaScript client library for the X API v2, shipping dual ESM and CommonJS bundles with complete TypeScript definitions.

## Key Features

- **Full Type Safety**: Strongly typed request bodies, option interfaces, and response schemas generated from OpenAPI.
- **Authentication**: Bearer Token (app-only), OAuth 2.0 User Context with PKCE, and OAuth 1.0a HMAC-SHA1 signing.
- **Smart Pagination**: `Paginator`, `PostPaginator`, `UserPaginator`, and `EventPaginator` with `for await (...)` support.
- **Event-Driven Streaming**: `EventDrivenStream` supporting both `.on('data', ...)` listeners and `for await (const event of stream)`.
- **Dual Module Format**: Native ESM (`import`) and CommonJS (`require`) builds for Node.js 18+ and modern runtimes.

## Quick Example

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const userResponse = await client.users.getByUsername("XDevelopers", {
  userFields: ["created_at", "public_metrics"],
});
console.log(userResponse.data);
```
