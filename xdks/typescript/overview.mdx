`@xdevplatform/xdk` is the official TypeScript and JavaScript SDK for the X API v2. It ships ESM and CommonJS builds with TypeScript types, OAuth helpers, paginators, and streaming.

<CardGroup cols={2}>
  <Card title="npm" icon="js" href="https://www.npmjs.com/package/@xdevplatform/xdk">

  </Card>
  <Card title="GitHub" icon="github" href="https://github.com/xdevplatform/xdk-typescript">

  </Card>
</CardGroup>

## Quick example

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const userResponse = await client.users.getByUsername("XDevelopers", {
  userFields: ["created_at", "public_metrics"],
});
console.log(userResponse.data);
```
