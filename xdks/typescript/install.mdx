Install `@xdevplatform/xdk` from [npm](https://www.npmjs.com/package/@xdevplatform/xdk).

## Package Managers

<CodeGroup>

```bash npm
npm install @xdevplatform/xdk
```

```bash pnpm
pnpm add @xdevplatform/xdk
```

```bash yarn
yarn add @xdevplatform/xdk
```

```bash bun
bun add @xdevplatform/xdk
```

</CodeGroup>

## Requirements

- **Node.js 18+** (uses built-in `fetch` and Web Crypto)
- **TypeScript 5.0+** (optional; bundled `.d.ts` declarations are included out of the box)

## ESM and CommonJS

`@xdevplatform/xdk` ships dual module entrypoints:

<CodeGroup>

```typescript ESM
import { Client } from "@xdevplatform/xdk";
```

```javascript CommonJS
const { Client } = require("@xdevplatform/xdk");
```

</CodeGroup>
