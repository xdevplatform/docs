Install `@xdevplatform/xdk` from [npm](https://www.npmjs.com/package/@xdevplatform/xdk). Requires Node.js 18+.

<CodeGroup>

```bash npm
npm install @xdevplatform/xdk
```

```bash pnpm
pnpm add @xdevplatform/xdk
```

```bash yarn
yarn add @xdevplatform/xdk
```

```bash bun
bun add @xdevplatform/xdk
```

</CodeGroup>

## ESM and CommonJS

Both module formats are included along with TypeScript `.d.ts` declarations:

<CodeGroup>

```typescript ESM
import { Client } from "@xdevplatform/xdk";
```

```javascript CommonJS
const { Client } = require("@xdevplatform/xdk");
```

</CodeGroup>
