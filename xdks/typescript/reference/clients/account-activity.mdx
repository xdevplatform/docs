Access **Account Activity** endpoints via `client.accountActivity` (`AccountActivityClient`).

## Methods

| Method | Endpoint | Behavior | Summary |
| :--- | :--- | :--- | :--- |
| [`createSubscription`](#createsubscription) | `POST /2/account_activity/webhooks/{webhook_id}/subscriptions/all` | Standard | Create Subscription |
| [`deleteSubscription`](#deletesubscription) | `DELETE /2/account_activity/webhooks/{webhook_id}/subscriptions/{user_id}/all` | Standard | Delete Subscription |

## `createSubscription`

<Badge color="green">POST</Badge> `/2/account_activity/webhooks/{webhook_id}/subscriptions/all`

**Create Subscription**

Creates an Account Activity subscription for the user and the given webhook.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: process.env.X_ACCESS_TOKEN });

const response = await client.accountActivity.createSubscription("1234567890", {});
console.log(response);
```

### Parameters

<ResponseField name="webhookId" type="Schemas.WebhookConfigId" required>
  `webhook_id` (path parameter).
</ResponseField>

<ResponseField name="body" type="CreateSubscriptionRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Promise<CreateSubscriptionResponse>`

## `deleteSubscription`

<Badge color="red">DELETE</Badge> `/2/account_activity/webhooks/{webhook_id}/subscriptions/{user_id}/all`

**Delete Subscription**

Deletes an Account Activity subscription for the given webhook and user ID.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const response = await client.accountActivity.deleteSubscription("1234567890", "2244994945");
console.log(response);
```

### Parameters

<ResponseField name="webhookId" type="Schemas.WebhookConfigId" required>
  `webhook_id` (path parameter).
</ResponseField>

<ResponseField name="userId" type="Schemas.UserId" required>
  `user_id` (path parameter).
</ResponseField>

**Returns:** `Promise<DeleteSubscriptionResponse>`
