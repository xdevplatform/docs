Access **Connections** endpoints via `client.connections` (`ConnectionsClient`).

## Methods

| Method | Endpoint | Behavior | Summary |
| :--- | :--- | :--- | :--- |
| [`deleteAll`](#deleteall) | `DELETE /2/connections/all` | Standard | Terminate All Connections |
| [`deleteByEndpoint`](#deletebyendpoint) | `DELETE /2/connections/{endpoint_id}` | Standard | Terminate Connections by Endpoint |
| [`deleteByUuids`](#deletebyuuids) | `DELETE /2/connections` | Standard | Terminate Multiple Connections |
| [`getConnectionHistory`](#getconnectionhistory) | `GET /2/connections` | Paginated | Get Connection History |

## `deleteAll`

<Badge color="red">DELETE</Badge> `/2/connections/all`

**Terminate All Connections**

Terminates all active streaming connections for the authenticated application.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const response = await client.connections.deleteAll();
console.log(response);
```

**Returns:** `Promise<DeleteAllResponse>`

## `deleteByEndpoint`

<Badge color="red">DELETE</Badge> `/2/connections/{endpoint_id}`

**Terminate Connections by Endpoint**

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

```

## `getConnectionHistory`

<Badge color="blue">GET</Badge> `/2/connections` <Badge color="purple">Paginated</Badge>

**Get Connection History**

Returns active and historical streaming connections with disconnect reasons for the authenticated application.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const response = await client.connections.getConnectionHistory();
console.log(response);
```
