## `activity`

<Badge color="blue">GET</Badge> `/2/activity/stream` <Badge color="green">Streaming</Badge>

**Activity Stream**

Stream of X Activities

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const stream = await client.stream.activity();
for await (const event of stream) {
  console.log(event);
}
```

### Parameters

<Expandable title="Optional parameters (ActivityOptions — 3)">

<ResponseField name="options.backfillMinutes" type="number">
  The number of minutes of backfill requested.
</ResponseField>

<ResponseField name="options.startTime" type="string">
  YYYY-MM-DDTHH:mm:ssZ. The earliest UTC timestamp from which the activities will be provided.
</ResponseField>

<ResponseField name="options.endTime" type="string">
  YYYY-MM-DDTHH:mm:ssZ. The latest UTC timestamp from which the activities will be provided.
</ResponseField>

</Expandable>

**Returns:** `Promise<EventDrivenStream>`

## `getRules`

<Badge color="blue">GET</Badge> `/2/tweets/search/stream/rules` <Badge color="purple">Paginated</Badge>

**Get Stream Rules**

Returns the active filtered-stream rules for the authenticated app. Provide `ids` to fetch specific rules; omit it to list all rules.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const response = await client.stream.getRules();
console.log(response);
```

### Parameters

<Expandable title="Optional parameters (GetRulesOptions — 3)">

<ResponseField name="options.ids" type="Array<string>">
  `ids` (query parameter).
</ResponseField>

<ResponseField name="options.maxResults" type="number">
  `max_results` (query parameter).
</ResponseField>

<ResponseField name="options.paginationToken" type="string">
  A base32hex-encoded pagination token that decodes to 8 bytes.
</ResponseField>

</Expandable>

**Returns:** `Promise<GetRulesResponse>`
