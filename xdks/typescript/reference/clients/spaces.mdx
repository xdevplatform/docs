## `getBuyers`

<Badge color="blue">GET</Badge> `/2/spaces/{id}/buyers` <Badge color="purple">Paginated</Badge>

**Get Space Ticket Buyers**

Retrieves a list of Users who purchased tickets to a specific Space by its ID.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: process.env.X_ACCESS_TOKEN });

const response = await client.spaces.getBuyers("1YqKDqWLPPlGV");
console.log(response);
```
