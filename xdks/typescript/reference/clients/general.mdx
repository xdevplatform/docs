## `getOpenApiSpec`

<Badge color="blue">GET</Badge> `/2/openapi.json`

**Get OpenAPI Spec**

Retrieves the full OpenAPI Specification in JSON format. (See https://github.com/OAI/OpenAPI-Specification/blob/master/README.md)

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const response = await client.general.getOpenApiSpec();
console.log(response);
```

**Returns:** `Promise<GetOpenApiSpecResponse>`
