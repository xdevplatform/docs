Access **Lists** endpoints via `client.lists` (`ListsClient`).

## Methods

| Method | Endpoint | Behavior | Summary |
| :--- | :--- | :--- | :--- |
| [`addMember`](#addmember) | `POST /2/lists/{id}/members` | Standard | Add List Member |
| [`create`](#create) | `POST /2/lists` | Standard | Create List |
| [`delete`](#delete) | `DELETE /2/lists/{id}` | Standard | Delete List |
| [`getById`](#getbyid) | `GET /2/lists/{id}` | Standard | Get List by ID |

| [`update`](#update) | `PUT /2/lists/{id}` | Standard | Update List |

## `addMember`

<Badge color="green">POST</Badge> `/2/lists/{id}/members`

**Add List Member**

Adds a User to a specific List by its ID.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: process.env.X_ACCESS_TOKEN });

const response = await client.lists.addMember("1450000000000000000", { "user_id": "2244994945" });
console.log(response);
```

### Parameters

<ResponseField name="id" type="Schemas.ListId" required>
  `id` (path parameter).
</ResponseField>

<ResponseField name="body" type="AddMemberRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Promise<AddMemberResponse>`
