## `getByWoeid`

<Badge color="blue">GET</Badge> `/2/trends/by/woeid/{woeid}`

**Get Trends by WOEID**

Retrieves trending topics for a specific location identified by its WOEID. `meta.location` describes that location: its `woeid` and `name`, and when they are known its `country`, `country_code`, `place_type` (`town`, `country` or `supername`) and `parent_id`, the WOEID of the place that contains it.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const response = await client.trends.getByWoeid(1);
console.log(response);
```

### Parameters

<ResponseField name="woeid" type="number" required>
  `woeid` (path parameter).
</ResponseField>

<Expandable title="Optional parameters (GetByWoeidOptions — 2)">

<ResponseField name="options.maxTrends" type="number">
  `max_trends` (query parameter).
</ResponseField>

<ResponseField name="options.trendFields" type={"Array<\"trend_name\" | \"tweet_count\">"}>
  A comma separated list of Trend fields to display.
</ResponseField>

</Expandable>

**Returns:** `Promise<GetByWoeidResponse>`

## `getLocations`

<Badge color="blue">GET</Badge> `/2/trends/locations`

**Get Trend Locations**

Retrieves every location that has trends. Each location has a WOEID to pass to `GET /2/trends/by/woeid/{woeid}`. The list is short and is returned whole, so the route takes no paging parameters.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const response = await client.trends.getLocations();
console.log(response);
```

### Parameters

<Expandable title="Optional parameters (GetLocationsOptions — 1)">

<ResponseField name="options.trendLocationFields" type={"Array<\"country\" | \"country_code\" | \"name\" | \"parent_id\" | \"place_type\" | \"woeid\">"}>
  A comma separated list of TrendLocation fields to display.
</ResponseField>

</Expandable>

**Returns:** `Promise<GetLocationsResponse>`

## `getPersonalized`

<Badge color="blue">GET</Badge> `/2/users/personalized_trends`

**Get Personalized Trends**

Retrieves personalized trending topics for the authenticated user.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: process.env.X_ACCESS_TOKEN });

const response = await client.trends.getPersonalized();
console.log(response);
```

### Parameters

<Expandable title="Optional parameters (GetPersonalizedOptions — 1)">

<ResponseField name="options.personalizedTrendFields" type={"Array<\"category\" | \"post_count\" | \"trend_name\" | \"trending_since\">"}>
  A comma separated list of PersonalizedTrend fields to display.
</ResponseField>

</Expandable>

**Returns:** `Promise<GetPersonalizedResponse>`
