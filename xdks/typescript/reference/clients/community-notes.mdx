Access **Community Notes** endpoints via `client.communityNotes` (`CommunityNotesClient`).

## Methods

| Method | Endpoint | Behavior | Summary |
| :--- | :--- | :--- | :--- |
| [`create`](#create) | `POST /2/notes` | Standard | Create a Community Note |
| [`delete`](#delete) | `DELETE /2/notes/{id}` | Standard | Delete a Community Note |
| [`evaluate`](#evaluate) | `POST /2/notes/evaluate` | Standard | Evaluate a Community Note |

## `create`

<Badge color="green">POST</Badge> `/2/notes`

**Create a Community Note**

Creates a Community Note on a Post. With test_mode set to true, the note is only for testing and is not publicly visible.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: process.env.X_ACCESS_TOKEN });

const response = await client.communityNotes.create(
  { "test_mode": true, "post_id": "1895000000000000000", info: { text: "Hello from XDK!", classification: "misinformed_or_potentially_misleading", "misleading_tags": ["disputed_claim_as_fact"], "trustworthy_sources": true } }
);
console.log(response);
```

### Parameters

<ResponseField name="body" type="CreateRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Promise<CreateResponse>`
