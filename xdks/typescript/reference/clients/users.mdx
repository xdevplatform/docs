## `blockDms`

<Badge color="green">POST</Badge> `/2/users/{id}/dm/block`

**Block DMs**

Blocks direct messages to or from a specific User by their ID for the authenticated user.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: process.env.X_ACCESS_TOKEN });

const response = await client.users.blockDms("2244994945");
console.log(response);
```

### Parameters

<ResponseField name="id" type="Schemas.UserId" required>
  `id` (path parameter).
</ResponseField>

**Returns:** `Promise<BlockDmsResponse>`

## `createBookmark`

<Badge color="green">POST</Badge> `/2/users/{id}/bookmarks`

**Create Bookmark**

Adds one or more Posts to the authenticated user's Bookmarks. Supply `tweet_id` for a single Post, or `tweet_ids` (at most 25) to bookmark several in one request. Optional `folder_id` applies to every Post in the request. Billing and rate limits still apply per HTTP request.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: process.env.X_ACCESS_TOKEN });

const response = await client.users.createBookmark("2244994945", { "tweet_id": "1895000000000000000" });
console.log(response);
```

### Parameters

<ResponseField name="id" type="Schemas.UserId" required>
  The authenticated user's numeric ID, not `me`: the `id` from Get My User (`GET /2/users/me`).
</ResponseField>

<ResponseField name="body" type="CreateBookmarkRequest" required>
  At least one of `tweet_id`, `tweet_ids` is required.
</ResponseField>

**Returns:** `Promise<CreateBookmarkResponse>`
