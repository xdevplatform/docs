Access **Communities** endpoints via `client.communities` (`CommunitiesClient`).

## Methods

| Method | Endpoint | Behavior | Summary |
| :--- | :--- | :--- | :--- |
| [`getById`](#getbyid) | `GET /2/communities/{id}` | Standard | Get Community by ID |
| [`search`](#search) | `GET /2/communities/search` | Paginated | Search Communities |

## `getById`

<Badge color="blue">GET</Badge> `/2/communities/{id}`

**Get Community by ID**

Retrieves details of a specific Community by its ID.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const response = await client.communities.getById("1895000000000000000");
console.log(response);
```

<ResponseField name="id" type="Schemas.CommunityId" required>

</ResponseField>

## `search`

<Badge color="blue">GET</Badge> `/2/communities/search` <Badge color="purple">Paginated</Badge>

**Search Communities**

Retrieves a list of Communities matching the specified search query.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: process.env.X_ACCESS_TOKEN });

const response = await client.communities.search("from:XDevelopers");
console.log(response);
```

### Parameters

<ResponseField name="query" type="string" required>
  `query` (query parameter).
</ResponseField>

<Expandable title="Optional parameters (SearchOptions — 4)">

<ResponseField name="options.maxResults" type="number">
  `max_results` (query parameter).
</ResponseField>

<ResponseField name="options.nextToken" type="string">
  `next_token` (query parameter).
</ResponseField>

<ResponseField name="options.paginationToken" type="string">
  `pagination_token` (query parameter).
</ResponseField>

<ResponseField name="options.communityFields" type={"Array<\"access\" | \"created_at\" | \"description\" | \"id\" | \"join_policy\" | \"member_count\" | \"name\">"}>
  A comma separated list of Community fields to display.
</ResponseField>

</Expandable>

**Returns:** `Promise<SearchResponse>`
