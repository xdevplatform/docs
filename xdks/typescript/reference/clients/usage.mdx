Access **Usage** endpoints via `client.usage` (`UsageClient`).

## Methods

| Method | Endpoint | Behavior | Summary |
| :--- | :--- | :--- | :--- |
| [`get`](#get) | `GET /2/usage/tweets` | Standard | Get Usage |
| [`getCredits`](#getcredits) | `GET /2/usage/credits` | Standard | Get Usage Credits |

## `get`

<Badge color="blue">GET</Badge> `/2/usage/tweets`

**Get Usage**

Retrieves usage statistics for Posts over a specified number of days.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const response = await client.usage.get();
console.log(response);
```

### Parameters

<Expandable title="Optional parameters (GetOptions — 2)">

<ResponseField name="options.days" type="number">
  `days` (query parameter).
</ResponseField>

<ResponseField name="options.usageFields" type={"Array<\"cap_reset_day\" | \"daily_client_app_usage\" | \"daily_project_usage\" | \"project_cap\" | \"project_id\" | \"project_usage\">"}>
  A comma separated list of Usage fields to display.
</ResponseField>

</Expandable>

**Returns:** `Promise<GetResponse>`

## `getCredits`

<Badge color="blue">GET</Badge> `/2/usage/credits`

**Get Usage Credits**

Returns the payer's developer-platform credit balance in USD. total_balance is max(0, prepaid_balance + free_balance); prepaid_balance may be negative.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const response = await client.usage.getCredits();
console.log(response);
```

**Returns:** `Promise<GetCreditsResponse>`
