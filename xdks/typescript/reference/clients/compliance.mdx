Access **Compliance** endpoints via `client.compliance` (`ComplianceClient`).

## Methods

| Method | Endpoint | Behavior | Summary |
| :--- | :--- | :--- | :--- |
| [`createJobs`](#createjobs) | `POST /2/compliance/jobs` | Standard | Create Compliance Job |
| [`deleteJobsById`](#deletejobsbyid) | `DELETE /2/compliance/jobs/{id}` | Standard | Cancel Compliance Job |
| [`downloadJobResults`](#downloadjobresults) | `GET /2/compliance/jobs/{id}/download` | Standard | Download Compliance Job Results |
| [`getJobs`](#getjobs) | `GET /2/compliance/jobs` | Standard | Get Compliance Jobs |
| [`getJobsById`](#getjobsbyid) | `GET /2/compliance/jobs/{id}` | Standard | Get Compliance Job by ID |
| [`uploadJobSubmission`](#uploadjobsubmission) | `PUT /2/compliance/jobs/{id}/upload` | Standard | Upload Compliance Job Submission |

## `createJobs`

<Badge color="green">POST</Badge> `/2/compliance/jobs`

**Create Compliance Job**

Creates a new Compliance Job for the specified job type.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const response = await client.compliance.createJobs({ type: "tweets" });
console.log(response);
```

  Request payload.
</ResponseField>

  A comma separated list of ComplianceJob fields to display.

</Expandable>

## `deleteJobsById`

<Badge color="red">DELETE</Badge> `/2/compliance/jobs/{id}`

**Cancel Compliance Job**

Cancels a Compliance Job that has not finished processing; its status becomes failed and a new job of the same type can be created.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const response = await client.compliance.deleteJobsById("1895000000000000000");
console.log(response);
```

## `downloadJobResults`

<Badge color="blue">GET</Badge> `/2/compliance/jobs/{id}/download`

**Download Compliance Job Results**

Downloads the results file of a completed Compliance Job using the signed URL returned at job creation.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const response = await client.compliance.downloadJobResults("1895000000000000000", "example");

```

<ResponseField name="id" type="string" required>

## `uploadJobSubmission`

<Badge color="orange">PUT</Badge> `/2/compliance/jobs/{id}/upload`

**Upload Compliance Job Submission**

Uploads the newline-delimited ID file for a Compliance Job using the signed URL returned at job creation.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const response = await client.compliance.uploadJobSubmission("1895000000000000000", "example", new Uint8Array());
console.log(response);
```

</ResponseField>

<ResponseField name="token" type="string" required>
