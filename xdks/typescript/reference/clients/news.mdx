## `get`

<Badge color="blue">GET</Badge> `/2/news/{id}`

**Get News Stories by ID**

Retrieves news story by its ID.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const response = await client.news.get("1895000000000000000");
console.log(response);
```

## `search`

<Badge color="blue">GET</Badge> `/2/news/search`

**Search News**

Retrieves a list of News stories matching the specified search query.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const response = await client.news.search("from:XDevelopers");
console.log(response);
```
