Access **Articles** endpoints via `client.articles` (`ArticlesClient`).

## Methods

| Method | Endpoint | Behavior | Summary |
| :--- | :--- | :--- | :--- |
| [`articleCreateDraft`](#articlecreatedraft) | `POST /2/articles/draft` | Standard | Create Draft Article |
| [`articlePublish`](#articlepublish) | `POST /2/articles/{article_id}/publish` | Standard | Publish Article |

## `articleCreateDraft`

<Badge color="green">POST</Badge> `/2/articles/draft`

**Create Draft Article**

Creates a new Article draft that can later be published.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: process.env.X_ACCESS_TOKEN });

const response = await client.articles.articleCreateDraft(
  { title: "example", "content_state": { blocks: [{}], entities: [{}] } }
);
console.log(response);
```

### Parameters

<ResponseField name="body" type="ArticleCreateDraftRequest" required>
  Create a draft Article.
</ResponseField>

**Returns:** `Promise<ArticleCreateDraftResponse>`

---

## `articlePublish`

<Badge color="green">POST</Badge> `/2/articles/{article_id}/publish`

**Publish Article**

Publishes a draft Article, making it publicly visible.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: process.env.X_ACCESS_TOKEN });

const response = await client.articles.articlePublish("1895000000000000000");
console.log(response);
```

### Parameters

<ResponseField name="articleId" type="string" required>
  `article_id` (path parameter).
</ResponseField>

**Returns:** `Promise<ArticlePublishResponse>`
