Access **Webhooks** endpoints via `client.webhooks` (`WebhooksClient`).

## Methods

| Method | Endpoint | Behavior | Summary |
| :--- | :--- | :--- | :--- |
| [`create`](#create) | `POST /2/webhooks` | Standard | Create Webhook |
| [`createStreamLink`](#createstreamlink) | `POST /2/tweets/search/webhooks/{webhook_id}` | Standard | Create Stream Link |
| [`createWebhookReplayJob`](#createwebhookreplayjob) | `POST /2/webhooks/replay` | Standard | Create Replay Job for Webhook |
| [`delete`](#delete) | `DELETE /2/webhooks/{webhook_id}` | Standard | Delete Webhook |
| [`deleteStreamLink`](#deletestreamlink) | `DELETE /2/tweets/search/webhooks/{webhook_id}` | Standard | Delete Stream Link |

| [`getStreamLinks`](#getstreamlinks) | `GET /2/tweets/search/webhooks` | Standard | Get Stream Links |

## `create`

<Badge color="green">POST</Badge> `/2/webhooks`

**Create Webhook**

Creates a new webhook configuration.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const response = await client.webhooks.create({ url: "https://example.com/webhook" });
console.log(response);
```

### Parameters

<ResponseField name="body" type="CreateRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Promise<CreateResponse>`

<Badge color="green">POST</Badge> `/2/tweets/search/webhooks/{webhook_id}`


<ResponseField name="webhookId" type="string" required>
  `webhook_id` (path parameter).
</ResponseField>

**Returns:** `Promise<CreateStreamLinkResponse>`

## `createWebhookReplayJob`

<Badge color="green">POST</Badge> `/2/webhooks/replay`

**Create Replay Job for Webhook**

Creates a replay job to retrieve events from up to the past 24 hours for all events delivered or attempted to be delivered to the webhook.

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const response = await client.webhooks.createWebhookReplayJob(
  { "webhook_id": "1234567890", "from_date": "example", "to_date": "example" }
);
console.log(response);
```

### Parameters

<ResponseField name="body" type="CreateWebhookReplayJobRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Promise<CreateWebhookReplayJobResponse>`
