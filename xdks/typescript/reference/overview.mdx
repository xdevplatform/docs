The official **TypeScript XDK** (`@xdevplatform/xdk`, `v0.7.2`) provides typed resource clients, authentication helpers, automatic pagination, and real-time streaming for the X API v2.

## Installation

```bash
npm install @xdevplatform/xdk
```

## `Client` Initialization

```typescript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });
```

<ResponseField name="bearerToken" type="string">
  App-only OAuth 2.0 Bearer Token for public read and search endpoints.
</ResponseField>
<ResponseField name="accessToken" type="string">
  OAuth 2.0 user-context access token for endpoints acting on behalf of a user.
</ResponseField>
<ResponseField name="oauth1" type="OAuth1">
  Configured `OAuth1` signer for OAuth 1.0a user-context requests.
</ResponseField>
<ResponseField name="baseUrl" type="string" default="https://api.x.com">
  Base URL for X API requests.
</ResponseField>
<ResponseField name="timeout" type="number">
  Request timeout in milliseconds.
</ResponseField>
