Streaming methods on `client.stream` return an `EventDrivenStream` that supports both `.on(...)` event listeners and `for await`.

## Event listeners

<CodeGroup>

```typescript title="stream.ts" lines wrap icon="square-js" theme={null}
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });

const stream = await client.stream.postsSample({
  tweetFields: ["id", "text", "created_at"],
  expansions: ["author_id"],
  userFields: ["id", "username", "name"],
});

stream.on("data", (event) => {
  console.log(event);
});
stream.on("keepAlive", () => {
  // heartbeat received
});
stream.on("error", (err) => console.error("Stream error:", err));
stream.on("close", () => console.log("Stream closed"));
```

```javascript title="stream.js" theme={null}
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: process.env.X_BEARER_TOKEN });
const stream = await client.stream.postsSample({ tweetFields: ["id", "text"] });

stream.on("data", (event) => console.log(event));
stream.on("error", (err) => console.error("Stream error:", err));
stream.on("close", () => console.log("Stream closed"));
```

</CodeGroup>

## Async iteration

```typescript
const stream = await client.stream.postsSample();

for await (const event of stream) {
  console.log(event);
}
```

## Closing a stream

```typescript
stream.close();
```
