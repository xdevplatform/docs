## `AddMemberAsync`

<Badge color="green">POST</Badge> `/2/lists/{id}/members`

**Add List Member**

Adds a User to a specific List by its ID.

```csharp
using System;
using Xdk;
using Xdk.Models;

using var client = new XClient(new XClientOptions
{
    AccessToken = Environment.GetEnvironmentVariable("X_ACCESS_TOKEN"),
});

var response = await client.Lists.AddMemberAsync(
    "1450000000000000000",
    new AddListsMemberRequest { UserId = "2244994945" }
);
Console.WriteLine(response);
```

### Parameters

<ResponseField name="id" type="string" required>
  `id` (path parameter).
</ResponseField>

<ResponseField name="body" type="AddListsMemberRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Task<AddListsMemberResponse>`
