## `CreateAsync`

<Badge color="green">POST</Badge> `/2/notes`

**Create a Community Note**

Creates a Community Note on a Post. With test_mode set to true, the note is only for testing and is not publicly visible.

```csharp
using System;
using Xdk;
using Xdk.Models;

using var client = new XClient(new XClientOptions
{
    AccessToken = Environment.GetEnvironmentVariable("X_ACCESS_TOKEN"),
});

var response = await client.CommunityNotes.CreateAsync(
    new CreateCommunityNotesRequest { TestMode = true, PostId = "1895000000000000000" }
);
Console.WriteLine(response);
```

### Parameters

<ResponseField name="body" type="CreateCommunityNotesRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Task<CreateCommunityNotesResponse>`
