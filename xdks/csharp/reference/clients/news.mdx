## `GetAsync`

<Badge color="blue">GET</Badge> `/2/news/{id}`

**Get News Stories by ID**

Retrieves news story by its ID.

```csharp
using System;
using Xdk;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

var response = await client.News.GetAsync("1895000000000000000");
Console.WriteLine(response);
```

<ResponseField name="id" type="string" required>
  `id` (path parameter).
</ResponseField>

## `SearchAsync`

<Badge color="blue">GET</Badge> `/2/news/search`

**Search News**

Retrieves a list of News stories matching the specified search query.

```csharp
using System;
using Xdk;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

var response = await client.News.SearchAsync("from:XDevelopers");
Console.WriteLine(response);
```

### Parameters

<ResponseField name="query" type="string" required>
  `query` (query parameter).
</ResponseField>

<Expandable title="Optional parameters (NewsClient.SearchOptions — 3)">

<ResponseField name="options.MaxResults" type="int">
  `max_results` (query parameter).
</ResponseField>

<ResponseField name="options.MaxAgeHours" type="int">
  `max_age_hours` (query parameter).
</ResponseField>

<ResponseField name="options.NewsFields" type="List<string>">
  A comma separated list of News fields to display.
</ResponseField>

</Expandable>

**Returns:** `Task<SearchNewsResponse>`
