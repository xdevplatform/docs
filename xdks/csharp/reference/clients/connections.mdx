| Method | Endpoint | Behavior | Summary |

## `DeleteAllAsync`

<Badge color="red">DELETE</Badge> `/2/connections/all`

**Terminate All Connections**

Terminates all active streaming connections for the authenticated application.

```csharp
using System;
using Xdk;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

var response = await client.Connections.DeleteAllAsync();
Console.WriteLine(response);
```

**Returns:** `Task<DeleteAllConnectionsResponse>`

## `DeleteByUuidsAsync`

<Badge color="red">DELETE</Badge> `/2/connections`

**Terminate Multiple Connections**

Terminates multiple streaming connections by their UUIDs for the authenticated application.

```csharp
using System;
using System.Collections.Generic;
using Xdk;
using Xdk.Models;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

var response = await client.Connections.DeleteByUuidsAsync(
    new DeleteConnectionsByUuidsRequest { Uuids = new List<string> { "example" } }
);
Console.WriteLine(response);
```

### Parameters

<ResponseField name="body" type="DeleteConnectionsByUuidsRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Task<DeleteConnectionsByUuidsResponse>`

## `GetConnectionHistoryAsync`

<Badge color="blue">GET</Badge> `/2/connections` <Badge color="purple">Paginated</Badge>

**Get Connection History**

Returns active and historical streaming connections with disconnect reasons for the authenticated application.

```csharp
using System;
using Xdk;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

await foreach (var page in client.Connections.GetConnectionHistoryPages())
{
    Console.WriteLine(page);
}
```

### Parameters

<Expandable title="Optional parameters (ConnectionsClient.GetConnectionHistoryOptions — 5)">

<ResponseField name="options.Status" type="string">
  `status` (query parameter).
</ResponseField>

<ResponseField name="options.Endpoints" type="List<string>">
  `endpoints` (query parameter).
</ResponseField>

<ResponseField name="options.MaxResults" type="int">
  `max_results` (query parameter).
</ResponseField>

<ResponseField name="options.PaginationToken" type="string">
  `pagination_token` (query parameter).
</ResponseField>

<ResponseField name="options.ConnectionFields" type="List<string>">
  A comma separated list of Connection fields to display.
</ResponseField>

</Expandable>

**Returns:** `Task<GetConnectionHistoryResponse>` (use `GetConnectionHistoryPages(...)` for `IAsyncEnumerable` page iteration)
