## `GetOpenApiSpecAsync`

<Badge color="blue">GET</Badge> `/2/openapi.json`

**Get OpenAPI Spec**

Retrieves the full OpenAPI Specification in JSON format. (See https://github.com/OAI/OpenAPI-Specification/blob/master/README.md)

```csharp
using System;
using Xdk;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

var response = await client.General.GetOpenApiSpecAsync();
Console.WriteLine(response);
```

**Returns:** `Task<Dictionary<string, JsonElement>>`
