## `CreateSubscriptionAsync`

<Badge color="green">POST</Badge> `/2/account_activity/webhooks/{webhook_id}/subscriptions/all`

**Create Subscription**

Creates an Account Activity subscription for the user and the given webhook.

```csharp
using System;
using Xdk;
using Xdk.Models;

using var client = new XClient(new XClientOptions
{
    AccessToken = Environment.GetEnvironmentVariable("X_ACCESS_TOKEN"),
});

var response = await client.AccountActivity.CreateSubscriptionAsync("1234567890", new CreateAccountActivitySubscriptionRequest());
Console.WriteLine(response);
```

### Parameters

<ResponseField name="webhookId" type="string" required>
  `webhook_id` (path parameter).
</ResponseField>

<ResponseField name="body" type="CreateAccountActivitySubscriptionRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Task<CreateAccountActivitySubscriptionResponse>`
