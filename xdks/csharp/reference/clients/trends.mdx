## `GetByWoeidAsync`

<Badge color="blue">GET</Badge> `/2/trends/by/woeid/{woeid}`

**Get Trends by WOEID**

Retrieves trending topics for a specific location identified by its WOEID. `meta.location` describes that location: its `woeid` and `name`, and when they are known its `country`, `country_code`, `place_type` (`town`, `country` or `supername`) and `parent_id`, the WOEID of the place that contains it.

```csharp
using System;
using Xdk;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

var response = await client.Trends.GetByWoeidAsync(1);
Console.WriteLine(response);
```

<ResponseField name="woeid" type="int" required>
  `woeid` (path parameter).
</ResponseField>

</Expandable>

## `GetLocationsAsync`

<Badge color="blue">GET</Badge> `/2/trends/locations`

**Get Trend Locations**

Retrieves every location that has trends. Each location has a WOEID to pass to `GET /2/trends/by/woeid/{woeid}`. The list is short and is returned whole, so the route takes no paging parameters.

```csharp
using System;
using Xdk;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

var response = await client.Trends.GetLocationsAsync();
Console.WriteLine(response);
```

### Parameters

<Expandable title="Optional parameters (TrendsClient.GetLocationsOptions — 1)">

<ResponseField name="options.TrendLocationFields" type="List<string>">
  A comma separated list of TrendLocation fields to display.
</ResponseField>

</Expandable>

**Returns:** `Task<GetTrendsLocationsResponse>`

## `GetPersonalizedAsync`

<Badge color="blue">GET</Badge> `/2/users/personalized_trends`

**Get Personalized Trends**

Retrieves personalized trending topics for the authenticated user.

```csharp
using System;
using Xdk;

using var client = new XClient(new XClientOptions
{
    AccessToken = Environment.GetEnvironmentVariable("X_ACCESS_TOKEN"),
});

var response = await client.Trends.GetPersonalizedAsync();
Console.WriteLine(response);
```
