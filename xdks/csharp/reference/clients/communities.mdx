Access **Communities** endpoints via `client.Communities` (`CommunitiesClient`).

## Methods

| Method | Endpoint | Behavior | Summary |
| :--- | :--- | :--- | :--- |
| [`GetByIdAsync`](#getbyidasync) | `GET /2/communities/{id}` | Standard | Get Community by ID |
| [`SearchAsync`](#searchasync) | `GET /2/communities/search` | Paginated | Search Communities |

## `GetByIdAsync`

<Badge color="blue">GET</Badge> `/2/communities/{id}`

**Get Community by ID**

Retrieves details of a specific Community by its ID.

```csharp
using System;
using Xdk;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

var response = await client.Communities.GetByIdAsync("1895000000000000000");
Console.WriteLine(response);
```

### Parameters

<ResponseField name="id" type="string" required>
  `id` (path parameter).
</ResponseField>

<Expandable title="Optional parameters (CommunitiesClient.GetByIdOptions — 1)">

<ResponseField name="options.CommunityFields" type="List<string>">
  A comma separated list of Community fields to display.
</ResponseField>

</Expandable>

**Returns:** `Task<GetCommunitiesByIdResponse>`

## `SearchAsync`

<Badge color="blue">GET</Badge> `/2/communities/search` <Badge color="purple">Paginated</Badge>

**Search Communities**

Retrieves a list of Communities matching the specified search query.

```csharp
using System;
using Xdk;

using var client = new XClient(new XClientOptions
{
    AccessToken = Environment.GetEnvironmentVariable("X_ACCESS_TOKEN"),
});

await foreach (var page in client.Communities.SearchPages("from:XDevelopers"))
{
    Console.WriteLine(page);
}
```

### Parameters

<ResponseField name="query" type="string" required>
  `query` (query parameter).
</ResponseField>

<Expandable title="Optional parameters (CommunitiesClient.SearchOptions — 4)">

<ResponseField name="options.MaxResults" type="int">
  `max_results` (query parameter).
</ResponseField>

<ResponseField name="options.NextToken" type="string">
  `next_token` (query parameter).
</ResponseField>

<ResponseField name="options.PaginationToken" type="string">
  `pagination_token` (query parameter).
</ResponseField>

<ResponseField name="options.CommunityFields" type="List<string>">
  A comma separated list of Community fields to display.
</ResponseField>

</Expandable>

**Returns:** `Task<SearchCommunitiesResponse>` (use `SearchPages(...)` for `IAsyncEnumerable` page iteration)
