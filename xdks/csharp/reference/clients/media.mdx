## `AddPostToAmplifyProgramsAsync`

<Badge color="green">POST</Badge> `/2/media/amplify/posts`

**Add Post to Amplify Programs**

Publishes one of the authenticated user's video posts into one or more active Amplify pre-roll programs the user is enrolled in as a publisher.

```csharp
using System;
using System.Collections.Generic;
using Xdk;
using Xdk.Models;

using var client = new XClient(new XClientOptions
{
    AccessToken = Environment.GetEnvironmentVariable("X_ACCESS_TOKEN"),
});

var response = await client.Media.AddPostToAmplifyProgramsAsync(
    new AddPostToAmplifyProgramsRequest { PostId = "1895000000000000000", ProgramIds = new List<string> { "1895000000000000000" } }
);
Console.WriteLine(response);
```

### Parameters

<ResponseField name="body" type="AddPostToAmplifyProgramsRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Task<AddPostToAmplifyProgramsResponse>`

## `AppendUploadAsync`

<Badge color="green">POST</Badge> `/2/media/upload/{id}/append`

**Append Media Upload**

Appends one segment of the file to a chunked upload. Send the segment base64-encoded in media (raw bytes in multipart bodies) and its position in the file in segment_index, counting from 0. A segment can be up to 8 MB; in a JSON body keep it to 4 MB or less, because base64 adds a third. After the last segment, call Finalize Media Upload.

```csharp
using System;
using Xdk;
using Xdk.Models;

using var client = new XClient(new XClientOptions
{
    AccessToken = Environment.GetEnvironmentVariable("X_ACCESS_TOKEN"),
});

var response = await client.Media.AppendUploadAsync(
    "1895000000000000000",
    new AppendMediaUploadRequest { Media = "example", SegmentIndex = 1 }
);
Console.WriteLine(response);
```

### Parameters

<ResponseField name="id" type="string" required>
  The upload id from Initialize Media Upload.
</ResponseField>

<ResponseField name="body" type="AppendMediaUploadRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Task<AppendMediaUploadResponse>`

## `FinalizeUploadAsync`

<Badge color="green">POST</Badge> `/2/media/upload/{id}/finalize`

**Finalize Media Upload**

Completes a chunked upload once every segment is appended. For video the result carries processing_info: the media can go on a Post only when its state is succeeded, so call Get Media Upload Status until it is. A result without processing_info is ready to use.

```csharp
using System;
using Xdk;

using var client = new XClient(new XClientOptions
{
    AccessToken = Environment.GetEnvironmentVariable("X_ACCESS_TOKEN"),
});

var response = await client.Media.FinalizeUploadAsync("1895000000000000000");
Console.WriteLine(response);
```

### Parameters

<ResponseField name="id" type="string" required>
  The upload id from Initialize Media Upload.
</ResponseField>

**Returns:** `Task<FinalizeMediaUploadResponse>`

## `GetUploadStatusAsync`

<Badge color="blue">GET</Badge> `/2/media/upload`

**Get Media Upload Status**

Returns how far X has processed an uploaded media file, in processing_info.state: pending, in_progress, succeeded or failed. Call it after Finalize Media Upload returns processing_info, waiting check_after_secs between calls, until the state is succeeded. A failed state means the media can't be used.

using System;
using Xdk;

{

## `InitializeUploadAsync`

<Badge color="green">POST</Badge> `/2/media/upload/initialize`

**Initialize Media Upload**

Starts a chunked media upload and returns its id. Use it for video and for other files too large for one request. For a video on a Post, set media_category to tweet_video, media_type to the file's type (for example video/mp4) and total_bytes to the file's size. Send the file with Append Media Upload, call Finalize Media Upload, then pass the id in media.media_ids on Create or Edit Post.

```csharp
using System;
using System.Collections.Generic;
using Xdk;
using Xdk.Models;

using var client = new XClient(new XClientOptions
{
    AccessToken = Environment.GetEnvironmentVariable("X_ACCESS_TOKEN"),
});

var response = await client.Media.InitializeUploadAsync(
    new InitializeMediaUploadRequest { AdditionalOwners = new List<string> { "example" } }
);
Console.WriteLine(response);
```

### Parameters

<ResponseField name="body" type="InitializeMediaUploadRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Task<InitializeMediaUploadResponse>`

## `UploadAsync`

<Badge color="green">POST</Badge> `/2/media/upload`

**Upload Media**

Uploads a media file in one request and returns its id. Send the file base64-encoded in media (raw bytes in multipart bodies). For a Post, set media_category to tweet_image (JPG, PNG, GIF or WEBP, up to 5 MB) or tweet_gif, then pass the returned id in media.media_ids on Create or Edit Post. DM media uses dm_image or dm_gif. For video, use Initialize Media Upload.

```csharp
using System;
using Xdk;
using Xdk.Models;

using var client = new XClient(new XClientOptions
{
    AccessToken = Environment.GetEnvironmentVariable("X_ACCESS_TOKEN"),
});

var response = await client.Media.UploadAsync(
    new MediaUploadRequest { Media = "example", MediaCategory = "tweet_image" }
);
Console.WriteLine(response);
```

### Parameters

<ResponseField name="body" type="MediaUploadRequest" required>
  Request payload.
</ResponseField>
