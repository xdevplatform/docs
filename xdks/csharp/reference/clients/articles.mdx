Access **Articles** endpoints via `client.Articles` (`ArticlesClient`).

## Methods

| Method | Endpoint | Behavior | Summary |
| :--- | :--- | :--- | :--- |
| [`ArticleCreateDraftAsync`](#articlecreatedraftasync) | `POST /2/articles/draft` | Standard | Create Draft Article |
| [`ArticlePublishAsync`](#articlepublishasync) | `POST /2/articles/{article_id}/publish` | Standard | Publish Article |

## `ArticleCreateDraftAsync`

<Badge color="green">POST</Badge> `/2/articles/draft`

**Create Draft Article**

Creates a new Article draft that can later be published.

```csharp
using System;
using Xdk;
using Xdk.Models;

using var client = new XClient(new XClientOptions
{
    AccessToken = Environment.GetEnvironmentVariable("X_ACCESS_TOKEN"),
});

var response = await client.Articles.ArticleCreateDraftAsync(new ArticleCreateDraftRequest { Title = "example" });
Console.WriteLine(response);
```

### Parameters

<ResponseField name="body" type="ArticleCreateDraftRequest" required>
  Create a draft Article.
</ResponseField>

**Returns:** `Task<ArticleCreateDraftResponse>`

## `ArticlePublishAsync`

<Badge color="green">POST</Badge> `/2/articles/{article_id}/publish`

**Publish Article**

Publishes a draft Article, making it publicly visible.

```csharp
using System;
using Xdk;

using var client = new XClient(new XClientOptions
{
    AccessToken = Environment.GetEnvironmentVariable("X_ACCESS_TOKEN"),
});

var response = await client.Articles.ArticlePublishAsync("1895000000000000000");
Console.WriteLine(response);
```

### Parameters

<ResponseField name="articleId" type="string" required>
  `article_id` (path parameter).
</ResponseField>

**Returns:** `Task<ArticlePublishResponse>`
