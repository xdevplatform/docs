## `CreateAsync`

<Badge color="green">POST</Badge> `/2/webhooks`

**Create Webhook**

Creates a new webhook configuration.

```csharp
using System;
using Xdk;
using Xdk.Models;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

var response = await client.Webhooks.CreateAsync(new CreateWebhooksRequest { Url = "https://example.com/webhook" });
Console.WriteLine(response);
```

### Parameters

<ResponseField name="body" type="CreateWebhooksRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Task<CreateWebhooksResponse>`

## `CreateWebhookReplayJobAsync`

<Badge color="green">POST</Badge> `/2/webhooks/replay`

**Create Replay Job for Webhook**

Creates a replay job to retrieve events from up to the past 24 hours for all events delivered or attempted to be delivered to the webhook.

```csharp
using System;
using Xdk;
using Xdk.Models;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

var response = await client.Webhooks.CreateWebhookReplayJobAsync(
    new CreateWebhookReplayJobRequest { WebhookId = "1234567890", FromDate = "example", ToDate = "example" }
);
Console.WriteLine(response);
```

### Parameters

<ResponseField name="body" type="CreateWebhookReplayJobRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Task<CreateWebhookReplayJobResponse>`
