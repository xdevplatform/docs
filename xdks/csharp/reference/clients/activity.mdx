## `CreateSubscriptionAsync`

<Badge color="green">POST</Badge> `/2/activity/subscriptions`

**Create X Activity Subscription**

Creates a subscription for an X activity event. OAuth2 user-context tokens must hold the scope matching the requested event_type: dm.read for chat.* and dm.* events, like.read for like.* events, mute.read for mute.* events, block.read for block.* events, follows.read for subscriptions.* events, and tweet.read for all other event types. Mute and block subscriptions are actor-only: filter.user_id must identify the authenticated user and direction is not supported. subscriptions.* events require a user-context token and filter.user_id must identify the authenticated user. Optional filter.qualifiers further narrow supported chat, follow, unfollow, like, subscriptions, and trends events.

```csharp
using System;
using Xdk;
using Xdk.Models;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

var response = await client.Activity.CreateSubscriptionAsync(
    new CreateActivitySubscriptionRequest { EventType = "profile.update.bio" }
);
Console.WriteLine(response);
```

### Parameters

<ResponseField name="body" type="CreateActivitySubscriptionRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Task<CreateActivitySubscriptionResponse>`

## `GetSubscriptionsAsync`

<Badge color="blue">GET</Badge> `/2/activity/subscriptions` <Badge color="purple">Paginated</Badge>

**Get X Activity Subscriptions**

Get a list of active subscriptions for XAA. Optional user_id narrows the list to subscriptions whose filter.user_id matches; with a user-context token it must identify the authenticated user.

```csharp
using System;
using Xdk;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

await foreach (var page in client.Activity.GetSubscriptionsPages())
{
    Console.WriteLine(page);
}
```

### Parameters

<Expandable title="Optional parameters (ActivityClient.GetSubscriptionsOptions — 3)">

<ResponseField name="options.MaxResults" type="int">
  `max_results` (query parameter).
</ResponseField>

<ResponseField name="options.PaginationToken" type="string">
  A base32hex-encoded pagination token that decodes to 9 bytes.
</ResponseField>

<ResponseField name="options.UserId" type="string">
  Only return subscriptions whose filter.user_id matches.
</ResponseField>

</Expandable>

**Returns:** `Task<GetActivitySubscriptionsResponse>` (use `GetSubscriptionsPages(...)` for `IAsyncEnumerable` page iteration)
