## `CreateJobsAsync`

<Badge color="green">POST</Badge> `/2/compliance/jobs`

**Create Compliance Job**

Creates a new Compliance Job for the specified job type.

```csharp
using System;
using Xdk;
using Xdk.Models;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

var response = await client.Compliance.CreateJobsAsync(new CreateComplianceJobsRequest { Type = "tweets" });
Console.WriteLine(response);
```

## `DeleteJobsByIdAsync`

<Badge color="red">DELETE</Badge> `/2/compliance/jobs/{id}`

**Cancel Compliance Job**

Cancels a Compliance Job that has not finished processing; its status becomes failed and a new job of the same type can be created.

```csharp
using System;
using Xdk;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

var response = await client.Compliance.DeleteJobsByIdAsync("1895000000000000000");
Console.WriteLine(response);
```
