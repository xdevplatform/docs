The official **C# XDK** (`XDevPlatform.Xdk`, `v0.1.2`) provides typed resource clients, authentication helpers, automatic pagination, and real-time streaming for the X API v2.

## Installation

```bash
dotnet add package XDevPlatform.Xdk
```

## `XClient` Initialization

```csharp
using System;
using Xdk;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});
```

<ResponseField name="BearerToken" type="string?">
  OAuth 2.0 Bearer Token for app-only endpoints.
</ResponseField>
<ResponseField name="AccessToken" type="string?">
  OAuth 2.0 user-context access token.
</ResponseField>
<ResponseField name="OAuth2" type="OAuth2Pkce?">
  `OAuth2Pkce` instance supporting PKCE code exchange and token refresh.
</ResponseField>
<ResponseField name="OAuth1" type="OAuth1?">
  `OAuth1` instance for OAuth 1.0a HMAC-SHA1 signing.
</ResponseField>
<ResponseField name="BaseUrl" type="string" default="https://api.x.com">
  Base URL for X API requests (`XClient` implements `IDisposable`).
</ResponseField>
