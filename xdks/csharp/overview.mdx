The **C# / .NET XDK** (`XDevPlatform.Xdk`) is X's official .NET client library for the X API v2, generated directly from the [official OpenAPI specification](https://api.x.com/2/openapi.json) and published on NuGet.

## Key Features

- **Zero External Runtime Dependencies**: Built entirely on `System.Net.Http.HttpClient` and `System.Text.Json` for .NET 8+.
- **First-Class Async & Cancellation**: Every endpoint method is `async` (`*Async`), accepts a `CancellationToken`, and `XClient` implements `IDisposable`.
- **Authentication**: App-only Bearer Token, OAuth 2.0 User Context with PKCE (`OAuth2Pkce`) and token refresh, and OAuth 1.0a HMAC-SHA1 (`OAuth1`).
- **Async Pagination (`IAsyncEnumerable<T>`)**: Paginated endpoints expose `*Pages(...)` returning `Paginator<T>`, enabling native `await foreach` loops.
- **Resilient Streaming (`IAsyncDisposable`)**: Streaming endpoints return `EventStream<T>` supporting `await using` and `await foreach` with incremental UTF-8 line decoding and exponential backoff reconnection.

## Quick Example

```csharp
using System;
using System.Collections.Generic;
using Xdk;
using Xdk.Clients;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

var response = await client.Users.GetByUsernameAsync(
    "XDevelopers",
    new UsersClient.GetByUsernameOptions
    {
        UserFields = new List<string> { "created_at", "public_metrics" },
    });

Console.WriteLine(response.Data);
```
