`XDevPlatform.Xdk` is the official C# / .NET SDK for the X API v2 (.NET 8+). It uses `System.Net.Http` and `System.Text.Json` with no extra runtime dependencies, async methods with `CancellationToken`, `IAsyncEnumerable<T>` pagination, and `EventStream<T>`.

## Quick example

```csharp
using System;
using System.Collections.Generic;
using Xdk;
using Xdk.Clients;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

var response = await client.Users.GetByUsernameAsync(
    "XDevelopers",
    new UsersClient.GetByUsernameOptions
    {
        UserFields = new List<string> { "created_at", "public_metrics" },
    });

Console.WriteLine(response.Data);
```
