Install `XDevPlatform.Xdk` from [NuGet](https://www.nuget.org/packages/XDevPlatform.Xdk). Requires .NET 8.0+.

<CodeGroup>

```bash .NET CLI
dotnet add package XDevPlatform.Xdk
```

```xml PackageReference (.csproj)
<ItemGroup>
  <PackageReference Include="XDevPlatform.Xdk" Version="0.1.2" />
</ItemGroup>
```

```powershell NuGet Package Manager
Install-Package XDevPlatform.Xdk
```

</CodeGroup>

## Custom `HttpClient`

In ASP.NET Core or worker services using `IHttpClientFactory`, pass a managed `HttpClient` via `XClientOptions.HttpClient`:

```csharp
using System.Net.Http;
using Xdk;

var httpClient = new HttpClient();
var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
    HttpClient = httpClient,
});
```

## Build from source

```bash
git clone https://github.com/xdevplatform/xdk-csharp.git
cd xdk-csharp
dotnet test
```
