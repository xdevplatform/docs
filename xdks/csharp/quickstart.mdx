Make your first authenticated X API v2 call with `XDevPlatform.Xdk` in minutes.

<Steps>
  <Step title="Create a project and add XDevPlatform.Xdk">
```bash
dotnet new console -n XdkQuickstart
cd XdkQuickstart
dotnet add package XDevPlatform.Xdk
```
  </Step>
  <Step title="Set your Bearer Token">
    Generate a **Bearer Token** in the [X Developer Console](https://console.x.com) and export it in your shell:

```bash
export X_BEARER_TOKEN="your_bearer_token_here"
```
  </Step>
  <Step title="Write and run Program.cs">
```csharp
using System;
using System.Collections.Generic;
using Xdk;
using Xdk.Clients;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

var user = await client.Users.GetByUsernameAsync("XDevelopers");
Console.WriteLine($"User: {user.Data}");

var posts = await client.Posts.SearchRecentAsync(
    "from:XDevelopers -is:retweet",
    new PostsClient.SearchRecentOptions
    {
        MaxResults = 10,
        PostFields = new List<string> { "created_at", "public_metrics" },
    });
Console.WriteLine($"Posts returned: {posts.Data?.Count ?? 0}");
```

    Run your app with `dotnet run`.
  </Step>
</Steps>
