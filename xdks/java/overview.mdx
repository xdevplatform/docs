The **Java XDK** (`com.x:xdk`) is X's official JVM client library for the X API v2, generated directly from the [official OpenAPI specification](https://api.x.com/2/openapi.json) and published to Maven Central.

## Key Features

- **Modern JVM Design**: Built on `java.net.http.HttpClient` and Jackson (`com.fasterxml.jackson`) for Java 17+, Java 21 virtual threads, Kotlin, and Scala.
- **Fluent Builders**: Configure `XClient.builder()`, typed request models (`new Schemas.CreatePostsRequest().text("...")`), and per-endpoint `*Options.builder()`.
- **Authentication**: App-only Bearer Token, OAuth 2.0 User Context with PKCE (`OAuth2Pkce`) and automatic refresh, and OAuth 1.0a HMAC-SHA1 (`OAuth1`).
- **Lazy Cursor Pagination**: Every paginated operation exposes a `*Pages(...)` method returning `Paginator<T>` (`Iterable<T>`).
- **Resilient Streaming**: Streaming endpoints return `EventStream<T>` (`Iterable<T>` & `AutoCloseable`) with incremental UTF-8 line framing and exponential backoff reconnection.

## Quick Example

```java
import com.x.xdk.Schemas;
import com.x.xdk.XClient;
import com.x.xdk.clients.UsersClient;
import java.util.List;

public class Example {
    public static void main(String[] args) {
        XClient client = XClient.builder()
            .bearerToken(System.getenv("X_BEARER_TOKEN"))
            .build();

        Schemas.GetUsersByUsernameResponse response = client.users().getByUsername(
            "XDevelopers",
            UsersClient.GetByUsernameOptions.builder()
                .userFields(List.of("created_at", "public_metrics"))
        );
        System.out.println(response.getData());
    }
}
```
