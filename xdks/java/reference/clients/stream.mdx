## `activity`

<Badge color="blue">GET</Badge> `/2/activity/stream` <Badge color="green">Streaming</Badge>

**Activity Stream**

Stream of X Activities

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

try (var stream = client.stream().activity()) {
    for (var event : stream) {
        System.out.println(event);
    }
}
```

### Parameters

<Expandable title="Optional parameters (StreamClient.ActivityOptions — 3)">

<ResponseField name="options.backfillMinutes" type="Integer">
  The number of minutes of backfill requested.
</ResponseField>

<ResponseField name="options.startTime" type="String">
  YYYY-MM-DDTHH:mm:ssZ. The earliest UTC timestamp from which the activities will be provided.
</ResponseField>

<ResponseField name="options.endTime" type="String">
  YYYY-MM-DDTHH:mm:ssZ. The latest UTC timestamp from which the activities will be provided.
</ResponseField>

</Expandable>

**Returns:** `EventStream<Schemas.ActivityStreamResponse>`

## `getRules`

<Badge color="blue">GET</Badge> `/2/tweets/search/stream/rules` <Badge color="purple">Paginated</Badge>

**Get Stream Rules**

Returns the active filtered-stream rules for the authenticated app. Provide `ids` to fetch specific rules; omit it to list all rules.

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

for (var page : client.stream().getRulesPages()) {
    System.out.println(page);
}
```

### Parameters

<Expandable title="Optional parameters (StreamClient.GetRulesOptions — 3)">

<ResponseField name="options.ids" type="List<String>">
  `ids` (query parameter).
</ResponseField>

<ResponseField name="options.maxResults" type="Integer">
  `max_results` (query parameter).
</ResponseField>

<ResponseField name="options.paginationToken" type="String">
  A base32hex-encoded pagination token that decodes to 8 bytes.
</ResponseField>

</Expandable>

**Returns:** `Schemas.GetRulesResponse` (use `getRulesPages(...)` for automatic `Paginator<...>` iteration)
