Access **Communities** endpoints via `client.communities()` (`CommunitiesClient`).

## Methods

| Method | Endpoint | Behavior | Summary |
| :--- | :--- | :--- | :--- |
| [`getById`](#getbyid) | `GET /2/communities/{id}` | Standard | Get Community by ID |
| [`search`](#search) | `GET /2/communities/search` | Paginated | Search Communities |

## `getById`

<Badge color="blue">GET</Badge> `/2/communities/{id}`

**Get Community by ID**

Retrieves details of a specific Community by its ID.

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

var response = client.communities().getById("1895000000000000000");
System.out.println(response);
```

### Parameters

<ResponseField name="id" type="String" required>
  `id` (path parameter).
</ResponseField>

  A comma separated list of Community fields to display.

</Expandable>

**Returns:** `Schemas.GetCommunitiesByIdResponse`

## `search`

<Badge color="blue">GET</Badge> `/2/communities/search` <Badge color="purple">Paginated</Badge>

**Search Communities**

Retrieves a list of Communities matching the specified search query.

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .accessToken(System.getenv("X_ACCESS_TOKEN"))
    .build();

for (var page : client.communities().searchPages("from:XDevelopers")) {
    System.out.println(page);
}
```

### Parameters

<ResponseField name="query" type="String" required>
  `query` (query parameter).
</ResponseField>

<Expandable title="Optional parameters (CommunitiesClient.SearchOptions — 4)">

<ResponseField name="options.maxResults" type="Integer">
  `max_results` (query parameter).
</ResponseField>

<ResponseField name="options.nextToken" type="String">
  `next_token` (query parameter).
</ResponseField>

<ResponseField name="options.paginationToken" type="String">
  `pagination_token` (query parameter).
</ResponseField>

<ResponseField name="options.communityFields" type="List<String>">
  A comma separated list of Community fields to display.
</ResponseField>

</Expandable>

**Returns:** `Schemas.SearchCommunitiesResponse` (use `searchPages(...)` for automatic `Paginator<...>` iteration)
