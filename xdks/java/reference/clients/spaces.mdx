## `getBuyers`

<Badge color="blue">GET</Badge> `/2/spaces/{id}/buyers` <Badge color="purple">Paginated</Badge>

**Get Space Ticket Buyers**

Retrieves a list of Users who purchased tickets to a specific Space by its ID.

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .accessToken(System.getenv("X_ACCESS_TOKEN"))
    .build();

for (var page : client.spaces().getBuyersPages("1YqKDqWLPPlGV")) {
    System.out.println(page);
}
```

### Parameters

<ResponseField name="id" type="String" required>
  `id` (path parameter).
</ResponseField>

<Expandable title="Optional parameters (SpacesClient.GetBuyersOptions — 5)">

<ResponseField name="options.maxResults" type="Integer">
  `max_results` (query parameter).
</ResponseField>

<ResponseField name="options.paginationToken" type="String">
  A base32hex-encoded pagination token.
</ResponseField>

<ResponseField name="options.userFields" type="List<String>">
  A comma separated list of User fields to display.
</ResponseField>

<ResponseField name="options.expansions" type="List<String>">
  A comma separated list of fields to expand.
</ResponseField>

<ResponseField name="options.postFields" type="List<String>">
  A comma separated list of Post fields to display.
</ResponseField>

</Expandable>

**Returns:** `Schemas.GetSpacesBuyersResponse` (use `getBuyersPages(...)` for automatic `Paginator<...>` iteration)

## `getByCreatorIds`

<Badge color="blue">GET</Badge> `/2/spaces/by/creator_ids`

**Get Spaces by Creator IDs**

Retrieves details of Spaces created by specified User IDs.

```java
import com.x.xdk.XClient;
import java.util.List;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

var response = client.spaces().getByCreatorIds(List.of("2244994945"));
System.out.println(response);
```
