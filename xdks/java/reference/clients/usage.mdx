Access **Usage** endpoints via `client.usage()` (`UsageClient`).

## Methods

| Method | Endpoint | Behavior | Summary |
| :--- | :--- | :--- | :--- |
| [`get`](#get) | `GET /2/usage/tweets` | Standard | Get Usage |
| [`getCredits`](#getcredits) | `GET /2/usage/credits` | Standard | Get Usage Credits |

## `get`

<Badge color="blue">GET</Badge> `/2/usage/tweets`

**Get Usage**

Retrieves usage statistics for Posts over a specified number of days.

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

var response = client.usage().get();
System.out.println(response);
```

### Parameters

<Expandable title="Optional parameters (UsageClient.GetOptions — 2)">

<ResponseField name="options.days" type="Integer">
  `days` (query parameter).
</ResponseField>

<ResponseField name="options.usageFields" type="List<String>">
  A comma separated list of Usage fields to display.
</ResponseField>

</Expandable>

**Returns:** `Schemas.GetUsageResponse`

## `getCredits`

<Badge color="blue">GET</Badge> `/2/usage/credits`

**Get Usage Credits**

Returns the payer's developer-platform credit balance in USD. total_balance is max(0, prepaid_balance + free_balance); prepaid_balance may be negative.

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

var response = client.usage().getCredits();
System.out.println(response);
```

**Returns:** `Schemas.GetUsageCreditsResponse`
