Access **Community Notes** endpoints via `client.communityNotes()` (`CommunityNotesClient`).

## Methods

| Method | Endpoint | Behavior | Summary |
| :--- | :--- | :--- | :--- |
| [`create`](#create) | `POST /2/notes` | Standard | Create a Community Note |
| [`delete`](#delete) | `DELETE /2/notes/{id}` | Standard | Delete a Community Note |
| [`evaluate`](#evaluate) | `POST /2/notes/evaluate` | Standard | Evaluate a Community Note |
| [`searchEligiblePosts`](#searcheligibleposts) | `GET /2/notes/search/posts_eligible_for_notes` | Paginated | Search for Posts Eligible for Community Notes |
| [`searchWritten`](#searchwritten) | `GET /2/notes/search/notes_written` | Paginated | Search for Community Notes Written |

## `create`

<Badge color="green">POST</Badge> `/2/notes`

**Create a Community Note**

Creates a Community Note on a Post. With test_mode set to true, the note is only for testing and is not publicly visible.

```java
import com.x.xdk.Schemas;
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .accessToken(System.getenv("X_ACCESS_TOKEN"))
    .build();

var response = client.communityNotes().create(
    new Schemas.CreateCommunityNotesRequest().testMode(true).postId("1895000000000000000")
);
System.out.println(response);
```

### Parameters

<ResponseField name="body" type="Schemas.CreateCommunityNotesRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Schemas.CreateCommunityNotesResponse`

## `evaluate`

<Badge color="green">POST</Badge> `/2/notes/evaluate`

## `searchEligiblePosts`

<Badge color="blue">GET</Badge> `/2/notes/search/posts_eligible_for_notes` <Badge color="purple">Paginated</Badge>

**Search for Posts Eligible for Community Notes**

Retrieves Posts that are eligible for Community Notes.

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .accessToken(System.getenv("X_ACCESS_TOKEN"))
    .build();

for (var page : client.communityNotes().searchEligiblePostsPages(true)) {
    System.out.println(page);
}
```
