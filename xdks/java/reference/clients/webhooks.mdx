## `create`

<Badge color="green">POST</Badge> `/2/webhooks`

**Create Webhook**

Creates a new webhook configuration.

```java
import com.x.xdk.Schemas;
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

var response = client.webhooks().create(
    new Schemas.CreateWebhooksRequest().url("https://example.com/webhook")
);
System.out.println(response);
```

### Parameters

<ResponseField name="body" type="Schemas.CreateWebhooksRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Schemas.CreateWebhooksResponse`

## `createWebhookReplayJob`

<Badge color="green">POST</Badge> `/2/webhooks/replay`

**Create Replay Job for Webhook**

Creates a replay job to retrieve events from up to the past 24 hours for all events delivered or attempted to be delivered to the webhook.

```java
import com.x.xdk.Schemas;
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

var response = client.webhooks().createWebhookReplayJob(
    new Schemas.CreateWebhookReplayJobRequest().webhookId("1234567890").fromDate("example").toDate("example")
);
System.out.println(response);
```

### Parameters

<ResponseField name="body" type="Schemas.CreateWebhookReplayJobRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Schemas.CreateWebhookReplayJobResponse`
