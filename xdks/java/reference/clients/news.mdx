| Method | Endpoint | Behavior | Summary |

| [`search`](#search) | `GET /2/news/search` | Standard | Search News |

## `get`

<Badge color="blue">GET</Badge> `/2/news/{id}`

**Get News Stories by ID**

Retrieves news story by its ID.

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

var response = client.news().get("1895000000000000000");
System.out.println(response);
```

## `search`

<Badge color="blue">GET</Badge> `/2/news/search`

**Search News**

Retrieves a list of News stories matching the specified search query.

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

var response = client.news().search("from:XDevelopers");
System.out.println(response);
```

### Parameters

<ResponseField name="query" type="String" required>
  `query` (query parameter).
</ResponseField>

<Expandable title="Optional parameters (NewsClient.SearchOptions — 3)">

<ResponseField name="options.maxResults" type="Integer">
  `max_results` (query parameter).
</ResponseField>

<ResponseField name="options.maxAgeHours" type="Integer">
  `max_age_hours` (query parameter).
</ResponseField>

<ResponseField name="options.newsFields" type="List<String>">
  A comma separated list of News fields to display.
</ResponseField>

</Expandable>

**Returns:** `Schemas.SearchNewsResponse`
