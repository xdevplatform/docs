## `createJobs`

<Badge color="green">POST</Badge> `/2/compliance/jobs`

**Create Compliance Job**

Creates a new Compliance Job for the specified job type.

```java
import com.x.xdk.Schemas;
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

var response = client.compliance().createJobs(new Schemas.CreateComplianceJobsRequest().type("tweets"));
System.out.println(response);
```

## `deleteJobsById`

<Badge color="red">DELETE</Badge> `/2/compliance/jobs/{id}`

**Cancel Compliance Job**

Cancels a Compliance Job that has not finished processing; its status becomes failed and a new job of the same type can be created.

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

var response = client.compliance().deleteJobsById("1895000000000000000");
System.out.println(response);
```

### Parameters

<ResponseField name="id" type="String" required>

## `downloadJobResults`

<Badge color="blue">GET</Badge> `/2/compliance/jobs/{id}/download`

**Download Compliance Job Results**

Downloads the results file of a completed Compliance Job using the signed URL returned at job creation.

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

var response = client.compliance().downloadJobResults("1895000000000000000", "example");
System.out.println(response);
```

### Parameters

<ResponseField name="id" type="String" required>
  `id` (path parameter).
</ResponseField>

<ResponseField name="token" type="String" required>

## `uploadJobSubmission`

<Badge color="orange">PUT</Badge> `/2/compliance/jobs/{id}/upload`

**Upload Compliance Job Submission**

Uploads the newline-delimited ID file for a Compliance Job using the signed URL returned at job creation.

```java

XClient client = XClient.builder()
```
