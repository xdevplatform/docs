## `getOpenApiSpec`

<Badge color="blue">GET</Badge> `/2/openapi.json`

**Get OpenAPI Spec**

Retrieves the full OpenAPI Specification in JSON format. (See https://github.com/OAI/OpenAPI-Specification/blob/master/README.md)

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

var response = client.general().getOpenApiSpec();
System.out.println(response);
```

**Returns:** `Map<String, Object>`
