## `createBookmark`

<Badge color="green">POST</Badge> `/2/users/{id}/bookmarks`

**Create Bookmark**

Adds one or more Posts to the authenticated user's Bookmarks. Supply `tweet_id` for a single Post, or `tweet_ids` (at most 25) to bookmark several in one request. Optional `folder_id` applies to every Post in the request. Billing and rate limits still apply per HTTP request.

```java
import com.x.xdk.Schemas;
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .accessToken(System.getenv("X_ACCESS_TOKEN"))
    .build();

var response = client.users().createBookmark(
    "2244994945",
    new Schemas.CreateUsersBookmarkRequest().tweetId("1895000000000000000")
);
System.out.println(response);
```

### Parameters

<ResponseField name="id" type="String" required>
  The authenticated user's numeric ID, not `me`: the `id` from Get My User (`GET /2/users/me`).
</ResponseField>

<ResponseField name="body" type="Schemas.CreateUsersBookmarkRequest" required>
  At least one of `tweet_id`, `tweet_ids` is required.
</ResponseField>

**Returns:** `JsonNode`
