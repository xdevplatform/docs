Access **Connections** endpoints via `client.connections()` (`ConnectionsClient`).

## Methods

| Method | Endpoint | Behavior | Summary |
| :--- | :--- | :--- | :--- |
| [`deleteAll`](#deleteall) | `DELETE /2/connections/all` | Standard | Terminate All Connections |
| [`deleteByEndpoint`](#deletebyendpoint) | `DELETE /2/connections/{endpoint_id}` | Standard | Terminate Connections by Endpoint |
| [`deleteByUuids`](#deletebyuuids) | `DELETE /2/connections` | Standard | Terminate Multiple Connections |
| [`getConnectionHistory`](#getconnectionhistory) | `GET /2/connections` | Paginated | Get Connection History |

## `deleteAll`

<Badge color="red">DELETE</Badge> `/2/connections/all`

**Terminate All Connections**

Terminates all active streaming connections for the authenticated application.

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

var response = client.connections().deleteAll();
System.out.println(response);
```

**Returns:** `Schemas.DeleteAllConnectionsResponse`

---

## `deleteByEndpoint`

<Badge color="red">DELETE</Badge> `/2/connections/{endpoint_id}`

**Terminate Connections by Endpoint**

Terminates all streaming connections for a specific endpoint ID for the authenticated application.

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

var response = client.connections().deleteByEndpoint("filtered_stream");
System.out.println(response);
```

### Parameters

<ResponseField name="endpointId" type="String" required>
  `endpoint_id` (path parameter).
</ResponseField>

**Returns:** `Schemas.DeleteConnectionsByEndpointResponse`

## `deleteByUuids`

<Badge color="red">DELETE</Badge> `/2/connections`

**Terminate Multiple Connections**

Terminates multiple streaming connections by their UUIDs for the authenticated application.

```java
import com.x.xdk.Schemas;
import com.x.xdk.XClient;
import java.util.List;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

var response = client.connections().deleteByUuids(
    new Schemas.DeleteConnectionsByUuidsRequest().uuids(List.of("example"))
);
System.out.println(response);
```

### Parameters

<ResponseField name="body" type="Schemas.DeleteConnectionsByUuidsRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Schemas.DeleteConnectionsByUuidsResponse`

## `getConnectionHistory`

<Badge color="blue">GET</Badge> `/2/connections` <Badge color="purple">Paginated</Badge>

**Get Connection History**

Returns active and historical streaming connections with disconnect reasons for the authenticated application.

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

for (var page : client.connections().getConnectionHistoryPages()) {
    System.out.println(page);
}
```

### Parameters

<Expandable title="Optional parameters (ConnectionsClient.GetConnectionHistoryOptions — 5)">

<ResponseField name="options.status" type="String">
  `status` (query parameter).
</ResponseField>

<ResponseField name="options.endpoints" type="List<String>">
  `endpoints` (query parameter).
</ResponseField>

<ResponseField name="options.maxResults" type="Integer">
  `max_results` (query parameter).
</ResponseField>

<ResponseField name="options.paginationToken" type="String">
  `pagination_token` (query parameter).
</ResponseField>

<ResponseField name="options.connectionFields" type="List<String>">
  A comma separated list of Connection fields to display.
</ResponseField>

</Expandable>

**Returns:** `Schemas.GetConnectionHistoryResponse` (use `getConnectionHistoryPages(...)` for automatic `Paginator<...>` iteration)
