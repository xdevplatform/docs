Access **Account Activity** endpoints via `client.accountActivity()` (`AccountActivityClient`).

## Methods

| Method | Endpoint | Behavior | Summary |
| :--- | :--- | :--- | :--- |
| [`createSubscription`](#createsubscription) | `POST /2/account_activity/webhooks/{webhook_id}/subscriptions/all` | Standard | Create Subscription |
| [`deleteSubscription`](#deletesubscription) | `DELETE /2/account_activity/webhooks/{webhook_id}/subscriptions/{user_id}/all` | Standard | Delete Subscription |
| [`getSubscriptionCount`](#getsubscriptioncount) | `GET /2/account_activity/subscriptions/count` | Standard | Get Subscription Count |

| [`validateSubscription`](#validatesubscription) | `GET /2/account_activity/webhooks/{webhook_id}/subscriptions/all` | Standard | Validate Subscription |

## `createSubscription`

<Badge color="green">POST</Badge> `/2/account_activity/webhooks/{webhook_id}/subscriptions/all`

**Create Subscription**

Creates an Account Activity subscription for the user and the given webhook.

```java
import com.x.xdk.Schemas;
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .accessToken(System.getenv("X_ACCESS_TOKEN"))
    .build();

var response = client.accountActivity().createSubscription("1234567890", new Schemas.CreateAccountActivitySubscriptionRequest());
System.out.println(response);
```

### Parameters

<ResponseField name="webhookId" type="String" required>
  `webhook_id` (path parameter).
</ResponseField>

<ResponseField name="body" type="Schemas.CreateAccountActivitySubscriptionRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Schemas.CreateAccountActivitySubscriptionResponse`

## `deleteSubscription`

<Badge color="red">DELETE</Badge> `/2/account_activity/webhooks/{webhook_id}/subscriptions/{user_id}/all`

**Delete Subscription**

Deletes an Account Activity subscription for the given webhook and user ID.

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

var response = client.accountActivity().deleteSubscription("1234567890", "2244994945");
System.out.println(response);
```

### Parameters

<ResponseField name="webhookId" type="String" required>
  `webhook_id` (path parameter).
</ResponseField>

<ResponseField name="userId" type="String" required>
  `user_id` (path parameter).
</ResponseField>

**Returns:** `Schemas.DeleteAccountActivitySubscriptionResponse`
