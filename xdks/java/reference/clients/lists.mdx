## `addMember`

<Badge color="green">POST</Badge> `/2/lists/{id}/members`

**Add List Member**

Adds a User to a specific List by its ID.

```java
import com.x.xdk.Schemas;
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .accessToken(System.getenv("X_ACCESS_TOKEN"))
    .build();

var response = client.lists().addMember(
    "1450000000000000000",
    new Schemas.AddListsMemberRequest().userId("2244994945")
);
System.out.println(response);
```

### Parameters

<ResponseField name="id" type="String" required>
  `id` (path parameter).
</ResponseField>

<ResponseField name="body" type="Schemas.AddListsMemberRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Schemas.AddListsMemberResponse`

## `create`
