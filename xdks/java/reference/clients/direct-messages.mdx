## `createByConversationId`

<Badge color="green">POST</Badge> `/2/dm_conversations/{dm_conversation_id}/messages`

**Create DM Message by Conversation ID**

Sends a new direct message to a specific conversation by its ID.

```java
import com.x.xdk.Schemas;
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .accessToken(System.getenv("X_ACCESS_TOKEN"))
    .build();

var response = client.directMessages().createByConversationId(
    "1500000000000000000",
    new Schemas.CreateDirectMessagesByConversationIdRequest().text("Hello from XDK!")
);
System.out.println(response);
```

### Parameters

<ResponseField name="dmConversationId" type="String" required>
  `dm_conversation_id` (path parameter).
</ResponseField>

<ResponseField name="body" type="Schemas.CreateDirectMessagesByConversationIdRequest" required>
  At least one of `text`, `attachments` is required.
</ResponseField>

**Returns:** `Schemas.CreateDirectMessagesByConversationIdResponse`

## `createConversation`

<Badge color="green">POST</Badge> `/2/dm_conversations`

**Create DM Conversation**

Initiates a new direct message conversation with specified participants.

```java
import com.x.xdk.Schemas;
import com.x.xdk.XClient;
import java.util.List;

XClient client = XClient.builder()
    .accessToken(System.getenv("X_ACCESS_TOKEN"))
    .build();

var response = client.directMessages().createConversation(
    new Schemas.CreateDirectMessagesConversationRequest().conversationType("Group").participantIds(List.of("2244994945"))
);
System.out.println(response);
```

### Parameters

<ResponseField name="body" type="Schemas.CreateDirectMessagesConversationRequest" required>
  Request payload.
</ResponseField>

**Returns:** `Schemas.CreateDirectMessagesConversationResponse`

## `dmConversationsMediaDownload`

<Badge color="blue">GET</Badge> `/2/dm_conversations/media/{dm_id}/{media_id}/{resource_id}`

**Download DM Media**

Downloads media attached to a legacy Direct Message. The requesting user must be a participant in the conversation containing the specified DM event. The response body contains raw binary bytes.

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .accessToken(System.getenv("X_ACCESS_TOKEN"))
    .build();

var response = client.directMessages().dmConversationsMediaDownload(
    "1895000000000000000",
    "3_1895000000000000000",
    "1895000000000000000"
);
System.out.println(response);
```

### Parameters

<ResponseField name="dmId" type="String" required>
  `dm_id` (path parameter).
</ResponseField>

<ResponseField name="mediaId" type="String" required>
  `media_id` (path parameter).
</ResponseField>

<ResponseField name="resourceId" type="String" required>
  `resource_id` (path parameter).
</ResponseField>

**Returns:** `byte[]`

## `getEvents`

<Badge color="blue">GET</Badge> `/2/dm_events` <Badge color="purple">Paginated</Badge>

**Get DM Events**

Retrieves a list of recent direct message events across all conversations.

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .accessToken(System.getenv("X_ACCESS_TOKEN"))
    .build();

for (var page : client.directMessages().getEventsPages()) {
    System.out.println(page);
}
```
