## Installation

```kotlin
implementation("com.x:xdk:0.2.0")
```

## `XClient` Initialization

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();
```

<ResponseField name="bearerToken(String)" type="XClient.Builder">
  Configures an OAuth 2.0 Bearer Token for app-only requests.
</ResponseField>
<ResponseField name="accessToken(String)" type="XClient.Builder">
  Configures an OAuth 2.0 user-context access token.
</ResponseField>
<ResponseField name="oauth2(OAuth2Pkce)" type="XClient.Builder">
  Attaches an `OAuth2Pkce` manager for automatic token refresh.
</ResponseField>
<ResponseField name="oauth1(OAuth1)" type="XClient.Builder">
  Attaches an `OAuth1` HMAC-SHA1 signer for OAuth 1.0a user-context requests.
</ResponseField>
<ResponseField name="baseUrl(String)" type="XClient.Builder" default="https://api.x.com">
  Overrides the X API base URL.
</ResponseField>
