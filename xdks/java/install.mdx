Install `com.x:xdk` from [Maven Central](https://central.sonatype.com/artifact/com.x/xdk).

## Prerequisites

- **JDK 17+** (tested on JDK 17 and JDK 21)
- Maven 3.8+ or Gradle 8+

## Add Dependency

<CodeGroup>

```xml Maven (pom.xml)
<dependency>
  <groupId>com.x</groupId>
  <artifactId>xdk</artifactId>
  <version>0.1.2</version>
</dependency>
```

```kotlin Gradle (build.gradle.kts)
dependencies {
    implementation("com.x:xdk:0.1.2")
}
```

```groovy Gradle (build.gradle)
dependencies {
    implementation 'com.x:xdk:0.1.2'
}
```

</CodeGroup>

## Build from Source

```bash
git clone https://github.com/xdevplatform/xdk-java.git
cd xdk-java
mvn test
```
