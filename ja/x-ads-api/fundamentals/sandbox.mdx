Sandbox は、Ads API の実装をテスト・構築するための環境です。

Sandbox で作成したキャンペーンはユーザーには配信されず、Funding Instrument のようなオブジェクトのテストレコードを動的に作成できます。

Sandbox を利用するには、ads-api-sandbox.x.com という適切なホスト名を呼び出すだけですが、Sandbox にしかない独自の機能もいくつか含まれています。

新しい広告主アカウントを作成するには、まず [POST accounts](/x-ads-api/campaign-management/reference#post-accounts) にリクエストを送ります。この呼び出しのレスポンスに、以降のリクエストに使用できる account_id が含まれています。これらのエンドポイントにより、複数の広告主アカウントを作成し、それに対してテストできます。

### Sandbox 限定エンドポイント一覧:

* [POST accounts](/x-ads-api/campaign-management/reference#post-accounts) Sandbox 上でアカウントを作成
* [POST accounts/:account_id/features](/x-ads-api/campaign-management/reference#post-accounts-account-id-features) Sandbox 上のアカウントにアカウント機能を追加
* [POST accounts/:account\_id/funding\_instruments](/x-ads-api/campaign-management/reference#post-accounts-account-id-funding-instruments) Sandbox 上のアカウントに funding instrument を追加
* [DELETE accounts/:account_id](/x-ads-api/campaign-management/reference#delete-accounts-account-id) Sandbox 上のアカウントを削除
* [DELETE accounts/:account_id/features](/x-ads-api/campaign-management/reference#delete-accounts-account-id-features) Sandbox 上のアカウントからアカウント機能を削除
* [DELETE accounts/:account\_id/funding\_instruments/:funding\_instrument\_id](/x-ads-api/campaign-management/reference#delete-accounts-account-id-funding-instruments-funding-instrument-id) Sandbox 上のアカウントから funding instrument を削除
