Ads API で成功するには、X Ads のエンティティが相互にどのように関係しているかを理解することが重要です。このチュートリアルでは、X Ads のオブジェクト階層の基本について説明します。

![X Ads API hierarchy](/images/adsapi-heirarchy.png.twimg.1920.png)

## Ad Group(line item)

Ads API 上で [line item](https://developer.x.com/content/developer-twitter/en/docs/tutorials/ads-api-hierarchy-terminology#line-items) と呼ばれる Ad Group は、campaign の下に存在し、X ユーザーのセットに対するターゲティングと入札に使用されます。広告主は、投稿またはメディア(例: In-stream 広告としてプロモートされる動画)を line item に関連付けることでプロモートします。「Ad Group」も参照してください。

## Account Media

広告アカウントに[account media](/x-ads-api/creatives/reference#account-media) としてアップロードされたクリエイティブのコレクションで、プロモート動画の[pre-roll アセット](/x-ads-api/campaign-management/reference#video-views-preroll-objective)(in-stream 広告とも呼ばれる)、および [X Audience Platform](https://developer.x.com/content/developer-twitter/en/docs/ads/measurement/overview/twitter-audience-platform) でプロモートできる画像を含められます。

## Ads Account

X Ads 階層の最上位に位置するのが広告アカウントです。1 つの広告アカウントは複数の X ユーザーによって管理される場合があります。当社のデモ家具店 @Furni は、広告アカウントを管理するユーザーの一例です。広告アカウントは、[base36](https://en.wikipedia.org/wiki/Base36) の英数字文字列である account_id で識別されます。

各アカウントの下には、キャンペーン間で再利用できる複数のエンティティタイプが格納されます。これには、ターゲティングに使用できる tailored audience、動画または画像である account media、投稿に追加できる拡張クリエイティブである Card などが含まれます。

## Amplify Video

動画アセットをアップロードする際、アップロード元は動画のカテゴリを定義できます(例: Tweet Video、Tweet Gif、Tweet Image、Amplify Video)。in-stream 広告として配信される動画をアップロードするには、amplify video カテゴリが必要です。これらの動画は配信可能にするための特別な処理が必要で、そのため Amplify Video のメディアカテゴリが必要です。

## Analytics

Analytics 指標は、パートナーおよび広告主が X 上でプロモートするコンテンツのパフォーマンスを理解するのに役立ちます。これには、インプレッション、クリック、動画視聴、支出などの情報が含まれます。加えて、パートナーおよび広告主は、リーチしたオーディエンスのさまざまなセグメントについて詳細なメトリクスを取得できます。

Ads API は、詳細なキャンペーンパフォーマンス指標を取得するための 2 つの方法をサポートしています: 同期と非同期です。

[同期 analytics](/x-ads-api/analytics#synchronous-analytics) リクエストでは、要求した指標がレスポンスで返されます。同期エンドポイントは短い時間範囲をサポートし、リアルタイムのキャンペーンパフォーマンス問い合わせに最適です。

[非同期 analytics](/x-ads-api/analytics#asynchronous-analytics) エンドポイントでは、関連する「ジョブ」が処理を終えた後にダウンロード可能な結果ファイルで要求した指標を受け取れます。非同期エンドポイントは、はるかに長い時間範囲でのメトリクス取得をサポートし、セグメント化データの返却が可能で、はるかに多くのデータを取得する用途を想定しています。レポート生成や履歴のバックフィルに最適です。

## Campaign

広告主が実行する各キャンペーンは、既存の funding instrument の下で作成する必要があります。キャンペーンでは、広告キャンペーンの名前、スケジュール、予算などを定義できます。Furni の例を続けると、「Furni home decor」というキャンペーンを作成するかもしれません。

なお、1 つの広告アカウントで有効なキャンペーンは最大 200 個に制限されています。この制限は広告主のアカウントマネージャーによって引き上げられる可能性があります。キャンペーンは、その終了時刻に達するか予算を使い切るまで有効とみなされます。一時停止されたキャンペーンも、キャンペーン制限の観点では有効なキャンペーンとしてカウントされます。

## Card

Card は、Tweet を視覚的に拡張して、画像、動画、UI 要素を含める方法を提供します。Ads API は、Tweet で使用可能ないくつかの Card タイプをサポートし、それらをキャンペーンでプロモートできます。

## クリエイティブ

広告主は、画像、GIF、動画などのクリエイティブを含む Tweet をキャンペーンでプロモートできます。これらのクリエイティブは、リッチな写真、動画、メディア体験を Tweet に添付できる X Card と関連付けることができます。クリエイティブは Tweet に直接添付することもできます。たとえば、テキストと動画(または最大 3 枚の画像)を含めてプロモート Tweet を作成できます。

各 line item は、実行するために少なくとも 1 つのクリエイティブが関連付けられている必要があります。新規フォロワーを獲得する Promoted Accounts、TX Audience Platform 全体で line item に使用する画像や動画などの Media Creatives、Promoted Posts など、いくつかのオプションがあります。

## Funding Instrument

広告アカウントの下には funding instrument もあり、これは広告主が X Ads で使用するために設定した資金源です。X と締結した挿入注文(insertion order)から、アカウントに紐付いたクレジットカードまで多岐にわたります。

## Line Item

キャンペーン内には、1 つ以上の ad group(Ads API では line item)を持てます。line item は、それぞれ独自のターゲティングセットと独自のクリエイティブを持つ、キャンペーンの異なるセグメントと考えられます。複数の line item を含むキャンペーンは、しばしば「ad group campaign」と呼ばれます。

1 つのキャンペーン内で複数の line item を持つ利点の 1 つは、ターゲティングとクリエイティブの組み合わせをより多様に作成できることです。

「Furni home decor」キャンペーンの下に 2 つの line item を作成することが考えられます: 一方は「Home buyers in San Francisco」、もう一方は「Home buyers in London」といった具合です。

1 つのキャンペーンあたり最大 100 個の line item が許可されており、1 つの広告アカウントは全キャンペーン合計で最大 4,000 個のアクティブ line item に制限されます。

## Mobile App Promotion (MAP)

Mobile App Promotion(MAP)は、広告主が X 経由でモバイルアプリをプロモートできるようにする一連のプロダクトです。これには、app install、コンバージョン、再エンゲージメントが含まれます。

## Mobile App Conversion Tracking (MACT)

X のモバイルアプリプロモーション計測により、広告主は install やその他のアプリ内コンバージョンを促進するように設計された X 上の広告キャンペーンの成功を追跡できます。X モバイル計測パートナーは、X 上でプロモートしているアプリからどのコンバージョンを追跡するかを広告主が管理できるようにします。MACT の概要を参照してください。

## Media Library

Media Library エンドポイントは、X Ads アカウントの画像、GIF、動画を管理する機能を提供します。ライブラリ内のメディアアセットは、投稿の作成や Card の作成に使用できます。また、複数のクリエイティブで再利用できるため、同じアセットを何度もアップロードする必要はありません。

## Promoted Account

Promoted Account(follower キャンペーン)は Who to Follow の一部で、ユーザーがまだフォローしていない、興味を持ちそうなアカウントを提案します。Promoted Account は、ユーザーが楽しめる可能性のあるさらに幅広いアカウントを紹介するのに役立ちます。

Promoted Account により、広告主は自身のアカウントをプロモートし、X 上でオーディエンスを拡大できます。フォロワーキャンペーンは Home Timeline、Who to Follow、検索結果など、X プラットフォーム全体の複数の場所に表示され、この提案は他の推奨アカウントと区別するために「Promoted」と表示されます。

## Promotable Users

各 X Ads アカウントには 1 つ以上の promotable users が存在します。これは広告アカウントを通じてプロモートできるユーザーです。Furni の @Furni ハンドルは、Furni の広告アカウント下の FULL promotable user の例です。これは @Furni とその tweet に対してあらゆるタイプのキャンペーンを実行できることを意味します。1 つの広告アカウントで FULL promotable user は 1 人だけです。

広告アカウントには、他の promotable user も存在し得ます。たとえば、@Jack の Furni 製品に関する Tweet をプロモートしたい場合、@Jack は RETWEETS_ONLY で示される retweet-only promotable user となります。広告主は、広告アカウントに retweet user を追加する方法について、X アカウントマネージャーに問い合わせてください。

## Promoted Video

Promoted Video は、広告主が費用を負担する Promoted Tweet 内の動画です。Home timeline、X の検索結果の上部、その他プラットフォーム上のさまざまな場所に表示され、「Promoted」と明確に表示されます。

## Publisher Network

[X Audience Platform](/x-ads-api/audiences) を参照してください。

## Scheduled Tweet

Scheduled Tweet を使うと、広告主またはユーザーは、後日公開されるようにスケジュールできる Tweet を作成できます。これらの Tweet を作成・管理する機能に加え、API では公開後にプロモートするために、これらの Tweet を line item に関連付けることができます。これにより、広告主はネイティブ Tweet の作成をあらかじめ準備し、主要な取り組みに先立ってキャンペーンクリエイティブを計画できます。たとえば、新製品発表と同時に公開される Tweet クリエイティブを事前準備することが可能です。

## Segmentation

Segmentation により、パートナーおよび広告主は年齢、デバイス、言語などの特定のターゲティング値ごとに分けたメトリクスを取得できます。これは非同期 analytics エンドポイントでのみ利用可能です。segmentation されたメトリクスをリクエストするには、segmentation_type リクエストパラメーターを使用します。segmentation のオプションの詳細については、Metrics and Segmentation を参照してください。

## Tailored Audience - List

List からの Tailored Audience は、Tailored Audience の 3 種類のうちの 1 つで、自身のユーザーおよび顧客データを含むファイルをアップロードして作成します。リストは X 上のユーザーとマッチングされ、キャンペーンで直接ターゲティングできます。関連する制限を確認してください。

## Tailored Audience - Web

Web からの Tailored Audience は Tailored Audience の 3 種類のうちの 1 つで、あなたのウェブサイトを訪問した X ユーザーのコレクションです。Web からの Tailored Audience を使用するには、ウェブサイトに X ピクセルをインストールするか、対応するタグマネージャーパートナーのいずれかを使用する必要があります。関連する制限を確認してください。

## Targeting Criteria

前述のとおり、targeting criteria は line item に関連付けられます。ロケーション、キーワード、性別から、ユーザーの行動や興味などのより詳細な属性まで、さまざまなターゲティングを使用できます。「Home Buyers in San Francisco」line item では、「San Francisco」ロケーションと合わせて「home buying」行動をターゲットにするかもしれません。

利用可能なターゲティングの種類の詳細については、developer サイトの Targeting Overview ページを参照してください。

## Twitter Object Nest (TON)

Twitter Object Nest(TON)は、Media Upload エンドポイントを通じてクリエイティブとして使用するためにアップロードされたメディアやさまざまなアセットを保持します。

## クリエイティブ

各 line item は、実行するために少なくとも 1 つのクリエイティブが関連付けられている必要があります。新規フォロワーを獲得する Promoted Accounts、X Audience Platform 全体の line item に使用する画像や動画などの Media Creatives、Promoted Posts など、いくつかのオプションがあります。以下は、@Furni がプロモートしてクリエイティブとして使用できる Post の例です。
