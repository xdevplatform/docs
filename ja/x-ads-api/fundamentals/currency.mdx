通貨の種類は [ISO-4217](http://en.wikipedia.org/wiki/ISO_4217) で識別されます。これは `USD` や `EUR` のような 3 文字の文字列です。通貨の値は micros で表現されます。USD の場合、$5.50 は 5.50*1e6、つまり 5,500,000 としてエンコードされます。「整数値」を表すには、すべての通貨について、ローカルの micro に 1e6(1\_000\_000)を掛ける必要があります。

Ads API は、X SMB Ads プロダクトが利用可能なすべての国の公式通貨を認識します。これらの国の完全な一覧は[こちら](https://business.x.com/en/help/overview/about-eligibility-for-twitter-ads.html)からご覧いただけます。

ほとんどの通貨は「精度」が 2(USD: $1.23 など)です。

* `AED`, `VEF`, `PKR`, `IDR`, `HKD`, `QAR`, `PHP`, `NZD`, `INR`, `EUR`, `ARS`, `THB`, `MXN`, `EGP`, `DZD`, `SAR`, `LBP`, `COP`, `TRY`, `SGD`, `MAD`, `AUD`, `USD`, `MYR`, `CAD`, `BRL`, `GBP`。

以下の通貨は小数を使用しません。

* `VND`, `KRW`, `CLP`, `JPY`

そして以下は 3 桁の小数を使用します。

* `KWD`, `IQD`, `BHD`, `TND`

通貨の使用は、[funding instrument](/x-ads-api/introduction) を通じて行われます。
