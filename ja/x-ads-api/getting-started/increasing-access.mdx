### 追加のアプリレベル権限のリクエスト

アプリケーションが以下のアプリレベル権限のいずれかに制限されており、追加のエンドポイントへアクセスしたい場合は、**Standard Access** に申し込むために X の担当者にご連絡ください。

2023 年 7 月以前に Ads API アクセスをリクエストした開発者は、以下のいずれかのアプリレベル権限をリクエストした可能性があります。これらは現在、Standard Access レベルに含まれます:

- **Analytics** (Read-only): ユーザーは[Analytics](https://developer.x.com/en/docs/twitter-ads-api/analytics/overview) エンドポイントに [read-only](https://developer.x.com/en/docs/apps/app-permissions) アクセスできます。Campaign Management、Creative、Custom Audiences のエンドポイントにはアクセスできませんが、Analytics エンドポイントのリクエストパラメーターでクリエイティブエンティティを渡すことで、メトリクスを取得できます。media_id や media_name の粒度を取得するには、ユーザーアプリケーションが Ads API の書き込みアクセスを持っている必要があります。

- **Campaign Management & Creative** (Read & Write): ユーザーは[Campaign Management](https://developer.x.com/en/docs/twitter-ads-api/campaign-management/overview) および [Creative](https://developer.x.com/en/docs/twitter-ads-api/creatives/overview) のエンドポイントに [read & write](https://developer.x.com/en/docs/apps/app-permissions) アクセスできます。ユーザーは Analytics エンドポイントにもアクセスできます。

- **Custom Audiences** (Read & Write): ユーザーは[Custom Audiences](https://developer.x.com/en/docs/twitter-ads-api/audiences/overview) エンドポイントに [read & write](https://developer.x.com/en/docs/apps/app-permissions) アクセスできます。ユーザーは Campaign Management、Creative、Analytics のエンドポイントにもアクセスできます。

- **Conversion** (Read & Write): ユーザーは[Mobile](https://developer.x.com/en/docs/twitter-ads-api/measurement/mobile-conversions/overview) および [Web Conversion](https://developer.x.com/en/docs/twitter-ads-api/measurement/web-conversions/overview) エンドポイントに [read & write](https://developer.x.com/en/docs/apps/app-permissions) アクセスできます。ユーザーは他の Ads API エンドポイントにアクセスできる場合とできない場合があります。

### user OAuth トークン制限の引き上げリクエスト

2023 年 7 月より前に Ads API アクセスをリクエストした開発者は、アプリケーションで user OAuth トークンが 5 個に制限されている場合があります。デベロッパーアプリのトークン上限を引き上げる必要がある場合は、X の担当者にご連絡ください。

<Note>**注:** Ads API のいずれのエンドポイントについても [rate limits](https://developer.x.com/en/docs/twitter-ads-api/rate-limiting) は引き上げません。レート制限の範囲内に収める方法については[ベストプラクティス](https://developer.x.com/en/docs/twitter-ads-api/rate-limiting)をご覧ください。</Note>
