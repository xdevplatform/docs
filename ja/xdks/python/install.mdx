XDK Python SDK は GitHub リポジトリから直接入手でき、`pip` でインストールできます。
## 前提条件
- Python 3.8 以上。
- `pip` と `venv`（仮想環境として推奨）。
## クイックインストール
GitHub のサブディレクトリから XDK をインストールします:
```bash
pip install xdk
```
これにより `main` ブランチから最新の生成バージョンが取得されます。
## 開発用インストール
開発や貢献のために:
1. リポジトリをクローンします:
   ```bash
   git clone https://github.com/xdevplatform/xdk.git
   cd xdk/python
   ```
2. 依存関係を editable モードでインストールします:
   ```bash
   pip install -e .
   ```
   これにより SDK と実行時の依存関係がインストールされます。
3. （任意）テスト/リント用の開発依存関係をインストールします:
   ```bash
   pip install -e .[dev]
   ```
## 動作確認
インストールを確認します:
```python
import xdk
print(xdk.__version__)  # Should print the XDK version
```
**注意:** XDK は OpenAPI 仕様から生成されているため、変更点については必ず [X API changelog](https://docs.x.com/changelog) とリポジトリの XDK リリースノートを確認してください。
Python XDK を使った詳細なコードサンプルは、[コードサンプル GitHub リポジトリ](https://github.com/xdevplatform/samples/tree/main/python)を参照してください。
