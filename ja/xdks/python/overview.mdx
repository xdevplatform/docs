Python XDK（X Developer Kit）は、Python を使って X API v2 を利用するための公式クライアントライブラリです。開発者が API をすぐに使い始めてアプリケーションを構築できるように設計されています。公式の [OpenAPI 仕様](https://api.x.com/2/openapi.json)に基づいて生成されており、低レベルの HTTP の詳細を抽象化しつつ、必要に応じてきめ細やかな制御も可能にします。
## 主な機能
- 🔐 **OAuth サポート**: Bearer Token（アプリのみ）認証、PKCE 付き OAuth 2.0（ユーザーコンテキスト）、OAuth 1.0 に完全対応。
- 🔄 **ページネーション**: 大量の結果を自動的にページ処理します。XDK が `next_token` を使った複数の API 呼び出しを面倒なしに処理します。
- 📡 **ストリーミング**: filtered stream のように永続的な HTTP 接続を必要とするエンドポイントで、リアルタイムデータストリーミングをサポートします。
- 🎯 **包括的なカバレッジ**: 検索、タイムライン、filtered-stream などを含む X API v2 のすべてのエンドポイントをサポートします。
**バージョン互換性**: Python 3.8 以上。CPython と PyPy でテスト済み。
