<Note>
**要点(tl;dr)**

成功へのトレンド: Red Cloud Financial Services は、鉱業会社の新しいグリーンテクノロジーのマーケティング支援を依頼された際、X アナリティクス上に構築された Audiense のターゲティングツールを活用してデータをマイニングし、新しいオーディエンスにリーチしました。
</Note>

## 状況

Red Cloud Financial Services は、上場鉱業会社であるクライアントが独自に開発した特許出願中の新技術について、まったく新しいオーディエンスに認知度を高めることを支援するよう依頼されました。

同社は、新しい領域へと進出し、その新しい顧客にリーチできるキャンペーンを効果的に運用するために、この新製品で成果を上げる方法を見つける必要がありました。

この依頼には、2 つの大きな課題がありました。

1. **新しいオーディエンスにリーチする**

    既存の鉱業顧客に焦点を合わせるのではなく、クライアントの新技術はグリーンイノベーションや社会的責任に関心のあるより広いセグメントに訴求するものでした。これは Red Cloud にとって未知の領域であり、以前に運用した過去のキャンペーンとはまったく異なるものでした。

1. **具体的な ROI の提示**

    このクライアントは有料キャンペーンの実施に慣れていませんでした。Red Cloud が認知ベースのキャンペーンの ROI を明確に示し、直接的な経験が限られているオーディエンスで成果を出すことを期待されるのは、大変な要求でした。

    Red Cloud は Audiense を活用し、既存顧客にリーチしつつ、見込みのある新しい顧客をリサーチしました。Audiense の X マーケティング製品は、強力なオーディエンスターゲティングツールを用いてインパクトのある X キャンペーンを実現することに特化しています。

## ソリューション

Red Cloud はまず期待値の設定から始めました。Audiense のインサイトを活用してキャンペーンパフォーマンスの予測を作成することで、Red Cloud はクライアントに対してキャンペーンの最終目標および関連 KPI についての期待値を設定できました。

Audiense の支援を受けて、Red Cloud は鉱業会社のニュースと関連する株式情報について X 上でのリサーチに注力しました。Audiense のプラットフォームにより、キャンペーンと動画視聴数増加およびウェブサイトトラフィック増加に反映される関心の高まりとの間の潜在的な相関を、簡単に見つけることができました。

3 段階のアプローチ:

1. まったく新しいオーディエンスを構築する。

    Red Cloud Financial はクライアントの方針を踏まえ、キャンペーンを集中させる主要オーディエンスとして、鉱業と投資に関心のある第 1 セグメント、クリーンテック、電気自動車、ESG、責任投資に関心のある第 2 セグメントを特定しました。X のデータにより、これらのオーディエンスを今後のキャンペーンとさらに整合させることができました。

1. 新しいオーディエンスをセグメント化する。

    新しいオーディエンスは幅広い業界にまたがっていましたが、それらの間には多くの共通点がありました。Audiense は Red Cloud Financial がこれらの新しいセグメントをマイニングし、インフルエンサーやコンテンツ消費習慣などを特定するのに役立ちました。これらのインサイトは、フォローするアカウントを決定し、返礼フォローによって Red Cloud およびクライアントのオーディエンスを成長させる後押しとなりました。

1. 最も価値の高いオーディエンスを見極める。

    最も価値の高いオーディエンスを見極めます。Red Cloud は Audiense の [Targeting Pack 機能](https://help.audiense.com/knowledge/what-is-a-targeting-pack)を利用して、レーザーフォーカスされた有料 X 広告キャンペーンを作成しつつ、蓄積した X セグメントのデータをオーガニックキャンペーンに活用しました。Targeting Pack 機能から得られたインサイトを活用し、Audiense と Red Cloud は 2 つのオーディエンスをターゲットにした 2 種類の独自動画を作成しました。どちらの動画が一貫してキャンペーンを最も牽引しているかを見極め、ターゲティングを軌道に乗せられました。

## インパクト

Audiense のプラットフォームと X リサーチにより、Red Cloud は適切なオーディエンスを見つけ、セグメント化し、フォロワーを増やすために活用し、オーガニック・有料コンテンツの両方に対する全体的なソーシャルメディア戦略に反映できました。

Red Cloud Financial はクライアントの期待を上回りました。実際、キャンペーンの結果が非常に良好だったため、クライアントは追加のキャンペーンを進めて拡大することを決定しました。

- 統合キャンペーンは 350 万件以上のインプレッションと 280 万回以上の総視聴数を獲得しました
- クライアントの特許出願中の新技術に関する会話量が増加しました
- ウェブサイトへの参照トラフィックが増加し、新技術に関するプロモーション記事とプレスリリースから 7,000 名の新規訪問者を含みました

これは、X 上でのオーディエンス分析とターゲティングが、新しいオーディエンスへのアクセス、マーケティングキャンペーンの磨き上げ、実際の成果の実現にどのように役立つかを示す好例です。クライアントのブランド構築とビジネス向上を支援する、絶好の機会となり得ます。
