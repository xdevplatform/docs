<Note>
**要点(tl;dr)**

デベロッパーでありクリエイターでもある Aaron Ng が、X API を用いて自身の X ネットワークを検索するエンジン Flocknet を構築した方法を紹介します。人々は Flocknet を活用してネットワークを広げ、人材を採用し、投資機会を発掘しています。当初は個人利用のために作られた Flocknet は、現在では X 上の何百万ものコンタクトを管理する手助けとなっています。
</Note>

## 課題

Aaron Ng がニューヨークのデザインカンファレンスに参加した際、同業者たちとつながって会いたいと考えていました。しかしそのとき、X 上のデザイナー仲間とすらつながるのは思っていた以上に難しいことに気付きました。彼のコミュニティの多く、特に業界の友人たちは X 上にいました。街に来ている友人が誰なのか、把握する方法はないのか? 誰が近くにいるのかを知らないまま、業界のつながりと会って話す方法はあるのか?

Aaron はすぐにこの課題を機会として捉えました。そして起業家精神の結果として、Flocknet が誕生したのです。

## ソリューション

たった 1 週間で、Aaron は X のネットワーク内で、Tweet を見なくても、人々、友人、その他の専門家を検索、並べ替え、追跡できるプロダクトを構築しました。彼はこのプロジェクトに X API を選び、こう述べています。「質問できる相手がいることを知っていて、[X の]チームが親身に対応してくれると分かっていることで、体験がぐっと良くなります」。さらに「作り続けるモチベーションを与えてくれたコミュニティの多くが X にありました。だからこそ X は私にとって非常に重要な場所であり、その利用体験を高めるためのツールを作りたかったのです」と付け加えています。

Aaron の創造性、原動力、経験の組み合わせにより、Flocknet が誕生しました。これは X のネットワーク内の人物を見つけるための検索エンジン兼コンタクト管理ツールです。X の follows エンドポイントと Python を活用し、Flocknet は職業、勤務先、所在地、その他多くの属性でフォロワーを検索できます。

当初は個人利用のためのものでしたが、Flocknet は大きな注目を集めたため、共有すべきものだと確信するに至りました。そこで彼はすぐに、Flocknet を現在の形にスケールアップする作業へと注力を移しました。

## インパクト

わずか数か月の間に、Flocknet はユーザーに代わって何百万ものコンタクトを管理するまでになりました。テック業界の人々にとって特に有用で、採用から投資、その間のあらゆる用途に活用されています。実際、Aaron 自身も Flocknet を通じて人材を採用してきました!

しかし、Aaron はまだ終わっていません。寄せられる機能要望に注力し、Aaron は継続的にプロダクトを拡張する方法を模索しています。

最終的に、Aaron は X をメタプラットフォームへと変え、コミュニティが主に X 上に存在するあらゆる人の体験を強化する方法を見つけました。彼は次のように述べています。「私はとにかくたくさんの物を作っています。自分にとって有用で、他の人にも有用なものを作るのが大好きなんです」。まさに、彼はそれを実行したのです。
