## 状況

COVID-19 の流行後、アジア系アメリカ人および太平洋諸島系住民(AAPI)を標的としたヘイトインシデントが増加しました。これらの一部はニュースで取り上げられましたが、数千人もの個人が全国の通報センターである [Stop AAPI Hate](https://stopaapihate.org/) に報告を寄せていました。同センターは研究、アドボカシー、キャパシティビルディングを通じてヘイトインシデントに対応・取り組んでいます。この時期に [The American Asian Foundation (TAAF)](https://www.taaf.org/) が設立されました。TAAF は、これらのインシデントが標的となった人々に個人的にどう影響しているかを新たな視点で照らし出すために X を活用しようと決めたチームの、原動力となりました。

## ソリューション

エンジニア 2 名の小規模なチームは、インシデントデータのソースとして X に注目しました。このプラットフォームを選んだ理由は 2 つあります。第一に、ニュース、人々の考え、日々の出来事、コミュニティ内の出来事など、豊富で多様な情報を含んでいるからです。そのため X は、さまざまな人口層のユニークで身近なサンプルを提供します。また、X は開発者がデータにアクセスできる、真にオープンな API を持つ唯一のプラットフォームであり、TAAF の開発者がそのデータを収集・分析するための詳細なツールも備えています。

チームは X API v2 の search Tweets および Tweets lookup エンドポイントを使用し、投稿ステータスを検索して、人々がヘイトインシデントを報告している時期を特定できるようにしました(使用しているハッシュタグも含めて)。これにより、チームは 1,023 文字の検索クエリを設計し、数十億の投稿から扱いやすい量まで絞り込めました。

次の課題は、それらの投稿が本当にヘイトインシデントに関するものであるかを検証することでした。チームは自然言語処理を用いたツールを開発し、数千件の投稿を選別してプロジェクトに関連するものを見つけました。学習済みの機械学習モデルを適用した後、精度をさらに高めるために人による検証を行いました。

2021 年、TAAF は Stop AAPI Hate 連合と共に [Documenting Anti-AAPI Hate Codebook](https://stopaapihate.org/wp-content/uploads/2021/12/SAH-x-TAAF-Codebook-FINAL-2021-08-19.pdf) の共著者となりました。このリソースには、コミュニティベースのデータ収集に関する基準および実践のドラフトが含まれており、X 上で人々が共有しているインシデントの分類にチームが役立てました。

そこから次の課題は、このデータを人々が容易に理解できる形で示すことでした。TAAF はデータ可視化ツール [Decoding Hate](https://decodinghate.taaf.org/) を作成し、膨大なデータをインタラクティブに表示しています。データ可視化スタジオの協力を得て、注釈付けした X データを取り込み、数千件の投稿を AAPI コミュニティ内で実際に起きていた真実を明らかにする示唆に富むストーリーへと変えることができました。

## インパクト

Decoding Hate プロジェクトは、他の方法では報告されずに埋もれていた数千件のヘイト関連インシデントを検出することに貢献し、現在も継続しています。このプロジェクトは、AAPI コミュニティ内で起きている個人の体験に対する認識を広げる継続的なツールとなっています。

次のフェーズでは、TAAF は Stop AAPI Hate と提携し、X 上でヘイトインシデントを報告する個々の人に対して、人による個別対応のパイロットを実施します。このフェーズでは、Stop AAPI Hate が、自身が経験したヘイトについて投稿している人々の多くと積極的にエンゲージし、[Stop AAPI Hate Reporting Center](https://stopaapihate.org/) を通じてインシデントを報告するよう促します。Stop AAPI Hate に報告する人が増えるほど、連合とそのパートナーは発生しているヘイトインシデントの性質をより深く理解し、最も効果的な政策的解決策を提唱できるようになります。

AAPI コミュニティで起きているヘイト関連インシデントを明らかにすると同時に、このプロジェクトは X API の価値にも光を当てています。このケースは、適切なデータを適切なツールで活用することで、開発者が X を用いて社会的意義のある取り組みでイノベーションを起こせることを示しています。
