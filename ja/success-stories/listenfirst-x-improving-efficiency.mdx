## 状況

歴史的に、デジタルマーケターにはデータを統合的に見る手段がありませんでした。あるシステムにはオーガニックデータがあり、別のシステムには有料データがあり、会話はさまざまな場所から流れてきます。しかし、クライアントやステークホルダーから「昨日の総インプレッションはいくつでしたか?」に続いて「オーガニックと有料の内訳はどうですか?」といった質問が寄せられる中、このデータを効率的に集約・解釈する仕組みの必要性はかつてなく高まっています。

これらの課題を解決すべく、10 年以上にわたって X デベロッパープラットフォーム上に構築されてきたソーシャル分析プラットフォームである ListenFirst は、単一のソースオブトゥルースからオーガニックおよび有料の X データを収集するツールを作る必要がありました。これまで、これらのオーガニックデータと有料データは異なるプラットフォーム、API、エンドポイントに分断されたサイロ内に存在しており、集約、合算、あるいは統合されることは想定されていませんでした。

## ソリューション

顧客向けのインサイトをより効率的に導き出す方法を模索する中で、ListenFirst は X の v2 エンドポイントを採用し、X 上でユーザーが話している内容を自社プラットフォームに取り込むプロセスを効率化しました。ListenFirst のチームは明確な目標を掲げて作業に取り掛かりました。よりクリーンなデータを作り出すことです。

> *「私たちにとって v2 の活用は、統合の最適化そのものです。サイト上で組み合わせる必要のあるパーツが少なくなれば、運用が容易になり、より多くのブランド、より多くのコンテンツ、より優れたインサイトへとオファリングを拡大できます。」*
>
> - Jonathan Farb、ListenFirst 最高プロダクト責任者

チームが X の v2 API、特に Tweets lookup エンドポイントの採用を優先した要因は、エンゲージメントとインプレッション数の精度でした。このエンドポイントを利用することで、ListenFirst は顧客が他所で目にする X ネイティブ分析と整合する、より信頼性の高いメトリクスを生成できるようになりました。

## インパクト

まだ導入初期ですが、v2 の採用は ListenFirst の効率に影響を及ぼしています。これまで、ListenFirst はさまざまな API のデータをつなぎ合わせる必要があり、数値がネイティブ分析で見られるものと一致していませんでした。v2 の利用により、ListenFirst の数値は X のネイティブ分析とほぼ同等になり、精度と顧客の信頼が向上しました。現在、ListenFirst はブランドが X 上でマーケティング戦略を完成させるのを支援する、根拠のある洗練されたインテリジェンスを提供できます。ListenFirst は、v2 のさらなる採用が精度と透明性の向上を通じてクライアントメトリクスへの信頼を高めると考えています。
