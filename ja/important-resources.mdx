## クイックリファレンス

### レスポンス構造

すべての v2 レスポンスは次の構造に従います。

```json
{
  "data": { ... },      // Primary object(s)
  "includes": { ... },  // Expanded objects (if requested)
  "meta": { ... },      // Pagination info
  "errors": [ ... ]     // Partial errors (if any)
}
```

### 一般的なパラメーター

| パラメーター | 用途 |
|:----------|:----|
| `tweet.fields` | 特定の投稿フィールドをリクエスト |
| `user.fields` | 特定のユーザーフィールドをリクエスト |
| `expansions` | 関連オブジェクトを含める |
| `max_results` | 1 ページあたりの結果数を制限 |
| `pagination_token` | 次の/前のページを取得 |

### 認証方法

| 方法 | ユースケース |
|:-------|:---------|
| Bearer Token | 読み取り専用の公開データ |
| OAuth 2.0 | 細かなスコープを持つユーザー操作 |
| OAuth 1.0a | ユーザー操作(レガシー、フル権限) |

[完全な認証ガイド →](/resources/fundamentals/authentication/overview)
