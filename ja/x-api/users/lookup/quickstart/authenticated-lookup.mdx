このガイドでは、`/me` エンドポイントを使って現在認証されているユーザーのプロフィールを取得する手順を説明します。

<Note>
**前提条件**

始める前に、以下が必要です:
- 承認済みの App がある [developer account](https://developer.x.com/en/portal/petition/essential/basic-info)
- ユーザー Access Token (OAuth 1.0a または OAuth 2.0 PKCE)
</Note>

---

## 認証済みユーザーを取得

ユーザー Access Token を使って `/me` エンドポイントへリクエストします:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/me?\
user.fields=created_at,description,verified,public_metrics,profile_image_url" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# 認証済みユーザーを取得
response = client.users.get_me(
    user_fields=["created_at", "description", "verified", "public_metrics", "profile_image_url"]
)

print(f"Username: {response.data.username}")
print(f"ID: {response.data.id}")
print(f"Followers: {response.data.public_metrics.followers_count}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// 認証済みユーザーを取得
const response = await client.users.getMe({
  userFields: ["created_at", "description", "verified", "public_metrics", "profile_image_url"],
});

console.log(`Username: ${response.data?.username}`);
console.log(`ID: ${response.data?.id}`);
console.log(`Followers: ${response.data?.public_metrics?.followers_count}`);
```

</CodeGroup>

## ユースケース

`/me` エンドポイントは以下の場面で不可欠です:

- **認証の確認** — ユーザーが適切に認証されていることを確認
- **user ID の取得** — 他の API 呼び出し用に認証済みユーザーの ID を取得
- **体験のパーソナライズ** — アプリでユーザーのプロフィールを表示
- **代理リクエスト** — 誰の代わりにリクエストを行っているかを把握

## ピン留めした Post を含める

ユーザーのピン留めした Post をリクエストします:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/me?\
user.fields=pinned_tweet_id&\
expansions=pinned_tweet_id&\
tweet.fields=created_at,text" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# ピン留めした Post 付きで認証済みユーザーを取得
response = client.users.get_me(
    user_fields=["pinned_tweet_id"],
    expansions=["pinned_tweet_id"],
    tweet_fields=["created_at", "text"]
)

print(f"Username: {response.data.username}")
# ピン留めされた Post は response.includes.tweets にあります
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// ピン留めした Post 付きで認証済みユーザーを取得
const response = await client.users.getMe({
  userFields: ["pinned_tweet_id"],
  expansions: ["pinned_tweet_id"],
  tweetFields: ["created_at", "text"],
});

console.log(`Username: ${response.data?.username}`);
// ピン留めされた Post は response.includes?.tweets にあります
```

</CodeGroup>

## 利用可能なフィールド

| Field | Description |
|:------|:------------|
| `created_at` | アカウント作成日 |
| `description` | ユーザーの bio |
| `profile_image_url` | アバターの URL |
| `verified` | 認証済みステータス |
| `public_metrics` | フォロワー/フォロー中の件数 |
| `location` | ユーザーが設定した所在地 |
| `url` | ユーザーの Web サイト |
| `protected` | 非公開アカウントのステータス |
| `pinned_tweet_id` | ピン留めした Post の ID |

---

## 認証要件

<Warning>
`/me` エンドポイントは User Context 認証が必要です。App-Only (Bearer Token) 認証はサポートされていません。
</Warning>

いずれかを利用してください:
- [OAuth 1.0a User Context](/resources/fundamentals/authentication)
- [OAuth 2.0 Authorization Code with PKCE](/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2)
