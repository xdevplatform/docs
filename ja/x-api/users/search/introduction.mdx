User Search エンドポイントでは、キーワードでユーザーを検索できます。名前、username、bio 内の内容でユーザーを見つけられます。

## 概要

<CardGroup cols={2}>
  <Card title="キーワード検索" icon="/icons/xds/icon-search.svg">
    名前、username、bio で検索
  </Card>
  <Card title="ユーザーを発見" icon="user-plus">
    関連するアカウントを見つける
  </Card>
</CardGroup>

---

## エンドポイント

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/search`](/x-api/users/search-users) | ユーザーを検索 |

---

## リクエスト例

```bash
curl "https://api.x.com/2/users/search?\
query=python%20developer&\
user.fields=description,verified,public_metrics" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

## レスポンス例

```json title="レスポンス例" lines wrap icon="/icons/xds/icon-brackets.svg"
{
  "data": [
    {
      "id": "1234567890",
      "name": "Python Developer",
      "username": "pythondev",
      "description": "Building cool things with Python",
      "verified": false,
      "public_metrics": {
        "followers_count": 5000,
        "following_count": 200,
        "tweet_count": 1500
      }
    }
  ],
  "meta": {
    "result_count": 1
  }
}
```
