このガイドでは、List にメンバーを追加・削除する手順を説明します。

<Note>
**前提条件**

始める前に、以下が必要です:
- 承認済みの App がある [developer account](https://developer.x.com/en/portal/petition/essential/basic-info)
- ユーザー Access Token (OAuth 1.0a または OAuth 2.0 PKCE)
- 自分が所有する List
</Note>

---

## List にメンバーを追加

<Steps>
  <Step title="List ID と user ID を取得">
    List の ID と、追加したい相手の user ID が必要です。user ID は [user lookup エンドポイント](/x-api/users/lookup/introduction) で確認できます。
  </Step>

  <Step title="メンバーを追加">

<CodeGroup dropdown>

```bash cURL
curl -X POST "https://api.x.com/2/lists/1441162269824405510/members" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"user_id": "2244994945"}'
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# List にメンバーを追加
response = client.lists.add_member(
    list_id="1441162269824405510",
    user_id="2244994945"
)

print(f"Is member: {response.data.is_member}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// List にメンバーを追加
const response = await client.lists.addMember("1441162269824405510", {
  userId: "2244994945",
});

console.log(`Is member: ${response.data?.is_member}`);
```

</CodeGroup>

  </Step>

  <Step title="レスポンスを確認">
    ```json
    {
      "data": {
        "is_member": true
      }
    }
    ```
  </Step>
</Steps>

## List からメンバーを削除

<CodeGroup dropdown>

```bash cURL
curl -X DELETE "https://api.x.com/2/lists/1441162269824405510/members/2244994945" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# List からメンバーを削除
response = client.lists.remove_member(
    list_id="1441162269824405510",
    user_id="2244994945"
)

print(f"Is member: {response.data.is_member}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// List からメンバーを削除
const response = await client.lists.removeMember(
  "1441162269824405510",
  "2244994945"
);

console.log(`Is member: ${response.data?.is_member}`);
```

</CodeGroup>

**レスポンス:**

```json
{
  "data": {
    "is_member": false
  }
}
```

## 重要なポイント

<Note>
- メンバーを管理できるのは自分が所有する List のみです
- List へのユーザー追加に、その相手の許可は必要ありません
- 公開 List に追加された場合、ユーザーはどの List に追加されたかを確認できます
</Note>
