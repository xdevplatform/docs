### Manage List members: Standard v1.1 と X API v2 の比較

これまで standard v1.1 の [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create) および [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy) エンドポイントを利用してきた方向けに、standard v1.1 と X API v2 の manage List members エンドポイントの類似点と相違点を理解するのに役立つことを目的としたガイドです。

* **類似点**
    * 認証
* **相違点**
    * エンドポイント URL
    * App と Project の要件
    * HTTP メソッド
    * レート制限
    * リクエストパラメータ

#### 類似点

**認証**

いずれのエンドポイントバージョンも [OAuth 1.0a User Context](https://developer.x.com/content/developer-twitter/resources/fundamentals/authentication) をサポートしています。したがって、以前 standard v1.1 の manage List member エンドポイントのいずれかを利用していた場合、X API v2 版へ移行しても同じ認証方式を継続して利用できます。

#### 相違点

**エンドポイント URL**

* Standard v1.1 エンドポイント:
    * POST https://api.x.com/1.1/lists/members/create.json
        (指定した List にメンバーを追加)
    * POST https://api.x.com/1.1/lists/members/destroy.json
        (指定した List からメンバーを削除)
* X API v2 エンドポイント:
    * POST https://api.x.com/2/lists/:id/members
        (指定した List にメンバーを追加)

    * DELETE https://api.x.com/2/lists/:id/members/:user_id
        (指定した List からメンバーを削除)

**レート制限**

| **Standard v1.1** | **X API v2** |
| :--- | :--- |
| /1.1/lists/members/create.json<br/><br/>なし | /2/lists/:id/members<br/><br/>OAuth 1.0a User Context で 15 分あたり 300 リクエスト<br/><br/>OAuth 2.0 Authorization Code with PKCE で 15 分あたり 300 リクエスト |
| /1.1/lists/members/destroy.json<br/><br/>なし | /2/lists/:id/members/:user_id<br/><br/>OAuth 1.0a User Context で 15 分あたり 300 リクエスト<br/><br/>OAuth 2.0 Authorization Code with PKCE で 15 分あたり 300 リクエスト |

**App と Project の要件**

X API v2 エンドポイントでは、リクエスト認証時に [Project](/resources/fundamentals/developer-apps) に紐づく [developer App](/resources/fundamentals/developer-apps) の認証情報の使用が必須です。すべての X API v1.1 エンドポイントは、App または Project に関連する App の認証情報を利用できます。

**リクエストパラメータ**

以下の standard v1.1 リクエストパラメータには X API v2 に相当するものがあります:

| **Standard v1.1** | **X API v2** |
| :--- | :--- |
| list_id | id  |
| slug | 相当なし |
| screen_name | 相当なし |
| owner\_screen\_name | 相当なし |
| owner_id | 相当なし |
