X Activity API が配信するイベント（[永続 HTTP ストリーム](/x-api/activity/activity-stream) または [webhook](/x-api/webhooks/introduction) 経由）は、共通のエンベロープを共有します。

| フィールド | 説明 |
| --- | --- |
| `event_uuid` | このイベント配信の一意な識別子 |
| `filter` | マッチしたフィルター（例：`user_id` または `keyword`） |
| `event_type` | 購読しているイベントタイプ |
| `tag` | 購読時に設定した任意のタグ（設定されている場合） |
| `payload` | イベント固有のデータ |
| `includes` | 利用可能な場合の展開オブジェクト（ユーザー、ツイートなど） |

```json
{
  "data": {
    "event_uuid": "2080388949189468542",
    "filter": {
      "user_id": "1830023695835787264"
    },
    "event_type": "post.create",
    "tag": "my post create",
    "payload": {},
    "includes": {}
  }
}
```

以下の例は、代表的な実際のペイロードです。フィールドの提供可否は、アカウント設定、展開、配信時点のオブジェクトの状態によって異なる場合があります。サポートされるイベントタイプと認証要件の全リストについては、[はじめに](/x-api/activity/introduction)を参照してください。

## Like イベント

### `like.create`

フィルター対象のユーザーが Post に「いいね」したとき、または自分の Post に「いいね」されたときに発火します。プライベートイベント — ユーザーコンテキスト認証が必要です。任意の `direction` フィルター（`inbound` または `outbound`）に対応しています。

`payload` は次のフィールドを持つ like オブジェクトです。

| フィールド | 説明 |
| --- | --- |
| `id` | いいねイベントの ID |
| `liked_tweet_id` | いいねされた Post の ID |
| `tweet_author_id` | いいねされた Post の作成者 |
| `created_at` | いいねされた Post の作成時刻（利用可能な場合） |
| `timestamp_ms` | イベントのタイムスタンプ（ミリ秒、利用可能な場合） |

### `dm.received`

フィルター対象のユーザーが暗号化されていない DM を受信したときに発火します。ペイロード形状は `dm.sent` と同じです（`direct_message_events` と `users` マップ）。プライベートイベント — ユーザーコンテキスト認証が必要です。

### `dm.read`

参加者がフィルター対象ユーザーの暗号化されていない DM を読んだとき（既読受信）に発火します。プライベートイベント — ユーザーコンテキスト認証が必要です。

### `dm.indicate_typing`

参加者がフィルター対象のユーザーへメッセージを入力しているときに発火します。プライベートイベント — ユーザーコンテキスト認証が必要です。

## News イベント

### `news.new`

Enterprise および Partner 限定。`keyword` でフィルタリングします。`payload` には Grok がキュレートしたニュースフィールドが含まれます。

| フィールド | 説明 |
| --- | --- |
| `category` | ニュースのカテゴリー |
| `headline` | 見出しのテキスト |
| `hook` | 短いフック / ティーザー |
| `summary` | より長い要約 |
