## X API の Filtered stream エンドポイントを比較する

v2 の Filtered stream エンドポイント群は、[standard v1.1 statuses/filter](https://developer.x.com/en/docs/x-api/v1/tweets/filter-realtime/api-reference/post-statuses-filter) と [PowerTrack API](/x-api/enterprise-gnip-2.0/powertrack-api) を置き換えます。旧バージョンの Filtered stream エンドポイントを使用したコード、アプリ、ツールをお持ちで、より新しい X API v2 エンドポイントへの移行を検討中の場合、この比較が出発点として役立ちます。

より詳細な移行ガイドは以下をご覧ください:

[Standard v1.1 から X API v2 への移行と比較](x-api/posts/filtered-stream#standard-v1-1-compared-to-x-api-v2)

[PowerTrack API から X API v2 への移行](/x-api/enterprise-gnip-2.0/powertrack-api#powertrack-operators)

以下の表は、X が提供する Filtered streaming エンドポイントを比較しています:

| :--- | :--- | :--- | :--- |
| アクセス | X App | Enterprise 契約とアカウントが必要 | 開発者アカウント([登録](https://developer.x.com/en/portal/petition/essential/basic-info))、および [Project](/resources/fundamentals/developer-apps) 内の [X App](/resources/fundamentals/developer-apps) が必要 |
| :--- | :--- | :--- | :--- |
| Host domain | **https://stream.x.com** | **https://gnip-stream.x.com** | **https://api.x.com** |

| [認証](/resources/fundamentals/authentication) | OAuth 1.0a User Context | HTTP Basic Authentication | OAuth 2.0 App-Only |
| サポートする HTTP メソッド | POST | GET  <br/>POST | GET  <br/>POST |

| [リカバリと冗長性機能](/x-api/fundamentals/recovery-and-redundancy) | なし | Backfill、冗長接続、Replay API |     |
| Keep-alive シグナル / ハートビート | 少なくとも 20 秒ごとに空行 (\\r\\n など) | 10 秒ごとに空行 (\\r\\n など) | 少なくとも 20 秒ごとに空行 (\\r\\n など) |
| レイテンシ | 10 秒 | 2 秒<br/><br/>URL アンワインディングエンリッチメント使用時は少なくとも 10 秒 | 10 秒 |
| 最大許容ルール数 | 1 ルール(エンドポイント接続リクエスト内) | 契約により決定、最大 250,000 | Pay-per-use: 1,000 ルール |
| ルールフィルターの制限 | 接続あたり 1 クエリ、最大で以下のいずれか:<br/><br/>\- 400 の track キーワード<br/><br/>\- 5000 の follow ユーザー ID<br/><br/>\- 25 の location box | ルールあたり最大 2,048 文字 | Pay-per-use: ルールあたり 1,024 文字 |
| [Post JSON フォーマット](/x-api/fundamentals/data-dictionary) | Standard v1.1 フォーマット | [Native Enriched](/x-api/enterprise-gnip-2.0/fundamentals/data-dictionary#native-enriched-tweet-object) または Activity Streams([コンソール](/x-api/enterprise-gnip-2.0/fundamentals/overview)で選択) | [X API v2 フォーマット](/x-api/fundamentals/data-dictionary)(**fields** および **expansions** リクエストパラメーターで決定、v1.1 フォーマットとは後方互換性なし)<br/><br/>Standard v1.1 フォーマットから X API v2 フォーマットへの移行方法については、[データフォーマット移行ガイド](/x-api/migrate/data-format-migration)を参照してください。Native Enriched と Activity Streams のデータフォーマット移行ガイドは近日中に公開予定です。 |
