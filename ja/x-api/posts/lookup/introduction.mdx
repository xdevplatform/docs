Post lookup エンドポイントを使用して、ID を指定して 1 件以上の投稿を取得できます。これらのエンドポイントを使うと、最新の投稿詳細を取得したり、投稿の利用可否を確認したり、編集履歴を確認したりできます。

## 概要

投稿は X の中核となるコンテンツです。各投稿には以下を含められます:
- 最大 280 文字のテキスト
- 添付メディア(画像、動画、GIF)
- Poll、場所、URL
- 返信、引用、メンション

投稿は作成から 30 分以内に最大 5 回まで編集でき、各編集は新しい投稿 ID を生成し、編集履歴は保持されます。

## ユースケース

- **投稿コンテンツの表示** — アプリで投稿詳細を表示
- **利用可否の確認** — 投稿がまだ存在するか、削除されたかを確認
- **コンプライアンス管理** — コンプライアンスイベント用に投稿の変更を追跡
- **アナリティクス** — 特定投稿のエンゲージメント指標を取得

---

## エンドポイント

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/tweets/:id`](/x-api/posts/get-post-by-id) | ID を指定して単一の投稿を取得 |
| GET | [`/2/tweets`](/x-api/posts/get-posts-by-ids) | ID を指定して複数の投稿を取得(最大 100 件) |
