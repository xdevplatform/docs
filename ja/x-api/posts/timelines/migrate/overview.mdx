## X API のタイムラインエンドポイントを比較する

v2 の逆時系列タイムライン、ユーザーの投稿タイムライン、およびユーザーのメンションタイムラインのエンドポイントは、それぞれ [v1.1 statuses/home_timeline,](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-home_timeline)、[v1.1 statuses/user_timeline](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-user_timeline.html)、および [v1.1 statuses/mentions_timeline](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-mentions_timeline.html) エンドポイントを置き換えます。このエンドポイントの旧バージョンを使用したコード、アプリ、ツールをお持ちで、より新しい X API v2 エンドポイントへの移行を検討中の場合、本ガイドが役立ちます。詳細な移行ガイドは [Standard v1.1 から X API v2 への移行](/x-api/posts/timelines/migrate/standard-to-twitter-api-v2)を参照してください。

このページには 3 つの比較表があります:

* 逆時系列ホームタイムライン
* ユーザーの投稿タイムライン
* ユーザーのメンションタイムライン

### 逆時系列ホームタイムライン

以下の表は standard v1.1 と X API v2 のホームタイムラインエンドポイントを比較しています:

|     |     |     |
| :--- | :--- | :--- |
| **Description** | **Standard v1.1** | **X API v2** |
| ドキュメント | [API リファレンス](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-home_timeline) | [API リファレンス](https://developer.x.com/x-api/posts/timelines#user-mention-timeline-3) |
| サポートする HTTP メソッド | `GET` | `GET` |
| Host domain | `https://api.x.com` | `https://api.x.com` |
| Endpoint paths | `/1.1/statuses/home_timeline.json` | `/2/users/:id/timelines/reverse_chronological` |
| 必須パラメーター | `user_id` または `screen_name` | パスパラメーター :id に設定されたユーザー ID |
| 認証 | OAuth 1.0a User Context | OAuth 1.0a User Context<br/><br/>[OAuth 2.0 Authorization Code Flow with PKCE](/fundamentals/authentication/oauth-2-0/authorization-code) |
| リクエストレート制限 | OAuth 1.0a User Context で 15 分あたり 15 リクエスト<br/><br/>リクエスト上限: 24 時間あたり 100,000 件。 | 15 分ウィンドウあたり 180 リクエスト |
| レスポンスあたりのデフォルト投稿数 | 15  | 100 |
| レスポンスあたりの最大投稿数 | 800 | このエンドポイントは、直近 7 日間にタイムライン上で作成されたすべての投稿と、作成日時にかかわらず最新 800 件を返します。 |
| 投稿の編集履歴を提供 | ✔   | ✔   |
| 利用可能な履歴投稿 | 最新 800 件の投稿(Retweet を含む) | 最新 3,200 件の投稿(Retweet を含む) |
| タイムラインナビゲーションオプション | since_id(排他的)、更新ポーリング用<br/><br/>`max_id`(包含的) | `start_time`<br/><br/>end_time<br/><br/>`since_id`(排他的)、更新ポーリング用<br/><br/>`until_id`(排他的) |
| 結果精緻化用のオプションパラメーター | `count`<br/><br/>`exclude_replies`<br/><br/>`include_rts`<br/><br/>`trim_user`<br/><br/>`tweet_mode`<br/><br/>`since_id`<br/><br/>`max_id` | `max_results`<br/><br/>`exclude`(retweets,replies)<br/><br/>`tweet.fields`<br/><br/>`user.fields`<br/><br/>`place.fields`<br/><br/>`media.fields`<br/><br/>`poll.fields`<br/><br/>`expansions`<br/><br/>`start_time`<br/><br/>`end_time`<br/><br/>`since_id`<br/><br/>`until_id` |
| [annotations](/x-api/fundamentals/post-annotations) のリクエストと受信をサポート | N/A | tweet.fields に annotations が含まれる場合、結果は投稿テキストに基づく推論された annotation データ('Music Genre' と 'Folk Music'、'Musician' と 'Dolly Parton' など)で注釈されます |
| 特定の Post [メトリクス](/x-api/fundamentals/metrics)のリクエストと受信をサポート | N/A | `tweet.fields` に annotations が含まれる場合、結果は Post ごとに public_metrics(`retweet_count`、`reply_count`、`quote_count`、`like_count`、`impression_count`、`bookmark_count` を含む)、non_public_metrics(`impression_count`、`user_profile_clicks`、`url_link_clicks`、`engagements` を含む)で注釈されます。<br/><br/>view_count や動画再生メトリクスなどの追加メディアメトリクス。<br/><br/>プロモート投稿の場合、User Context で追加の organic\_metrics と promoted\_metrics が利用可能。 |
| [conversation_id](/x-api/fundamentals/conversation-id) のリクエストと受信をサポート | N/A | 値が返信スレッドで最初に公開された投稿を表す conversation_id フィールドを返し、会話の追跡を支援します。 |
| Post JSON フォーマット | [Standard v1.1 データフォーマット](https://developer.x.com/en/docs/twitter-api/v1/data-dictionary/overview.html) | [X API v2](/x-api/fundamentals/data-dictionary) フォーマット(fields と expansions リクエストパラメーターで決定、v1.1 フォーマットとは後方互換性なし)<br/><br/>Standard v1.1 フォーマットから X API v2 フォーマットへの移行方法については、[データフォーマット移行ガイド](/x-api/migrate/data-format-migration)を参照してください。 |
| 結果順 | 逆時系列 | 逆時系列 |
| 結果ページネーション | N/A、Post ID による移動を使用する必要あり | pagination_token を使用して結果を前後に移動可能 |
| [Project](/resources/fundamentals/developer-apps) に紐づく[開発者 App](/resources/fundamentals/developer-apps) の認証情報が必要 |     | ✔   |
