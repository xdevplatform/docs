Timelines エンドポイントを使用すると、ユーザーのタイムライン、メンションフィード、ホームフィードから投稿を取得できます。ユーザーが投稿したコンテンツを取得したり、そのユーザーに対するメンションを表示したり、パーソナライズされたホームタイムラインを表示したりできます。

## エンドポイント

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/tweets`](/x-api/users/get-posts) | ユーザーの投稿を取得 |
| GET | [`/2/users/:id/mentions`](/x-api/users/get-mentions) | ユーザーをメンションする投稿を取得 |
| GET | [`/2/users/:id/timelines/reverse_chronological`](/x-api/users/get-timeline) | ホームタイムラインを取得 |

---

## ユーザーの投稿タイムライン

特定ユーザーが作成した最新の投稿を取得します。

### 特徴

- 最新 3,200 件までの投稿
- 返信や retweet の除外
- ページネーションサポート
- 時間ベースフィルタリングによる履歴アクセス

## 逆時系列ホームタイムライン

認証ユーザーのホームタイムラインを逆時系列順で取得します。

### 特徴

- フォロー中アカウントからの投稿
- 最新 3,200 件(または 7 日間)
- アルゴリズムランキングを除外
- ユーザー認証が必要

<Note>
このエンドポイントには [OAuth 1.0a User Context](/resources/fundamentals/authentication) または [OAuth 2.0 Authorization Code with PKCE](/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) が必要です。
</Note>

## フィルタリングオプション

### Exclude パラメーター

特定の投稿タイプを除外します:

| Value | Effect |
|:------|:-------|
| `retweets` | retweet を除外 |
| `replies` | reply を除外 |

```bash
curl "https://api.x.com/2/users/123/tweets?exclude=retweets,replies" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

### 時間ベースのフィルタリング

| Parameter | Description |
|:----------|:------------|
| `start_time` | 最も古い投稿タイムスタンプ (ISO 8601) |
| `end_time` | 最も新しい投稿タイムスタンプ (ISO 8601) |
| `since_id` | この ID より後の投稿を返す |
| `until_id` | この ID より前の投稿を返す |
