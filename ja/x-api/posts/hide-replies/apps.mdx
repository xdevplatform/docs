## hide replies エンドポイントを使用するアプリ

以下は、hide replies エンドポイントを統合した開発者が構築した注目すべきアプリのコレクションです。彼らは自らのテクノロジーと X API を組み合わせ、すべてのユーザーが公開会話を高めるのに役立つ有用な体験を作り出しています。

 ![Clarabridge](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/clarabridge.jpg.twimg.1920.jpg)

**Clarabridge**

Clarabridge は hide replies を統合し、企業が X フィードをクリーンで読みやすく保てるようにします。返信を手動で非表示にでき、エージェントは Clarabridge のテキスト分析を使って、暴言やブランドポリシーに合わない言葉を自動的に検出することもできます。

[サイトへ ▸](https://www.clarabridge.com/ "サイトへ ▸")

[X の Clarabridge](https://x.com/Clarabridge "X の Clarabridge")

 ![Perspective API テンプレートアプリ](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/perspective-logo.png.twimg.1920.png)

**Perspective API テンプレートアプリ**

Perspective は、有害なコメントを検出するために Jigsaw(Alphabet 内のユニット)がトレーニングした AI です。このアプリは、着信する返信を検出し、Perspective が過去に見た有害コメントとどの程度似ているかを示す「スコア」に基づいて返信を自動的に非表示にします。これは X が開発したオープンソースのテンプレートアプリです。ユーザー向けのツールを構築するためにカスタマイズしてご利用ください。

[アプリを使う ▸](https://quintessential-yoke.glitch.me "アプリを使う ▸")

[X の Jigsaw](https://x.com/jigsaw "X の Jigsaw")

**Reshuffle**

Reshuffle は、ビジネスアプリケーションを柔軟なスクリプトで接続するプラットフォームです。定義したキーワードを含む返信を検出して非表示にする統合スクリプトを構築しました。試すには、Hide replies が有効な有効な App があることを確認し、リポジトリの指示に従ってください。

[アプリへ ▸](https://github.com/reshufflehq/reshuffle "アプリへ ▸")

[X の Reshuffle](https://x.com/reshufflehq "X の Reshuffle")

 ![Hide unwanted replies](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 396 397%22%3E%3C/svg%3E)

**Hide unwanted replies**

人気アプリ QuotedReplies の開発者である Dara Oladosu は、過去にミュートした特定のキーワードを含む返信など、乱暴な振る舞いをする可能性がより高いと自ら判断した基準に該当する返信を自動的に非表示にするアプリを構築しました。

**Pandaflow**
