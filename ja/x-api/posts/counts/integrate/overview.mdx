このページでは、Post counts エンドポイントを統合するためのツールと重要な概念を扱います。

## 役立つツール

主要な概念に入る前に、これらのエンドポイントの機能をテストできる次のツールやコードサンプルの利用をお勧めします。

### コードサンプル

お好みのプログラミング言語でこれらのエンドポイントをセットアップしてみませんか?[GitHub ページ](https://github.com/xdevplatform/Twitter-API-v2-sample-code)には、出発点として利用できるさまざまなコードサンプル([Python クライアント](https://github.com/xdevplatform/search-tweets-python)を含む)を公開しています。

### ライブラリ

コミュニティによる多数の[サードパーティ製ライブラリ](/tools-and-libraries)を活用して開発を始められます。適切なバージョンタグを探すことで、v2 エンドポイントに対応したライブラリを見つけられます。

### Postman

Postman はこれらのエンドポイントをテストするのに最適なツールです。各 Postman リクエストにはエンドポイントのすべてのパラメーターが含まれており、利用可能なオプションを素早く把握するのに役立ちます。当社の Postman コレクションについて詳しくは、[Postman を使う](/tutorials/postman-getting-started)ページをご覧ください。

## 重要な概念

### 認証

すべての X API v2 エンドポイントは、キーとトークン(認証情報)のセットで[認証](/resources/fundamentals/authentication)されたリクエストを必要とします。このエンドポイントでは [OAuth 2.0 Bearer Token](/resources/fundamentals/authentication#oauth-2-0) の使用が必須です。つまり、リクエストを成功させるには [Bearer Token](/resources/fundamentals/authentication#bearer-token-also-known-as-app-only) を渡す必要があります。Bearer Token は開発者 App から直接生成することも、[POST oauth2/token](/resources/fundamentals/authentication#post-oauth2-token) エンドポイントを用いて生成することもできます。

### Developer Console、Project、開発者 App

X API v2 エンドポイントを利用するには、[開発者アカウント](/resources/fundamentals/developer-portal)を所有し、そのアカウント内に [Project](/resources/fundamentals/developer-apps) を設定し、その Project 内に[開発者 App](/resources/fundamentals/developer-apps) を作成する必要があります。その開発者 App のキーとトークンは recent Post counts エンドポイントで利用できます。full-archive Post counts エンドポイントを利用したい場合や、advanced 演算子・より長いクエリ長を使いたい場合は、Enterprise アクセスの承認を受ける必要があります。

詳細は Enterprise アクセスに関するセクションをご覧ください。

### レート制限

毎日、数千人の開発者が X API にリクエストを送信しています。そのボリュームを管理するため、各エンドポイントには[レート制限](/x-api/fundamentals/rate-limits)が設定されており、App または認証済みユーザーの代理として送信できるリクエスト数が制限されています。

このエンドポイントは App レベルでレート制限されます。つまり、開発者は特定の App(使用中の認証情報から特定される)を通じて、一定期間内にこのエンドポイントへ送信できるリクエスト数に制限があります。

### クエリの構築

これらのエンドポイントの中核的な特徴は、単一のクエリを使用して投稿をフィルタリングし、件数として返す点です。クエリは、メッセージのキーワード、ハッシュタグ、URL など、投稿とユーザーの属性に一致する演算子で構成されます。演算子はブールロジックと括弧で組み合わせて、クエリの一致挙動をより詳細に調整できます。

詳細は[クエリを組み立てる方法](/x-api/posts/counts/integrate/build-a-query)のガイドをご覧ください。

### ページネーション

recent Post counts では next_token は返されません。つまり、granularity にかかわらず、直近 7 日間の投稿ボリュームを 1 回の API 呼び出しで取得できます。

full-archive Post counts では、直近 30 日間のデータが取得できます。30 日を超えるデータを取得するには next_token が返され、それを使ってページネーションを行い追加のデータを取得できます。
