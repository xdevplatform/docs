このページでは、Powerstream 固有のリカバリと冗長性機能について説明します。すべてのストリーミングエンドポイントにまたがるリカバリと冗長性に関する包括的なガイダンスについては、[リカバリと冗長性の基礎ガイド](/x-api/fundamentals/recovery-and-redundancy)を参照してください。

## Powerstream のリカバリ機能

リカバリと冗長性のコアコンセプトは、すべてのストリーミングエンドポイントに適用されます。次の内容は基礎ガイドを参照してください:

- 冗長接続
- Backfill と Recovery の判断ツリー
- ベストプラクティス

## Backfill

**5 分以下**の切断には、`backfillMinutes` パラメーターを使用します:

```bash
curl 'https://api.x.com/2/powerstream?backfillMinutes=5' \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

<Note>
古い Post から先に配信されます。Post は重複排除**されない**ため、システムは重複を許容する必要があります。
</Note>

## Recovery

**5 分より長い**切断(最大 24 時間)には、`startTime` および `endTime` パラメーターを使用します:

| Parameter | Type | 説明 |
|:----------|:-----|:------------|
| `startTime` | ISO 8601 date | リカバリ開始時刻 (UTC) |
| `endTime` | ISO 8601 date | リカバリ終了時刻 (UTC) |

```bash
curl 'https://api.x.com/2/powerstream?startTime=2022-07-12T15:10:00Z&endTime=2022-07-12T15:20:00Z' \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

接続されると、Recovery は指定された期間を再ストリーミングした後、切断します。
