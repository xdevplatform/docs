## X 上の人々のために構築する方法

私たちは、公共の会話にポジティブな影響を与え、X 上の人々に役立つ新しいツールや製品を構築していただくため、プラットフォームを開放しています。特に、次の領域で新しいイノベーションと開発を推奨したいと考えています。

<CardGroup>
  <Card title="健全性と安全性のために会話をモデレーションする" icon="bullhorn" iconType="solid">
  公共の会話の健全性と安全性を向上させましょう。人々が安心して、X への参加にワクワクできるよう、コンテンツモデレーションツールをはじめとしたソリューションを構築してください。人々が自身のイン(体験)をコントロールするための総合的な選択肢を提供する補完的な技術を作りましょう。

  [**詳細を見る**](/x-api/what-to-build#moderate-conversations-for-health-and-safety) <Icon icon="/icons/xds/icon-arrow-right.svg"/>
  </Card>

  <Card title="クリエイションと自己表現を可能にする" icon="bullhorn" iconType="solid">
  リーチを広げ、ブランドを表現し、情熱を共有する人々とつながりたいクリエイター、ブランド、個人向けのツールを構築しましょう。あるいは、クロスポストコンテンツ、ゲーミフィケーション、便利なボットなど、X 上での人々のエンゲージ方法を広げましょう。

  [**詳細を見る**](/x-api/what-to-build#enable-creation-and-personal-expression) <Icon icon="/icons/xds/icon-arrow-right.svg"/>
  </Card>

  <Card title="「今何が起きているか」を計測・分析する" icon="bullhorn" iconType="solid">
  人々が公共の会話や自身のコンテンツを計測、分析し、インサイトを導き出すのを支援します。オーディエンスをより深く理解し、コンテンツのパフォーマンスとインパクトを測定し、より情報に基づいた意思決定を行うなど、多くのことを実現できます。

  [**詳細を見る**](/x-api/what-to-build#measure-and-analyze-whats-happening) <Icon icon="/icons/xds/icon-arrow-right.svg"/>
  </Card>
  <Card title="コミュニティ体験を向上する" icon="bullhorn" iconType="solid">
  X は誰のためのプラットフォームでもあり、私たちはあなたの専門知識を、X 上のさまざまなコミュニティの独自ニーズに役立てることを後押ししたいと考えています。新興グローバル市場向けにローカライズされたソリューションを構築する場合でも、ゲームや金融などのコミュニティ体験を強化する場合でも、皆さんが X で自分の居場所を見つけられるようにしたいのです。

  [**詳細を見る**](/x-api/what-to-build#improve-community-experiences) <Icon icon="/icons/xds/icon-arrow-right.svg"/>
  </Card>
  <Card title="コンテンツをキュレーション・レコメンドする" icon="bullhorn" iconType="solid">
  新しいコンテンツの発見や新しいつながりを人々にもたらすアプリ、ボット、その他のツールを構築しましょう。あるいは、人々が最も関心のあるコンテンツをより多く見られるように、キュレーションされたカスタマイズ可能な体験を構築しましょう。

  [**詳細を見る**](/x-api/what-to-build#curate-and-recommend-content) <Icon icon="/icons/xds/icon-arrow-right.svg"/>
  </Card>
  <Card title="公益にインパクトを与える" icon="bullhorn" iconType="solid">
  画期的な研究を行い、公衆衛生や気候危機に関する知識の発展を後押しし、非商用で公益のために構築しましょう。

  [**詳細を見る**](/x-api/what-to-build#impact-the-greater-good) <Icon icon="/icons/xds/icon-arrow-right.svg"/>
  </Card>
</CardGroup>
