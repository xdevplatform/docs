## 教育者

X API を教室に取り入れて、学生にプログラミングの基礎と価値あるデータ処理スキルを教えましょう。

**リソース:**

コースで X API の活用をご検討中の教育者の方はいますか? この[X API を用いた指導ガイド](https://dev.to/suhemparack/a-guide-to-teaching-with-the-twitter-api-v2-3n08)は、X API、教育者に使われている理由、API を用いて教えられている授業の種類、そして始めるにあたって知っておくべきすべての事柄を理解するのに役立ちます。

**スポットライト:**

以下のカリキュラムは、X API v2 を用いて構築・実施されています。

- Dr. Tanu Mitra による [Social Media Data Mining and Analysis](https://canvas.uw.edu/courses/1434897)

- Dr. Chris Bail による [Data Science & Society](https://dssoc.github.io/)

- Dr. Melanie Walsh による [Introduction to Cultural Analytics & Python](https://melaniewalsh.github.io/Intro-Cultural-Analytics/welcome.html)

- Dr. Chris Barrie による [Oxford Spring School in Advanced Research Methods, Analysing X Data](https://github.com/cjbarrie/oxspsch)
