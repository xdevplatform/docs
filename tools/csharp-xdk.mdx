The [C# / .NET XDK](https://github.com/xdevplatform/xdk-csharp) (`XDevPlatform.Xdk` on NuGet) is the official .NET client library for the X API v2, targeting .NET 8+ with zero external runtime dependencies (`System.Net.Http` and `System.Text.Json`), `CancellationToken` support on every call, `Paginator<T>`, and `EventStream<T>`.

## Installation

<CodeGroup>

```bash .NET CLI
dotnet add package XDevPlatform.Xdk
```

```xml PackageReference
<ItemGroup>
  <PackageReference Include="XDevPlatform.Xdk" Version="0.1.2" />
</ItemGroup>
```

</CodeGroup>

Requires .NET 8.0+.

---

## Quick start

```csharp
using System;
using Xdk;

using var client = new XClient(new XClientOptions
{
    BearerToken = Environment.GetEnvironmentVariable("X_BEARER_TOKEN"),
});

var user = await client.Users.GetByUsernameAsync("XDevelopers");
Console.WriteLine(user.Data);
```

  <Tab title="OAuth 2.0 PKCE">
```csharp
using System;
using Xdk;
using Xdk.Auth;

var oauth2 = new OAuth2Pkce(
    clientId: Environment.GetEnvironmentVariable("X_CLIENT_ID")!,
    clientSecret: Environment.GetEnvironmentVariable("X_CLIENT_SECRET"),
    redirectUri: "http://localhost:8080/callback",
    scopes: new[] { "tweet.read", "tweet.write", "users.read", "offline.access" }
);

string authUrl = oauth2.GetAuthorizationUrl("state-token");
OAuth2Token token = await oauth2.ExchangeCodeAsync(authCode);

using var client = new XClient(new XClientOptions { OAuth2 = oauth2 });
```
  </Tab>
  <Tab title="OAuth 1.0a">
```csharp
using System;
using Xdk;
using Xdk.Auth;

var oauth1 = new OAuth1(
    apiKey: Environment.GetEnvironmentVariable("X_API_KEY")!,
    apiSecret: Environment.GetEnvironmentVariable("X_API_SECRET")!,
    callback: "oob",
    accessToken: Environment.GetEnvironmentVariable("X_ACCESS_TOKEN"),
    accessTokenSecret: Environment.GetEnvironmentVariable("X_ACCESS_TOKEN_SECRET")
);

using var client = new XClient(new XClientOptions { OAuth1 = oauth1 });
```

## Common methods

| Category | Method |
|:---------|:-------|
| **Posts** | `client.Posts.SearchRecentPages(query, opts)`, `client.Posts.CreateAsync(body)` |
| **Users** | `client.Users.GetMeAsync()`, `client.Users.GetByUsernameAsync(username)` |
| **Streams** | `client.Stream.PostsStream()`, `client.Stream.PostsSampleStream()` |
| **Spaces** | `client.Spaces.GetByIdAsync(id)` |
| **Lists** | `client.Lists.GetByIdAsync(id)` |
| **Direct Messages** | `client.DirectMessages.GetEventsPages()` |
