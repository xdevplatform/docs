## Installation

<CodeGroup>

```xml Maven
<dependency>
  <groupId>com.x</groupId>
  <artifactId>xdk</artifactId>
  <version>0.2.0</version>
</dependency>
```

```kotlin Gradle (Kotlin DSL)
dependencies {
    implementation("com.x:xdk:0.2.0")
}
```

```groovy Gradle (Groovy)
dependencies {
    implementation 'com.x:xdk:0.2.0'
}
```

</CodeGroup>

Requires JDK 17+.

## Quick start

```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();

var user = client.users().getByUsername("XDevelopers");
System.out.println(user.getData());
```

## Authentication

<Tabs>
  <Tab title="Bearer Token">
```java
import com.x.xdk.XClient;

XClient client = XClient.builder()
    .bearerToken(System.getenv("X_BEARER_TOKEN"))
    .build();
```
  </Tab>
  <Tab title="OAuth 2.0 PKCE">
```java
import com.x.xdk.XClient;
import com.x.xdk.auth.OAuth2Pkce;
import com.x.xdk.auth.OAuth2Token;
import java.util.List;

OAuth2Pkce oauth2 = new OAuth2Pkce(
    System.getenv("X_CLIENT_ID"),
    System.getenv("X_CLIENT_SECRET"),
    "http://localhost:8080/callback",
    List.of("tweet.read", "tweet.write", "users.read", "offline.access")
);

String authUrl = oauth2.getAuthorizationUrl("state-token");
OAuth2Token token = oauth2.exchangeCode(authCode);

XClient client = XClient.builder().oauth2(oauth2).build();
```
  </Tab>
  <Tab title="OAuth 1.0a">
```java
import com.x.xdk.XClient;
import com.x.xdk.auth.OAuth1;

OAuth1 oauth1 = new OAuth1(
    System.getenv("X_API_KEY"),
    System.getenv("X_API_SECRET"),
    "oob",
    System.getenv("X_ACCESS_TOKEN"),
    System.getenv("X_ACCESS_TOKEN_SECRET")
);

XClient client = XClient.builder().oauth1(oauth1).build();
```

## Common methods

| Category | Method |
|:---------|:-------|
| **Posts** | `client.posts().searchRecentPages(query, opts)`, `client.posts().create(body)` |
| **Users** | `client.users().getMe()`, `client.users().getByUsername(username)` |
| **Streams** | `client.stream().posts()`, `client.stream().postsSample()` |
| **Spaces** | `client.spaces().getById(id)` |
| **Lists** | `client.lists().getById(id)` |
| **Direct Messages** | `client.directMessages().getEventsPages()` |
