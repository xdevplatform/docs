## Referencia rápida

### Estructura de la respuesta

Todas las respuestas de v2 siguen esta estructura:

```json
{
  "data": { ... },      // Objeto(s) principal(es)
  "includes": { ... },  // Objetos expandidos (si se solicitan)
  "meta": { ... },      // Información de paginación
  "errors": [ ... ]     // Errores parciales (si los hay)
}
```

### Parámetros comunes

| Parámetro | Uso |
|:----------|:----|
| `tweet.fields` | Solicita campos específicos de post |
| `user.fields` | Solicita campos específicos de usuario |
| `expansions` | Incluir objetos relacionados |
| `max_results` | Limitar resultados por página |
| `pagination_token` | Obtener página siguiente/anterior |

### Métodos de autenticación

| Método | Caso de uso |
|:-------|:---------|
| Bearer Token | Datos públicos de solo lectura |
| OAuth 2.0 | Acciones de usuario con scopes granulares |
| OAuth 1.0a | Acciones de usuario (legacy, permisos completos) |

[Guía completa de autenticación →](/resources/fundamentals/authentication/overview)
