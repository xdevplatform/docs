Opciones de solicitud para las llamadas a la API

## Propiedades

<ParamField name="timeout" type="number">
Tiempo de espera de la solicitud en milisegundos

</ParamField>

<ParamField name="headers" type="Record&lt;string, string&gt;">
Encabezados adicionales

</ParamField>

<ParamField name="signal" type="AbortSignal">
Señal de solicitud para cancelación

</ParamField>

<ParamField name="body" type="string">
Cuerpo de la solicitud

</ParamField>

<ParamField name="raw" type="boolean">
Devolver el envoltorio HTTP sin procesar en lugar del cuerpo analizado

</ParamField>

<ParamField name="security" type="Record&lt;string, string[]&gt;[]">
Requisitos de seguridad para el endpoint (de la especificación OpenAPI): se usan para la selección inteligente de autenticación

</ParamField>
