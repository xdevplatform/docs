Interfaz de respuesta paginada

Representa la estructura de una respuesta paginada de la API desde la X API.

## Parámetros de tipo

| Nombre | Descripción |
| :------ | :------ |
| `T` | El tipo de elementos en la respuesta |

## Propiedades

<ResponseField name="data" type="T[]" required>
Array de elementos en la página actual

</ResponseField>

<ResponseField name="meta" type="Object">
Metadatos de paginación

<Expandable title="propiedades">
<ResponseField name="Name" type="Type | Description" required>
</ResponseField>

<ResponseField name="resultCount" type="number | Number of results in the current page">
</ResponseField>

<ResponseField name="nextToken" type="string | Token for fetching the next page">
</ResponseField>

<ResponseField name="previousToken" type="string | Token for fetching the previous page">
</ResponseField>
</Expandable>
</ResponseField>

<ResponseField name="includes" type="Record&lt;string, any&gt;">
Objetos incluidos adicionales (usuarios, tweets, etc.)

</ResponseField>

<ResponseField name="errors" type="any[]">
Cualquier error en la respuesta

</ResponseField>
