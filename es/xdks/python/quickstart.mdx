Este ejemplo muestra cómo buscar Posts rápidamente usando el XDK con autenticación de Bearer Token.
## Paso 1: Instala el SDK
```bash
pip install xdk
```
## Paso 2: Obtén tu Bearer Token
1. Inicia sesión en la [X Developer Console](https://developer.x.com/en/portal/dashboard).
2. Crea o selecciona una app.
3. En "Keys and Tokens", genera un Bearer Token (autenticación app-only).
## Paso 3: Escribe y ejecuta tu primer script
Crea un archivo `quickstart.py`:
```python title="Example" lines wrap icon="python"
# Import the client
from xdk import Client
# Replace with your actual Bearer Token
client = Client(bearer_token="YOUR_BEARER_TOKEN_HERE")
# Fetch recent Posts mentioning "api"
# search_recent returns an Iterator, so iterate over it
for page in client.posts.search_recent(query="api", max_results=10):
    if page.data and len(page.data) > 0:
        # Access first Post - Pydantic models support both attribute and dict access
        first_post = page.data[0]
        post_text = first_post.text if hasattr(first_post, 'text') else first_post.get('text', '')
        print(f"Latest Post: {post_text}")
        break
    else:
        print("No Posts found.")
        break
```
Ejecútalo:
```bash
python quickstart.py
```
**Salida esperada**:
```
Latest Post: Exciting updates on XDK Python SDK!
```
**Solución de problemas**: Si obtienes un error 401, verifica tu Bearer Token. Para rate limits (429), espera y reintenta.
