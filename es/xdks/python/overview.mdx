El Python XDK (X Developer Kit) es nuestra biblioteca cliente oficial para interactuar con la X API v2 usando Python. Permite a los desarrolladores comenzar rápidamente con nuestra API y construir aplicaciones sobre ella. Se genera a partir de nuestra [especificación OpenAPI](https://api.x.com/2/openapi.json) oficial. Abstrae los detalles HTTP de bajo nivel y, al mismo tiempo, ofrece control detallado cuando se necesita.
## Características principales
- 🔐 **Soporte de OAuth**: Soporte completo para autenticación con Bearer Token (app-only), OAuth 2.0 con PKCE (contexto de usuario) y OAuth 1.0.
- 🔄 **Paginación**: Recorre automáticamente resultados grandes. El XDK se encarga de la paginación sin que tengas que hacer múltiples llamadas a la API usando el `next_token`.
- 📡 **Streaming**: Admite streaming de datos en tiempo real para endpoints como filtered stream, que requieren una conexión http persistente.
- 🎯 **Cobertura integral**: Admite todos los endpoints de la X API v2, incluidos búsqueda, timelines, filtered-stream y más.
**Compatibilidad de versiones**: Python 3.8+. Probado en CPython y PyPy.
