Cursor-based pagination utilities for the X API SDK.

This module provides a Cursor class for elegant pagination support across
all API clients. The Cursor enables easy iteration over paginated results
using both .pages() and .items() methods with proper type safety.

### `xdk.paginator.cursor`

Crea un cursor con inferencia y validación de tipos adecuadas.
Esta función factory ayuda con la inferencia de tipos para que obtengas
sugerencias de tipo adecuadas para el tipo de respuesta, y valida que el método
admita paginación tanto en análisis estático como en tiempo de ejecución.
