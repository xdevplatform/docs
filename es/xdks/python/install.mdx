El SDK del XDK para Python está disponible directamente desde el repositorio de GitHub y se puede instalar mediante `pip`.
## Requisitos previos
- Python 3.8 o superior.
- `pip` y `venv` para entornos virtuales (recomendado).
## Instalación rápida
Instala el XDK desde el subdirectorio de GitHub:
```bash
pip install xdk
```
Esto obtiene la última versión generada desde la rama `main`.
## Instalación para desarrollo
Para desarrollo o para contribuir:
1. Clona el repositorio:
   ```bash
   git clone https://github.com/xdevplatform/xdk.git
   cd xdk/python
   ```
2. Instala las dependencias en modo editable:
   ```bash
   pip install -e .
   ```
   Esto instala el SDK y sus dependencias de ejecución.
3. (Opcional) Instala las dependencias de desarrollo para pruebas/linting:
   ```bash
   pip install -e .[dev]
   ```
## Verificación
Prueba la instalación:
```python
import xdk
print(xdk.__version__)  # Should print the XDK version
```
**Nota:** Como el XDK se genera a partir de la especificación OpenAPI, revisa siempre el [changelog de la X API](https://docs.x.com/changelog) y las notas de versión del XDK en el repositorio para conocer cualquier cambio.
Para ejemplos de código detallados usando el Python XDK, consulta nuestro [repositorio de ejemplos de código en GitHub](https://github.com/xdevplatform/samples/tree/main/python).
