El sandbox es un entorno para que pruebes y construyas tu implementación de la Ads API.

Las campañas creadas a través del sandbox no se servirán a los usuarios y se pueden crear registros de prueba para objetos como Funding Instruments de forma dinámica.

Usar el sandbox es tan simple como llamar al hostname apropiado ads-api-sandbox.x.com, pero también contiene funcionalidades únicas que solo se encuentran en el sandbox.

Haz una solicitud inicial a [POST accounts](/x-ads-api/campaign-management/reference#post-accounts) para crear una nueva cuenta de anunciante. La respuesta de esta llamada contendrá un account_id que se puede usar en solicitudes posteriores. Estos endpoints permiten a los consumidores crear y probar contra múltiples cuentas de anunciante.

### Lista de endpoints solo del Sandbox:

* [POST accounts](/x-ads-api/campaign-management/reference#post-accounts) Crea una cuenta en el sandbox
* [POST accounts/:account_id/features](/x-ads-api/campaign-management/reference#post-accounts-account-id-features) Añade una feature de cuenta a una cuenta en el sandbox
* [POST accounts/:account\_id/funding\_instruments](/x-ads-api/campaign-management/reference#post-accounts-account-id-funding-instruments) Añade un funding instrument a una cuenta en el sandbox
* [DELETE accounts/:account_id](/x-ads-api/campaign-management/reference#delete-accounts-account-id) Elimina una cuenta en el sandbox
* [DELETE accounts/:account_id/features](/x-ads-api/campaign-management/reference#delete-accounts-account-id-features) Elimina una feature de cuenta de una cuenta en el sandbox
* [DELETE accounts/:account\_id/funding\_instruments/:funding\_instrument\_id](/x-ads-api/campaign-management/reference#delete-accounts-account-id-funding-instruments-funding-instrument-id) Elimina un funding instrument de una cuenta en el sandbox
