## Descripción general

La Catalog API es una solución de comercio que ofrece a los anunciantes la capacidad de configurar feeds de productos, agrupar productos en sets y gestionar de forma integral los productos del catálogo. La Catalog API permite la gestión programática del catálogo y otorga a los anunciantes más control sobre cómo se ingieren y actualizan sus catálogos.

Un catálogo contiene todo lo relativo al producto y product set del usuario y está asociado al handle del usuario. **Actualmente, un usuario solo puede crear un catálogo.**

La Catalog API admite dos formas de ingerir productos:

1. **Scheduled Feed**: añade una URL de feed (CSV, TSV o XML) que se recuperará periódicamente. X admite archivos de hasta 8GB.
2. **Batch Products API**: consulta, crea, actualiza y elimina atributos de productos con solicitudes por lotes (JSON).

Los merchants de X pueden crear product sets basados en reglas de filtro. Esto permite adjuntar metadatos adicionales a los productos y crear product sets especiales para funcionalidades de comercio orgánico o Dynamic Product Ads. La Catalog API y X Shopping Manager admiten dos tipos de product sets:

1. **Manual**: selecciona hasta 50 productos y establece un nombre y una descripción.
2. **Filter**: añade hasta 30 filtros para generar sets automáticamente (precio, categoría de producto de Google, tipo de producto, inventario, precio en oferta, campos personalizados, etc.).

### Requisitos previos

Los endpoints de la Catalog API están disponibles actualmente solo mediante **acceso anticipado**. Para solicitar acceso, contacta con tu representante de X o rellena el formulario correspondiente.

Debes aceptar los términos del servicio a través del [X Shopping Manager](https://ads.x.com/shopping_manager).

Para especificaciones de productos y detalles de Shopping Manager, consulta la [Guía de especificaciones de productos](https://business.x.com/en/help/shopping-specs.html).
