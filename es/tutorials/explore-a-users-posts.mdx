## Introducción

 Mientras que el [endpoint recent search](/x-api/posts/search/introduction) solo te permite obtener Posts publicados en los últimos 7 días, los endpoints de timeline de Posts de usuario y timeline de menciones de usuario te permiten recuperar Posts y menciones más antiguos que los últimos 7 días, para un usuario autorizado (usando el user ID). Los desarrolladores pueden usar estos endpoints para estudiar temas, entidades y sentimiento de los Posts del timeline o menciones de un usuario. En este tutorial te mostraremos cómo explorar los Posts y menciones de un usuario usando los endpoints user Tweet timeline y user mention timeline.
 

## Requisitos previos

*   Para usar los endpoints user Tweet timeline y user mention timeline, necesitarás tener una cuenta de desarrollador válida. 
*   También necesitarás un [Project](/resources/fundamentals/developer-apps) creado.
*   Debes haberte [registrado](https://developer.x.com/en/portal/petition/essential/basic-info) para una cuenta de desarrollador y haber activado la [nueva experiencia de Developer Console](https://developer.x.com/en/portal/opt-in.html). 
*   El acceso está disponible con claves y tokens activos para una App de desarrollador que esté asociada a un [Project](/resources/fundamentals/developer-apps) creado en la [Developer Console](/resources/fundamentals/developer-portal).
*   Un Bearer Token de tu App en la [X Developer Console](/resources/fundamentals/developer-portal).
*   Si no tienes una cuenta de desarrollador aprobada, puedes [solicitar una](https://developer.x.com/en/apply-for-access).

## Cómo obtener el user ID de un usuario para usarlo en los endpoints user Tweet timeline y user mention timeline

Los endpoints user Tweet timeline y user mention timeline te permiten obtener Posts usando el user ID. Para obtener el user ID a partir de un nombre de usuario, puedes usar el nuevo [endpoint user lookup v2](/x-api/users/lookup/quickstart/user-lookup). Reemplaza USER\_NAME con el nombre de usuario de tu elección y XXXX con tu propio bearer token obtenido arriba.

```bash
  curl --request GET 'https://api.x.com/2/users/by/username/USER_NAME --header 'Authorization: Bearer XXXXXX'
```

Verás el user ID en la respuesta como se muestra a continuación:

```json
{
   "data": {
       "id": "2244994945",
       "name": "Developers",
       "username": "XDevelopers"
   }
}
```


## Conectarse a los endpoints user Tweet timeline y user mention timeline

Para obtener el user Tweet timeline de un usuario, ejecuta el siguiente comando curl en tu terminal (asegúrate de reemplazar USER\_ID con el user ID de tu elección y XXXX con tu propio bearer token obtenido arriba)

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/tweets' --header 'Authorization: Bearer XXXXXX'
```


Verás que la respuesta JSON para estas solicitudes contiene por defecto el ID y el texto de los Posts (ejemplo abajo).

```yaml
{
   "id": "1334200897081987072",
   "text": "👀 If you are new to the X API v2, check out this step-by-step guide to making your first request https://t.co/4rZqThpSbp"
}
```

Si quieres que se devuelvan campos adicionales como parte de la respuesta (como información del usuario, campos adicionales del Tweet como context annotations, etc.), deberás especificar esos campos explícitamente en tu respuesta. Aprende cómo hacerlo en la [guía sobre el uso de fields y expansions](/x-api/fundamentals/data-dictionary/reference#how-to-use-fields-and-expansions).

También puedes obtener estos Posts usando los lenguajes de programación de tu elección. Consulta nuestro código de ejemplo en Python, Node (JavaScript), Java y Ruby para los endpoints user Tweet timeline y user mention timeline en nuestro [repositorio de Github](https://github.com/xdevplatform/Twitter-API-v2-sample-code).
 

## Explorando los Posts del usuario

Una vez que sepas cómo obtener Posts usando los endpoints user Tweet timeline y user mention timeline, puedes empezar a explorar sus Posts. Por ejemplo, si quisieras identificar entidades nombradas comunes presentes en las menciones de un usuario, puedes hacer lo siguiente:

En la solicitud a la API, especifica que quieres que se devuelva el objeto context\_annotations en las respuestas del Tweet:

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/mentions?tweet.fields=context_annotations' --header 'Authorization: Bearer XXXXXX'
```

En la respuesta, verás si hay entidades nombradas presentes en las menciones. Aquí tienes un ejemplo:

```json
{
   "domain": {
       "id": "47",
       "name": "Brand",
       "description": "Brands and Companies"
   },
   "entity": {
       "id": "783214",
       "name": "X"
   }
}
```

Si quisieras ver qué entidades populares aparecen en tus menciones, podrías llevar un conteo de entidades populares parseando cada Tweet en las menciones.

Si quisieras explorar la URL de imagen de vista previa para todos los Posts de tu timeline que contienen media, puedes hacer lo siguiente:

En la solicitud a la API, especifica que quieres el preview\_image\_url en los campos tweet.media y las expansions attachments.media\_keys
```bash
curl --request GET 'https://api.x.com/2/users/2244994945/mentions?max_results=100&media.fields=preview_image_url&expansions=attachments.media_keys' --header 'Authorization: Bearer XXXXXX'
```

En la respuesta, verás el preview\_image\_url en el objeto includes como se muestra a continuación:

```json
{
   "includes": {
       "media": [
           {
               "media_key": "16_1334657439640121344",
               "preview_image_url": "https://pbs.twimg.com/tweet_video_thumb/EoWn3rqU8AAtFWL.jpg",
               "type": "animated_gif"
           }
       ]
   }
}
```
