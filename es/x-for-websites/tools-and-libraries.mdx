## Recursos oficiales

Las siguientes herramientas pueden ayudarte a empezar con X for Websites.

<CardGroup cols={3}>
<Card
  title="publish.x.com"
  icon="/icons/xds/icon-logo-x.svg"
  href="https://publish.x.com/"
>
Crea tu propio Tweet, timeline o botón incrustado.
</Card>
<Card
  title="Twitter for WordPress"
  icon="/icons/xds/icon-logo-x.svg"
  href="https://github.com/twitter/wordpress"
>
Un plugin oficial para optimizar tu sitio de WordPress para X, incluidos las inserciones de Tweets y X Cards.
</Card>
<Card
  title="twemoji"
  icon="/icons/xds/icon-logo-x.svg"
  href="https://twemoji.x.com/"
>
El conjunto de caracteres emoji gratuito y de código abierto de X, incluida una biblioteca JavaScript para compatibilidad multiplataforma.
</Card>
</CardGroup>
