El botón de Mensaje es un pequeño botón que ayuda a tus clientes a enviarte fácilmente un Mensaje Directo en X. Permite que tus clientes te contacten para hacer preguntas y obtener soporte directamente desde tu sitio web.

Un botón de Mensaje consta de dos partes: un enlace al compositor de mensajes directos en X.com, y el JavaScript de X for Websites para enriquecer el enlace con el reconocible botón de Mensaje.

## Flujo de creación de mensajes

Al hacer clic en el botón, se redirigirá al usuario al compositor de Mensajes Directos, con los valores que definas en el marcado del botón previamente rellenados.

## Cómo añadir un botón de mensaje a tu sitio web

[publish.x.com](https://publish.x.com) es una herramienta de configuración sencilla para crear un botón de mensaje. Solo introduce tu @screenName para empezar.

### Manualmente

1. Crea un elemento ancla con el nombre de clase `twitter-dm-button`. Establece un atributo `href` con el valor `https://x.com/messages/compose` para crear un enlace a la vista de mensajes directos de X. El parámetro de consulta `recipient_id` es el ID del @username que debería recibir los mensajes.

```html
<a href="https://x.com/messages/compose?recipient_id=3805104374"
  class="twitter-dm-button" data-screen-name="@furni">
Message @furni</a>
```

2. Opcionalmente, prerrellena el texto del mensaje personalizando el parámetro de consulta `text`.

```html
<a href="https://x.com/messages/compose?recipient_id=3805104374&text=Hello%20world"
  class="twitter-dm-button" data-screen-name="@furni">
Message @furni</a>
```

3. Carga de forma asíncrona el JavaScript de X for Websites usando nuestro fragmento de carga. El script inicializará el botón de mensaje después de que se cargue el contenido de tu página.

### Parámetros de consulta

| Parámetro      | Descripción                                                                 |
|----------------|-----------------------------------------------------------------------------|
| `recipient_id` | **Obligatorio**. El ID del usuario de X que recibirá los mensajes. |
| `text`         | **Opcional**. El texto prerrellenado del mensaje. El texto debe estar codificado en URL. |

### Personalización del botón

#### Tamaño

Añade un atributo `data-size` con el valor `large` para mostrar un botón de mensaje más grande.
