Un botón Post admite prellenar el texto para compartir, hashtags y una referencia a una cuenta de X. Asocia cuentas de X relacionadas para atraer seguidores.

## Parámetros de contenido del Post

| Parámetro  | Descripción                                                                 | Ejemplo                              |
|------------|-----------------------------------------------------------------------------|--------------------------------------|
| `text`     | Texto prerrellenado resaltado en el compositor del Post.                     | `custom share text`                  |
| `url`      | URL incluida con el Post.                                                    | `https://dev.x.com/web/post-button` |
| `hashtags` | Una lista de hashtags separados por comas que se añadirán al texto predeterminado del Post. | `example,demo`                       |
| `via`      | Atribuye la fuente de un Post a un nombre de usuario de X.                   | `xdevelopers`                         |
| `related`  | Una lista separada por comas de cuentas relacionadas con el contenido de la URI compartida. | `xapi,x`                 |

## Parámetros de visualización del botón

Personaliza el tamaño del botón Post mostrado, la alineación del botón y más.

Estos parámetros visuales no se aplican a los Web Intents, cuyo estilo lo definen los sitios que los implementan por separado.

| Parámetro | Descripción                                                                 | Ejemplo |
|-----------|-----------------------------------------------------------------------------|---------|
| `size`    | Cuando se establece en `large`, muestra una versión más grande del botón. Usa `l` para iframe. | `large` |
| `lang`    | Un [código de idioma admitido por X](/x-for-websites/supported-languages). | `es`    |
| `dnt`     | Cuando se establece en `true`, el botón y su página incrustada en tu sitio no se utilizan con fines que incluyan [sugerencias personalizadas](https://support.x.com/articles/20169421) ni [anuncios personalizados](https://support.x.com/articles/20170405). | `true`  |

### Ejemplo con `data-*` HTML

```html
<a class="twitter-share-button"
  href="https://x.com/intent/tweet"
  data-size="large"
  data-text="custom share text"
  data-url="https://dev.x.com/web/tweet-button"
  data-hashtags="example,demo"
  data-via="xdevelopers"
  data-related="xapi,x">
Post
</a>
```

### Ejemplo de factory JavaScript

```javascript
twttr.widgets.createShareButton(
  "https:\/\/dev.x.com\/web\/tweet-button",
  document.getElementById("tweet-container"),
  {
    size: "large",
    text: "custom share text",
    hashtags: "example,demo",
    via: "xdevelopers",
    related: "xapi,x"
  }
);
```
