Un botón de Hashtag es un tipo especial de [botón Post](/x-for-websites/post-button/overview) para fomentar la participación en una conversación agrupada por palabra clave. [Lee más sobre los hashtags en X](https://support.x.com/articles/49309).

## Cómo añadir un botón de Hashtag a tu sitio web

1. Crea un nuevo elemento ancla con la clase `twitter-hashtag-button` para permitir que el JavaScript de X for Websites descubra el elemento y lo convierta en un botón de Hashtag. Establece el valor del atributo `href` en `https://x.com/intent/tweet` para crear un enlace al compositor de web intents de X.

```html
<a class="twitter-hashtag-button"
  href="https://x.com/intent/tweet">
Post</a>
```

2. Añade tu hashtag de interés como valor del parámetro de consulta `button_hashtag` y como parte del texto interno del elemento ancla.

```html
<a class="twitter-hashtag-button"
  href="https://x.com/intent/tweet?button_hashtag=XStories">
Post #XStories</a>
```

3. Carga de forma asíncrona [el JavaScript de X for Websites usando nuestro fragmento de carga](/x-for-websites/javascript-api/guides/set-up-x-for-websites). El fragmento de JavaScript comprobará si existe una versión previa en la página, inicializará una cola de funciones que se ejecutará una vez que el JavaScript de los widgets se haya cargado, y cargará el JavaScript de los widgets de forma asíncrona desde el CDN de X.

##  Definir hashtags secundarios

Incluye hashtags adicionales en el texto prerrellenado del Post usando el [parámetro de consulta hashtags del web intent](/x-for-websites/post-button/guides/web-intent). Un hashtag definido en el parámetro `button_hashtag` y mostrado en el botón aparecerá antes que los hashtags definidos en el parámetro `hashtags`.

## Factory function de JavaScript

La biblioteca de JavaScript de widgets de X admite la inserción dinámica de un botón de hashtag mediante la función `twttr.widgets.createHashtagButton`. Pasa un hashtag, el elemento contenedor de destino y las mismas opciones admitidas por la [factory function de JavaScript del botón Post](/x-for-websites/post-button/guides/javascript-factory-function). 

```javascript
twttr.widgets.createHashtagButton(
  "XStories",
  document.getElementById("container"),
  {
    size:"large"
  }
);
```
