Un botón de Mención es un tipo especial de [botón Post](/x-for-websites/post-button/overview) para fomentar un nuevo Post centrado en una interacción entre el usuario y una cuenta mencionada. Los Posts que comienzan con `@username` no aparecen en el timeline del autor en la vista predeterminada; el Post solo aparecerá en el timeline principal de los seguidores del autor si el usuario sigue tanto al autor como al usuario mencionado. [Lee más sobre @replies y @mentions](https://support.x.com/articles/14023).

## Cómo añadir un botón de Mención a tu sitio web

1. Crea un nuevo elemento ancla con la clase `twitter-mention-button` para permitir que el JavaScript de X for Websites descubra el elemento y lo convierta en un botón de Mención. Establece el valor del atributo `href` en `https://x.com/intent/tweet` para crear un enlace al compositor de web intents de X.

```html
<a class="twitter-mention-button"
  href="https://x.com/intent/tweet">
Post</a>
```

2. Añade el nombre de usuario de la cuenta mencionada como valor del parámetro de consulta `screen_name` y como parte del texto interno del elemento ancla.

```html
<a class="twitter-mention-button"
  href="https://x.com/intent/tweet?screen_name=XDevelopers">
Post to @XDevelopers</a>
```

3. Carga de forma asíncrona [X for Websites usando nuestro fragmento de carga](/x-for-websites/javascript-api/guides/set-up-x-for-websites). El fragmento de JavaScript comprobará si existe una versión previa en la página, inicializará una cola de funciones que se ejecutará una vez que el JavaScript de los widgets se haya cargado, y cargará el JavaScript de los widgets de forma asíncrona desde el CDN de X.

## Factory function de JavaScript

La biblioteca de JavaScript de widgets de X admite la inserción dinámica de un botón de Mención mediante la función `twttr.widgets.createMentionButton`. Pasa un nombre de usuario, el elemento contenedor de destino y las mismas opciones admitidas por la [factory function de JavaScript del botón Post](/x-for-websites/post-button/guides/javascript-factory-function).

```html
twttr.widgets.createMentionButton(
  "XDevelopers",
  document.getElementById("container"),
  {
    size:"large"
  }
);
```
