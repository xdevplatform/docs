La biblioteca de JavaScript de X for Websites admite la inserción dinámica de un botón Post mediante la función `twttr.widgets.createShareButton`. Pasa una URL para compartir, el elemento padre de destino y cualquier opción personalizada.

Los fragmentos de código de esta página asumen que `widgets.js` se ha cargado correctamente en tu página. Incluye un cargador de scripts asíncrono en tu página al inicializar `window.twttr`, tal como se describe en nuestra [documentación del cargador de JavaScript](/x-for-websites/javascript-api/guides/set-up-x-for-websites). Todo el código JavaScript que dependa de `widgets.js` debe ejecutarse en `twttr.ready` o después.

## Argumentos

| Parámetro  | Descripción                                                                 | Valor de ejemplo                              |
|------------|-----------------------------------------------------------------------------|--------------------------------------------|
| `url`      | Una URL para compartir, o una cadena vacía si no deseas incluir un componente de URL en el compositor del Post | `https://dev.x.com/`                 |
| `targetEl` | Nodo del DOM del elemento padre deseado                                      | `document.getElementById('container')`     |
| `options`  | Anula las opciones predeterminadas del widget. Consulta la [referencia de parámetros del botón Post](/x-for-websites/post-button/guides/parameter-reference) para más detalles | `{ text: 'Hello world' }`                  |

## Ejemplo


En la página existe un elemento con un ID de DOM `container`.

```html
<div id="container"></div>
```

El siguiente fragmento de código creará un nuevo botón Post con el texto de compartir preseleccionado “Hello world” y una URL compartida “/”, insertado en una página dentro de un elemento con el ID único `container`.

```javascript
twttr.widgets.createShareButton(
  '/',
  document.getElementById('container'),
  {
    text: 'Hello World'
  }
);
```

## Promesas

La función `twttr.widgets.createShareButton` devuelve una [Promise](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise). Puedes ejecutar código después de que se haya insertado un widget en tu página pasando un callback a la función `then` de la promesa resultante.

```javascript
twttr.widgets.createShareButton(...)
.then( function( el ) {
  console.log('Post button added.');
});
```

## Botones de hashtag y mención

Crea un botón de hashtag o de mención usando las funciones [twttr.widgets.createHashtagButton](/x-for-websites/post-button/guides/hashtag-button) y [twttr.widgets.createMentionButton](/x-for-websites/post-button/guides/mention-button) respectivamente. Se aplica el mismo objeto.
