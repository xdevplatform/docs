Un Web Intent de Post facilita a los visitantes de tu sitio redactar y publicar un Post para su audiencia desde un enlace en tu página web. Los sitios pueden configurar el texto y los hashtags del Post, pasar una URL e identificar cuentas de X relacionadas con la página.

## URL del Web Intent

```
https://x.com/intent/tweet
```

## Parámetros de consulta

| Parámetro     | Descripción                                                                 | Valor de ejemplo                                      |
|---------------|-----------------------------------------------------------------------------|----------------------------------------------------|
| `text`        | Texto del Post prerrellenado en UTF-8 y codificado en URL. El texto pasado aparecerá preseleccionado para que un usuario de X lo elimine o edite antes de publicar. La longitud del texto del Post pasado no debe superar los 280 caracteres combinados con cualquier parámetro hashtags, via o url pasado. El texto del Post que haga que el Post supere los 280 caracteres requerirá edición adicional por parte del usuario de X antes de que pueda publicarse correctamente. | `Hello%20World`                                    |
| `url`         | Una URL totalmente cualificada con esquema HTTP o HTTPS, [codificada en URL](http://en.wikipedia.org/wiki/Percent-encoding). La URL proporcionada será acortada por el t.co de X al número de caracteres especificado por short_url_length. | `https%3A%2F%2Fexample.com%2F`                     |
| `hashtags`    | Permite el descubrimiento fácil de Posts por tema incluyendo una lista de valores de hashtags separados por comas sin el carácter # inicial. | `nature,sunset`                                    |
| `via`         | Un nombre de usuario de X para asociar con el Post, como la cuenta de X de tu sitio. El nombre de usuario proporcionado se añadirá al final del Post con el texto “via @username”. A un usuario de X que no haya iniciado sesión se le animará a iniciar sesión o unirse a X para interactuar con los Posts de la cuenta via. La cuenta podrá sugerirse como cuenta a seguir después de que el usuario publique un Post. | `xdevelopers`                                       |
| `related`     | Sugiere nombres de usuario de X adicionales relacionados con el Post como valores separados por comas. X puede sugerir estas cuentas para seguir después de que el usuario publique su Post. Puedes proporcionar una breve descripción de cómo la cuenta se relaciona con el Post con una coma codificada en URL y texto después del nombre de usuario. | `x%3AX%20News,xapi%3AX%20API%20News` |
| `in_reply_to` | El Post ID de un Post padre en una conversación, como el Post inicial de tu sitio o de la cuenta del autor. | `525001166233403393`                               |
