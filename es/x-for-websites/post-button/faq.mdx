## ¿El botón Post admite otros idiomas?

Sí. Incluye un parámetro `lang` para establecer explícitamente el idioma del botón Post. Consulta la lista de [idiomas admitidos por X for Websites](/x-for-websites/supported-languages) para conocer más sobre los idiomas admitidos.

## ¿Cuáles son las dimensiones del botón Post?

El botón Post mide 55 píxeles de ancho y 20 píxeles de alto.

### Botón Post internacionalizado

Los botones Post internacionalizados tienen dimensiones ligeramente diferentes.

| Idioma   | código lang | Dimensiones  |
|----------|-----------|--------------|
| Inglés   | `en`      | 55px por 20px |
| Japonés  | `ja`      | 80px por 20px |
| Español  | `es`      | 64px por 20px |

## Quiero usar varios botones Post en mi página. ¿Hay algo que deba saber?

Si quieres usar más de un botón Post en una página, hay un par de cosas que deberías comprobar.

1. Si estás usando el botón Post con JavaScript, asegúrate de incluir el JavaScript `widgets.js` solo una vez. El mejor lugar para colocar el JavaScript es antes del cierre `</body>`.
2. Para evitar la duplicación de contenido en tu página, considera usar las etiquetas `rel="me"` y `rel="canonical"` en lugar de los datos via y url en cada botón Post.

## ¿Puedo controlar el orden de las cuentas recomendadas?

Solo se muestran dos cuentas y, por defecto, el usuario indicado en via se muestra primero, con la primera cuenta relacionada mostrada a continuación. Si el usuario ya sigue al usuario indicado en via, en su lugar el Share Box mostrará las dos primeras cuentas relacionadas a las que el usuario no siga. No se muestra ninguna cuenta si el usuario sigue a todas las cuentas sugeridas (via y related).

Más información sobre [cuentas relacionadas](/x-for-websites/post-button/overview).

## ¿Funciona el botón Post sobre HTTPS?

Sí, el botón Post funciona sobre HTTPS.
