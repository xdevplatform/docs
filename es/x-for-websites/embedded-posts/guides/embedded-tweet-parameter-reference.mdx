Un Post incrustado admite personalización mediante atributos `data-*` y factory functions de JavaScript. Este documento de referencia describe los parámetros utilizados en todos los formatos.

Consulta la [oEmbed API](/x-for-websites/oembed-api) para establecer estos parámetros como parte de una respuesta HTML para un Post ID o URL.

## Parámetros

| Parámetro     | Descripción                                                                 | Ejemplo    |
|---------------|-----------------------------------------------------------------------------|------------|
| `id`          | El ID numérico del Post deseado.                                            | `20`       |
| `cards`       | Cuando se establece en `hidden`, los enlaces de un Post no se expanden a vistas previas de foto, vídeo o enlace. | `hidden`   |
| `conversation`| Cuando se establece en `none`, solo se mostrará el Post citado incluso si es una respuesta a otro Post. | `none`     |
| `theme`       | Cuando se establece en `dark`, muestra el Post con texto claro sobre un fondo oscuro. | `dark`     |
| `width`       | El ancho máximo del Post renderizado en píxeles enteros. Este valor debe estar entre 250 y 550 píxeles. | `325`      |
| `align`       | Flotar el Post a la `left`, `right` o `center` respecto a su contenedor. Se suele configurar para permitir que el texto u otro contenido se ajuste alrededor del Post. | `right`    |
| `lang`        | Un [código de idioma admitido por X](/x-for-websites/supported-languages). Carga los componentes de texto en el idioma especificado. Nota: no afecta al texto del Post citado. | `es`       |
| `dnt`         | Cuando se establece en `true`, el Post y su página incrustada en tu sitio no se utilizan con fines que incluyan [sugerencias personalizadas](https://support.x.com/articles/20169421) ni [anuncios personalizados](https://support.x.com/articles/20170405). | `true`     |

### Ejemplo HTML

```html
<blockquote class="twitter-tweet" data-lang="en">
  <p lang="en" dir="ltr">just setting up my twttr</p>&mdash; Jack (@jack) <a href="https://x.com/jack/status/20">March 21, 2006</a>
</blockquote>
```

### Ejemplo de factory JavaScript

```javascript
twttr.widgets.createTweet(
  "20",
  document.getElementById("tweet-container"),
  {
    theme: "dark"
  }
);
```

<Note>
El Post ID numérico debe pasarse como string.
</Note>
