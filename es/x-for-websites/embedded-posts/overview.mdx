Los Posts incrustados traen el contenido que elijas de X a los artículos de tu sitio web. Un Post incrustado incluye fotos, vídeo y medios de Cards creados para su visualización en X, e incluso puede transmitir vídeo en vivo desde Periscope. Todos los aspectos de los requisitos de visualización de X se gestionan por ti al usar nuestras herramientas: atribución del autor, acciones del Post, hashtags, menciones y otros componentes clave de la experiencia de X.

Un Post incrustado consta de dos partes: un fragmento HTML alojado en tu página web, y el JavaScript de X for Websites para transformar ese código en un Post totalmente renderizado. Puedes copiar el marcado del Post incrustado generado desde el menú del Post en x.com, pegar una URL en un CMS compatible, o añadir un Post a la página de forma programática usando una factory function de JavaScript.

## Incrustar desde x.com

Cada Post mostrado en x.com incluye un código de inserción para copiar y pegar fácilmente en tu página web. Activa el menú del Post y selecciona “Embed Post” para generar el marcado a incluir en tu página web:

## Convertir URLs de Post usando oEmbed

Convierte una URL de Post en marcado de Post incrustado de forma programática usando la oEmbed API. Haz que incrustar un Post en tu CMS o app sea tan simple como pegar una URL de Post.

```bash
https://publish.x.com/oembed?
  url=https://x.com/Interior/status/463440424141459456
```

Nuestra [guía de buenas prácticas de CMS](/x-for-websites/embedded-posts/guides/cms-best-practices) describe patrones comunes para los sitios que añaden soporte de software para Posts incrustados.

## Personalizar la visualización del Post

Personaliza un Post incrustado según el diseño visual y las preferencias de visualización de tu sitio incluyendo parámetros adicionales en el HTML de tu Post incrustado.

### Ajustar al esquema de color de tu sitio

Un Post incrustado admite temas de color claro y oscuro. Personaliza los widgets de X [a nivel de página con elementos `<meta>`](/x-for-websites/webpage-properties) o `añade atributos data-*` a los elementos `<blockquote>` generados individualmente.

Consulta nuestra [documentación de referencia de Posts incrustados](/x-for-websites/embedded-posts/guides/embedded-tweet-parameter-reference) para ver la lista completa de opciones de Post incrustado.

### No mostrar el Post previo en el hilo de conversación

Un Post puede ser una respuesta a otro Post. De forma predeterminada, incluimos un resumen del Post previo en la conversación para proporcionar contexto.

Establece el parámetro de consulta oEmbed `hide_thread=true` o añade el atributo `data-conversation="none"` al elemento `<blockquote>` resultante para evitar la visualización del Post padre.

### Ocultar fotos, vídeos y Cards

Un Post puede incluir una foto, un vídeo o un enlace a otro contenido que admita una [Card](https://dev.x.com/cards/overview). De forma predeterminada, estos medios se muestran en los Posts incrustados. Puedes ocultar estos medios si así lo prefieres editorialmente.

Establece el parámetro de consulta oEmbed `hide_media=true` o añade el atributo `data-cards="hidden"` al elemento `<blockquote>` resultante para evitar la visualización del contenido expandido.

### Personalizar la alineación

Un Post incrustado se alinea a la izquierda de forma predeterminada. El Post puede alinearse al centro o a la derecha si se prefiere, usando la personalización align. Aunque históricamente CSS proporciona numerosos trucos para centrar contenido en una página web, este es el método recomendado y oficialmente compatible.

## Renderizar un Post con JavaScript

Nuestro JavaScript de widgets escanea el DOM al ejecutarse, convirtiendo los elementos `blockquote.twitter-tweet` en Posts incrustados totalmente renderizados según el contenido del elemento.

Si insertas contenido nuevo dinámicamente en una página, pasa el nuevo fragmento del documento a [twttr.widgets.load()](/x-for-websites/javascript-api/guides/scripting-loading-and-initialization) para inicializar el contenido de los Posts incrustados.

Para renderizar directamente un Post incrustado en tiempo de ejecución, utiliza la función [twttr.widgets.createTweet()](/x-for-websites/embedded-posts/guides/embedded-post-javascript-factory-function).
