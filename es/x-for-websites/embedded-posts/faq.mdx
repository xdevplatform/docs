## Un Post totalmente renderizado no se muestra en mi página

Un Post incrustado consta de dos partes: un `<blockquote>` que contiene la información del Post y el archivo JavaScript de un servidor de X que convierte el `<blockquote>` en un Post totalmente renderizado.

Si ves el texto del Post en tu página pero no un Post totalmente renderizado, es posible que tu CMS o interfaz de edición haya eliminado el `<script>` necesario para renderizar el Post.

Prueba a cambiar a un modo de “texto”, “HTML” o “edición de código” para introducir directamente la información preformateada del Post. Los editores de texto enriquecido o WYSIWYG pueden malinterpretar el código HTML pegado, lo que puede interferir con la colocación de un Post en tu página.

Si no puedes trabajar de forma fiable con HTML en tus artículos, tú o tu equipo de sitio web deberíais añadir el JavaScript de X for Websites a la plantilla de tu página web para interpretar cualquier botón o widget en la página. Añade el siguiente código justo antes del elemento de cierre `</body>` en la plantilla de tu sitio web:

```javascript
<script id="twitter-wjs" type="text/javascript" async defer src="//platform.x.com/widgets.js"></script>
```

El fragmento de JavaScript anterior carga el JavaScript de widgets de X si aún no está presente en la página. El JavaScript cargado convertirá los Posts incrustados, los Timelines incrustados, los Post Buttons y los Follow Buttons de tu página en widgets y botones interactivos.

## ¿Qué sucede cuando un autor elimina su Post?

El JavaScript de widgets de X no mostrará un Post totalmente renderizado si el Post ya no existe en X. El `<blockquote>` de reserva que contiene la información del Post seguirá siendo visible en la página.

## ¿Los Posts incrustados se adaptan a mi sitio responsive?

Un Post incrustado se ajustará al ancho de su elemento contenedor cuando se inserte en una página. Un Post incrustado requiere un ancho mínimo de 220 píxeles y ocupará hasta 550 píxeles horizontales.

## ¿Cómo puedo crear un Post incrustado con una altura consistente?

Un Post incrustado básico incluye el texto del Post hasta 140 caracteres, la información del autor, una marca de tiempo y las acciones del Post. De forma predeterminada, un Post incrustado muestra el Post previo en una conversación y las fotos, un vídeo o una vista previa de enlace asociados al Post. Establece los parámetros conversation y cards en false para limitar la visualización del Post a su formato básico.
