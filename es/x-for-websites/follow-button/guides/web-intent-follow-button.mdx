Los [Web Intents](/x-for-websites/web-intents/overview) muestran acciones de X optimizadas para su visualización en una ventana de navegador pequeña. Un sitio web puede enlazar a un web intent de seguir mediante un simple enlace en cualquier sitio web. Los widgets JavaScript de X for Websites utilizan el web intent de seguir para invitar a los usuarios a seguir una cuenta.

Una ventana de Web Intent de seguir incluye un formulario de inicio de sesión en línea para los usuarios de X que no hayan iniciado sesión.

El usuario seguirá la cuenta tras un inicio de sesión exitoso mediante el formulario de inicio de sesión en línea del web intent de seguir. El estado del seguimiento se confirma mediante el botón “Following” mostrado en la ventana del web intent.

Recomendamos renderizar la ventana hija del Web Intent con unas dimensiones de al menos 550 píxeles de ancho y 420 píxeles de alto.

## URL del Web Intent

```
https://x.com/intent/follow
```

## Parámetros de consulta

Un Web Intent de seguir debe referenciar una cuenta de X mediante `screen_name` o `user_id`. Un `screen_name` puede cambiar; recomendamos usar `user_id` siempre que sea posible.

| Parámetro     | Descripción                                                  | Valor de ejemplo  |
|---------------|--------------------------------------------------------------|-------------------|
| `screen_name` | El nombre de usuario de X de la cuenta que quieres que siga el usuario | `xdevelopers`      |
| `user_id`     | El identificador de usuario de X de la cuenta que quieres que siga el usuario | `2244994945`      |
