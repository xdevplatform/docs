Un botón Seguir puede personalizarse a partir de su configuración predeterminada especificando sobrescrituras de parámetros.

| Parámetro        | Descripción                                                                 | Ejemplo    |
|------------------|-----------------------------------------------------------------------------|------------|
| `screen_name`    | El nombre de usuario de X que se va a seguir. Se extrae automáticamente del atributo `href` del elemento ancla cuando se utiliza marcado de botón mejorado con JavaScript. | `XDevelopers` |
| `show_screen_name` | Establece en `false` para ocultar el nombre de usuario de la cuenta especificada. | `false`    |
| `size`           | Establece en `large` para mostrar un botón más grande.                      | `large`    |
| `lang`           | Un [código de idioma admitido por X](/x-for-websites/supported-languages). | `es`       |
| `dnt`            | Cuando se establece en `true`, el botón y su página incrustada en tu sitio no se utilizan con fines que incluyan [sugerencias personalizadas](https://support.x.com/articles/20169421) ni [anuncios personalizados](https://support.x.com/articles/20170405). | `true`     |

## Ejemplo HTML

```html
<a class="twitter-follow-button"
  href="https://x.com/XDevelopers"
  data-show-screen-name="false"
  data-size="large"
>
Follow @XDevelopers
</a>
```

## Ejemplo de JavaScript

```javascript
twttr.widgets.createFollowButton(
  "XDevelopers",
  document.getElementById("container"),
  {
    showScreenName: "false",
    size: "large"
  }
);
```
