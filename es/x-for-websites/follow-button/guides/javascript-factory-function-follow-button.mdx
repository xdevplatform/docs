La biblioteca de JavaScript de X for Websites admite la inserción dinámica de un botón Seguir mediante la función `twttr.widgets.createFollowButton`. Pasa un nombre de usuario de X, el elemento padre de destino y cualquier opción personalizada.

Los fragmentos de código de esta página asumen que `widgets.js` se ha cargado correctamente en tu página. Incluye un cargador de scripts asíncrono en tu página al inicializar `window.twttr`, tal como se describe en nuestra [documentación del cargador de JavaScript](/x-for-websites/javascript-api/guides/set-up-x-for-websites). Todo el código JavaScript que dependa de `widgets.js` debe ejecutarse en `twttr.ready` o después.

## Argumentos

| Parámetro    | Descripción                                      | Valor de ejemplo                              |
|--------------|--------------------------------------------------|--------------------------------------------|
| `username`   | Un nombre de usuario de X                        | `'XDevelopers'`                             |
| `targetEl`   | Nodo del DOM del elemento padre deseado          | `document.getElementById('container')`     |
| `options`    | Anula las opciones predeterminadas del widget    | `{ size: 'large' }`                        |

## Ejemplo

En la página existe un elemento con un ID de DOM `container`.

```html
<div id="container"></div>
```

El siguiente fragmento de código creará un nuevo botón Seguir para el nombre de usuario de X “XDevelopers”, insertado en una página dentro de un elemento con el ID único `container`.

```javascript
twttr.widgets.createFollowButton(
  'XDevelopers',
  document.getElementById('container'),
  {
    size: 'large'
  }
);
```

## Promesas

La función `twttr.widgets.createFollowButton` devuelve una [Promise](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise). Puedes ejecutar código después de que se haya insertado un widget en tu página pasando un callback a la función `then` de la promesa resultante.

```javascript
twttr.widgets.createFollowButton(...)
.then( function( el ) {
  console.log('Follow button added.');
});
```
