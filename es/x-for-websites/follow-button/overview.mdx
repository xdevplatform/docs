El botón Seguir es un pequeño botón que se muestra en tu sitio web para ayudar a los usuarios a seguir fácilmente una cuenta de X. Un botón Seguir consta de dos partes: un enlace a una página de [web intent de seguir](/x-for-websites/follow-button/overview) en x.com y el JavaScript de X for Websites para transformar el enlace en nuestro reconocible botón Seguir.

## Cómo añadir un botón Seguir a tu sitio web

El sitio [publish.x.com](https://publish.x.com) incluye una herramienta sencilla para generar el código de inserción de un botón Seguir y copiarlo y pegarlo en la plantilla de tu sitio web. Solo introduce un @screenName para empezar.

### Manualmente

1. Crea un elemento ancla con el nombre de clase `twitter-follow-button`. Establece el atributo `href` apuntando a la URL de un perfil de X.

```html
<a class="twitter-follow-button"
  href="https://x.com/XDevelopers">
Follow @XDevelopers</a>
```

2. Personaliza los parámetros del botón Seguir usando atributos `data-*`.

```html
<a class="twitter-follow-button"
  href="https://x.com/XDevelopers"
  data-size="large">
Follow @XDevelopers</a>
```

3. Carga de forma asíncrona el JavaScript de X for Websites usando nuestro fragmento de carga. El script inicializará el botón Seguir después de que se cargue el contenido de tu página.


## Personalización del botón

### Ocultar el nombre de usuario

Oculta el nombre de usuario del botón Seguir mostrado estableciendo el valor del atributo `data-show-screen-name` en `false`.

### Estilo de botón grande

Añade el valor `large` al atributo `data-size` para mostrar un botón Seguir más grande.
