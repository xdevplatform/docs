Los recursos están disponibles para dar soporte a una experiencia de usuario consistente en aplicaciones que aprovechan Twitter y sitios que usan Web Intents. Se recomienda que los almacenes dentro de tu propia aplicación. Para más información sobre el uso de estas marcas, consulta nuestros Display Requirements.

## Logotipo de X

Descarga los activos actuales del logotipo de X (incluidos varios tamaños y colores) directamente desde el [brand toolkit](https://about.x.com/en/who-we-are/brand-toolkit) oficial.

## Acciones de Tweet

Una acción de Tweet representa una acción posible sobre un Tweet con un estado “on” si el usuario ya ha completado la acción.

Todas las acciones de Tweet se muestran con un relleno gris medio (#AAB8C2) en su estado predeterminado. Todas las acciones de Tweet deberían establecer una opacidad del 50% cuando la acción está siendo activada por el usuario (por ejemplo, la pseudo-clase CSS `:active`). La acción mantiene el color de relleno anterior durante su estado de pulsado/activación, cambiando al estado “on” tras activarse la acción.

Las acciones de retweet y like aparecen en estado “on” si el usuario actual ha realizado la acción. Una propiedad del [objeto Tweet](/x-api/fundamentals/data-dictionary/reference#post-tweet) `retweeted` o `favorited` con valor true comunica el estado de visualización “on” esperado.

Una acción de retweet se muestra desactivada si el usuario actual coincide con el autor del Tweet. Una acción desactivada tiene un 30% de opacidad.

La opacidad del icono de retweet debería ajustarse durante la activación del icono. El icono de retweet debería aparecer en el estado “on” si la respuesta del objeto Tweet para el usuario actual tiene una propiedad `retweeted` con valor `true`. Puede existir un estado inactivo de la acción Tweet cuando el usuario actual es el mismo que el autor del Tweet.
