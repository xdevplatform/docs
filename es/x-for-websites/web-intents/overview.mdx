Los Web Intents proporcionan flujos para trabajar con Tweets y usuarios de X: Tweet, Reply, Retweet, Like y Follow. Permiten a los usuarios interactuar con contenido de X en el contexto de tu sitio, sin salir de la página o tener que autorizar una nueva app solo para la interacción. Los web intents son compatibles con la web móvil, incluyen gestores nativos en iOS y Android cuando la app de X está instalada, y son muy fáciles de implementar.

## Trabajar con Web Intents

Los Web Intents son la forma más sencilla de permitir que las personas hagan Tweets o sigan cuentas de X directamente desde tu sitio. Los Web Intents llevan automáticamente al usuario a la mejor experiencia con la sesión iniciada para completar la acción especificada, incluyendo compositores de Tweet o vistas de perfil de X dentro de las apps X for iOS y X for Android. Si un usuario no tiene una cuenta de X, tendrá la oportunidad de iniciar sesión en X o crear una cuenta antes de completar la acción especificada originalmente. Los Web Intents no requieren configurar una aplicación de X, almacenar credenciales de app ni pedir permisos de app al usuario antes de publicar.

[El JavaScript de X for Websites](/x-for-websites/javascript-api/guides/set-up-x-for-websites) disparará automáticamente los [eventos JavaScript](/x-for-websites/javascript-api/guides/javascript-api) apropiados cuando esté incluido en una página web.

Los Web Intents no pueden cargarse dentro de un iframe. Un autor de X debe ver la página web completa antes de decidir redactar un nuevo Tweet o una acción de Tweet prerrellenada por tu Web Intent especificado, o seguir una cuenta de X especificada.

Las imágenes de los iconos para likes, respuestas y reposts están disponibles en nuestra página de [Recursos de imagen](/x-for-websites/web-intents/image-resources). Consulta nuestros [Display Requirements](https://about.x.com/company/display-requirements) para obtener consejos sobre cómo renderizar Tweets y otros recursos de X.

Si tu audiencia habla otro idioma distinto del inglés, te recomendamos usar intents localizados. 

### Empezar

Los Web Intents pueden invocarse de forma flexible mediante una combinación ligera de JavaScript y HTML y están pensados para abrirse en una nueva ventana.

La forma más sencilla de usar intents es incluir el JavaScript de X for Websites en cualquier página web en la que desees invocar un intent. Si ya has configurado el [botón Tweet](/x-for-websites/post-button/overview), ya estás preparado para los Web Intents.

Combinado con etiquetas ancla estándar e [iconografía familiar](https://dev.x.com/basics/image-resources) como los ejemplos siguientes, este JavaScript abrirá automáticamente una ventana del tamaño apropiado al hacer clic. Solo necesitas cargar `platform.x.com/widgets.js` una vez.

```html
<script type="text/javascript" async src="https://platform.twitter.com/widgets.js"></script>
<a href="https://twitter.com/intent/tweet?in_reply_to=463440424141459456">Reply</a>
<a href="https://twitter.com/intent/retweet?tweet_id=463440424141459456">Retweet</a>
<a href="https://twitter.com/intent/like?tweet_id=463440424141459456">Like</a>
```

## Lista de Web Intents

### Tweet o Reply a un Tweet

- [https://x.com/intent/tweet](https://x.com/intent/tweet?in_reply_to=463440424141459456&related=xdevelopers)


Consulta la [documentación del Web Intent de Tweet](/x-for-websites/post-button/overview) para más información sobre el intent de Tweet.

### Retweet a un Tweet

- [https://x.com/intent/retweet](https://x.com/intent/retweet?tweet_id=463440424141459456&related=xdevelopers,x,support)

Los [Retweets](https://support.x.com/articles/77606-what-is-retweet-rt) son una forma potente de permitir que tus usuarios compartan tu contenido con sus seguidores.

#### Parámetros admitidos

- `tweet_id`

Cada Tweet se identifica mediante un ID. Puedes encontrar este valor a través de la API o viendo la página de enlace permanente de cualquier Tweet, generalmente accesible haciendo clic en la fecha “published at” de un tweet.

### Like a un Tweet


- [https://twitter.com/intent/like](https://x.com/intent/like?tweet_id=463440424141459456)


Los usuarios [dan like](https://support.x.com/articles/20169874) por diversas razones: cuando les encanta un Tweet, cuando quieren guardarlo para más tarde o para dar una señal de agradecimiento. El intent de like te permite ofrecer esta acción de Tweet y complementarla con cuentas sugeridas relevantes para que el usuario siga.

#### Parámetros admitidos

- `tweet_id`

Cada Tweet se identifica mediante un ID. Puedes encontrar este valor a través de la API o viendo la página de enlace permanente de cualquier Tweet, generalmente accesible haciendo clic en la marca de tiempo mostrada junto a un Tweet.

### Mini-perfil

- [https://x.com/intent/user](https://x.com/intent/user?screen_name=NASA)

Este Intent proporciona una forma discreta de enlazar nombres de personas, empresas y servicios a sus cuentas de X. La nueva pestaña destaca de forma prominente la foto de perfil de la cuenta, la biografía, los tweets recientes y un botón Follow fácil de usar.

Más recursos de imagen.

#### Parámetros admitidos

- `screen_name`

Cada usuario de X tiene un screen name, pero pueden cambiar. Recomendamos usar user_id siempre que sea posible.

- `user_id`

Los IDs de usuario de X están disponibles a través de la API e identifican de forma única a un usuario.

### Follow


- [https://twitter.com/intent/follow](https://x.com/intent/follow?screen_name=NASA)

Un [Web Intent de follow](/x-for-websites/follow-button/guides/web-intent-follow-button) muestra un formulario de inicio de sesión en línea para los usuarios que no han iniciado sesión y sigue a la cuenta de X objetivo tras un inicio de sesión exitoso.


## Localización

Puedes pasar un parámetro de consulta `lang` como parte de cualquier web intent para sobrescribir el idioma de visualización de un usuario con sesión iniciada o los idiomas aceptados por el navegador. Consulta [Idiomas de X for Websites](/x-for-websites/supported-languages) para ver una lista de valores admitidos de `lang`.

## Optimización

### Dependencias limitadas

Algunos sitios pueden preferir incrustar el JavaScript discreto de web intents en línea o sin dependencia de `platform.twitter.com`. El fragmento siguiente ofrecerá una funcionalidad equivalente sin la dependencia externa.

```javascript title="Ejemplo" expandable lines wrap icon="square-js"
(function() {
  if (window.__twitterIntentHandler) return;
  var intentRegex = /twitter\.com\/intent\/(\w+)/,
      windowOptions = 'scrollbars=yes,resizable=yes,toolbar=no,location=yes',
      width = 550,
      height = 420,
      winHeight = screen.height,
      winWidth = screen.width;

  function handleIntent(e) {
    e = e || window.event;
    var target = e.target || e.srcElement,
        m, left, top;

    while (target && target.nodeName.toLowerCase() !== 'a') {
      target = target.parentNode;
    }

    if (target && target.nodeName.toLowerCase() === 'a' && target.href) {
      m = target.href.match(intentRegex);
      if (m) {
        left = Math.round((winWidth / 2) - (width / 2));
        top = 0;

        if (winHeight > height) {
          top = Math.round((winHeight / 2) - (height / 2));
        }

        window.open(target.href, 'intent', windowOptions + ',width=' + width +
                                           ',height=' + height + ',left=' + left + ',top=' + top);
        e.returnValue = false;
        e.preventDefault && e.preventDefault();
      }
    }
  }

  if (document.addEventListener) {
    document.addEventListener('click', handleIntent, false);
  } else if (document.attachEvent) {
    document.attachEvent('onclick', handleIntent);
  }
  window.__twitterIntentHandler = true;
}());
```
