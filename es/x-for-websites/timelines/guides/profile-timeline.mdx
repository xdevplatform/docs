Un timeline de perfil muestra los últimos Posts ordenados del más nuevo al más antiguo de una cuenta pública específica de X.

## Marcado HTML

Se puede añadir un timeline de perfil responsive a una página web mediante una plantilla HTML común. Genera el marcado para un timeline de perfil incrustado en [publish.x.com](https://publish.x.com).

Un ejemplo de plantilla:

```html
<a class="twitter-timeline"
  href="https://x.com/{screen_name}">
Posts by @{screen_name}
</a>
```

```html
<a class="twitter-timeline"
  href="https://x.com/XDevelopers">
Posts by @XDevelopers
</a>
```

## Factory function de JavaScript

La biblioteca de JavaScript de widgets de X admite la inserción dinámica de un timeline de perfil incrustado mediante la función `twttr.widgets.createTimeline`. Pasa la definición de la fuente de datos, el elemento contenedor de destino y un objeto de opciones opcional para insertar un timeline incrustado en tu página.

Los parámetros HTML `data-*` se escriben en camelCase cuando se pasan como propiedades de un objeto de opciones.

```javascript
twttr.widgets.createTimeline(
  {
    sourceType: "profile",
    screenName: "XDevelopers"
  },
  document.getElementById("container")
);
```
