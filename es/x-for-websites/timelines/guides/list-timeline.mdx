Un timeline de lista muestra los últimos Posts ordenados del más nuevo al más antiguo de una lista pública curada de cuentas de X. El timeline incluye una cabecera que muestra el nombre, la descripción y el curador de la lista. [Lee más sobre las listas de X](https://support.x.com/articles/76460).

## Marcado HTML

Se puede añadir a una página web un timeline responsive respaldado por una lista de X mediante una plantilla HTML común.

Un ejemplo de plantilla:

```html
<a class="twitter-timeline"
  href="https://x.com/{screen_name}/lists/{slug}">
Posts from https://x.com/{screen_name}/lists/{slug}
</a>
```

```html
<a class="twitter-timeline"
  href="https://x.com/x/lists/official-twitter-accts">
Posts from https://x.com/x/lists/official-twitter-accts
</a>
```

## Factory function de JavaScript

La biblioteca de JavaScript de X for Websites admite la inserción dinámica de un timeline de lista incrustado mediante la función `twttr.widgets.createTimeline`. Pasa la definición de la fuente de datos, el elemento contenedor de destino y un objeto de opciones opcional para insertar un timeline incrustado en tu página.

Los parámetros HTML `data-*` se escriben en camelCase cuando se pasan como propiedades de un objeto de opciones.

```javascript
twttr.widgets.createTimeline(
  {
    sourceType: "list",
    ownerScreenName: "XDevelopers",
    slug: "national-parks"
  },
  document.getElementById("container")
);
```
