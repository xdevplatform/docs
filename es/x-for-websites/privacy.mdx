## ¿Qué información recopila X a través de X for Websites y cómo se utiliza esa información?

Cuando visualizas contenido de X, como Tweets incrustados, botones o timelines integrados en otros sitios web mediante X for Websites, X puede recibir información, incluida la página web que visitaste, tu dirección IP, el tipo de navegador, el sistema operativo y datos de cookies. Esta información nos ayuda a mejorar nuestros productos y servicios. Obtén más información sobre los datos que recibimos y cómo los utilizamos en nuestra [política de privacidad](https://x.com/privacy) y [política de cookies](https://help.x.com/en/rules-and-policies/x-cookies).

## ¿Durante cuánto tiempo conservan esta información?

Para proteger la privacidad, nunca asociamos el historial de navegación web que recopilamos a través de X for Websites con los nombres, direcciones de correo electrónico, números de teléfono o handles de X de los clientes, y lo eliminamos, ofuscamos o agregamos en un plazo no superior a 30 días, tal como se explica en nuestra [política de privacidad](https://x.com/privacy). No almacenamos este historial de navegación web procedente de determinados dominios, como .mil y .gov.
