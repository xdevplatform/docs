Si estás integrando tu sitio con X mediante [X for Websites](/x-for-websites/overview) y [Web Intents](/x-for-websites/web-intents/overview), puedes enriquecer tu aplicación con JavaScript. De forma predeterminada, `widgets-js` encontrará el marcado en una página y convertirá el marcado básico y funcional en widgets interactivos enriquecidos. Además, existen varias funciones de `widgets-js` que permiten a los desarrolladores trabajar con el contenido de X de forma dinámica, después de que la página se haya cargado.

Esta documentación se ha dividido en capítulos:

- [Configurar X for Websites](/x-for-websites/javascript-api/guides/set-up-x-for-websites)
- [Controlar la carga e inicialización de los widgets](/x-for-websites/javascript-api/guides/scripting-loading-and-initialization)
- [Factory functions para generar widgets](/x-for-websites/javascript-api/guides/scripting-factory-functions)
- [Eventos de widgets y Web Intents](/x-for-websites/javascript-api/guides/javascript-api)

Estas funciones permiten integrar el contenido de un usuario de X en tu sitio de forma dinámica en una aplicación JavaScript, e integrar las interacciones del usuario en la experiencia de tu propia aplicación.

Por favor, haz preguntas y comparte tu código y ejemplos en el [foro de desarrolladores](https://devcommunity.x.com/). También puedes consultar la [documentación principal de X for Websites](/x-for-websites/javascript-api/guides/set-up-x-for-websites).
