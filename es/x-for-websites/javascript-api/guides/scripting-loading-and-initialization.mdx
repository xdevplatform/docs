## Inicializar contenido incrustado después de que se haya cargado una página

La mayoría de integraciones de X for Websites funcionarán bien con el código de inserción recomendado en la [documentación de configuración](/x-for-websites/javascript-api/guides/set-up-x-for-websites), pero es posible que quieras optimizar cómo y cuándo los widgets JavaScript de Twitter for Websites escanean el DOM de la página para descubrir nuevos elementos HTML aptos para su conversión en botones o widgets.

Si se inserta contenido dinámicamente en una página (por ejemplo, carga diferida de contenido o el uso de una técnica de `pushState` para navegar entre artículos), es necesario parsear los nuevos botones y widgets usando la función `twttr.widgets.load()`.

```javascript
twttr.widgets.load()
```

Si se llama sin argumentos, `widgets-js` buscará en todo el árbol DOM de `document.body` widgets sin inicializar. Para un mejor rendimiento, pasa un objeto `HTMLElement` para restringir la búsqueda solo a los hijos de ese elemento.

Ejemplo:

```javascript
twttr.widgets.load(
  document.getElementById("container")
);
```
