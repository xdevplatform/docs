El JavaScript de X for Websites dispara eventos en la inicialización y después de que un usuario interactúa con un widget. Mejora tu aplicación y tu analítica aprovechando los eventos del widget.

Ten en cuenta que los eventos de Web Intent se disparan cuando ocurre la interacción, no cuando la acción se completa.

Vincula un evento de widget de X en tu código JavaScript registrando una función de callback con `twttr.events.bind`.

```javascript
twttr.events.bind(
  'click',
  function (ev) {
    console.log(ev);
  }
);
```

## El objeto de evento de Intent

Cuando ocurre una acción detectable dentro de un Web Intent o widget, se pasa un objeto que representa el evento a tu callback de JavaScript. Los objetos de evento de Intent incluyen los siguientes datos:

### Propiedades del objeto de evento de intent

| Propiedad | Tipo de dato    | Descripción                                                                                                           |
|----------|--------------|-----------------------------------------------------------------------------------------------------------------------|
| `target` | `HTMLElement` | El nodo del DOM donde se instancia el widget. Probablemente un iframe, pero también puede ser el elemento original del código de inserción si el widget no se inicializó, u otro elemento sandbox. Usa este valor para diferenciar entre distintos intents o botones en la misma página. |
| `region` | `String`     | Detalle ampliado que indica dónde en un widget se originó el evento. Por ejemplo, los componentes botón o contador de las integraciones de Post button o Follow button, o las acciones del Post dentro de un Post incrustado. |
| `data`   | `Object`     | Pares clave/valor relevantes para el evento.                                                                                |

## Espera de recursos asíncronos

Cargar el archivo widgets.js de forma asíncrona requerirá que esperes antes de vincular eventos: las funciones a las que llamas aún no existen. Deberás envolver tus vinculaciones de eventos en una función de callback, como la cola de funciones asíncronas twttr.ready, que se invocará una vez que todo se haya cargado. Todos los ejemplos de eventos a continuación asumen que has envuelto esas vinculaciones de eventos en este callback.

```javascript
twttr.ready(
  function (twttr) {
    // bind events here
  }
);
```

## Eventos disponibles

### loaded

Ocurre después de que `twttr.widgets.load` haya inicializado los widgets en una página. Incluye un array de referencias a los nodos de widget recién creados.

```javascript
twttr.events.bind(
  'loaded',
  function (event) {
    event.widgets.forEach(function (widget) {
      console.log("Created widget", widget.id);
    });
  }
);
```

### rendered

Ocurre después de que un widget individual en una página se renderiza. Incluye una referencia al nodo del widget recién creado. Ocurre al mismo tiempo que `loaded`, pero para cada widget individual. También se dispara al crear un widget con una factory function.

```javascript
twttr.events.bind(
  'rendered',
  function (event) {
    console.log("Created widget", event.target.id);
  }
);
```

### tweet

Este evento se disparará cuando el usuario haga clic en un Web Intent de Post.

Incluye un Post en respuesta a un [Post incrustado](/x-for-websites/timelines/overview) o un Post mostrado en un [Timeline incrustado](/x-for-websites/timelines/overview).

```javascript
twttr.events.bind(
  'tweet',
  function (event) {
    // Do something there
  }
);
```

### follow

Este evento rellenará el `user_id` o `screen_name` de la cuenta seguida en el argumento data del objeto de evento, según los parámetros que hayas proporcionado en el web intent.

```javascript
twttr.events.bind(
  'follow',
  function (event) {
    var followedUserId = event.data.user_id;
    var followedScreenName = event.data.screen_name;
  }
);
```

### retweet

Este evento rellenará el `source_tweet_id` del Post original que se ha reposteado en el argumento data del objeto de evento.

```javascript
twttr.events.bind(
  'retweet',
  function(event) {
    var repostedPostId = event.data.source_tweet_id;
  }
);
```

### like

Este evento rellenará el `tweet_id` del Post al que se le dio like en el argumento data del objeto de evento.

```javascript
twttr.events.bind(
  'like',
  function(event) {
    var likedPostId = event.data.tweet_id;
  }
);
```

### click

Recibe un evento cuando el usuario invoca un Web Intent desde dentro de un widget incrustado.

## Ejemplo: detectar eventos para analítica web


Es fácil capturar estos eventos y enviarlos a tu solución de analítica web. Ten en cuenta que deberás usar los protocolos HTTP o HTTPs en la página anfitriona para que estos eventos funcionen.

```javascript title="Ejemplo" expandable lines wrap icon="square-js"
// Log any kind of Web Intent event to Google Analytics
// Category: "twitter_web_intents"
// Action: Intent Event Type
// Label: Identifier for action taken: tweet_id, screen_name/user_id, click region

// First, load the widgets.js file asynchronously
window.twttr = (function(d, s, id) {
  var js, fjs = d.getElementsByTagName(s)[0],
    t = window.twttr || {};
  if (d.getElementById(id)) return;
  js = d.createElement(s);
  js.id = id;
  js.src = "https://platform.x.com/widgets.js";
  fjs.parentNode.insertBefore(js, fjs);

  t._e = [];
  t.ready = function(f) {
    t._e.push(f);
  };

  return t;
}(document, "script", "twitter-wjs"));

// Define our custom event handlers
function clickEventToAnalytics (intentEvent) {
  if (!intentEvent) return;
  var label = intentEvent.region;
  pageTracker._trackEvent('twitter_web_intents', intentEvent.type, label);
}

function postIntentToAnalytics (intentEvent) {
  if (!intentEvent) return;
  var label = "tweet";
  pageTracker._trackEvent(
    'twitter_web_intents',
    intentEvent.type,
    label
  );
}

function likeIntentToAnalytics (intentEvent) {
  postIntentToAnalytics(intentEvent);
}

function repostIntentToAnalytics (intentEvent) {
  if (!intentEvent) return;
  var label = intentEvent.data.source_tweet_id;
  pageTracker._trackEvent(
    'twitter_web_intents',
    intentEvent.type,
    label
  );
}

function followIntentToAnalytics (intentEvent) {
  if (!intentEvent) return;
  var label = intentEvent.data.user_id + " (" + intentEvent.data.screen_name + ")";
  pageTracker._trackEvent(
    'twitter_web_intents',
    intentEvent.type,
    label
  );
}

// Wait for the asynchronous resources to load
twttr.ready(function (twttr) {
  // Now bind our custom intent events
  twttr.events.bind('click', clickEventToAnalytics);
  twttr.events.bind('tweet', postIntentToAnalytics);
  twttr.events.bind('retweet', repostIntentToAnalytics);
  twttr.events.bind('like', likeIntentToAnalytics);
  twttr.events.bind('follow', followIntentToAnalytics);
});
```
