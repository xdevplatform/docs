Establece preferencias de widgets en todo un sitio web incluyendo elementos `<meta>` y `<link>` en tus páginas.

Los ajustes de widget especificados en un `<meta>` pueden sobrescribirse a nivel de widget individual. Orden de precedencia:

1. parámetro de consulta del enlace del web intent
2. atributo del widget
3. elemento meta o link

## Desactivar el escaneo del DOM para widgets y botones

El JavaScript de X for Websites escanea `document.body` tras la inicialización para localizar botones, widgets y web intents para su mejora. Desactiva este escaneo si el contenido de X solo se carga mediante [factory functions de JavaScript](/x-for-websites/javascript-api/guides/set-up-x-for-websites) o si prefieres [llamar directamente a load](/x-for-websites/javascript-api/guides/scripting-loading-and-initialization) sobre un fragmento más pequeño de la página.

```html
<meta
  name="twitter:widgets:autoload"
  content="off">
```

## Enlace canónico

El [botón Post](/x-for-websites/post-button/overview) utiliza la [relación canonical del enlace de la página](http://tools.ietf.org/html/rfc6596) expresada en un `<link>` como URL compartida si la propiedad URL no se establece en el marcado del botón.

Añade un enlace canónico en la sección `<head>` de tu página web.

```html
<link
  rel="canonical"
  href="/">
```

## Identificar el perfil de X de la página

Rellena la propiedad `via` de un botón Tweet enlazando a la página de tu perfil de X con un token de relación de enlace me.

Establece una relación de enlace `me` en la sección `<head>` de tu página web.

```xml
<link
  rel="me"
  href="https://x.com/XDevelopers">
```

También puedes establecer una relación `me` desde un elemento ancla en tu página, como un botón Follow.

```html
<a
  class="x-follow-button"
  rel="me"
  href="https://x.com/XDevelopers">
Follow @XDevelopers
</a>
```

## Tema

Sobrescribe la preferencia de tema `light` predeterminada para un [Post incrustado](/x-for-websites/embedded-posts/overview) o un [Timeline incrustado](/x-for-websites/timelines/overview).

```html
<meta
  name="twitter:widgets:theme"
  content="dark">
```

## Parámetro Do not track

Puedes elegir si los widgets de X en tu sitio ayudan a personalizar el contenido y las sugerencias para los usuarios de X, incluidos los anuncios. Puedes optar por no permitir el uso de información de tu sitio web para la personalización siguiendo las instrucciones que aparecen a continuación. Incluye el siguiente fragmento dentro de los elementos `<meta>` y `<link>` de tus páginas que contienen widgets de X for Websites:

```html
<meta name="twitter:dnt" content="on">
```

También puedes optar por no permitir este uso de datos para un widget específico, estableciendo el parámetro opcional `data-dnt` en true, como se muestra en el ejemplo siguiente:

```html
<a
  class="twitter-share-button"
  href="https://x.com/share"
  data-dnt="true">
Tweet</a>
<script async defer
  src="//platform.x.com/widgets.js"
  charset="utf-8">
</script>
```

## Desactivar la funcionalidad que podría desencadenar advertencias de Content Security Policy

Un Tweet incrustado o un Timeline incrustado puede mostrarse con capacidades restringidas cuando una [Content Security Policy](http://en.wikipedia.org/wiki/Content_Security_Policy) restringe la carga en línea de X. Establece `csp=on` para desactivar la funcionalidad que podría mostrar advertencias de Content Security Policy en tu sitio.

```html
<meta
  name="twitter:widgets:csp"
  content="on">
```
