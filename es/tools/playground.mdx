El [API Playground](https://github.com/xdevplatform/playground) es un servidor mock local que simula la X API v2 completa. Prueba endpoints, construye prototipos y explora la API sin consumir créditos reales de la API.

<Card title="Repositorio de GitHub" icon="github" href="https://github.com/xdevplatform/playground">
  Código fuente, releases y documentación completa.
</Card>

## Instalación

Requiere Go 1.21+. Instala desde el código fuente o descarga un binario precompilado desde [releases](https://github.com/xdevplatform/playground/releases).

<Tabs>
  <Tab title="Go install">
```bash
go install github.com/xdevplatform/playground/cmd/playground@latest
playground start
```
  </Tab>
  <Tab title="Compilar desde el código fuente">
```bash
git clone https://github.com/xdevplatform/playground.git
cd playground
go build -o playground ./cmd/playground
./playground start
```
  </Tab>
</Tabs>

El servidor arranca en `http://localhost:8080` por defecto.

## Inicio rápido

Haz solicitudes igual que las harías contra la API real: usa `test_token` como tu bearer token:

```bash title="me" lines wrap icon="terminal"
# Consultar un usuario
curl -H "Authorization: Bearer test_token" \
  http://localhost:8080/2/users/me

# Crear un post
curl -X POST -H "Authorization: Bearer test_token" \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello from the playground!"}' \
  http://localhost:8080/2/tweets

# Buscar posts
curl -H "Authorization: Bearer test_token" \
  "http://localhost:8080/2/tweets/search/recent?query=hello"
```

Abre `http://localhost:8080/playground` en tu navegador para la interfaz interactiva.

## Qué incluye

| Función | Descripción |
|:--------|:------------|
| **Validación de solicitudes** | Valida las solicitudes contra la spec de OpenAPI |
| **Errores realistas** | Devuelve códigos y mensajes de error apropiados |
| **Soporte de streaming** | Endpoints de streaming simulados |
| **Rate limiting** | Simulación configurable de rate limits |
| **Soporte de CORS** | Funciona con aplicaciones basadas en navegador |
| **Seguimiento de uso** | Endpoints simulados de facturación y seguimiento de créditos |
| **Persistencia de estado** | Persistencia opcional en archivo en `~/.playground/` |
