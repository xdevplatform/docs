Los endpoints de gestión de bloqueos de DM te permiten bloquear o desbloquear una cuenta especificada en nombre de un usuario autenticado. Para estos endpoints hay disponibles dos métodos POST:

* **/2/users/:id/dm/block**: Te permite bloquear una cuenta
* **/2/users/:id/dm/unblock**: Te permite desbloquear una cuenta


### Primeros pasos
### Autenticación

Como estás realizando solicitudes en nombre de un usuario, debes autenticar estos endpoints con [OAuth 1.0a User Context](/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow) o [OAuth 2.0 Authorization Code with PKCE](/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2), y utilizar los Access Tokens de usuario asociados al usuario en cuyo nombre estás haciendo la solicitud. Puedes generar este Access Token de usuario usando el [flujo OAuth de 3 pasos](https://developer.x.com/resources/fundamentals/authentication/obtaining-user-access-tokens) (OAuth 1.0a) o usando el [flujo Authorization Code with PKCE grant](/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) (OAuth 2.0).

### Realizar una solicitud

Bloquear

Una vez que un usuario se haya autenticado con tu app, puedes llamar al endpoint Block en nombre del usuario como se muestra a continuación:

      ```
      curl --request POST 'https://api.x.com/2/users/:id/dm/block' --header 'Authorization: ••••••'
      ```




Si la solicitud es exitosa, deberías ver la respuesta JSON como se muestra a continuación:

```json
{
   "data": {
       "blocked": true
   }
}
```




**Desbloquear**

Una vez que un usuario se haya autenticado con tu app, puedes llamar al endpoint Unblock en nombre del usuario como se muestra a continuación:

      ```
      curl --request POST 'https://api.x.com/2/users/:id/dm/unblock' --header 'Authorization: ••••••'
      ```




Si la solicitud es exitosa, deberías ver la respuesta JSON como se muestra a continuación:

```json
{
   "data": {
       "blocked": false
   }
}
```
