Esta guía cubre los conceptos clave que necesitas para integrar los endpoints de gestión de Mensajes Directos en tu aplicación.

---

## Autenticación

Los endpoints de DM requieren autenticación de usuario:

| Método | Descripción |
|:-------|:------------|
| [OAuth 2.0 Authorization Code with PKCE](/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) | Recomendado |
| [OAuth 1.0a User Context](/resources/fundamentals/authentication) | Soporte legacy |

<Warning>
La autenticación App-Only no es compatible. Todos los Mensajes Directos son privados.
</Warning>

### Scopes requeridos (OAuth 2.0)

| Scope | Requerido para |
|:------|:-------------|
| `dm.write` | Enviar y eliminar mensajes |
| `dm.read` | Requerido con dm.write |
| `tweet.read` | Requerido con scopes dm |
| `users.read` | Requerido con scopes dm |

---

## Descripción general de endpoints

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| POST | `/2/dm_conversations/with/:participant_id/messages` | Enviar mensaje uno a uno |
| POST | `/2/dm_conversations` | Crear conversación grupal |
| POST | `/2/dm_conversations/:dm_conversation_id/messages` | Añadir mensaje a conversación |
| DELETE | `/2/dm_events/:event_id` | Eliminar un mensaje |

## Enviar mensajes

### Mensaje uno a uno

Envía un mensaje a un usuario específico. Crea una nueva conversación si no existe una:

<CodeGroup dropdown>

```bash cURL
curl -X POST "https://api.x.com/2/dm_conversations/with/9876543210/messages" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello!"}'
```

```python SDK de Python
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# Send a one-to-one DM
response = client.dm_conversations.create_message(
    participant_id="9876543210",
    text="Hello!"
)
print(response.data)
```

```javascript SDK de JavaScript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// Send a one-to-one DM
const response = await client.dmConversations.createMessage({
  participantId: "9876543210",
  text: "Hello!",
});
console.log(response.data);
```

</CodeGroup>

### Conversación grupal

Crea un nuevo grupo y envía el primer mensaje:

<CodeGroup dropdown>

```bash cURL
curl -X POST "https://api.x.com/2/dm_conversations" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "conversation_type": "Group",
    "participant_ids": ["944480690", "906948460078698496"],
    "message": {"text": "Welcome to our group!"}
  }'
```

```python SDK de Python
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# Create a group conversation
response = client.dm_conversations.create(
    conversation_type="Group",
    participant_ids=["944480690", "906948460078698496"],
    message={"text": "Welcome to our group!"}
)
print(response.data)
```

```javascript SDK de JavaScript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// Create a group conversation
const response = await client.dmConversations.create({
  conversationType: "Group",
  participantIds: ["944480690", "906948460078698496"],
  message: { text: "Welcome to our group!" },
});
console.log(response.data);
```

</CodeGroup>

<Note>
El campo `conversation_type` debe estar configurado como `"Group"` (sensible a mayúsculas).
</Note>

### Añadir a una conversación existente

Envía un mensaje a cualquier conversación de la que formes parte:

<CodeGroup dropdown>

```bash cURL
curl -X POST "https://api.x.com/2/dm_conversations/1582103724607971328/messages" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text": "Another message"}'
```

```python SDK de Python
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# Add message to existing conversation
response = client.dm_conversations.add_message(
    dm_conversation_id="1582103724607971328",
    text="Another message"
)
print(response.data)
```

```javascript SDK de JavaScript
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// Add message to existing conversation
const response = await client.dmConversations.addMessage({
  dmConversationId: "1582103724607971328",
  text: "Another message",
});
console.log(response.data);
```

</CodeGroup>

## Adjuntos de medios

Adjunta un elemento de medio (foto, video o GIF) por mensaje.

<Steps>
  <Step title="Sube el medio">
    Usa el [endpoint de Media Upload](/x-api/media/quickstart/media-upload-chunked) para subir tu archivo y obtener un `media_id`.
  </Step>

  <Step title="Inclúyelo en el mensaje">
```json
{
  "text": "Check out this image!",
  "attachments": [{"media_id": "1583157113245011970"}]
}
```
  </Step>
</Steps>

<Note>
- El usuario autenticado debe haber subido el medio
- El medio está disponible durante 24 horas después de la carga
- Solo se admite un adjunto por mensaje
</Note>

## Compartir posts

Incluye un Post en tu mensaje añadiendo la URL del Post al texto:

```json
{
  "text": "Have you seen this? https://x.com/XDevelopers/status/1580559079470145536"
}
```

La respuesta incluirá un campo `referenced_tweets` con el ID del Post.

---

## Requisitos de mensaje

| Campo | Requerido | Notas |
|:------|:---------|:------|
| `text` | Sí* | Requerido si no hay attachments |
| `attachments` | Sí* | Requerido si no hay text |

*Al menos uno de `text` o `attachments` debe proporcionarse.

---

## Compatibilidad de IDs con v1.1

Los IDs de conversación y evento se comparten entre los endpoints v1.1 y v2. Esto permite flujos híbridos:

- Crear mensajes con v2
- Eliminar mensajes con v1.1 (aún no disponible en v2)
- Referenciar los IDs de conversación de las URLs de x.com

## Gestión de errores

| Estado | Error | Solución |
|:-------|:------|:---------|
| 400 | Solicitud inválida | Verifica el formato del cuerpo de la solicitud |
| 401 | Unauthorized | Verifica el access token |
| 403 | Forbidden | Verifica los scopes y permisos de usuario |
| 429 | Too Many Requests | Espera y reintenta |

### Problemas comunes

<AccordionGroup>
  <Accordion title="No se puede enviar al usuario">
    El destinatario puede tener configuraciones de DM que impiden mensajes de usuarios desconocidos, o puede haberte bloqueado.
  </Accordion>

  <Accordion title="El adjunto de media falló">
    Asegúrate de que el medio fue subido por el mismo usuario autenticado y tiene menos de 24 horas.
  </Accordion>

  <Accordion title="La creación del grupo falló">
    Verifica que todos los IDs de participante sean válidos y que los usuarios permitan invitaciones a DM grupales.
  </Accordion>
</AccordionGroup>
