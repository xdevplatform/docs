Los endpoints de gestión de Mensajes Directos te permiten enviar y eliminar Mensajes Directos en nombre de usuarios autenticados.

## Endpoints

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| POST | `/2/dm_conversations` | Crear una nueva conversación |
| POST | `/2/dm_conversations/with/:participant_id/messages` | Enviar a conversación uno a uno |
| POST | `/2/dm_conversations/:dm_conversation_id/messages` | Enviar a conversación existente |
| DELETE | `/2/dm_events/:id` | Eliminar un evento de DM |

---

## Ejemplo: Enviar un mensaje

```bash
curl -X POST "https://api.x.com/2/dm_conversations/with/1234567890/messages" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello! How are you?"}'
```

## Ejemplo de respuesta

```json
{
  "data": {
    "dm_conversation_id": "1234567890-0987654321",
    "dm_event_id": "1122334455667788990"
  }
}
```

---

## Tipos de mensajes

Puedes enviar mensajes de texto y adjuntar medios:

```json
{
  "text": "Check out this photo!",
  "attachments": [{
    "media_id": "1234567890123456789"
  }]
}
```
