Los endpoints de búsqueda de Mensajes Directos te permiten recuperar eventos de DM para el usuario autenticado, incluyendo mensajes tanto de conversaciones uno a uno como grupales.

## Descripción general

<CardGroup cols={2}>
  <Card title="Todos los eventos de DM" icon="messages">
    Obtén todos los eventos de DM del usuario
  </Card>
  <Card title="Uno a uno" icon="/icons/xds/icon-chat.svg">
    Obtén eventos de una conversación específica
  </Card>
  <Card title="Por ID de conversación" icon="/icons/xds/icon-chat-unread.svg">
    Obtén eventos por ID de conversación
  </Card>
  <Card title="Tipos de eventos" icon="/icons/xds/icon-bell.svg">
    Mensajes, entradas y salidas
  </Card>
</CardGroup>

---

## Endpoints

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/dm_events`](/x-api/direct-messages/get-dm-events) | Obtén todos los eventos de DM del usuario |
| GET | [`/2/dm_conversations/with/:participant_id/dm_events`](/x-api/direct-messages/get-dm-events-for-a-dm-conversation) | Obtén eventos de conversación uno a uno |
| GET | [`/2/dm_conversations/:dm_conversation_id/dm_events`](/x-api/direct-messages/get-dm-events-for-a-dm-conversation-1) | Obtén eventos por ID de conversación |

---

## Tipos de eventos

| Evento | Descripción |
|:------|:------------|
| `MessageCreate` | Se envió un mensaje en la conversación |
| `ParticipantsJoin` | Un usuario se unió a la conversación |
| `ParticipantsLeave` | Un usuario abandonó la conversación |

---

## Retención de datos

<Note>
Los eventos de hasta hace **30 días** están disponibles a través de estos endpoints.
</Note>
