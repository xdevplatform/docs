## Recuperar datos perdidos

Si experimentas una desconexión, consulta [Recuperación y redundancia](/x-api/fundamentals/recovery-and-redundancy) para conocer estrategias que recuperan datos perdidos, incluyendo:

- **Backfill** — Usa el parámetro `backfillMinutes` para desconexiones de 5 minutos o menos
- **Recovery** — Usa los parámetros `startTime` y `endTime` para desconexiones más largas (hasta 24 horas)

### Ejemplo de backfill de Powerstream

```bash
curl 'https://api.x.com/2/powerstream?backfillMinutes=5' \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

### Ejemplo de recuperación de Powerstream

```bash
curl 'https://api.x.com/2/powerstream?startTime=2022-07-12T15:10:00Z&endTime=2022-07-12T15:20:00Z' \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```
