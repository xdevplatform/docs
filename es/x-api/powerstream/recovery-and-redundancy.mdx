Esta página cubre las funciones de recuperación y redundancia específicas de Powerstream. Para una guía integral sobre recuperación y redundancia en todos los endpoints de streaming, consulta la [guía de fundamentos de recuperación y redundancia](/x-api/fundamentals/recovery-and-redundancy).

## Funciones de recuperación de Powerstream

Los conceptos principales de recuperación y redundancia se aplican a todos los endpoints de streaming. Consulta la guía de fundamentos para:

- Conexiones redundantes
- Árbol de decisión Backfill vs. Recuperación
- Buenas prácticas

## Backfill

Para desconexiones de **5 minutos o menos**, usa el parámetro `backfillMinutes`:

```bash
curl 'https://api.x.com/2/powerstream?backfillMinutes=5' \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

<Note>
Los Posts más antiguos se entregan primero. Los Posts **no** se deduplican — tu sistema debe tolerar duplicados.
</Note>

## Recuperación

Para desconexiones **de más de 5 minutos** (hasta 24 horas), usa los parámetros `startTime` y `endTime`:

| Parámetro | Tipo | Descripción |
|:----------|:-----|:------------|
| `startTime` | Fecha ISO 8601 | Hora de inicio desde la cual recuperar (UTC) |
| `endTime` | Fecha ISO 8601 | Hora final hasta la cual recuperar (UTC) |

```bash
curl 'https://api.x.com/2/powerstream?startTime=2022-07-12T15:10:00Z&endTime=2022-07-12T15:20:00Z' \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

Una vez conectado, Recovery volverá a transmitir el período especificado y luego se desconectará.
