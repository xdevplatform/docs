El endpoint Usage te permite monitorear tu uso de la API, incluido el número de Posts consumidos. Realiza un seguimiento programático de tu uso para gestionar costos y mantenerte dentro de los límites.

<Note>
Los planes de pago por uso están sujetos a un tope mensual de 2 millones de lecturas de Post. Si necesitas mayor volumen, considera un [plan Enterprise](/forms/enterprise-api-interest).
</Note>

## Endpoint

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/usage/tweets`](/x-api/usage/get-usage) | Obtener datos de uso de Post |

---

## Datos de respuesta

La respuesta incluye los conteos diarios de consumo de Post:

```json title="Respuesta de ejemplo" lines wrap icon="/icons/xds/icon-brackets.svg"
{
  "data": {
    "daily_project_usage": [
      {
        "date": "2024-01-15",
        "usage": [
          {
            "app_id": "12345678",
            "tweets_consumed": 15420
          }
        ]
      }
    ],
    "project_id": "1234567890",
    "project_cap": 10000000
  }
}
```

### Campos

| Campo | Descripción |
|:------|:------------|
| `daily_project_usage` | Arreglo de datos de uso diario |
| `date` | Fecha en formato YYYY-MM-DD |
| `app_id` | El ID de tu App |
| `tweets_consumed` | Posts consumidos ese día |
| `project_cap` | Tu límite mensual de Posts |

---

## Solicitud de ejemplo

```bash
curl "https://api.x.com/2/usage/tweets" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

## Casos de uso

- **Monitoreo de costos** — Rastrea el consumo frente a tu presupuesto
- **Alertas** — Configura alertas cuando te acerques a los límites
- **Optimización** — Identifica endpoints de alto consumo
- **Reportes** — Genera reportes de uso

<Tip>
Los recursos se deduplican dentro de una ventana UTC de 24 horas, por lo que solicitar el mismo recurso varias veces en un día solo cuenta como un cargo. [Más información sobre precios →](/x-api/getting-started/pricing)
</Tip>
