Un objeto de medio representa una única foto, video o GIF animado. Los objetos de medios son utilizados por muchos endpoints dentro de la X API, y pueden incluirse en Posts, Mensajes Directos, perfiles de usuario, creatividades publicitarias y otros lugares. Cada objeto de medio puede tener múltiples variantes de visualización o reproducción, con diferentes resoluciones o formatos.

## Tipos de medios y restricciones de tamaño

Restricciones de tamaño para la carga mediante la API 

- **Imagen**: `5 MB`
- **GIF**: `15 MB`
- **Video**: `512 MB` (cuando se usa `media_category=amplify_video`)

## Creación

Objetos como Posts, Mensajes Directos, imágenes de perfil de usuario, tarjetas de anuncios alojadas, etc. pueden contener uno o más objetos de medios. Estos objetos de nivel superior se conocen colectivamente como entidades. A la API de creación de entidades correspondiente (por ejemplo, [`POST /2/tweets`](/x-api/posts/creation-of-a-post)) se le pueden pasar uno o más objetos de medios utilizando un `media_id` único.

Una entidad que contiene objetos de medios se puede crear siguiendo estos pasos:

1. Sube el archivo o archivos de medios usando la carga [por partes](/x-api/media/quickstart/media-upload-chunked) recomendada (imágenes/GIF/video), o la carga [simple](/x-api/media/upload-media) más antigua (solo imágenes).
1. Recibe un `media_id` del paso 1. Este paso puede repetirse varias veces con diferentes medios si la entidad permite pasar varios parámetros `media_id`.
1. Crea la entidad llamando al endpoint apropiado, incluyendo el `media_id` y otros parámetros requeridos. Por ejemplo, adjunta un `media_id` a un Post usando el endpoint [`POST /2/tweets`](/x-api/posts/creation-of-a-post).
