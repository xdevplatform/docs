## Endpoint

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/spaces/search`](/x-api/spaces/search-spaces) | Buscar Spaces |

---

## Parámetros

| Parámetro | Descripción |
|:----------|:------------|
| `query` | Consulta de búsqueda (obligatorio) |
| `state` | Filtrar por `live` o `scheduled` |
| `space.fields` | Campos adicionales de Space |
| `expansions` | Objetos relacionados a incluir |

---

## Solicitud de ejemplo

```bash
curl "https://api.x.com/2/spaces/search?\
query=AI&\
state=live&\
space.fields=title,host_ids,participant_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
