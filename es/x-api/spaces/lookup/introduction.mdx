## Endpoints

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/spaces/:id`](/x-api/spaces/get-space-by-id) | Obtener Space por ID |
| GET | [`/2/spaces`](/x-api/spaces/get-spaces-by-ids) | Obtener Spaces por IDs |
| GET | [`/2/spaces/by/creator_ids`](/x-api/spaces/get-spaces-by-creator-ids) | Obtener Spaces por user IDs de creador |
| GET | [`/2/spaces/:id/buyers`](/x-api/spaces/get-space-ticket-buyers) | Obtener compradores de entradas para un Space |
| GET | [`/2/spaces/:id/tweets`](/x-api/spaces/get-space-posts) | Obtener Posts compartidos en un Space |

## Campos de respuesta

Por defecto, la respuesta incluye `id` y `state`. Solicita campos adicionales:

| Campo | Descripción |
|:------|:------------|
| `title` | Título del Space |
| `host_ids` | User IDs de los hosts |
| `speaker_ids` | User IDs de los speakers |
| `participant_count` | Número de participantes |
| `scheduled_start` | Hora de inicio programada |
| `started_at` | Hora de inicio real |
| `ended_at` | Hora de finalización |
| `is_ticketed` | Si el Space tiene entradas |

### Estados de Space

| Estado | Descripción |
|:------|:------------|
| `live` | Actualmente activo |
| `scheduled` | Programado a futuro |
| `ended` | Ha finalizado |

---

## Solicitud de ejemplo

```bash
curl "https://api.x.com/2/spaces/1DXxyRYNejbKM?\
space.fields=title,host_ids,participant_count,scheduled_start,state" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
