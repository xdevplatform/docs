## Endpoint

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/communities/search`](/x-api/communities/search-communities) | Buscar Communities |

---

## Parámetros

| Parámetro | Descripción |
|:----------|:------------|
| `query` | Consulta de búsqueda (obligatorio) |
| `max_results` | Resultados por página (máx. 100) |
| `community.fields` | Campos adicionales de Community |

---

## Solicitud de ejemplo

```bash
curl "https://api.x.com/2/communities/search?\
query=Python&\
max_results=10&\
community.fields=name,description,member_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
