El endpoint de búsqueda de news permite a los desarrolladores obtener noticias y titulares que están sonando en X.

Este endpoint admite autenticación app-auth y user-auth para OAuth1 y OAuth2 PKCE.

## Primeros pasos

Para usar el endpoint, necesitas un [bearer token](/fundamentals/authentication/oauth-2-0/application-only) desde el [Developer Console](https://developer.x.com/en/portal/dashboard).

Una vez que tengas el bearer token, puedes llamar a la news API como se muestra a continuación:

```bash
curl 'https://api.x.com/2/news/1989418137272422538?news.fields=contexts,cluster_posts_results' --header 'Authorization: Bearer XXXXX'
```
