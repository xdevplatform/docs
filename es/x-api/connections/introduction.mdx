Los endpoints de Stream Connections te permiten recuperar el historial de las conexiones de streaming de tu aplicación y terminar conexiones activas o múltiples. Úsalos para monitorear el estado de las conexiones, resolver problemas como conexiones duplicadas y gestionar sesiones de streaming para endpoints como Filtered Stream y Sampled Stream.

<Note>
Estos endpoints requieren [autenticación con Bearer Token](/fundamentals/authentication/oauth-2-0/application-only) y están disponibles para apps con acceso a endpoints de streaming.
</Note>

## Endpoints

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/connections`](/x-api/connections/get-connection-history) | Obtener conexiones de streaming activas e históricas |
| DELETE | [`/2/connections/all`](/x-api/connections/terminate-all-connections) | Terminar todas las conexiones activas |
| DELETE | [`/2/connections/{endpoint_id}`](/x-api/connections/terminate-connections-by-endpoint) | Terminar conexiones para un endpoint específico |
| DELETE | [`/2/connections`](/x-api/connections/terminate-multiple-connections) | Terminar múltiples conexiones por UUIDs |

---

## Casos de uso

- **Solucionar desconexiones** — Revisa el historial para diagnosticar problemas ([ver manejo de desconexiones](/x-api/fundamentals/handling-disconnections))
- **Aplicar límites de conexión** — Termina conexiones duplicadas o en exceso
- **Limpiar sesiones** — Detén todos los streams antes de mantenimiento o redespliegue
- **Monitorear el uso** — Rastrea patrones de conexión en endpoints como filtered_stream, sample_stream
