Esta guía te muestra cómo agregar y eliminar bookmarks usando la X API.

<Note>
**Requisitos previos**

Antes de comenzar, necesitarás:
- Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
- Un User Access Token con el scope `bookmark.write` (OAuth 2.0 PKCE)
</Note>

---

## Agregar un bookmark

<Steps>
  <Step title="Obtén tu ID de usuario">
    Necesitas el ID de tu usuario autenticado. Puedes encontrarlo usando el endpoint `/2/users/me` o el [endpoint de user lookup](/x-api/users/lookup/introduction).
  </Step>

  <Step title="Obtén el ID del Post">
    Encuentra el ID del Post en la URL cuando visualizas un Post:

    ```
    https://x.com/XDevelopers/status/1460323737035677698
                                    └── Este es el ID del Post
    ```
  </Step>

  <Step title="Agrega el bookmark">

<CodeGroup dropdown>

```bash cURL
curl -X POST "https://api.x.com/2/users/2244994945/bookmarks" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1460323737035677698"}'
```

```python Python SDK
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# Agrega un bookmark
response = client.bookmarks.create(
    user_id="2244994945",
    tweet_id="1460323737035677698"
)

print(f"Bookmarked: {response.data.bookmarked}")
```

```javascript JavaScript SDK
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// Agrega un bookmark
const response = await client.bookmarks.create("2244994945", {
  tweetId: "1460323737035677698",
});

console.log(`Bookmarked: ${response.data?.bookmarked}`);
```

</CodeGroup>

  </Step>

  <Step title="Revisa la respuesta">
    ```json
    {
      "data": {
        "bookmarked": true
      }
    }
    ```
  </Step>
</Steps>

## Eliminar un bookmark

Elimina un Post de tus bookmarks:

<CodeGroup dropdown>

```bash cURL
curl -X DELETE "https://api.x.com/2/users/2244994945/bookmarks/1460323737035677698" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python Python SDK
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# Elimina un bookmark
response = client.bookmarks.delete(
    user_id="2244994945",
    tweet_id="1460323737035677698"
)

print(f"Bookmarked: {response.data.bookmarked}")
```

```javascript JavaScript SDK
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// Elimina un bookmark
const response = await client.bookmarks.delete("2244994945", "1460323737035677698");

console.log(`Bookmarked: ${response.data?.bookmarked}`);
```

</CodeGroup>

**Respuesta:**

```json
{
  "data": {
    "bookmarked": false
  }
}
```

## Scopes requeridos

Al usar OAuth 2.0 PKCE, tu access token debe tener estos scopes:

| Scope | Description |
|:------|:------------|
| `bookmark.write` | Agregar y eliminar bookmarks |
| `tweet.read` | Leer datos de Posts |
| `users.read` | Leer datos de usuarios |
