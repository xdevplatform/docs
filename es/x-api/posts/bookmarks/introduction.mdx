Los endpoints de Bookmarks te permiten ver, agregar y eliminar Posts guardados como bookmarks para el usuario autenticado. Los bookmarks son privados y solo son visibles para el usuario que los creó.

## Descripción general

<CardGroup cols={2}>
  <Card title="Ver bookmarks" icon="bookmark">
    Obtén todos los Posts guardados como bookmarks
  </Card>
  <Card title="Agregar bookmark" icon="plus">
    Guarda un Post como bookmark
  </Card>
  <Card title="Eliminar bookmark" icon="minus">
    Elimina un Post guardado como bookmark
  </Card>
  <Card title="Carpetas de bookmarks" icon="folder">

  </Card>
</CardGroup>

## Endpoints

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/bookmarks`](/x-api/users/get-bookmarks) | Obtiene los bookmarks del usuario |
| POST | [`/2/users/:id/bookmarks`](/x-api/users/create-bookmark) | Guarda un Post como bookmark |
| DELETE | [`/2/users/:id/bookmarks/:tweet_id`](/x-api/users/delete-bookmark) | Elimina un bookmark |
| GET | [`/2/users/:id/bookmarks/folders`](/x-api/users/get-bookmark-folders) | Obtiene las carpetas de bookmarks |
| GET | [`/2/users/:id/bookmarks/folders/:folder_id`](/x-api/users/get-bookmarks-by-folder-id) | Obtiene los Posts de una carpeta |

---

## Ejemplo: Obtener bookmarks

```bash
curl "https://api.x.com/2/users/123456789/bookmarks?\
tweet.fields=created_at,author_id,public_metrics" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

## Ejemplo: Agregar bookmark

```bash
curl -X POST "https://api.x.com/2/users/123456789/bookmarks" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
