## Comparación de los endpoints de filtered stream de la X API

El grupo de endpoints de filtered stream v2 está reemplazando [statuses/filter estándar v1.1](https://developer.x.com/en/docs/x-api/v1/tweets/filter-realtime/api-reference/post-statuses-filter) y la [API de PowerTrack](/x-api/enterprise-gnip-2.0/powertrack-api). Si tienes código, apps o herramientas que utilizan una versión anterior del endpoint de filtered stream y estás considerando migrar al endpoint más reciente de X API v2, entonces esta comparación puede ayudarte a comenzar. 

Consulta nuestras guías de migración más detalladas para:

[Migrar de Standard v1.1 comparado con X API v2](x-api/posts/filtered-stream#standard-v1-1-compared-to-x-api-v2)

[Migrar de la API de PowerTrack a X API v2](/x-api/enterprise-gnip-2.0/powertrack-api#powertrack-operators)
