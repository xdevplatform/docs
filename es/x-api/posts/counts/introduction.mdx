Los endpoints de Post counts devuelven el volumen de Posts que coinciden con una consulta a lo largo del tiempo, sin devolver los propios Posts. Utiliza estos endpoints para analizar tendencias, comprender el tamaño de una conversación y refinar consultas antes de realizar búsquedas.

## Descripción general

<CardGroup cols={2}>
  <Card title="Análisis de volumen" icon="/icons/xds/icon-bar-chart.svg">
    Construye líneas de tendencia y visualizaciones que muestran el volumen de Posts a lo largo del tiempo
  </Card>
  <Card title="Refinamiento de consultas" icon="/icons/xds/icon-filter.svg">
    Estima el tamaño del resultado antes de ejecutar consultas de búsqueda completas
  </Card>
  <Card title="Detección de eventos" icon="calendar">
    Identifica cuándo alcanzaron su pico las conversaciones en torno a eventos
  </Card>
  <Card title="Investigación eficiente" icon="gauge-high">
    Comprende la escala de una conversación sin recuperar todos los Posts
  </Card>
</CardGroup>

## Endpoints

| Endpoint | Description | Access |
|:---------|:------------|:-------|
| GET [`/2/tweets/counts/recent`](/x-api/posts/get-count-of-recent-posts) | Cuenta los Posts de los últimos 7 días | Todos los desarrolladores |
| GET [`/2/tweets/counts/all`](/x-api/posts/get-count-of-all-posts) | Cuenta los Posts del archivo completo | Pay-per-use, Enterprise |

---

## Opciones de granularidad

Especifica cómo se agrupan los recuentos utilizando el parámetro `granularity`:

| Granularity | Description | Use case |
|:------------|:------------|:---------|
| `minute` | Recuentos por minuto | Monitorización en tiempo real |
| `hour` | Recuentos por hora (predeterminado) | Análisis diario |
| `day` | Recuentos por día | Tendencias a largo plazo |

## Recent counts

Cuenta los Posts de los **últimos 7 días**. Disponible para todos los desarrolladores.

### Características

- Recuentos agrupados por minuto, hora o día
- Los mismos operadores de consulta que recent search
- Longitud de consulta de 512 caracteres

### Ejemplo de respuesta

```json
{
  "data": [
    { "start": "2024-01-15T00:00:00.000Z", "end": "2024-01-15T01:00:00.000Z", "tweet_count": 1523 },
    { "start": "2024-01-15T01:00:00.000Z", "end": "2024-01-15T02:00:00.000Z", "tweet_count": 1247 },
    { "start": "2024-01-15T02:00:00.000Z", "end": "2024-01-15T03:00:00.000Z", "tweet_count": 892 }
  ],
  "meta": {
    "total_tweet_count": 3662
  }
}
```

## Full-archive counts

Cuenta los Posts del **archivo completo** hasta 2006.

<Note>
Los full-archive counts están disponibles para clientes pay-per-use y Enterprise.
</Note>

### Características

- Cuenta Posts históricos de cualquier período de tiempo
- Todos los operadores de consulta disponibles
- Longitud de consulta de 1,024 caracteres (4,096 para Enterprise)

### Paginación

Los resultados paginan con 31 días por respuesta:
- **Granularidad de día**: 31 días por página
- **Granularidad de hora**: 744 horas (31 días) por página
- **Granularidad de minuto**: 44,640 minutos (31 días) por página

Post counts usa la misma sintaxis de consulta que los endpoints de search:

```
python lang:en -is:retweet
```

## Notas importantes

<Note>
**Counts vs resultados de búsqueda**

Los recuentos pueden no coincidir exactamente con los resultados de búsqueda. Los endpoints de búsqueda aplican filtrado de cumplimiento adicional que los endpoints de counts no realizan.
</Note>
