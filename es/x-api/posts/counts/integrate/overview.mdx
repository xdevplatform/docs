Esta página cubre las herramientas y los conceptos clave para integrar los endpoints de Post counts.

## Herramientas útiles

Antes de comenzar a explorar algunos conceptos clave, te recomendamos que uses una de las siguientes herramientas o ejemplos de código para empezar a probar la funcionalidad de estos endpoints.

### Ejemplos de código

¿Te interesa configurar estos endpoints con código en tu lenguaje de programación preferido? Contamos con varios ejemplos de código disponibles que puedes usar como punto de partida en nuestra [página de GitHub](https://github.com/xdevplatform/Twitter-API-v2-sample-code), incluido un [cliente en Python](https://github.com/xdevplatform/search-tweets-python).

### Bibliotecas

Aprovecha una de nuestras muchas [bibliotecas de terceros de la comunidad](/tools-and-libraries) para ayudarte a comenzar. Puedes encontrar una biblioteca que funcione con los endpoints v2 buscando la etiqueta de versión correspondiente.

### Postman

Postman es una excelente herramienta que puedes usar para probar estos endpoints. Cada solicitud de Postman incluye todos los parámetros del endpoint para ayudarte a comprender rápidamente lo que tienes disponible. Para obtener más información sobre nuestras colecciones de Postman, visita nuestra página [Usando Postman](/tutorials/postman-getting-started).

## Conceptos clave

### Autenticación

Todos los endpoints de X API v2 requieren que las solicitudes estén [autenticadas](/resources/fundamentals/authentication) con un conjunto de credenciales, también conocidas como keys y tokens. Este endpoint específico requiere el uso de [OAuth 2.0 Bearer Token](/resources/fundamentals/authentication#oauth-2-0), lo que significa que debes pasar un [Bearer Token](/resources/fundamentals/authentication#bearer-token-also-known-as-app-only) para hacer una solicitud exitosa. Puedes generar un Bearer Token directamente desde una developer App o generarlo usando el endpoint [POST oauth2/token](/resources/fundamentals/authentication#post-oauth2-token).

### Developer Console, Projects y developer Apps

Para trabajar con cualquier endpoint de X API v2, debes tener una [cuenta de desarrollador](/resources/fundamentals/developer-portal), configurar un [Project](/resources/fundamentals/developer-apps) dentro de esa cuenta y crear una [developer App](/resources/fundamentals/developer-apps) dentro de ese Project. Tus keys y tokens dentro de esa developer App funcionarán para los endpoints de recent Post counts. Si deseas usar el endpoint de full-archive Post counts, o utilizar los operadores avanzados y la longitud de consulta más larga, deberás haber sido aprobado para acceso enterprise.

Visita nuestra sección sobre acceso enterprise para obtener más información.

### Límites de tasa

Cada día, miles de desarrolladores realizan solicitudes a la X API. Para ayudar a gestionar el volumen, se colocan [límites de tasa](/x-api/fundamentals/rate-limits) en cada endpoint que limitan el número de solicitudes que cada desarrollador puede hacer en nombre de una app o en nombre de un usuario autenticado.

Este endpoint tiene un límite de tasa a nivel de App, lo que significa que tú, el desarrollador, solo puedes realizar un cierto número de solicitudes a este endpoint durante un período de tiempo dado desde cualquier App (asumido por las credenciales que estás usando). 

### Construir consultas

La característica central de estos endpoints es su uso de una sola consulta para filtrar los Posts en los recuentos que se te entregan. Estas consultas se componen de operadores que coinciden con atributos de Posts y usuarios, como palabras clave del mensaje, hashtags y URLs. Los operadores pueden combinarse en consultas con lógica booleana y paréntesis para ayudar a refinar el comportamiento de coincidencia de la consulta.

Puedes usar nuestra guía sobre [cómo construir una consulta](/x-api/posts/counts/integrate/build-a-query) para obtener más información.

### Paginación

Para recent Post counts, no se devuelve un next_token, lo que significa que independientemente de la granularidad, obtendrás el volumen de Posts de los últimos 7 días en una sola llamada a la API.

Para full-archive Post counts, obtendrás datos de los últimos 30 días. Para datos de más de 30 días, obtendrás un next_token que luego puedes usar para paginar y obtener los datos adicionales.
