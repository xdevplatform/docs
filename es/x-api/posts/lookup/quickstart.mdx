Esta guía te muestra cómo hacer tu primera solicitud de Post lookup usando la X API v2.

<Note>
**Requisitos previos**

Antes de comenzar, necesitarás:
- Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
- El Bearer Token de tu App (que se encuentra en la Developer Console en "Keys and tokens")
</Note>

---

<Steps>
  <Step title="Encuentra un ID de Post">
    Cada Post tiene un ID único. Puedes encontrarlo en la URL del Post:

    ```
    https://x.com/XDevelopers/status/1228393702244134912
                                    └── Este es el ID del Post
    ```
  </Step>

  <Step title="Realiza una solicitud">

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/tweets/1228393702244134912" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python Python SDK
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obtén un solo Post por ID
response = client.posts.get("1228393702244134912")
print(response.data)
```

```javascript JavaScript SDK
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

const response = await client.posts.get("1228393702244134912");
console.log(response.data);
```

</CodeGroup>

  </Step>

  <Step title="Revisa la respuesta">
    La respuesta predeterminada incluye el `id`, `text` y `edit_history_tweet_ids` del Post:

    ```json
    {
      "data": {
        "id": "1228393702244134912",
        "text": "What did the developer write in their Valentine's card?\n\nwhile(true) {\n    I = Love(You);\n}",
        "edit_history_tweet_ids": ["1228393702244134912"]
      }
    }
    ```
  </Step>

  <Step title="Solicita fields adicionales">
    Usa parámetros de consulta para obtener más datos:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/tweets/1228393702244134912?\
tweet.fields=created_at,public_metrics,author_id&\
expansions=author_id&\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obtén un Post con fields y expansions adicionales
response = client.posts.get(
    "1228393702244134912",
    tweet_fields=["created_at", "public_metrics", "author_id"],
    expansions=["author_id"],
    user_fields=["username", "verified"]
)

print(response.data)
print(response.includes)  # Contiene el objeto de usuario del autor
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

const response = await client.posts.get("1228393702244134912", {
  tweetFields: ["created_at", "public_metrics", "author_id"],
  expansions: ["author_id"],
  userFields: ["username", "verified"],
});

console.log(response.data);
console.log(response.includes); // Contiene el objeto de usuario del autor
```

</CodeGroup>

  </Step>

  <Step title="Consulta múltiples Posts">
    Recupera hasta 100 Posts en una sola solicitud:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/tweets?\
ids=1228393702244134912,1227640996038684673,1199786642791452673&\
tweet.fields=created_at,author_id" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obtén múltiples Posts por IDs
response = client.posts.get_posts(
    ids=["1228393702244134912", "1227640996038684673", "1199786642791452673"],
    tweet_fields=["created_at", "author_id"]
)

for post in response.data:
    print(f"{post.id}: {post.text[:50]}...")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

const response = await client.posts.getPosts({
  ids: ["1228393702244134912", "1227640996038684673", "1199786642791452673"],
  tweetFields: ["created_at", "author_id"],
});

response.data?.forEach((post) => {
  console.log(`${post.id}: ${post.text?.slice(0, 50)}...`);
});
```

</CodeGroup>

  </Step>
