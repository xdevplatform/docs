## Autenticación

### Recent search

Recent search admite múltiples métodos de autenticación:

| Method | Use case |
|:-------|:---------|
| [OAuth 2.0 App-Only](/resources/fundamentals/authentication#oauth-2-0) | Datos públicos de Post |
| [OAuth 2.0 Authorization Code with PKCE](/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) | Métricas privadas |
| [OAuth 1.0a User Context](/resources/fundamentals/authentication) | Métricas privadas |

### Full-archive search

Full-archive search solo admite autenticación [OAuth 2.0 App-Only](/resources/fundamentals/authentication#oauth-2-0).

<Warning>
Las métricas privadas (`non_public_metrics`, `organic_metrics`, `promoted_metrics`) no están disponibles con full-archive search porque solo admite autenticación App-Only.
</Warning>

## Construcción de consultas

Las consultas usan operadores para coincidir con Posts. Combina operadores con lógica booleana:

```
(AI OR "machine learning") lang:en -is:retweet has:links
```

### Límites de longitud de consulta

| Access level | Recent search | Full-archive search |
|:-------------|:--------------|:--------------------|
| Self-serve | 512 caracteres | 1,024 caracteres |
| Enterprise | 4,096 caracteres | 4,096 caracteres |

### Tipos de operadores

| Type | Description | Example |
|:-----|:------------|:--------|
| **Independiente** | Puede usarse solo | `#python`, `from:user` |
| **Requiere conjunción** | Debe usarse con un operador independiente | `has:media`, `is:retweet` |

## Fields y expansions

Por defecto, la respuesta incluye solo `id`, `text` y `edit_history_tweet_ids`. Usa parámetros para solicitar datos adicionales.

### Ejemplo de solicitud

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/tweets/search/recent?\
query=python&\
tweet.fields=created_at,public_metrics,author_id&\
expansions=author_id,attachments.media_keys&\
user.fields=username,verified&\
media.fields=url,type" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Busca Posts recientes
for page in client.posts.search_recent(
    query="python",
    tweet_fields=["created_at", "public_metrics", "author_id"],
    expansions=["author_id", "attachments.media_keys"],
    user_fields=["username", "verified"],
    media_fields=["url", "type"],
    max_results=100
):
    for post in page.data:
        print(f"{post.text} - Likes: {post.public_metrics.like_count}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Busca Posts recientes
const paginator = client.posts.searchRecent("python", {
  tweetFields: ["created_at", "public_metrics", "author_id"],
  expansions: ["author_id", "attachments.media_keys"],
  userFields: ["username", "verified"],
  mediaFields: ["url", "type"],
  maxResults: 100,
});

for await (const page of paginator) {
  page.data?.forEach((post) => {
    console.log(`${post.text} - Likes: ${post.public_metrics?.like_count}`);
  });
}
```

</CodeGroup>

### Expansions disponibles

| Expansion | Returns |
|:----------|:--------|
| `author_id` | Objeto de usuario del autor |
| `attachments.media_keys` | Objetos de media adjuntos |
| `attachments.poll_ids` | Objetos de encuesta adjuntos |
| `referenced_tweets.id` | Posts citados o respondidos |
| `geo.place_id` | Objetos de lugar |
| `entities.mentions.username` | Objetos de usuario mencionados |

## Paginación

Los endpoints de search devuelven resultados en páginas. Usa el `next_token` de la respuesta para obtener páginas adicionales.

### Cómo funciona

1. Haz tu solicitud inicial con `max_results`
2. Verifica el objeto `meta` para `next_token`
3. Incluye `next_token` en solicitudes posteriores
4. Repite hasta que no se devuelva ningún `next_token`

### Ejemplo

<CodeGroup dropdown>

```bash cURL
# Primera solicitud
curl "https://api.x.com/2/tweets/search/recent?query=python&max_results=100" \
  -H "Authorization: Bearer $BEARER_TOKEN"

# Solicitud posterior con token de paginación
curl "https://api.x.com/2/tweets/search/recent?query=python&max_results=100&next_token=NEXT_TOKEN" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# El SDK maneja la paginación automáticamente
all_posts = []

for page in client.posts.search_recent(query="python", max_results=100):
    if page.data:
        all_posts.extend(page.data)

print(f"Found {len(all_posts)} posts")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

async function getAllResults(query) {
  const allPosts = [];

  // El SDK maneja la paginación automáticamente
  const paginator = client.posts.searchRecent(query, { maxResults: 100 });

  for await (const page of paginator) {
    if (page.data) {
      allPosts.push(...page.data);
    }
  }

  return allPosts;
}

// Uso
const posts = await getAllResults("python");
console.log(`Found ${posts.length} posts`);
```

</CodeGroup>

## Ediciones de Post

Los Posts pueden editarse hasta 5 veces dentro de los 30 minutos. Los endpoints de search siempre devuelven la versión más reciente.

### Consideraciones

- `edit_history_tweet_ids` contiene todos los IDs de Post (más antiguos primero)
- Los Posts obtenidos después de la ventana de 30 minutos representan la versión final
- Para casos de uso casi en tiempo real, los Posts publicados recientemente aún pueden editarse
