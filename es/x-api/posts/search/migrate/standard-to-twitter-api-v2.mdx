### Standard v1.1 comparado con X API v2

Si has estado trabajando con v1.1 [search/posts](/x-api/posts/search/introduction), el objetivo de esta guía es ayudarte a entender las similitudes y diferencias entre el endpoint estándar y el de X API v2 search Posts.

* **Similitudes**
    * OAuth 1.0a User Context y OAuth 2.0 App-Only
    * Soporte para historial y metadatos de edición de Post. 
* **Diferencias**
    * URLs de endpoint
    * Requisitos de App y Project
    * Formato de datos de respuesta
    * Parámetros de solicitud
    * Nuevos operadores de consulta

    * Precedencia de operadores AND / OR 

#### Similitudes

**Autenticación OAuth 1.0a User Context y OAuth 2.0 App-Only**

El endpoint v1.1 search/posts y el endpoint recent search de X API v2 admiten tanto [OAuth 1.0a User Context](/resources/fundamentals/authentication) como [OAuth 2.0 App-Only](/resources/fundamentals/authentication#oauth-2-0). 

Por lo tanto, si anteriormente utilizabas el endpoint estándar v1.1 search, puedes continuar usando el mismo método de autenticación si migras a la versión X API v2. 

Dependiendo de tu biblioteca/paquete de autenticación de elección, la autenticación App-Only es probablemente la forma más sencilla de comenzar y se puede configurar con un simple encabezado de solicitud. Para aprender a generar un App Access Token, consulta esta [guía de OAuth 2.0 App-Only](/resources/fundamentals/authentication#bearer-token-also-known-as-app-only). 

Si deseas aprovechar la capacidad de obtener métricas privadas o de publicidad con el endpoint de X API v2, necesitarás usar OAuth 1.0a User Context y pasar los user access tokens relacionados con el usuario que publicó el Post cuyas métricas deseas obtener. 


**Soporte para historial y metadatos de edición de Post**

Ambas versiones proporcionan metadatos que describen cualquier historial de edición. Consulta las [referencias de la API de search](/x-api/posts/recent-search) y la [página de fundamentos de edición de Post](/x-api/fundamentals/edit-posts) para obtener más detalles.
