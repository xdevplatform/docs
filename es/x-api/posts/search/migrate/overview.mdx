## Comparación de los endpoints de Search Posts de la X API

El endpoint v2 Search Tweets eventualmente reemplazará al [endpoint estándar v1.1 search/posts](/x-api/posts/search/introduction) y a la [Enterprise Search API](/x-api/enterprise-gnip-2.0/fundamentals/search-api). Si tienes código, apps o herramientas que utilizan una versión anterior de un endpoint de search de X y estás considerando migrar a los endpoints más recientes de X API v2, esta guía es para ti. 

---

**Comparación de operadores de filtrado**

Las cuatro versiones diferentes (standard, enterprise y v2) de search Posts difieren en qué operadores están disponibles, y también tienen distintos niveles de disponibilidad de operadores dentro de cada versión, que se explican a continuación. 

Enterprise

* No hay sub-niveles de operadores enterprise

X API v2

* **Self-serve:** disponible al usar cualquier Project
* **Enterprise:** disponible al usar un Project 

Puedes obtener más información sobre cada uno de estos conjuntos de operadores en sus respectivas guías:

* [Operadores Enterprise](/x-api/enterprise-gnip-2.0/fundamentals/search-api#available-operators)
* [Operadores de X API v2](/x-api/posts/search/integrate/build-a-query#operators)
