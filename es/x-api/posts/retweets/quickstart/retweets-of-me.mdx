Esta guía te muestra cómo recuperar tus Posts que han sido retweeteados por otros.

<Note>
**Requisitos previos**

Antes de comenzar, necesitarás:
- Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
- Un User Access Token (OAuth 1.0a o OAuth 2.0 PKCE)
</Note>

---

## ¿Por qué usar Retweets de mí?

El endpoint Retweets de mí te ayuda a:

- **Realizar seguimiento de la interacción** — ve cuáles de tus Posts están siendo compartidos
- **Comprender la resonancia** — aprende qué contenido resuena con tu audiencia
- **Informar la estrategia** — ajusta tu estrategia de contenido según los patrones de compartición

## Obtener tus Posts retweeteados

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/reposts_of_me?\
tweet.fields=created_at,public_metrics&\
max_results=10" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python Python SDK
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# Obtén tus Posts que han sido retweeteados
for page in client.posts.get_reposts_of_me(
    tweet_fields=["created_at", "public_metrics"],
    max_results=10
):
    for post in page.data:
        print(f"{post.text[:50]}... - Retweets: {post.public_metrics.retweet_count}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// Obtén tus Posts que han sido retweeteados
const paginator = client.posts.getRepostsOfMe({
  tweetFields: ["created_at", "public_metrics"],
  maxResults: 10,
});

for await (const page of paginator) {
  page.data?.forEach((post) => {
    console.log(`${post.text?.slice(0, 50)}... - Retweets: ${post.public_metrics?.retweet_count}`);
  });
}
```

</CodeGroup>

## Filtrar por rango de tiempo

Obtén los Posts retweeteados de un período específico:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/reposts_of_me?\
start_time=2024-01-01T00%3A00%3A00Z&\
end_time=2024-01-31T23%3A59%3A59Z&\
tweet.fields=created_at,public_metrics" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# Obtén los Posts retweeteados de un rango de tiempo
for page in client.posts.get_reposts_of_me(
    start_time="2024-01-01T00:00:00Z",
    end_time="2024-01-31T23:59:59Z",
    tweet_fields=["created_at", "public_metrics"]
):
    for post in page.data:
        print(f"{post.created_at}: {post.text[:50]}...")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// Obtén los Posts retweeteados de un rango de tiempo
const paginator = client.posts.getRepostsOfMe({
  startTime: "2024-01-01T00:00:00Z",
  endTime: "2024-01-31T23:59:59Z",
  tweetFields: ["created_at", "public_metrics"],
});

for await (const page of paginator) {
  page.data?.forEach((post) => {
    console.log(`${post.created_at}: ${post.text?.slice(0, 50)}...`);
  });
}
```

</CodeGroup>

## Parámetros comunes

| Parameter | Description | Default |
|:----------|:------------|:--------|
| `max_results` | Resultados por página (1-100) | 10 |
| `start_time` | Timestamp más antiguo del Post (ISO 8601) | — |
| `end_time` | Timestamp más reciente del Post (ISO 8601) | — |
| `pagination_token` | Token para la siguiente página | — |
| `tweet.fields` | Fields adicionales de Post | `id`, `text` |
