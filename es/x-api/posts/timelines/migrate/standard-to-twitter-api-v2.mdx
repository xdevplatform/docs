## Timelines Standard v1.1 a timelines de X API v2

Si has estado trabajando con los endpoints de timelines v1.1 (statuses/user\_timeline y statuses/mentions\_timeline), el objetivo de esta guía es ayudarte a entender las similitudes y diferencias entre los endpoints de timelines estándar y de X API v2 para que puedas migrar tu integración actual a la nueva versión.

* **Similitudes:**
    * Autenticación:
        * OAuth 1.0a User Context (reverse chronological home timeline, user Post timeline y user mentions timeline)
        * OAuth 2.0 App-Only (user Post timeline)
    * Límite de acceso histórico: user timeline (user Post timeline) proporciona acceso a los 3200 Posts más recientes; mentions timeline (user mention timeline) proporciona acceso a las 800 menciones más recientes.
    * Soporte para historial y metadatos de edición de Post
    * Límites de tasa (user Post timeline)
    * Sondeo de actualización: capacidad de recuperar nuevos resultados desde since_id
    * Recorrer timelines por IDs de Post
    * Especificaciones de resultados:
        * Orden de resultados: los resultados se devuelven en orden cronológico inverso
        * Capacidad de excluir respuestas (solo user Post timeline)
        * Capacidad de excluir Retweets (solo user Post timeline)
* **Diferencias**
    * Nueva capacidad de autenticación: 
        * OAuth 2.0 App-Only (user mention timeline)
        * OAuth 2.0 Authorization Code Flow with PKCE (reverse chronological home timeline, user Post timeline y user mentions timeline)
    * Requisitos de acceso: requisitos de App y Project de X API v2
    * Límites de tasa (user mention timeline y reverse chronological home timeline)
    * Método de paginación adicional
        * Diferente max_results (count) por respuesta
    * Formato de datos de respuesta
    * Parámetros de solicitud
        * Personalizado
