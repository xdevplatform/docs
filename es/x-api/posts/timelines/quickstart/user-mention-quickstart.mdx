Esta guía te muestra cómo recuperar Posts que mencionan a un usuario específico.

<Note>
**Requisitos previos**

Antes de comenzar, necesitarás:
- Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
- El Bearer Token de tu App (para datos públicos) o un User Access Token (para métricas privadas)
</Note>

## Obtener menciones de usuario

<Steps>
  <Step title="Obtén el ID de usuario">
    Encuentra el ID de usuario usando el [endpoint de user lookup](/x-api/users/lookup/introduction). Por ejemplo, @XDevelopers tiene el ID de usuario `2244994945`.
  </Step>

  <Step title="Solicita el timeline de menciones">

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/2244994945/mentions?\
tweet.fields=created_at,public_metrics,author_id&\
expansions=author_id&\
user.fields=username,verified&\
max_results=10" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obtén el timeline de menciones con paginación
for page in client.posts.get_user_mentions(
    "2244994945",
    tweet_fields=["created_at", "public_metrics", "author_id"],
    expansions=["author_id"],
    user_fields=["username", "verified"],
    max_results=10
):
    for post in page.data:
        print(f"@{post.author_id}: {post.text[:50]}...")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Obtén el timeline de menciones con paginación
const paginator = client.posts.getUserMentions("2244994945", {
  tweetFields: ["created_at", "public_metrics", "author_id"],
  expansions: ["author_id"],
  userFields: ["username", "verified"],
  maxResults: 10,
});

for await (const page of paginator) {
  page.data?.forEach((post) => {
    console.log(`@${post.author_id}: ${post.text?.slice(0, 50)}...`);
  });
}
```

## Filtrar menciones

### Excluir respuestas

Obtén solo los Posts originales que mencionan al usuario:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/2244994945/mentions?\
exclude=replies&\
max_results=10" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obtén las menciones excluyendo respuestas
for page in client.posts.get_user_mentions(
    "2244994945",
    exclude=["replies"],
    max_results=10
):
    for post in page.data:
        print(post.text)
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Obtén las menciones excluyendo respuestas
const paginator = client.posts.getUserMentions("2244994945", {
  exclude: ["replies"],
  maxResults: 10,
});

for await (const page of paginator) {
  page.data?.forEach((post) => {
    console.log(post.text);
  });
}
```

</CodeGroup>

### Obtener menciones en un rango de tiempo

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/2244994945/mentions?\
start_time=2024-01-01T00%3A00%3A00Z&\
end_time=2024-01-31T23%3A59%3A59Z" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obtén las menciones en un rango de tiempo
for page in client.posts.get_user_mentions(
    "2244994945",
    start_time="2024-01-01T00:00:00Z",
    end_time="2024-01-31T23:59:59Z"
):
    for post in page.data:
        print(f"{post.created_at}: {post.text[:50]}...")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Obtén las menciones en un rango de tiempo
const paginator = client.posts.getUserMentions("2244994945", {
  startTime: "2024-01-01T00:00:00Z",
  endTime: "2024-01-31T23:59:59Z",
});

for await (const page of paginator) {
  page.data?.forEach((post) => {
    console.log(`${post.created_at}: ${post.text?.slice(0, 50)}...`);
  });
}
```

</CodeGroup>

## Parámetros comunes

| Parameter | Description | Default |
|:----------|:------------|:--------|
| `max_results` | Resultados por página (1-100) | 10 |
| `start_time` | Timestamp más antiguo del Post (ISO 8601) | — |
| `end_time` | Timestamp más reciente del Post (ISO 8601) | — |
| `since_id` | Devuelve Posts posteriores a este ID | — |
| `until_id` | Devuelve Posts anteriores a este ID | — |
| `exclude` | Excluye `retweets`, `replies` o ambos | — |
| `pagination_token` | Token para la siguiente página | — |
