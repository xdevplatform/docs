Los endpoints de Timelines te permiten recuperar Posts de los timelines de usuarios, feeds de menciones y home feeds. Obtén el contenido publicado por un usuario, ve qué Posts los mencionan o visualiza su home timeline personalizado.

## Endpoints

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/tweets`](/x-api/users/get-posts) | Obtiene los Posts de un usuario |
| GET | [`/2/users/:id/mentions`](/x-api/users/get-mentions) | Obtiene los Posts que mencionan a un usuario |
| GET | [`/2/users/:id/timelines/reverse_chronological`](/x-api/users/get-timeline) | Obtiene el home timeline |

## Timeline de Posts de usuario

Obtén los Posts más recientes creados por un usuario específico.

### Características

- Hasta 3,200 Posts más recientes
- Filtra respuestas y retweets
- Compatible con paginación
- Acceso histórico con filtrado basado en tiempo

## Home timeline en cronología inversa

Obtén el home timeline del usuario autenticado en orden cronológico inverso.

### Características

- Posts de cuentas seguidas
- Los 3,200 Posts más recientes (o 7 días)
- Excluye ranking algorítmico
- Requiere autenticación de usuario

<Note>
Este endpoint requiere [OAuth 1.0a User Context](/resources/fundamentals/authentication) o [OAuth 2.0 Authorization Code with PKCE](/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2).
</Note>

## Opciones de filtrado

### Parámetro exclude

Filtra tipos específicos de Post:

| Value | Effect |
|:------|:-------|
| `retweets` | Excluir retweets |
| `replies` | Excluir respuestas |

```bash
curl "https://api.x.com/2/users/123/tweets?exclude=retweets,replies" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

### Filtrado basado en tiempo

| Parameter | Description |
|:----------|:------------|
| `start_time` | Timestamp más antiguo del Post (ISO 8601) |
| `end_time` | Timestamp más reciente del Post (ISO 8601) |
| `since_id` | Devuelve Posts posteriores a este ID |
| `until_id` | Devuelve Posts anteriores a este ID |
