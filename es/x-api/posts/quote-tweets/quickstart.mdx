Esta guía te muestra cómo recuperar Quote Posts (Posts que citan otro Post).

<Note>
**Requisitos previos**

Antes de comenzar, necesitarás:
- Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
- El Bearer Token de tu App
</Note>

---

<Steps>
  <Step title="Encuentra el ID del Post" icon="/icons/xds/icon-chat.svg">
    Obtén el ID del Post del cual quieres encontrar las citas. Puedes encontrarlo en la URL del Post:

    ```
    https://x.com/XDevelopers/status/1409931481552543749
                                    └── Este es el ID del Post
    ```
  </Step>

  <Step title="Solicita los Quote Posts" icon="terminal">

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/tweets/1409931481552543749/quote_tweets?\
tweet.fields=created_at,public_metrics,author_id&\
expansions=author_id&\
user.fields=username,verified&\
max_results=10" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obtén los Quote Posts con paginación
for page in client.posts.get_quote_tweets(
    "1409931481552543749",
    tweet_fields=["created_at", "public_metrics", "author_id"],
    expansions=["author_id"],
    user_fields=["username", "verified"],
    max_results=10
):
    for post in page.data:
        print(f"{post.text[:50]}... - Likes: {post.public_metrics.like_count}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Obtén los Quote Posts con paginación
const paginator = client.posts.getQuoteTweets("1409931481552543749", {
  tweetFields: ["created_at", "public_metrics", "author_id"],
  expansions: ["author_id"],
  userFields: ["username", "verified"],
  maxResults: 10,
});

for await (const page of paginator) {
  page.data?.forEach((post) => {
    console.log(`${post.text?.slice(0, 50)}... - Likes: ${post.public_metrics?.like_count}`);
  });
}
```

  <Step title="Pagina los resultados" icon="/icons/xds/icon-arrow-right.svg">
    Los SDKs manejan la paginación automáticamente. Para cURL, usa el `next_token` para obtener más Quote Posts:

    ```bash
    curl "https://api.x.com/2/tweets/1409931481552543749/quote_tweets?\
    max_results=10&\
    pagination_token=avdjwk0udyx6" \
      -H "Authorization: Bearer $BEARER_TOKEN"
    ```
