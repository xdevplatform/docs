El endpoint Hide Replies te permite ocultar o mostrar respuestas a Posts creados por el usuario autenticado. Las respuestas ocultas siguen siendo accesibles pero requieren un clic adicional para ser vistas.

## Endpoint

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| PUT | [`/2/tweets/:tweet_id/hidden`](/x-api/posts/hide-reply) | Ocultar o mostrar una respuesta |

---

## Cómo funciona

Envía una solicitud PUT con `hidden: true` para ocultar una respuesta, o `hidden: false` para mostrarla:

```json
{
  "hidden": true
}
```

---

## Ejemplo: ocultar una respuesta

```bash
curl -X PUT "https://api.x.com/2/tweets/1234567890/hidden" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"hidden": true}'
```

## Ejemplo de respuesta

```json
{
  "data": {
    "hidden": true
  }
}
```
