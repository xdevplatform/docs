### Likes lookup: Standard v1.1 comparado con X API v2

Si has estado trabajando con el endpoint estándar v1.1 [GET favorites/list](https://developer.x.com/en/docs/x-api/v1/tweets/post-and-engage/api-reference/get-favorites-list), el objetivo de esta guía es ayudarte a entender las similitudes y diferencias entre los endpoints estándar v1.1 y X API v2 de Likes lookup.

Con v2, también hemos introducido un nuevo endpoint de liked users que te permite obtener información sobre los usuarios que dieron like a un Post.

* **Similitudes**
    * Autenticación
    * Límites de tasa
* **Diferencias**
    * URLs de endpoint

    * Limitaciones de la solicitud
    * Requisitos de App y Project

    * Parámetros de solicitud
    * Nuevo formato JSON

#### Similitudes

**Autenticación**

Tanto los endpoints estándar v1.1 como los de X API v2 Likes lookup utilizan [OAuth 1.0a User Context](/resources/fundamentals/authentication#oauth-1-0a-2) o [OAuth 2.0 Bearer Token](/resources/fundamentals/authentication#bearer-token-also-known-as-app-only). Por lo tanto, si anteriormente estabas utilizando los endpoints estándar v1.1 [GET favorites/list](https://developer.x.com/en/docs/x-api/v1/tweets/post-and-engage/api-reference/get-favorites-list), puedes continuar usando el mismo método de autenticación si migras a la versión X API v2 si así lo deseas. 

Dependiendo de tu biblioteca/paquete de autenticación de elección, la autenticación con Bearer Token es probablemente la forma más sencilla de comenzar y se puede configurar con un simple encabezado de solicitud. Para aprender a generar un Bearer Token, consulta [esta guía de OAuth 2.0 Bearer Token](/resources/fundamentals/authentication#bearer-token-also-known-as-app-only).
