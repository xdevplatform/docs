Los endpoints de Likes te permiten dar y quitar likes a Posts, ver qué usuarios dieron like a un Post y obtener los Posts a los que un usuario ha dado like.

## Endpoints

### Consulta de likes

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/tweets/:id/liking_users`](/x-api/posts/get-liking-users) | Obtiene los usuarios que dieron like a un Post |
| GET | [`/2/users/:id/liked_tweets`](/x-api/users/get-liked-posts) | Obtiene los Posts a los que un usuario dio like |

### Gestionar likes

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| POST | [`/2/users/:id/likes`](/x-api/users/like-post) | Dar like a un Post |
| DELETE | [`/2/users/:id/likes/:tweet_id`](/x-api/users/unlike-post) | Quitar like a un Post |

---

## Notas importantes

<Note>
El endpoint de usuarios que dieron like devuelve un máximo de **100 usuarios** por Post para todo el tiempo, independientemente del número real de likes.
</Note>

---

## Ejemplo: obtener usuarios que dieron like

```bash
curl "https://api.x.com/2/tweets/1234567890/liking_users?\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

## Ejemplo: dar like a un Post

```bash
curl -X POST "https://api.x.com/2/users/123456789/likes" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
