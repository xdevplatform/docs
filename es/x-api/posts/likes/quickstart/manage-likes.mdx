Esta guía te muestra cómo dar y quitar likes a Posts usando la X API.

<Note>
**Requisitos previos**

Antes de comenzar, necesitarás:
- Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
- Un User Access Token (OAuth 1.0a o OAuth 2.0 PKCE)
</Note>

---

## Dar like a un Post

<Steps>
  <Step title="Obtén tu ID de usuario">
    Necesitas el ID de tu usuario autenticado. Puedes encontrarlo usando el [endpoint de user lookup](/x-api/users/lookup/introduction) o desde tu Access Token (la parte numérica es tu ID de usuario).
  </Step>

  <Step title="Obtén el ID del Post">
    Encuentra el ID del Post en la URL cuando visualizas un Post:

    ```
    https://x.com/XDevelopers/status/1228393702244134912
                                    └── Este es el ID del Post
    ```
  </Step>

  <Step title="Envía la solicitud de like">

<CodeGroup dropdown>

```bash cURL
curl -X POST "https://api.x.com/2/users/123456789/likes" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1228393702244134912"}'
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Da like a un Post
response = client.posts.like(
    user_id="123456789",
    tweet_id="1228393702244134912"
)

print(f"Liked: {response.data.liked}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// Da like a un Post
const response = await client.posts.like("123456789", {
  tweetId: "1228393702244134912",
});

console.log(`Liked: ${response.data?.liked}`);
```

</CodeGroup>

  </Step>

  <Step title="Revisa la respuesta">
    ```json
    {
      "data": {
        "liked": true
      }
    }
    ```
  </Step>
</Steps>

## Quitar like a un Post

Elimina un like de un Post:

<CodeGroup dropdown>

```bash cURL
curl -X DELETE "https://api.x.com/2/users/123456789/likes/1228393702244134912" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Quita el like de un Post
response = client.posts.unlike(
    user_id="123456789",
    tweet_id="1228393702244134912"
)

print(f"Liked: {response.data.liked}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// Quita el like de un Post
const response = await client.posts.unlike("123456789", "1228393702244134912");

console.log(`Liked: ${response.data?.liked}`);
```

</CodeGroup>

**Respuesta:**

```json
{
  "data": {
    "liked": false
  }
}
```
