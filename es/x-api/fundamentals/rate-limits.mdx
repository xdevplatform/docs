Los rate limits controlan el número de solicitudes que puedes hacer a cada endpoint. Superar los límites da como resultado un error 429 hasta que se restablezca la ventana.

---

## Cómo funcionan los rate limits

| Concepto | Descripción |
|:--------|:------------|
| **Ventana de tiempo** | Normalmente 15 minutos o 24 horas |
| **Límites por usuario** | Aplican con OAuth 1.0a o tokens de usuario OAuth 2.0 |
| **Límites por app** | Aplican con Bearer Token (app-only) |
| **Por endpoint** | Cada endpoint tiene sus propios límites |

---

## Consultar tus límites

Las cabeceras de respuesta muestran tu estado actual de rate limit:

```
x-rate-limit-limit: 900
x-rate-limit-remaining: 847
x-rate-limit-reset: 1705420800
```

| Cabecera | Descripción |
|:-------|:------------|
| `x-rate-limit-limit` | Máximo de solicitudes permitidas |
| `x-rate-limit-remaining` | Solicitudes restantes en la ventana |
| `x-rate-limit-reset` | Timestamp Unix cuando se restablece la ventana |

## Gestión de rate limits

Cuando alcanzas un rate limit, recibirás una respuesta 429:

```json
{
  "errors": [{
    "code": 88,
    "message": "Rate limit exceeded"
  }]
}
```

### Estrategia de recuperación

1. Consulta `x-rate-limit-reset` para saber cuándo se restablece la ventana
2. Espera hasta ese momento antes de reintentar
3. Usa backoff exponencial si es necesario

```python title="Ejemplo" lines wrap icon="python"
import time

def make_request_with_backoff(url, headers):
    response = requests.get(url, headers=headers)
    
    if response.status_code == 429:
        reset_time = int(response.headers.get('x-rate-limit-reset', 0))
        wait_time = max(reset_time - time.time(), 60)
        time.sleep(wait_time)
        return make_request_with_backoff(url, headers)
    
    return response
```

## Rate limits vs. facturación

Los rate limits y la facturación son cosas separadas:

| Concepto | Propósito |
|:--------|:--------|
| **Rate limits** | Controlar la frecuencia de solicitudes para la estabilidad del sistema |
| **Facturación de uso** | Cobrar por los datos recuperados (pago por uso) |

Puedes estar dentro de los rate limits pero aún así incurrir en costos de uso, o alcanzar los rate limits sin costo adicional.
