La X API v2 usa precios de **pago por uso**. Se te cobra según el consumo real de la API, rastreado a nivel de app.

---

## Cómo funciona la facturación

| Concepto | Descripción |
|:--------|:------------|
| **Basado en créditos** | Compra créditos por adelantado, deducidos a medida que usas la API |
| **Precios por solicitud** | Diferentes endpoints tienen diferentes costos |
| **Seguimiento en tiempo real** | Monitoriza el uso en la Developer Console |

<Note>
Los planes de pago por uso están sujetos a un límite mensual de 2 millones de lecturas de Posts. Si necesitas un volumen mayor, considera un [plan Enterprise](/forms/enterprise-api-interest).
</Note>

## Deduplicación

<Note>
**Deduplicación diaria**: Si el mismo post se devuelve desde varias consultas dentro de un día, solo cuenta una vez para la facturación.
</Note>

Esto significa:

- Recuperar el mismo post varias veces en un día = 1 cargo
- Recuperar un post nuevamente al día siguiente = 1 cargo adicional
- Diferentes posts en la misma solicitud = cada uno cuenta por separado

## Detalles de precios

Para los precios actuales por endpoint y operación, visita la [Developer Console](https://console.x.com).

Los precios pueden variar según:

- Tipo de endpoint (search vs. lookup vs. stream)
- Operación (lectura vs. escritura)
- Alcance de datos (reciente vs. archivo completo)

## Preguntas frecuentes

<Accordion title="¿Qué sucede si me quedo sin créditos?">
Las solicitudes a la API fallarán hasta que compres más créditos. Configura alertas de saldo para evitar interrupciones.
</Accordion>

<Accordion title="¿Hay mínimos mensuales?">
No. Paga solo por lo que uses. Puedes tener meses con cero uso y cero costo.
</Accordion>

<Accordion title="¿Cómo se factura el streaming?">
Cada post único entregado a través de filtered stream cuenta para el uso, sujeto a la deduplicación diaria.
</Accordion>

<Accordion title="¿Cuentan las solicitudes fallidas?">
No. Solo se facturan las respuestas exitosas que devuelven datos.
</Accordion>
