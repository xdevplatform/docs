La X API proporciona métricas de interacción para posts y medios. Accede a las métricas públicas con cualquier autenticación, o a las métricas privadas de tu propio contenido con autenticación de usuario.

---

## Tipos de métricas

| Tipo | Autenticación | Descripción |
|:-----|:---------------|:------------|
| **Public** | Bearer Token | Visible para cualquiera (impresiones, likes, reposts, replies) |
| **Non-public** | User context | Métricas privadas (clics) |
| **Organic** | User context | Métricas de vistas no promocionadas |
| **Promoted** | User context | Métricas de vistas de anuncios |

<Note>
**Límite de 30 días**: Las métricas non-public, organic y promoted solo están disponibles para posts creados en los últimos 30 días.
</Note>

---

## Métricas disponibles

### Métricas de post

| Métrica | Tipo | Ruta del campo |
|:-------|:-----|:-----------|
| Reposts | Public | `public_metrics.retweet_count` |
| Quotes | Public | `public_metrics.quote_count` |
| Likes | Public | `public_metrics.like_count` |
| Replies | Public | `public_metrics.reply_count` |
| Impressions | Public | `public_metrics.impression_count` |
| Bookmarks | Public | `public_metrics.bookmark_count` |
| URL clicks | Non-public | `non_public_metrics.url_link_clicks` |
| Profile clicks | Non-public | `non_public_metrics.user_profile_clicks` |
| Engagements | Non-public | `non_public_metrics.engagements` |

### Métricas de media (videos)

| Métrica | Tipo | Ruta del campo |
|:-------|:-----|:-----------|
| Views | Public | `public_metrics.view_count` |
| Playback 0% | Non-public | `non_public_metrics.playback_0_count` |
| Playback 25% | Non-public | `non_public_metrics.playback_25_count` |
| Playback 50% | Non-public | `non_public_metrics.playback_50_count` |
| Playback 75% | Non-public | `non_public_metrics.playback_75_count` |
| Playback 100% | Non-public | `non_public_metrics.playback_100_count` |

## Solicitar métricas

### Métricas públicas (cualquier autenticación)

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=public_metrics" \
  -H "Authorization: Bearer $TOKEN"
```

Respuesta:

```json title="Ejemplo de respuesta" lines wrap icon="/icons/xds/icon-brackets.svg"
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "public_metrics": {
      "retweet_count": 50,
      "reply_count": 12,
      "like_count": 234,
      "quote_count": 5,
      "bookmark_count": 8,
      "impression_count": 5432
    }
  }
}
```

### Métricas privadas (user context)

Requiere OAuth 1.0a o OAuth 2.0 con contexto de usuario para posts que poseas:

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=non_public_metrics,organic_metrics" \
  -H "Authorization: OAuth oauth_consumer_key=...,oauth_token=..."
```

Respuesta:

```json title="Ejemplo de respuesta" lines wrap icon="/icons/xds/icon-brackets.svg"
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "non_public_metrics": {
      "impression_count": 5432,
      "url_link_clicks": 89,
      "user_profile_clicks": 156,
      "engagements": 345
    },
    "organic_metrics": {
      "impression_count": 5432,
      "like_count": 234,
      "reply_count": 12,
      "retweet_count": 50,
      "url_link_clicks": 89,
      "user_profile_clicks": 156
    }
  }
}
```

## Métricas de video

Para las métricas de reproducción de video, usa la expansion de media:

```bash
curl "https://api.x.com/2/tweets/1234567890?\
tweet.fields=attachments&\
expansions=attachments.media_keys&\
media.fields=public_metrics,non_public_metrics" \
  -H "Authorization: OAuth ..."
```

Respuesta:

```json title="Ejemplo de respuesta" expandable lines wrap icon="/icons/xds/icon-brackets.svg"
{
  "data": {
    "id": "1234567890",
    "text": "Check out this video!",
    "attachments": {
      "media_keys": ["13_9876543210"]
    }
  },
  "includes": {
    "media": [{
      "media_key": "13_9876543210",
      "type": "video",
      "public_metrics": {
        "view_count": 12543
      },
      "non_public_metrics": {
        "playback_0_count": 12543,
        "playback_25_count": 9876,
        "playback_50_count": 7654,
        "playback_75_count": 5432,
        "playback_100_count": 3210
      }
    }]
  }
}
```

## Métricas orgánicas vs. promocionadas

Si un post fue promocionado como anuncio, las métricas se dividen entre vistas orgánicas y promocionadas:

| Contexto | Descripción |
|:--------|:------------|
| **Organic** | Métricas de vistas normales en el timeline |
| **Promoted** | Métricas de impresiones pagadas de anuncios |
| **Public** | Total combinado (organic + promoted) |

Solicita ambos para ver el desglose:

```bash
tweet.fields=public_metrics,organic_metrics,promoted_metrics
```

## Definiciones de métricas

<Accordion title="Impressions">
Cantidad de veces que el post apareció en la pantalla de un usuario. No es único — el mismo usuario viendo dos veces cuenta como dos impresiones.
</Accordion>

<Accordion title="Repost count">
Número de reposts (retweets). No incluye quote posts.
</Accordion>

<Accordion title="Quote count">
Número de quote posts (reposts con comentario). Estos son siempre orgánicos.
</Accordion>

<Accordion title="Bookmark count">
Número de veces que el post ha sido guardado por usuarios.
</Accordion>

<Accordion title="Video views">
Agregado en todos los posts que contienen el video. Un video repost en múltiples posts tiene un único conteo total de vistas.
</Accordion>

<Accordion title="Playback quartiles">
Número de usuarios únicos que reprodujeron cada porcentaje del video. Útil para comprender las tasas de abandono.
</Accordion>
