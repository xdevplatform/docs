Las anotaciones proporcionan metadatos semánticos sobre el contenido de los posts. X analiza los posts para identificar entidades (personas, lugares, productos) y contexto (temas, dominios) para ayudarte a comprender y filtrar el contenido.

---

## Tipos de anotaciones

### Anotaciones de entidad

El reconocimiento de entidades con nombre (NER) identifica menciones específicas en el texto del post:

| Tipo | Ejemplos |
|:-----|:---------|
| **Person** | Barack Obama, Elon Musk |
| **Place** | San Francisco, Japan |
| **Product** | iPhone, ChatGPT |
| **Organization** | NASA, Google |
| **Other** | Super Bowl, Diabetes |

Las anotaciones de entidad incluyen una puntuación de confianza y una posición en el texto.

### Anotaciones de contexto

Análisis semántico que clasifica los posts por tema y dominio:

- **Domain**: Categoría amplia (Sports, Entertainment, Technology)
- **Entity**: Tema específico dentro del dominio (NBA, Marvel Movies, AI)

Las anotaciones de contexto ayudan a filtrar y categorizar posts sin depender de palabras clave.

---

## Solicitar anotaciones

Añade `context_annotations` y `entities` a tus `tweet.fields`:

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=context_annotations,entities" \
  -H "Authorization: Bearer $TOKEN"
```

## Estructura de respuesta

```json title="Ejemplo de respuesta" expandable lines wrap icon="/icons/xds/icon-brackets.svg"
{
  "data": {
    "id": "1234567890",
    "text": "Just saw the new Marvel movie - it was amazing!",
    "entities": {
      "annotations": [
        {
          "start": 17,
          "end": 22,
          "probability": 0.9234,
          "type": "Organization",
          "normalized_text": "Marvel"
        }
      ]
    },
    "context_annotations": [
      {
        "domain": {
          "id": "86",
          "name": "Movie",
          "description": "A film"
        },
        "entity": {
          "id": "1234567890",
          "name": "Marvel Cinematic Universe"
        }
      },
      {
        "domain": {
          "id": "65",
          "name": "Interests and Hobbies Vertical"
        },
        "entity": {
          "id": "781974596752842752",
          "name": "Entertainment"
        }
      }
    ]
  }
}
```

## Campos de anotación de entidad

| Campo | Descripción |
|:------|:------------|
| `start` | Posición inicial en el texto |
| `end` | Posición final en el texto |
| `probability` | Puntuación de confianza (0-1) |
| `type` | Tipo de entidad (Person, Place, etc.) |
| `normalized_text` | Nombre de entidad estandarizado |

## Uso de anotaciones en filtros

### Search y filtered stream

Filtra posts por el ID de entidad de anotación de contexto:

```bash
# Posts about a specific entity
context:86.1234567890

# Posts in a specific domain
context:86.*
```

### Ejemplos prácticos

```bash
# Posts about the NBA
query=context:26.852137520

# Posts about Apple products
query=context:47.10026792024

# Posts about movies
query=context:86.*
```

---

## Notas importantes

<Warning>
**No todos los posts están anotados.** La cobertura de las anotaciones depende de:
- Soporte de idioma
- Cobertura de temas en la taxonomía de X
- Riqueza semántica del texto del post
</Warning>

- Las anotaciones no son retroactivas — solo se aplican cuando las entidades se están rastreando
- La misma entidad puede aparecer en múltiples dominios (por ejemplo, una celebridad es a la vez Person y Actor)
- Los IDs de entidad son estables entre dominios
