## Descripción general


Cada día, muchos miles de desarrolladores realizan solicitudes a la X API. Para ayudar a gestionar el enorme volumen de estas solicitudes, se establecen límites sobre el número de solicitudes que se pueden realizar. Estos límites nos ayudan a proporcionar la API confiable y escalable de la que depende nuestra comunidad de desarrolladores.

El número máximo de solicitudes permitidas se basa en un intervalo de tiempo, un período o ventana de tiempo específicos. Si un endpoint tiene un rate limit de 900 solicitudes/15 minutos, se permiten hasta 900 solicitudes en cualquier intervalo de 15 minutos.
