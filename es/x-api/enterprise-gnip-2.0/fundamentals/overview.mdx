## Descripción general

>La consola enterprise (en console.gnip.com) está disponible para clientes de datos enterprise con acceso contratado a la API enterprise. Si actualmente no eres cliente de datos enterprise pero deseas más información, puedes aprender más sobre [datos enterprise](https://developer.x.com/en/products/x-api/enterprise) aquí.

Esta es una descripción general del panel de la consola enterprise de X. Las secciones cubiertas se refieren a cada área específica de la consola para detalles del producto, uso y gestión general de la cuenta. Si tienes alguna pregunta sobre tu cuenta específica, contacta a tu gerente de cuenta designado, o revisa nuestra [documentación técnica para productos enterprise](/x-api/enterprise-gnip-2.0/enterprise-gnip).

Como parte del proceso de prueba enterprise y de incorporación con tu gerente de cuenta, los clientes enterprise recibirán un acceso a [console.gnip.com](http://console.gnip.com), que es la interfaz de usuario donde se puede revisar y configurar el acceso al producto enterprise. El acceso inicial a la consola para el admin del cliente lo configura X como parte del proceso de incorporación enterprise, y luego los admins pueden agregar usuarios adicionales. La consola enterprise te permite gestionar y acceder a más detalles relacionados con tus productos enterprise.

**Aviso: Ten en cuenta que algunas de las funciones que se muestran en el video, incluidos ciertos enriquecimientos de streams y productos con fuentes de datos que no son de X, pueden ya no estar disponibles.**

## Pestaña de productos

Al iniciar sesión en tu cuenta en [console.gnip.com](http://console.gnip.com), aterrizarás en la pestaña de productos del panel. Esta página incluye una descripción general de los productos enterprise actualmente disponibles en tu cuenta.

Para productos que usan entrega en streaming como PowerTrack o Decahose, esta página lista el nombre del producto y la etiqueta del stream, el número de conexiones activas actuales, el número de reglas actualmente activas para cada uno (cuando corresponda) y el conteo bruto de actividades (por ejemplo, Posts) entregadas en las últimas 24 horas.

Para productos con entrega REST, como Search API, esta página lista el nombre del producto, las etiquetas (también mostradas como "streams"), las actividades actuales (por ejemplo, Posts) devueltas a través de estos endpoints, y algunos conteos diferentes de solicitudes por endpoint.

Ten en cuenta que la [Usage API](/x-api/enterprise-gnip-2.0/fundamentals/usage) entrega gran parte de estos datos de forma programática.

Los detalles específicos por stream están disponibles haciendo clic en el nombre o en el botón de configuración.

### Descripción general

Al hacer clic en uno de los streams en el panel principal, se te llevará a una página de descripción general para ese stream.

Para productos con entrega en streaming, esta página incluye lo siguiente:

1.  Un gráfico de volumen del número de actividades que se te entregan a través de cada conexión de stream específica

2.  Detalles (ID de conexión y dirección IP) de las conexiones actualmente activas en el stream

3.  Un registro de eventos recientes de conexión, desconexión y actualización de reglas para tu stream


Ten en cuenta que la escala del gráfico puede ajustarse con los enlaces en la esquina superior derecha. La visibilidad de conexiones y desconexiones individuales puede alternarse haciendo clic en la clave apropiada en la leyenda directamente debajo del gráfico.

### Conexiones

La página de Conexiones proporciona detalles sobre eventos recientes de conexión en tu stream. Esto incluye los tiempos de inicio y fin de cada conexión (en formato de 24 horas UTC), la duración de cada conexión, la IP del servidor que hizo la conexión, un ID único de conexión para fines de referencia, y el estado actual de la conexión. El estado corresponde al evento más reciente para la conexión especificada; es decir, Client Connected o una desconexión, con el tipo de desconexión especificado. Para más detalles sobre depuración de conexiones, visita la [guía de desconexiones explicadas](/x-api/enterprise-gnip-2.0/powertrack-api#integrating-with-powertrack).

### API Help

La página API Help proporciona las URLs de endpoint de la API para tu stream, así como el endpoint de la Rules API para el stream, cuando corresponda. Además, incluye comandos curl de ejemplo e instrucciones sobre cómo conectarse al endpoint del stream, y cómo agregar, eliminar y listar reglas programáticamente desde el endpoint de la Rules API de tu stream.

### Reglas

La pestaña Rules está disponible para streams de PowerTrack, y proporciona una forma rápida de comenzar ingresando manualmente reglas en texto plano a través de una interfaz de usuario. Ten en cuenta que la interfaz solo admite agregar hasta 1000 reglas mediante este método manual, y solo debe usarse para pruebas iniciales. Recomendamos gestionar tus reglas programáticamente a través de la [Rules API](/x-api/enterprise-gnip-2.0/powertrack-api#api-reference-index) en cualquier entorno de producción.

### Configuración

La pestaña Settings te permite cambiar el formato de salida de los datos en tu stream, donde se admiten varias opciones de formato. Para cambiar el formato, simplemente usa los botones de opción que indican las diferentes opciones. El cambio surtirá efecto al reconectarse al stream. Ten en cuenta que actualizar esta configuración se aplicará inmediatamente en la próxima solicitud o conexión y puede romper tu parser con el nuevo formato.

**Ten en cuenta:** La configuración recomendada para obtener la mayor cantidad de datos es "Leave data in the original format", que devolverá los datos en el formato nativo enriquecido [aquí](/x-api/enterprise-gnip-2.0/fundamentals/data-dictionary#post-object). El formato de Activity streams se describe [aquí](/x-api/enterprise-gnip-2.0/fundamentals/data-dictionary#activity-object).

## Pestaña de uso

La pestaña Usage brinda información sobre tu uso de tus streams durante varios períodos de tiempo. Para acceso programático a la información de uso, consulta la [Usage API](/x-api/enterprise-gnip-2.0/fundamentals/usage).

### Mensual

La página Monthly Usage muestra el uso de tu stream desglosado por producto. Por ejemplo, los productos de cobertura (por ejemplo, PowerTrack, Historical PowerTrack y PowerTrack Replay) para una fuente de datos determinada se agruparán para proporcionar datos separados, así como un conteo agregado combinado. Los conteos incluyen un total actual del mes hasta la fecha, un final de mes estimado (basado en el uso de este mes hasta ahora y el tiempo restante en el mes) y los conteos de los dos meses anteriores.

En particular, estos conteos están deduplicados para cada producto y stream. Si recibiste el mismo Post a través de múltiples conexiones al mismo stream de PowerTrack, ese Post se contará una vez para estos fines. Los conteos se actualizan cada 24 horas a las 00:00 UTC.

### Diario

La página Daily Usage proporciona conteos diarios deduplicados para cada día del mes actual, desglosados por producto. Los conteos se actualizan cada 24 horas a las 00:00 UTC.

### Reglas

Los límites de reglas se basan en tu paquete contratado de reglas de PowerTrack y se aplican en todos los streams de un "tipo" determinado. Los conteos se actualizan cada vez que se agrega o elimina una nueva regla.

## Pestaña de cuenta

### Mi perfil

Consulta detalles sobre tu perfil de usuario individual y cambia tu contraseña aquí. Además, puedes configurar avisos de umbral de uso de la cuenta específicos para tu cuenta. Los avisos de estado de la API están disponibles a través de la página de estado en https://api.twitterstat.us.

### Configuración de la cuenta

Puedes agregar, eliminar y editar usuarios, y configurar notificaciones por correo electrónico para usuarios individuales y alertas de umbral de uso.
<Frame>
  <img src="/images/account-settings.png.twimg.1920.png"/>
</Frame>
Ten en cuenta que hay tres tipos de usuarios: Account Admin, User y Email Only.

*   Los admins de cuenta tienen permiso para crear/eliminar/editar otros usuarios, y pueden usar autenticación básica con nombre de usuario (email) y contraseña para conectarse a las APIs enterprise

*   Los usuarios no pueden crear o modificar otros usuarios, pero pueden usar autenticación básica con nombre de usuario (email) y contraseña para conectarse a las APIs enterprise

*   Los usuarios Email Only no tienen acceso al panel, no están autorizados para conectarse a las APIs enterprise y solo reciben notificaciones si están configurados para recibirlas en la sección Notifications.


### Umbrales de uso

Configura umbrales de volumen para tus productos. Estos iniciarán alertas por correo electrónico para los usuarios que hayan configurado esas notificaciones en sus perfiles, tanto para el umbral de advertencia como para el umbral crítico para cada producto.
<Frame>
  <img src="/images/usage-thresholds.png.twimg.1920.png"/>
</Frame>
Ten en cuenta que estos umbrales se evalúan una vez al día a las 19:30 (UTC), y no se evalúan en tiempo real.
