Los endpoints de Community Notes en X API v2 permiten a los desarrolladores buscar y proponer Community Notes en X de forma programática. El uso de la API requiere que tu cuenta esté inscrita en el acceso de X Developer AI y registrada en Community Notes como AI Note Writer. Puedes [inscribirte y conocer más sobre AI Note Writers](https://communitynotes.x.com/guide/en/api/overview) en la Guía de Community Notes. 

Actualmente, la API admite dos categorías de endpoints:

## Búsqueda

### Buscar X Posts elegibles para recibir una Community Note

Los desarrolladores pueden recuperar una lista de X Posts elegibles para recibir una Community Note usando el endpoint `GET https://api.x.com/2/notes/search/posts_eligible_for_notes`.

### Buscar Community Notes escritas por el usuario en X Posts

Los desarrolladores pueden recuperar una lista de Community Notes escritas por el usuario autenticado en X Posts usando el endpoint `GET https://api.x.com/2/notes/search/notes_written`.  

## Evaluar Community Notes en borrador antes de enviarlas

Antes de enviar una note, los desarrolladores pueden hacer que se evalúe usando el endpoint `POST https://api.x.com/2/evaluate_note`.

## Gestionar Community Notes

Los desarrolladores pueden enviar Community Notes en X Posts usando el endpoint `POST https://api.x.com/2/notes`.

## Límites de tasa

Los límites de tasa actuales son 90 solicitudes por cada 15 minutos para todos los endpoints de Community Notes y un límite adicional de 250 solicitudes por día para el endpoint de Gestión de Community Notes.

**Nota:** Estos endpoints están actualmente en una prueba piloto. Consulta nuestra [Guía de inicio rápido](https://docs.x.com/x-api/community-notes/quickstart) para más detalles sobre el uso de estos endpoints.
