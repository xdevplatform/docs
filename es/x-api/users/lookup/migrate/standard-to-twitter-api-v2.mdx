### Standard v1.1 comparado con X API v2

Si has estado trabajando con los endpoints estándar v1.1 GET users/show y GET users/lookup, el objetivo de esta guía es ayudarte a entender las similitudes y diferencias entre los endpoints estándar y los endpoints de X API v2 para users lookup.

* **Similitudes**
    * OAuth 1.0a User Context
    * Límites de usuarios por solicitud
* **Diferencias**
    * URLs de endpoints
    * Requisitos de App y Project
    * Formato de los datos de respuesta
    * Parámetros de solicitud

#### Similitudes

**Método de autenticación OAuth 1.0a User Context**

El endpoint estándar admite [OAuth 1.0a User Context](/resources/fundamentals/authentication#oauth-1-0a-2), mientras que los nuevos endpoints de users lookup de X API v2 admiten tanto OAuth 1.0a User Context como [App only](/resources/fundamentals/authentication#oauth-2-0). Por lo tanto, si anteriormente utilizabas uno de los endpoints estándar v1.1 de users lookup, puedes seguir utilizando el mismo método de autenticación si migras a la versión de X API v2.

Dependiendo de tu biblioteca/paquete de autenticación preferido, la autenticación App only es probablemente la forma más sencilla de empezar y se puede establecer con un encabezado de solicitud simple. Para aprender cómo generar un Access Token App only, consulta [esta guía de App only](/resources/fundamentals/authentication#bearer-token-also-known-as-app-only).

**Límites de usuarios por solicitud**

El endpoint estándar v1.1 GET users/lookup te permite especificar 100 usuarios por solicitud. Esto también se aplica a los endpoints GET /users y GET /users/by. Para especificar los 100 usuarios completos, deberás pasar el parámetro ids (GET /users) o el parámetro username (GET /users/by) como parámetro de consulta, e incluir la lista de user IDs/usernames en una lista separada por comas.
