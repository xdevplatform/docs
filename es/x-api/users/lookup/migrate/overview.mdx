## Comparación de los endpoints de users lookup de X API

Los endpoints v2 de user lookup reemplazarán a los estándar v1.1 [GET users/lookup](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/get-users-lookup.html) y [GET users/show](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/get-users-show.html). Si tienes código, aplicaciones o herramientas que utilizan una de estas versiones de los endpoints de user lookup y estás considerando migrar al nuevo endpoint de X API v2, este conjunto de guías es para ti.


Las siguientes tablas comparan los distintos tipos de endpoints de users lookup:


|     |     |     |
| :--- | :--- | :--- |
| **Descripción** | **Standard v1.1** | **X API v2** |
| Métodos HTTP admitidos | `GET` | `GET` |
| Dominio del host | `https://api.x.com` | `https://api.x.com` |
| Ruta del endpoint | `/1.1/users/show.json` `/1.1/users/lookup.json` | `/2/users`<br/><br/>`/2/users/:id`<br/><br/>`/2/users/by`<br/><br/>`/2/users/by/:username` |
| [Autenticación](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br/><br/>App only<br/><br/>OAuth 2.0 Authorization Code with PKCE |
| [Rate limits](/resources/fundamentals/rate-limits) de solicitudes por defecto | 900 solicitudes por 15 min (por usuario)<br/><br/>/show - 900 solicitudes por 15 min (por app)  <br/>/lookup - 300 solicitudes por 15 min (por app) | 900 solicitudes por 15 min (por usuario)<br/><br/>300 solicitudes por 15 min (por app) |
| Máximo de usuarios por respuesta | /show -  1<br/><br/>/lookup - 100 | 100 |
| Formato del objeto JSON de respuesta | Formato Standard v1.1 | [Formato de X API v2](/x-api/fundamentals/data-dictionary) (determinado por los parámetros de solicitud fields y expansions, no compatible con versiones anteriores en formato v1.1)<br/><br/>Para saber más sobre cómo migrar del formato Standard v1.1 al formato X API v2, visita nuestra [guía de migración de formatos de datos](/x-api/migrate/data-format-migration). |
| Admite seleccionar qué [fields](/x-api/fundamentals/data-dictionary) devolver en el payload |     | ✔   |
| Admite los fields de [annotations](/x-api/fundamentals/post-annotations) (en el Post fijado) |     | ✔   |
| Admite solicitar nuevos fields de [metrics](/x-api/fundamentals/metrics) (en el Post fijado) |     | ✔   |
| Admite el field [conversation_id](/x-api/fundamentals/conversation-id) (en el Post fijado) |     | ✔   |
| Requiere el uso de credenciales de una [App de desarrollador](/resources/fundamentals/developer-apps) asociada a un [project](/resources/fundamentals/developer-apps) |     | ✔   |
