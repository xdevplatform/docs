Los endpoints de Mutes te permiten silenciar y dejar de silenciar usuarios, y recuperar la lista de usuarios silenciados por el usuario autenticado.

## Endpoints

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/muting`](/x-api/users/get-muting) | Obtiene los usuarios silenciados |
| POST | [`/2/users/:id/muting`](/x-api/users/mute-user) | Silencia a un usuario |
| DELETE | [`/2/users/:source_user_id/muting/:target_user_id`](/x-api/users/unmute-user) | Deja de silenciar a un usuario |

---

## Ejemplo: Obtener usuarios silenciados

```bash
curl "https://api.x.com/2/users/123456789/muting?\
user.fields=username,description" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

## Ejemplo: Silenciar a un usuario

```bash
curl -X POST "https://api.x.com/2/users/123456789/muting" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "9876543210"}'
```
