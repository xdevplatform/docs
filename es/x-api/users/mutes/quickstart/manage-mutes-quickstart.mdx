Esta guía te guía en el proceso de silenciar y dejar de silenciar usuarios usando la X API.

<Note>
**Requisitos previos**

Antes de comenzar, necesitarás:
- Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
- User Access Token (OAuth 1.0a u OAuth 2.0 PKCE)
</Note>

---

## Silenciar a un usuario

<Steps>
  <Step title="Obtén tu user ID">
    Necesitas el ID de tu usuario autenticado. Puedes encontrarlo usando el [endpoint user lookup](/x-api/users/lookup/introduction) o desde tu Access Token (la parte numérica es tu user ID).
  </Step>

  <Step title="Obtén el user ID de destino">
    Encuentra el user ID de la cuenta que deseas silenciar usando el [endpoint user lookup](/x-api/users/lookup/introduction).
  </Step>

  <Step title="Envía la solicitud de silencio">

<CodeGroup dropdown>

```bash cURL
curl -X POST "https://api.x.com/2/users/123456789/muting" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "9876543210"}'
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Silenciar a un usuario
response = client.users.mute(
    source_user_id="123456789",
    target_user_id="9876543210"
)

print(f"Muting: {response.data.muting}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// Silenciar a un usuario
const response = await client.users.mute("123456789", {
  targetUserId: "9876543210",
});

console.log(`Muting: ${response.data?.muting}`);
```

</CodeGroup>

  </Step>

  <Step title="Revisa la respuesta">
    ```json
    {
      "data": {
        "muting": true
      }
    }
    ```
  </Step>
</Steps>

## Dejar de silenciar a un usuario

Elimina un silencio de un usuario:

<CodeGroup dropdown>

```bash cURL
curl -X DELETE "https://api.x.com/2/users/123456789/muting/9876543210" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Dejar de silenciar a un usuario
response = client.users.unmute(
    source_user_id="123456789",
    target_user_id="9876543210"
)

print(f"Muting: {response.data.muting}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// Dejar de silenciar a un usuario
const response = await client.users.unmute("123456789", "9876543210");

console.log(`Muting: ${response.data?.muting}`);
```

</CodeGroup>

**Respuesta:**

```json
{
  "data": {
    "muting": false
  }
}
```

## Silenciar vs Bloquear

| Característica | Silenciar | Bloquear |
|:--------|:-----|:------|
| Ver sus Posts | No | No |
| Ellos ven tus Posts | Sí | No |
| Ellos pueden seguirte | Sí | No |
| Ellos pueden enviarte DMs | Sí | No |
| Ellos lo saben | No | Sí |
