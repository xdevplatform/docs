## Comparación de los endpoints de mutes de X API

#### Mutes lookup

El endpoint v2 de mutes lookup reemplazará a los estándar [v1.1 GET mutes/users/ids](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/get-mutes-users-ids) y [GET mutes/users/list](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/get-mutes-users-list).

Las siguientes tablas comparan los endpoints mute estándar v1.1 y de X API v2:


| Descripción | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP admitidos | **GET** | **GET** |
| Dominio del host | **https://api.x.com** | **https://api.x.com** |
| Ruta del endpoint | **/1.1/mutes/users/ids.json**<br/><br/>/1.1/mutes/users/list.json | **/2/users/:id/muting** |
| [Autenticación](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br/><br/>OAuth 2.0 Authorization Code with PKCE |
| [Rate limits](/resources/fundamentals/rate-limits) de solicitudes por defecto | 15 solicitudes por 15 min (por usuario) | 15 solicitudes por 15 min (por usuario) |
| Formatos de datos | Formato Standard v1.1 | [Formato de X API v2](/x-api/fundamentals/data-dictionary) (determinado por los parámetros de solicitud fields y expansions, no compatible con versiones anteriores en formato v1.1)<br/><br/>Para saber más sobre cómo migrar del formato Standard v1.1 al formato X API v2, visita nuestra [guía de migración de formatos de datos](/x-api/migrate/data-format-migration). |
| Requiere el uso de credenciales de una [App de desarrollador](/resources/fundamentals/developer-apps) asociada a un [Project](/resources/fundamentals/developer-apps) |     | ✔️  |

#### Manage mutes

Los endpoints v2 de manage mutes reemplazarán a los estándar v1.1 [POST mutes/users/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/post-mutes-users-create) y [POST mutes/users/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/post-mutes-users-destroy).

Las siguientes tablas comparan los endpoints mute estándar v1.1 y de X API v2:

**Silenciar a un usuario**

| Descripción | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP admitidos | POST | POST |
| Dominio del host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/mutes/users/create.json | /2/users/:id/muting |
| [Autenticación](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br/><br/>OAuth 2.0 Authorization Code with PKCE |
| [Rate limits](/resources/fundamentals/rate-limits) de solicitudes por defecto | 50 solicitudes por 15 min | 50 solicitudes por 15 min |
| Requiere el uso de credenciales de una [App de desarrollador](/resources/fundamentals/developer-apps) asociada a un [Project](/resources/fundamentals/developer-apps) |     | ✔️  |
