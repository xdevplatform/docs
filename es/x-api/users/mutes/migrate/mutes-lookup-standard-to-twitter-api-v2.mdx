### Mutes lookup: Standard v1.1 comparado con X API v2

Si has estado trabajando con los endpoints estándar v1.1 [GET mutes/users/ids](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/get-mutes-users-ids) y [GET mutes/users/list](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/get-mutes-users-list), el objetivo de esta guía es ayudarte a entender las similitudes y diferencias entre los endpoints de mutes lookup estándar v1.1 y de X API v2.

* **Similitudes**
    * Autenticación
* **Diferencias**
    * URLs de endpoints

    * Límites de usuarios por solicitud
    * Requisitos de App y Project
    * Formatos de datos de respuesta
    * Parámetros de solicitud

#### Similitudes

**Autenticación**

Tanto los endpoints estándar v1.1 como los de X API v2 de mutes lookup utilizan [OAuth 1.0a User Context](/resources/fundamentals/authentication#oauth-1-0a-2). Por lo tanto, si anteriormente utilizabas uno de los endpoints estándar v1.1 de mutes lookup, puedes seguir usando el mismo método de autenticación si migras a la versión de X API v2.

#### Diferencias

**URLs de endpoints**

* Endpoints estándar v1.1:
    * GET https://api.x.com/1.1/mutes/users/ids.json
        (lista de user IDs que el usuario especificado ha silenciado)
    * GET https://api.x.com/1.1/mutes/users/lists.json
        (lista de usuarios que están silenciados por el usuario especificado)
* Endpoint X API v2:
    * GET https://api.x.com/2/users/:id/muting
        (lista de usuarios que están silenciados por el user ID especificado)
