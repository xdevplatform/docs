Los endpoints de Blocks te permiten recuperar la lista de usuarios bloqueados por el usuario autenticado, así como bloquear y desbloquear usuarios.

<Callout icon="/icons/xds/icon-key.svg" color="#22C55E" iconType="regular">
Los endpoints para bloquear y desbloquear usuarios solo están disponibles en el plan Enterprise. Puedes completar el formulario de interés Enterprise [aquí](/forms/enterprise-api-interest).
</Callout>

## Endpoints

| Método | Endpoint | Descripción | Disponibilidad |
|:-------|:---------|:------------|:---------------|
| GET | [`/2/users/:id/blocking`](/x-api/users/get-blocking) | Obtiene los usuarios bloqueados | <div className="flex items-center gap-1 flex-nowrap whitespace-nowrap"><Badge color="blue" size="xs">Pay-per-use</Badge><Badge color="green" size="xs">Enterprise</Badge></div> |
| POST | `/2/users/:id/blocking` | Bloquea a un usuario | <Badge color="green" size="xs">Enterprise</Badge> |
| DELETE | `/2/users/:source_user_id/blocking/:target_user_id` | Desbloquea a un usuario | <Badge color="green" size="xs">Enterprise</Badge> |

---

## Ejemplo: Obtener usuarios bloqueados

```bash
curl "https://api.x.com/2/users/123456789/blocking?\
user.fields=username,description" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

## Ejemplo: Bloquear a un usuario (solo Enterprise)

```bash
curl -X POST "https://api.x.com/2/users/123456789/blocking" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "9876543210"}'
```
