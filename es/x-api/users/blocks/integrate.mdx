## Autenticación

Los endpoints de bloqueos requieren autenticación de usuario:

| Método | Descripción |
|:-------|:------------|
| [OAuth 2.0 Authorization Code with PKCE](/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) | Recomendado para nuevas aplicaciones |
| [OAuth 1.0a User Context](/resources/fundamentals/authentication) | Soporte heredado |

<Warning>
La autenticación App-Only no es compatible. Debes autenticarte en nombre de un usuario.
</Warning>

### Scopes requeridos (OAuth 2.0)

| Scope | Requerido para |
|:------|:---------------|
| `block.read` | Obtener cuentas bloqueadas |
| `block.write` | Bloquear y desbloquear cuentas |
| `users.read` | Requerido con scopes de bloqueo |

## Resumen de endpoints

| Método | Endpoint | Descripción | Disponibilidad |
|:-------|:---------|:------------|:---------------|
| GET | `/2/users/:id/blocking` | Obtiene la lista de cuentas bloqueadas | <div className="flex items-center gap-1 flex-nowrap whitespace-nowrap"><Badge color="blue" size="xs">Pay-per-use</Badge><Badge color="green" size="xs">Enterprise</Badge></div> |
| POST | `/2/users/:id/blocking` | Bloquea una cuenta | <Badge color="green" size="xs">Enterprise</Badge> |
| DELETE | `/2/users/:source_user_id/blocking/:target_user_id` | Desbloquea una cuenta | <Badge color="green" size="xs">Enterprise</Badge> |

## Paginación

Para usuarios con listas de bloqueo grandes, los resultados están paginados:

<CodeGroup dropdown>

```bash cURL
# Primera solicitud
curl "https://api.x.com/2/users/123/blocking?max_results=100" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"

# Solicitud posterior con token de paginación
curl "https://api.x.com/2/users/123/blocking?max_results=100&pagination_token=NEXT_TOKEN" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

# Usa el token de acceso de usuario de OAuth 2.0
client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# El SDK gestiona la paginación automáticamente
all_blocked = []

for page in client.users.get_blocking(user_id="123", max_results=100):
    if page.data:
        all_blocked.extend(page.data)

print(f"Blocked {len(all_blocked)} users")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

async function getAllBlockedUsers(userId) {
  const allBlocked = [];

  // El SDK gestiona la paginación automáticamente
  const paginator = client.users.getBlocking(userId, { maxResults: 100 });

  for await (const page of paginator) {
    if (page.data) {
      allBlocked.push(...page.data);
    }
  }

  return allBlocked;
}

// Uso
const blocked = await getAllBlockedUsers("123");
console.log(`Blocked ${blocked.length} users`);
```

</CodeGroup>

## Gestión de errores

| Estado | Error | Solución |
|:-------|:------|:---------|
| 400 | Invalid request | Verifica el formato del ID de usuario |
| 401 | Unauthorized | Verifica el token de acceso |
| 403 | Forbidden | Verifica scopes y permisos. Bloquear/desbloquear requieren [Enterprise](/forms/enterprise-api-interest) |
| 404 | Not Found | El usuario no existe |
| 429 | Too Many Requests | Espera y reintenta |
