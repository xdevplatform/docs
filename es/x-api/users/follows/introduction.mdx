Los endpoints de Follows te permiten seguir y dejar de seguir usuarios, y recuperar listas de seguidores y seguidos de cualquier usuario.

## Endpoints

### Follows lookup

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/followers`](/x-api/users/get-followers) | Obtiene los seguidores de un usuario |
| GET | [`/2/users/:id/following`](/x-api/users/get-following) | Obtiene a quién sigue un usuario |

### Manage follows

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| POST | [`/2/users/:id/following`](/x-api/users/follow-user) | Sigue a un usuario |
| DELETE | [`/2/users/:source_user_id/following/:target_user_id`](/x-api/users/unfollow-user) | Deja de seguir a un usuario |

---

## Ejemplo: Obtener seguidores

```bash
curl "https://api.x.com/2/users/2244994945/followers?\
user.fields=username,verified,public_metrics" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

## Ejemplo: Seguir a un usuario

```bash
curl -X POST "https://api.x.com/2/users/123456789/following" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "2244994945"}'
```
