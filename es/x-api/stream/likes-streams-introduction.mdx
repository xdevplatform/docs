Los endpoints de Likes Streams entregan eventos de like en tiempo real a través de conexiones HTTP GET persistentes. Estos streams brindan acceso a la actividad de likes en X, permitiéndote rastrear patrones de interacción, monitorear el rendimiento del contenido y analizar el comportamiento de likes a gran escala.

Hay dos streams disponibles:

* **Stream de All Likes** — Entrega todos los eventos públicos de like en tiempo real (firehose).
* **Stream de Sampled Likes** — Entrega una muestra del 10% de los eventos públicos de like.

Estos endpoints de streaming utilizan autenticación [OAuth 2.0 App-Only](/resources/fundamentals/authentication#oauth-2-0).

_Para usar estas APIs, primero debes configurar una cuenta con nuestro equipo de ventas enterprise._

<Note>
**Configuración de la cuenta**

Para acceder a estos endpoints, necesitarás:

* Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) aprobada.
* Autenticarte usando las claves y tokens de una [App de desarrollador](/resources/fundamentals/developer-apps) que se encuentre dentro de un [Project](/resources/fundamentals/developer-apps).

Aprende más sobre cómo obtener acceso a los endpoints de la X API v2 en nuestra [guía de introducción](/x-api/getting-started/getting-access).
</Note>

## Endpoints

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/likes/firehose/stream`](/x-api/stream/stream-all-likes) | Transmite todos los eventos de like en tiempo real |
| GET | [`/2/likes/sample10/stream`](/x-api/stream/stream-sampled-likes) | Transmite una muestra del 10% de los eventos de like |
