## ¿Qué es X API v2?

X API v2 es ahora la X API principal y es donde se centran la inversión en producto y la innovación. Nos hemos asociado con desarrolladores para construir la próxima generación de la X API con el fin de servir mejor a nuestra diversa comunidad de desarrolladores. Con base en los comentarios de los desarrolladores, hemos reconstruido la API para servir mejor a un conjunto más amplio de necesidades, hemos introducido nuevas funciones y endpoints, y hemos mejorado la experiencia del desarrollador.

Durante los últimos años, nos asociamos con desarrolladores y reconstruimos la API para servir mejor a un conjunto más amplio de necesidades, introducir nuevas funciones y endpoints y mejorar la experiencia del desarrollador. Estamos comprometidos con seguir construyendo una plataforma de desarrollo abierta y estamos emocionados por ver lo que construyas con X API v2.

## ¿Por qué migrar?

X API v2 se construye sobre una base moderna y más sostenible e incluye tanto endpoints de reemplazo mejorados para los productos estándar v1.1 y empresariales, como funcionalidad totalmente nueva. Recomendamos encarecidamente a los clientes de las APIs heredadas (v1.1 y empresariales) que comiencen a migrar a v2, ya que tenemos la intención de darlas de baja eventualmente. Usa la X API para escuchar y analizar la conversación pública, interactuar con personas en X e innovar.

En esta sección, hablaremos sobre los endpoints y la funcionalidad.

Aunque la mayoría de los endpoints en X API v2 son reemplazos, hemos introducido varios endpoints nuevos. Aquí hay algunos ejemplos de nuevos endpoints que hemos publicado en v2:

- [Endpoints de Spaces](/x-api/spaces/introduction) para ayudar a las personas a aprovechar más X Spaces y permitir a los desarrolladores ayudar a dar forma al futuro de las conversaciones de audio.
- [Ocultar respuestas](/x-api/posts/hide-replies/introduction), que te permite construir herramientas que ayudan a limitar el impacto de respuestas abusivas, que distraen o engañosas a gran escala.
- Nuevos endpoints de Lists que te permiten [fijar y desfijar Lists](/x-api/lists/pinned-lists/introduction) o buscar las Lists fijadas de una persona.
- Nuevos [endpoints de batch compliance](/x-api/compliance/batch-compliance/introduction) que te permiten garantizar que tus datos almacenados de usuario y Tweet cumplan con las normas.

## Nueva funcionalidad

X API v2 también incluye nuevas funciones que te ayudarán a obtener más valor de la X API. Gran parte de lo nuevo ha sido impulsado por tus comentarios e incluye ciertas funciones que anteriormente estaban reservadas para clientes empresariales.

Algunas de las mejoras en la API incluyen:

- [Un diseño consistente entre endpoints](/x-api/fundamentals/consistency)
- [La capacidad de especificar qué campos y objetos se devuelven en el payload de la respuesta](/x-api/fundamentals/data-dictionary/reference#how-to-use-fields-and-expansions)
- [Objetos de datos nuevos y más detallados](/x-api/fundamentals/data-dictionary)
- [Recibe y filtra datos con nueva información contextual proporcionada por las Tweet annotations](/x-api/fundamentals/post-annotations)
- [Acceso a nuevas métricas](/x-api/fundamentals/metrics)
- [Identifica y filtra fácilmente conversaciones que pertenecen a un hilo de respuestas](/x-api/fundamentals/conversation-id)
- [Funcionalidad avanzada y mayor acceso a datos para investigadores académicos](https://developer.x.com/content/developer-twitter/en/products/twitter-api/academic-research)
- [Funcionalidad de recuperación y redundancia para endpoints de streaming](/x-api/fundamentals/recovery-and-redundancy)
- [Devuelve fácilmente el conteo de Tweets que coinciden con una consulta](/x-api/posts/counts/introduction)
- [Compatibilidad con Edit Tweets](/x-api/fundamentals/edit-posts)
- Filtrado de spam de alta confianza
- Las URLs acortadas se expanden por completo para un filtrado y análisis más efectivos
- Objetos JSON de respuesta simplificados al eliminar campos obsoletos y modernizar etiquetas
- Devolución del 100% de los Tweets públicos y disponibles que coinciden con las consultas de búsqueda
- "Rules" de streaming para que puedas realizar cambios sin interrumpir las conexiones
- Lenguaje de consulta más expresivo para search Tweets, Tweet counts y filtered stream
- Especificación OpenAPI para construir nuevas librerías y rastrear los cambios de forma más transparente
