## Introducción

Con el lanzamiento de la versión v2 de la X API, hemos adoptado un nuevo formato de respuesta de datos y un método para solicitar distintos objetos y campos, al que simplemente llamamos el formato X API v2. 

En la sección de diferencias generales, puedes conocer algunos cambios que son relevantes para usuarios estándar y empresariales. Sin embargo, también preparamos una guía específica para el [formato Native de v1.1 estándar](https://developer.x.com/en/docs/x-api/v1/data-dictionary/overview), el [formato Native Enriched](/x-api/enterprise-gnip-2.0/fundamentals/data-dictionary#native-enriched-tweet-object) empresarial y el [formato Activity Streams](/x-api/enterprise-gnip-2.0/fundamentals/data-dictionary#activity-object) empresarial, que ayuda a mapear campos y explica qué fields y expansions debes usar para solicitar los nuevos campos de v2. 

* [Formato Native a X API v2 (v1.1 estándar)](/x-api/migrate/data-format-migration#migrating-from-standard-v1-1s-data-format-to-v2) 
* [Native Enriched a X API v2 (empresarial)](/x-api/migrate/data-format-migration#migrating-from-native-enriched-data-format-to-v2)
* [Activity Streams a X API v2 (empresarial)](/x-api/migrate/data-format-migration#migrating-from-activity-streams-data-format-to-v2)

También puede interesarte nuestra [herramienta visual de migración de formato de datos](/x-api/migrate/data-format-migration#visual-data-format-migration-tool) para ayudarte a ver rápidamente las diferencias entre el [formato de datos de X API v1.1](https://developer.x.com/en/docs/x-api/v1/data-dictionary/overview) y el [formato X API v2](/x-api/introduction).
