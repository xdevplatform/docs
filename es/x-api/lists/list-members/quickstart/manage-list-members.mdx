Esta guía te guía en el proceso de añadir y eliminar miembros de una List.

<Note>
**Requisitos previos**

Antes de comenzar, necesitarás:
- Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
- User Access Token (OAuth 1.0a u OAuth 2.0 PKCE)
- Una List de tu propiedad
</Note>

---

## Añadir un miembro a una List

<Steps>
  <Step title="Obtén el ID de la List y el user ID">
    Necesitas el ID de tu List y el user ID de la persona que quieres añadir. Encuentra los user IDs usando el [endpoint user lookup](/x-api/users/lookup/introduction).
  </Step>

  <Step title="Añade el miembro">

<CodeGroup dropdown>

```bash cURL
curl -X POST "https://api.x.com/2/lists/1441162269824405510/members" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"user_id": "2244994945"}'
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Añadir un miembro a una List
response = client.lists.add_member(
    list_id="1441162269824405510",
    user_id="2244994945"
)

print(f"Is member: {response.data.is_member}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// Añadir un miembro a una List
const response = await client.lists.addMember("1441162269824405510", {
  userId: "2244994945",
});

console.log(`Is member: ${response.data?.is_member}`);
```

</CodeGroup>

  </Step>

  <Step title="Revisa la respuesta">
    ```json
    {
      "data": {
        "is_member": true
      }
    }
    ```
  </Step>
</Steps>

## Eliminar un miembro de una List

<CodeGroup dropdown>

```bash cURL
curl -X DELETE "https://api.x.com/2/lists/1441162269824405510/members/2244994945" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Eliminar un miembro de una List
response = client.lists.remove_member(
    list_id="1441162269824405510",
    user_id="2244994945"
)

print(f"Is member: {response.data.is_member}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// Eliminar un miembro de una List
const response = await client.lists.removeMember(
  "1441162269824405510",
  "2244994945"
);

console.log(`Is member: ${response.data?.is_member}`);
```

</CodeGroup>

**Respuesta:**

```json
{
  "data": {
    "is_member": false
  }
}
```

## Notas importantes

<Note>
- Solo puedes gestionar miembros de Lists de tu propiedad
- Añadir un usuario a una List no requiere su permiso
- Los usuarios pueden ver a qué Lists públicas han sido añadidos
</Note>
