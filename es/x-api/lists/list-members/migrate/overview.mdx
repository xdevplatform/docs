## Comparación de los endpoints de List members de X API


El grupo de endpoints v2 de List members reemplazará a los estándar v1.1 [GET lists/members](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-members), [GET lists/memberships](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-memberships), [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create) y [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy). Si tienes código, aplicaciones o herramientas que usan una de estas versiones de los endpoints de List member y estás considerando migrar al nuevo endpoint de X API v2, este conjunto de guías es para ti.

### List members lookup

Los endpoints v2 de List members lookup reemplazarán a los estándar [GET lists/members](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-members), [GET lists/memberships](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-memberships).

### Gestionar List members

Los endpoints v2 de manage List members reemplazarán a los estándar [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create), [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy).

Las siguientes tablas comparan los endpoints List estándar v1.1 y de X API v2:

**Añadir miembro**

| Descripción | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP admitidos | POST | POST |
| Dominio del host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/lists/members/create.json | /2/lists/:id/members |
| [Autenticación](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br/><br/>OAuth 2.0 Authorization Code with PKCE |
| [Rate limits](/resources/fundamentals/rate-limits) de solicitudes por defecto | Ninguno | 300 solicitudes por 15 min (por usuario) |

**Eliminar miembro**

| Descripción | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP admitidos | POST | DELETE |
| Dominio del host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/lists/members/destroy.json | /2/lists/:id/:user_id |
| [Autenticación](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br/><br/>OAuth 2.0 Authorization Code with PKCE |
| [Rate limits](/resources/fundamentals/rate-limits) de solicitudes por defecto | Ninguno | 300 solicitudes por 15 min (por usuario) |

Para acceder a los endpoints de X API v2, debes [registrarte para una cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info). Al autenticarte, debes usar claves y tokens de una [App de desarrollador](/resources/fundamentals/developer-apps) que se encuentre dentro de un [Project](/resources/fundamentals/developer-apps).

Obtén más información sobre cómo acceder a los endpoints de X API v2 en nuestra página [primeros pasos](/x-api/getting-started/getting-access).
