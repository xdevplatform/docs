Los endpoints de List Members te permiten ver los miembros de una List, añadir miembros a tus Lists y eliminarlos. También puedes ver de qué Lists es miembro un usuario.

## Endpoints

### List members lookup

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/lists/:id/members`](/x-api/lists/get-list-members) | Obtiene los miembros de una List |
| GET | [`/2/users/:id/list_memberships`](/x-api/users/get-list-memberships) | Obtiene las Lists en las que está un usuario |

### Manage List members

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| POST | [`/2/lists/:id/members`](/x-api/lists/add-list-member) | Añade un miembro |
| DELETE | [`/2/lists/:id/members/:user_id`](/x-api/lists/remove-list-member) | Elimina un miembro |

---

## Ejemplo: Obtener miembros de una List

```bash
curl "https://api.x.com/2/lists/1234567890/members?\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

## Ejemplo: Añadir un miembro

```bash
curl -X POST "https://api.x.com/2/lists/1234567890/members" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"user_id": "9876543210"}'
```
