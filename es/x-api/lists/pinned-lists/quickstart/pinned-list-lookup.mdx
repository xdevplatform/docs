Esta guía te guía en la recuperación de las Lists fijadas de un usuario.

<Note>
**Requisitos previos**

Antes de comenzar, necesitarás:
- Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
- User Access Token (OAuth 1.0a u OAuth 2.0 PKCE)
</Note>

---

## Obtener Lists fijadas

<Steps>
  <Step title="Obtén tu user ID">
    Necesitas el ID de tu usuario autenticado. Puedes encontrarlo usando el [endpoint user lookup](/x-api/users/lookup/introduction) o desde tu Access Token (la parte numérica es tu user ID).
  </Step>

  <Step title="Solicita las Lists fijadas">

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/2244994945/pinned_lists?\
list.fields=follower_count,member_count,owner_id&\
expansions=owner_id&\
user.fields=created_at,username" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# Obtener Lists fijadas
response = client.lists.get_pinned(
    "2244994945",
    list_fields=["follower_count", "member_count", "owner_id"],
    expansions=["owner_id"],
    user_fields=["created_at", "username"]
)

for lst in response.data:
    print(f"{lst.name} - {lst.follower_count} followers")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// Obtener Lists fijadas
const response = await client.lists.getPinned("2244994945", {
  listFields: ["follower_count", "member_count", "owner_id"],
  expansions: ["owner_id"],
  userFields: ["created_at", "username"],
});

response.data?.forEach((lst) => {
  console.log(`${lst.name} - ${lst.follower_count} followers`);
});
```

</CodeGroup>

## Fields de List disponibles

| Field | Descripción |
|:------|:------------|
| `description` | Descripción de la List |
| `owner_id` | User ID del propietario |
| `private` | Si la List es privada |
| `member_count` | Número de miembros |
| `follower_count` | Número de seguidores |
| `created_at` | Fecha de creación de la List |
