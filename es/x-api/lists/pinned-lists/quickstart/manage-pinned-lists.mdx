Esta guía te guía en el proceso de fijar y desfijar Lists.

<Note>
**Requisitos previos**

Antes de comenzar, necesitarás:
- Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
- User Access Token (OAuth 1.0a u OAuth 2.0 PKCE)
</Note>

---

## Fijar una List

<Steps>
  <Step title="Obtén tu user ID y el ID de la List">
    Necesitas el ID de tu usuario autenticado y el ID de la List que quieres fijar. Encuentra los IDs de List en la URL al ver una List.
  </Step>

  <Step title="Fija la List">

<CodeGroup dropdown>

```bash cURL
curl -X POST "https://api.x.com/2/users/2244994945/pinned_lists" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"list_id": "1454155907651158017"}'
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Fijar una List
response = client.lists.pin(
    user_id="2244994945",
    list_id="1454155907651158017"
)

print(f"Pinned: {response.data.pinned}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// Fijar una List
const response = await client.lists.pin("2244994945", {
  listId: "1454155907651158017",
});

console.log(`Pinned: ${response.data?.pinned}`);
```

</CodeGroup>

  </Step>

  <Step title="Revisa la respuesta">
    ```json
    {
      "data": {
        "pinned": true
      }
    }
    ```
  </Step>
</Steps>

## Desfijar una List

<CodeGroup dropdown>

```bash cURL
curl -X DELETE "https://api.x.com/2/users/2244994945/pinned_lists/1454155907651158017" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Desfijar una List
response = client.lists.unpin(
    user_id="2244994945",
    list_id="1454155907651158017"
)

print(f"Pinned: {response.data.pinned}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// Desfijar una List
const response = await client.lists.unpin("2244994945", "1454155907651158017");

console.log(`Pinned: ${response.data?.pinned}`);
```

</CodeGroup>

**Respuesta:**

```json
{
  "data": {
    "pinned": false
  }
}
```

## Notas importantes

<Note>
- Solo puedes fijar Lists que sigues o de las que eres propietario
- Las Lists fijadas aparecen en la parte superior de tus Lists en la app de X
- Existe un límite en la cantidad de Lists que puedes fijar
</Note>
