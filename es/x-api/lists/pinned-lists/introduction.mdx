Los endpoints de Pinned Lists te permiten ver, fijar y desfijar Lists para el usuario autenticado. Las Lists fijadas aparecen de forma destacada en la interfaz de X del usuario.

## Endpoints

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/pinned_lists`](/x-api/users/get-pinned-lists) | Obtiene las Lists fijadas |
| POST | [`/2/users/:id/pinned_lists`](/x-api/users/pin-list) | Fija una List |
| DELETE | [`/2/users/:id/pinned_lists/:list_id`](/x-api/users/unpin-list) | Desfija una List |

---

## Ejemplo: Obtener Lists fijadas

```bash
curl "https://api.x.com/2/users/123456789/pinned_lists?\
list.fields=name,description,member_count" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

## Ejemplo: Fijar una List

```bash
curl -X POST "https://api.x.com/2/users/123456789/pinned_lists" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"list_id": "9876543210"}'
```
