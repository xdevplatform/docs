Los endpoints de List lookup te permiten recuperar información sobre Lists. Consulta una List específica por ID u obtén todas las Lists propiedad de un usuario.

## Resumen

  <Card title="Por propietario" icon="/icons/xds/icon-person.svg">
    Obtén todas las Lists propiedad de un usuario
  </Card>

## Endpoints

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/lists/:id`](/x-api/lists/get-list-by-id) | Obtiene una List por ID |
| GET | [`/2/users/:id/owned_lists`](/x-api/users/get-owned-lists) | Obtiene las Lists propiedad de un usuario |

---

## Fields de respuesta

Por defecto, la respuesta incluye `id` y `name`. Solicita fields adicionales:

| Field | Descripción |
|:------|:------------|
| `description` | Descripción de la List |
| `owner_id` | User ID del propietario |
| `private` | Si la List es privada |
| `follower_count` | Número de seguidores |
| `member_count` | Número de miembros |
| `created_at` | Fecha de creación de la List |

### Solicitud de ejemplo

```bash
curl "https://api.x.com/2/lists/1234567890?\
list.fields=description,owner_id,member_count,follower_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
