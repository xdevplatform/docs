## Autenticación

Los endpoints de List lookup admiten múltiples métodos de autenticación:

| Método | Ideal para | ¿Acceso a Lists privadas? |
|:-------|:-----------|:--------------------------|
| [OAuth 2.0 App-Only](/resources/fundamentals/authentication#oauth-2-0) | Datos públicos de Lists | No |
| [OAuth 2.0 Authorization Code with PKCE](/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) | Aplicaciones orientadas al usuario | Sí (propias/seguidas) |
| [OAuth 1.0a User Context](/resources/fundamentals/authentication) | Integraciones heredadas | Sí (propias/seguidas) |

### Solicitud de ejemplo

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/lists/84839422?\
list.fields=description,member_count,follower_count,private" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python Python SDK
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obtener una List por ID
response = client.lists.get(
    list_id="84839422",
    list_fields=["description", "member_count", "follower_count", "private"]
)
print(response.data)
```

```javascript JavaScript SDK
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

const response = await client.lists.get("84839422", {
  listFields: ["description", "member_count", "follower_count", "private"],
});
console.log(response.data);
```

</CodeGroup>

## Fields y expansions

### Respuesta predeterminada

```json
{
  "data": {
    "id": "84839422",
    "name": "Tech News"
  }
}
```

### Fields disponibles

<Accordion title="list.fields">
| Field | Descripción |
|:------|:------------|
| `created_at` | Marca de tiempo de creación de la List |
| `description` | Descripción de la List |
| `follower_count` | Número de seguidores |
| `member_count` | Número de miembros |
| `owner_id` | User ID del propietario |
| `private` | Si la List es privada |
</Accordion>

<Accordion title="user.fields (requiere expansion owner_id)">
| Field | Descripción |
|:------|:------------|
| `username` | @handle del propietario |
| `name` | Nombre visible del propietario |
| `verified` | Estado de verificación del propietario |
| `profile_image_url` | URL del avatar del propietario |
</Accordion>

### Ejemplo con expansions

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/lists/84839422?\
list.fields=description,member_count,follower_count,owner_id&\
expansions=owner_id&\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obtener List con expansion del propietario
response = client.lists.get(
    list_id="84839422",
    list_fields=["description", "member_count", "follower_count", "owner_id"],
    expansions=["owner_id"],
    user_fields=["username", "verified"]
)

print(response.data)
print(response.includes)  # Contiene el objeto de usuario del propietario
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

const response = await client.lists.get("84839422", {
  listFields: ["description", "member_count", "follower_count", "owner_id"],
  expansions: ["owner_id"],
  userFields: ["username", "verified"],
});

console.log(response.data);
console.log(response.includes); // Contiene el objeto de usuario del propietario
```

</CodeGroup>

## Paginación

Al recuperar Lists propias, los resultados están paginados:

<CodeGroup dropdown>

```bash cURL
# Primera solicitud
curl "https://api.x.com/2/users/123/owned_lists?max_results=100" \
  -H "Authorization: Bearer $BEARER_TOKEN"

# Solicitud posterior con token de paginación
curl "https://api.x.com/2/users/123/owned_lists?max_results=100&pagination_token=NEXT_TOKEN" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# El SDK gestiona la paginación automáticamente
all_lists = []

for page in client.lists.get_user_owned_lists(user_id="123", max_results=100):
    if page.data:
        all_lists.extend(page.data)

print(f"Found {len(all_lists)} lists")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

async function getAllOwnedLists(userId) {
  const allLists = [];

  // El SDK gestiona la paginación automáticamente
  const paginator = client.lists.getUserOwnedLists(userId, { maxResults: 100 });

  for await (const page of paginator) {
    if (page.data) {
      allLists.push(...page.data);
    }
  }

  return allLists;
}

// Uso
const lists = await getAllOwnedLists("123");
console.log(`Found ${lists.length} lists`);
```

## Lists privadas

- Las Lists privadas solo son visibles para el propietario
- Debes autenticarte como el propietario para recuperar los detalles de una List privada
- El field `private` indica si una List es privada

---

## Gestión de errores

| Estado | Error | Solución |
|:-------|:------|:---------|
| 400 | Invalid request | Verifica el formato del ID de List |
| 401 | Unauthorized | Verifica la autenticación |
| 403 | Forbidden | La List puede ser privada |
| 404 | Not Found | La List no existe |
| 429 | Too Many Requests | Espera y reintenta |
