## Comparación de los endpoints de List lookup de X API

El grupo de endpoints v2 List lookup reemplazará a los estándar v1.1 [GET lists/show](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-show) y [GET lists/ownership](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-ownerships). Si tienes código, aplicaciones o herramientas que usan una de estas versiones de los endpoints de List lookup y estás considerando migrar al nuevo endpoint de X API v2, este conjunto de guías es para ti.

Las siguientes tablas comparan los endpoints List estándar v1.1 y de X API v2:

**List Lookup by ID**

|     |     |     |
| :--- | :--- | :--- |
| Descripción | Standard v1.1 | X API v2 |
| Métodos HTTP admitidos | `GET` | `GET` |
| Dominio del host | `https://api.x.com` | `https://api.x.com` |
| Ruta del endpoint | `/1.1/lists/show.json` | `/2/lists/:id` |
| [Autenticación](/resources/fundamentals/authentication) | OAuth 1.0a User Context<br/><br/>App only | OAuth 1.0a User Context<br/><br/>OAuth 2.0 Authorization Code with PKCE<br/><br/>App only |
| [Rate limits](/resources/fundamentals/rate-limits) de solicitudes por defecto | 75 solicitudes por 15 min con OAuth 1.0a<br/><br/>75 solicitudes por 15 min con OAuth 2.0<br/><br/>75 solicitudes por 15 min con App only | 75 solicitudes por 15 min con OAuth 1.0a<br/><br/>75 solicitudes por 15 min con OAuth 2.0<br/><br/>75 solicitudes por 15 min con App only |

**Búsqueda de Lists propiedad del usuario**

|     |     |     |
| :--- | :--- | :--- |
| Descripción | Standard v1.1 | X API v2 |
| Métodos HTTP admitidos | `GET` | `GET` |
| Dominio del host | `https://api.x.com` | `https://api.x.com` |
| Ruta del endpoint | `/1.1/lists/ownerships.json` | `/2/users/:id/owned_lists` |
| [Autenticación](/resources/fundamentals/authentication) | OAuth 1.0a User Context<br/><br/>App only | OAuth 1.0a User Context<br/><br/>OAuth 2.0 Authorization Code with PKCE<br/><br/>App only |
| [Rate limits](/resources/fundamentals/rate-limits) de solicitudes por defecto | 15 solicitudes por 15 min con OAuth 1.0a<br/><br/>15 solicitudes por 15 min con App only | 15 solicitudes por 15 min con OAuth 1.0a<br/><br/>15 solicitudes por 15 min con OAuth 2.0<br/><br/>15 solicitudes por 15 min con App only |

Para acceder a los endpoints de X API v2, debes [registrarte para una cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info). Al autenticarte, debes usar claves y tokens de una [App de desarrollador](/resources/fundamentals/developer-apps) que se encuentre dentro de un [Project](/resources/fundamentals/developer-apps).

Obtén más información sobre cómo acceder a los endpoints de X API v2 en nuestra página [primeros pasos](/x-api/getting-started/getting-access).
