Los endpoints Manage Lists te permiten crear, actualizar y eliminar Lists en nombre de usuarios autenticados.

## Resumen

<CardGroup cols={2}>
  <Card title="Crear" icon="plus">
    Crea una nueva List
  </Card>
  <Card title="Actualizar" icon="pen">
    Actualiza el nombre y la descripción de la List
  </Card>
  <Card title="Eliminar" icon="trash">
    Elimina una List
  </Card>
</CardGroup>

---

## Endpoints

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| POST | [`/2/lists`](/x-api/lists/create-list) | Crea una nueva List |
| PUT | [`/2/lists/:id`](/x-api/lists/update-list) | Actualiza una List |
| DELETE | [`/2/lists/:id`](/x-api/lists/delete-list) | Elimina una List |

---

## Ejemplo: Crear una List

```bash
curl -X POST "https://api.x.com/2/lists" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Tech News",
    "description": "My favorite tech journalists",
    "private": false
  }'
```

## Respuesta de ejemplo

```json
{
  "data": {
    "id": "1234567890",
    "name": "Tech News"
  }
}
```
