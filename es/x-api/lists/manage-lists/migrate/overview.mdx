## Comparación de los endpoints de Lists de X API

Los endpoints v2 de manage Lists eventualmente reemplazarán a [POST lists/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-create), [POST lists/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-destroy) y [POST lists/update](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-update). Si tienes código, aplicaciones o herramientas que usan una versión anterior de estos endpoints y estás considerando migrar a la nueva X API v2, esta guía es para ti.

Las siguientes tablas comparan los endpoints List estándar v1.1 y de X API v2:

**Crear una List**

| Descripción | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP admitidos | POST | POST |
| Dominio del host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/lists/create.json | /2/lists |
| [Autenticación](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| [Rate limits](/resources/fundamentals/rate-limits) de solicitudes por defecto | Ninguno | 300 solicitudes por 15 min (por usuario) |

**Eliminar una List**

| Descripción | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP admitidos | POST | DELETE |
| Dominio del host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/lists/destroy.json | /2/lists/:id |
| [Autenticación](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| [Rate limits](/resources/fundamentals/rate-limits) de solicitudes por defecto | Ninguno | 300 solicitudes por 15 min (por usuario) |

**Actualizar una List**

| Descripción | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP admitidos | POST | PUT |
| Dominio del host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/lists/update.json | /2/lists/:id |
| [Autenticación](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| [Rate limits](/resources/fundamentals/rate-limits) de solicitudes por defecto | Ninguno | 300 solicitudes por 15 min (por usuario) |

Para acceder a los endpoints de X API v2, debes [registrarte para una cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info). Al autenticarte, debes usar claves y tokens de una [App de desarrollador](/resources/fundamentals/developer-apps) que se encuentre dentro de un [Project](/resources/fundamentals/developer-apps).

Obtén más información sobre cómo acceder a los endpoints de X API v2 en nuestra página [primeros pasos](/x-api/getting-started/getting-access).
