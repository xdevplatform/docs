## 소개

[recent search 엔드포인트](/x-api/posts/search/introduction)는 지난 7일 동안 게시된 Post만 가져올 수 있는 반면, user Post timeline과 user mention timeline 엔드포인트는 인증된 사용자에 대해(사용자 ID 사용) 지난 7일보다 오래된 Post와 언급을 조회할 수 있습니다. 개발자는 이러한 엔드포인트를 사용하여 사용자의 timeline 또는 언급에서 Post의 주제, 엔티티, 감정을 연구할 수 있습니다. 이 튜토리얼에서는 user Tweet timeline과 user mention timeline 엔드포인트를 사용하여 사용자의 Post와 언급을 탐색하는 방법을 보여드립니다.


## 사전 요건

*   user Tweet timeline 및 user mention timeline 엔드포인트를 사용하려면 유효한 개발자 계정이 있어야 합니다.
*   또한 [Project](/resources/fundamentals/developer-apps)가 생성되어 있어야 합니다.
*   개발자 계정에 [가입](https://developer.x.com/en/portal/petition/essential/basic-info)하고, [새로운 Developer Console 경험](https://developer.x.com/en/portal/opt-in.html)을 활성화해야 합니다.
*   [Developer Console](/resources/fundamentals/developer-portal)에서 생성한 [Project](/resources/fundamentals/developer-apps)에 연결된 개발자 App의 활성 키와 토큰으로 액세스할 수 있습니다.
*   [X Developer Console](/resources/fundamentals/developer-portal)의 App에서 얻은 Bearer Token.
*   승인된 개발자 계정이 없다면 [신청](https://developer.x.com/en/apply-for-access)할 수 있습니다.

## user Tweet timeline 및 user mention timeline 엔드포인트에서 사용할 사용자 ID를 가져오는 방법

user Tweet timeline 및 user mention timeline 엔드포인트는 사용자 ID를 사용하여 Post를 가져올 수 있게 합니다. 사용자 이름에서 사용자 ID를 얻으려면 새 [user lookup endpoint v2](/x-api/users/lookup/quickstart/user-lookup)를 사용할 수 있습니다. USER\_NAME을 원하는 사용자 이름으로, XXXX를 위에서 얻은 bearer 토큰으로 바꾸세요.

```bash
  curl --request GET 'https://api.x.com/2/users/by/username/USER_NAME --header 'Authorization: Bearer XXXXXX'
```

아래와 같이 응답에서 사용자 ID를 볼 수 있습니다:

```json
{
   "data": {
       "id": "2244994945",
       "name": "Developers",
       "username": "XDevelopers"
   }
}
```


## user Tweet timeline 및 user mention timeline 엔드포인트에 연결하기

사용자의 user Tweet timeline을 가져오려면 터미널에서 다음 curl 명령을 실행하세요(USER\_ID를 원하는 사용자 ID로, XXXX를 위에서 얻은 bearer 토큰으로 반드시 바꾸세요).

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/tweets' --header 'Authorization: Bearer XXXXXX'
```


이러한 요청에 대한 JSON 응답에는 기본적으로 Post의 ID와 텍스트가 포함된 것을 확인할 수 있습니다(예시는 아래 참고).

```yaml
{
   "id": "1334200897081987072",
   "text": "👀 If you are new to the X API v2, check out this step-by-step guide to making your first request https://t.co/4rZqThpSbp"
}
```

응답에 추가 필드(사용자 정보, context annotation과 같은 추가 Tweet 필드 등)를 포함하려면 응답에서 해당 필드를 명시적으로 지정해야 합니다. [필드와 확장 사용 가이드](/x-api/fundamentals/data-dictionary/reference#how-to-use-fields-and-expansions)에서 방법을 알아보세요.

원하는 프로그래밍 언어를 사용해 이러한 Post를 가져올 수도 있습니다. user Tweet timeline 및 user mention timeline 엔드포인트에 대한 Python, Node (JavaScript), Java, Ruby 샘플 코드는 [Github 저장소](https://github.com/xdevplatform/Twitter-API-v2-sample-code)에서 확인하세요.


## 사용자의 Post 탐색하기

user Tweet timeline 및 user mention timeline 엔드포인트를 사용하여 Post를 가져오는 방법을 알게 되면 그들의 Post를 탐색할 수 있습니다. 예를 들어 사용자의 언급에 있는 일반적인 명명된 엔티티를 식별하려면 다음을 수행할 수 있습니다:

API 요청에서 Tweet 응답에 context\_annotations 객체가 반환되도록 지정합니다:

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/mentions?tweet.fields=context_annotations' --header 'Authorization: Bearer XXXXXX'
```

응답에서 언급에 명명된 엔티티가 있는지 확인할 수 있습니다. 예시는 다음과 같습니다:

```json
{
   "domain": {
       "id": "47",
       "name": "Brand",
       "description": "Brands and Companies"
   },
   "entity": {
       "id": "783214",
       "name": "X"
   }
}
```

언급에 어떤 인기 엔티티가 나타나는지 확인하고 싶다면, 언급의 각 Tweet을 파싱하여 인기 엔티티의 수를 집계할 수 있습니다.

미디어가 포함된 timeline의 모든 Post에 대한 미리보기 이미지 URL을 탐색하려면 다음을 수행할 수 있습니다:

API 요청에서 tweet.media 필드에 preview\_image\_url을, 그리고 attachments.media\_keys expansions을 지정합니다.
```bash
curl --request GET 'https://api.x.com/2/users/2244994945/mentions?max_results=100&media.fields=preview_image_url&expansions=attachments.media_keys' --header 'Authorization: Bearer XXXXXX'
```

응답에서 다음과 같이 includes 객체에 preview\_image\_url이 표시됩니다:

```json
{
   "includes": {
       "media": [
           {
               "media_key": "16_1334657439640121344",
               "preview_image_url": "https://pbs.twimg.com/tweet_video_thumb/EoWn3rqU8AAtFWL.jpg",
               "type": "animated_gif"
           }
       ]
   }
}
```

사용자의 Post를 탐색하는 방법을 이해했다면, 다른 API 및 서비스를 사용하여 해당 Post로 더 많은 작업을 수행할 수 있습니다. 아래는 user Tweet timeline과 user mention timeline 엔드포인트를 사용할 때 유용한 리소스입니다.
