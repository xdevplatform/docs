Python XDK(X Developer Kit)는 Python을 사용하여 X API v2와 상호 작용하기 위한 공식 클라이언트 라이브러리입니다. 개발자가 우리 API를 빠르게 시작하고 이를 사용하여 애플리케이션을 구축할 수 있게 해줍니다. 공식 [OpenAPI 사양](https://api.x.com/2/openapi.json)을 기반으로 생성됩니다. 저수준 HTTP 세부 사항을 추상화하면서도 필요할 때 세밀한 제어를 제공합니다.
## 주요 기능
- 🔐 **OAuth 지원**: Bearer Token(앱 전용) 인증, PKCE를 사용한 OAuth 2.0(사용자 컨텍스트) 및 OAuth 1.0에 대한 완전한 지원.
- 🔄 **페이지네이션**: 대량의 결과를 자동으로 페이지로 나눕니다. XDK는 `next_token`을 사용하여 여러 API 호출을 하지 않아도 페이지네이션을 처리합니다.
- 📡 **스트리밍**: 지속적인 http 연결이 필요한 filtered stream과 같은 엔드포인트에 대해 실시간 데이터 스트리밍을 지원합니다.
- 🎯 **포괄적인 커버리지**: search, timelines, filtered-stream 등을 포함한 모든 X API v2 엔드포인트를 지원합니다.
**버전 호환성**: Python 3.8 이상. CPython과 PyPy에서 테스트되었습니다.
