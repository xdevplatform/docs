XDK Python SDK는 GitHub 저장소에서 직접 사용할 수 있으며 `pip`을 통해 설치할 수 있습니다.
## 사전 준비 사항
- Python 3.8 이상.
- 가상 환경을 위한 `pip` 및 `venv` (권장).
## 빠른 설치
GitHub 하위 디렉토리에서 XDK를 설치합니다:
```bash
pip install xdk
```
`main` 브랜치에서 최신 생성 버전을 가져옵니다.
## 개발 설치
개발 또는 기여를 위해:
1. 저장소를 복제합니다:
   ```bash
   git clone https://github.com/xdevplatform/xdk.git
   cd xdk/python
   ```
2. 편집 가능한 모드로 종속성을 설치합니다:
   ```bash
   pip install -e .
   ```
   이는 SDK와 그 런타임 종속성을 설치합니다.
3. (선택 사항) 테스트/린팅용 개발 종속성을 설치합니다:
   ```bash
   pip install -e .[dev]
   ```
## 검증
설치를 테스트합니다:
```python
import xdk
print(xdk.__version__)  # Should print the XDK version
```
**참고:** XDK는 OpenAPI 사양을 사용하여 생성되므로, 항상 [X API changelog](https://docs.x.com/changelog)와 저장소의 XDK 릴리스 노트에서 변경 사항을 확인하세요.
Python XDK를 사용하는 자세한 코드 예제는 [코드 샘플 GitHub 저장소](https://github.com/xdevplatform/samples/tree/main/python)를 확인하세요.
