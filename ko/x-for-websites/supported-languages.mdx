## 언어 지원

번역된 위젯 텍스트는 [x.com이 지원하는 언어](https://about.x.com/en) 중 34개에서 사용할 수 있습니다.

X for Websites 위젯 및 버튼이 지원하는 언어:

```html
<a
  class="twitter-share-button"
  href="https://x.com/share"
  data-lang="es">
X
</a>
```

X for Websites는 위젯 마크업에 언어가 제공되지 않은 경우 DOM 트리에서의 위치를 기반으로 가장 적절한 언어를 추출합니다. 지원되지 않는 스크립트나 지역을 정의하는 페이지는 사용 가능한 가장 유사한 언어로 매핑됩니다. 예를 들어 포르투갈어가 사용 가능하지만 브라질 지역 현지화가 없는 경우 `pt-BR`은 `pt`를 사용합니다.

페이지의 언어 코드가 사용 가능한 번역과 일치하지 않는 경우 기본값은 미국 영어입니다.

<Note>
언어 설정은 액션 텍스트 및 타임스탬프 표시와 같은 X 요소의 언어에만 영향을 미치며, Tweet 텍스트는 항상 원래 작성된 언어로 표시됩니다.
</Note>

## 브라우저 지원

우리는 [ECMAScript Level 5](https://en.wikipedia.org/wiki/ECMAScript#5th_Edition) 이상을 지원하는 모든 브라우저와 webview를 지원합니다. 여기에는 모든 최신 브라우저와 webview가 포함됩니다. 위젯은 모든 최신 데스크톱 및 모바일 브라우저와 모바일 webview에서 빌드 및 테스트됩니다.

렌더링되지 않는 유일한 예외는 ECMAScript level 5를 지원하지 않는 브라우저와 Internet Explorer 11 및 이하 버전입니다.
