### 추가 앱 수준 권한 요청하기

애플리케이션이 아래 앱 수준 권한 중 하나로 제한되어 있고 추가 엔드포인트에 액세스하려면 X 담당자에게 문의하여 **Standard Access**를 신청하세요.

2023년 7월 이전에 Ads API 액세스를 요청한 개발자는 다음 앱 수준 권한 중 하나를 요청했을 수 있으며, 이는 현재 Standard Access 수준에 포함됩니다:

- **Analytics** (읽기 전용): 사용자는 [읽기 전용](https://developer.x.com/en/docs/apps/app-permissions) 액세스로 [Analytics](https://developer.x.com/en/docs/twitter-ads-api/analytics/overview) 엔드포인트에 액세스할 수 있습니다. Campaign Management, Creative 또는 Custom Audiences 엔드포인트에는 액세스할 수 없지만, Analytics 엔드포인트의 요청 파라미터를 통해 크리에이티브 엔티티를 전달함으로써 지표를 가져올 수 있습니다. media_id 또는 media_name 세분화를 가져오려면 사용자 애플리케이션에 Ads API 쓰기 액세스가 필요합니다.

- **Campaign Management & Creative** (읽기 및 쓰기): 사용자는 [읽기 및 쓰기](https://developer.x.com/en/docs/apps/app-permissions) 액세스로 [Campaign Management](https://developer.x.com/en/docs/twitter-ads-api/campaign-management/overview) 및 [Creative](https://developer.x.com/en/docs/twitter-ads-api/creatives/overview) 엔드포인트에 액세스할 수 있습니다. 사용자는 Analytics 엔드포인트에도 액세스할 수 있습니다.

- **Custom Audiences** (읽기 및 쓰기): 사용자는 [읽기 및 쓰기](https://developer.x.com/en/docs/apps/app-permissions) 액세스로 [Custom Audiences](https://developer.x.com/en/docs/twitter-ads-api/audiences/overview) 엔드포인트에 액세스할 수 있습니다. 사용자는 Campaign Management, Creative, Analytics 엔드포인트에도 액세스할 수 있습니다.

- **Conversion** (읽기 및 쓰기): 사용자는 [읽기 및 쓰기](https://developer.x.com/en/docs/apps/app-permissions) 액세스로 [Mobile](https://developer.x.com/en/docs/twitter-ads-api/measurement/mobile-conversions/overview) 및 [Web Conversion](https://developer.x.com/en/docs/twitter-ads-api/measurement/web-conversions/overview) 엔드포인트에 액세스할 수 있습니다. 사용자는 다른 Ads API 엔드포인트에 액세스할 수도 있고 그렇지 않을 수도 있습니다.

### 사용자 OAuth 토큰 제한 증가 요청

2023년 7월 이전에 Ads API 액세스를 요청한 개발자는 애플리케이션에 사용자 OAuth 토큰 5개 제한이 있을 수 있습니다. 개발자 App의 토큰 제한을 늘려야 한다면 X 담당자에게 문의하세요.

<Note>**참고:** 어떤 Ads API 엔드포인트에 대해서도 [rate limit](https://developer.x.com/en/docs/twitter-ads-api/rate-limiting)을 증가시키지 않습니다. rate limit 이내로 유지하는 방법에 대해서는 [모범 사례](https://developer.x.com/en/docs/twitter-ads-api/rate-limiting)를 확인하세요.</Note>
