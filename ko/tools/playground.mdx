[API Playground](https://github.com/xdevplatform/playground)는 X API v2 전체를 시뮬레이션하는 로컬 mock 서버입니다. 실제 API 크레딧을 소모하지 않고도 엔드포인트를 테스트하고 프로토타입을 구축하며 API를 탐색할 수 있습니다.

</Card>

## 설치

Go 1.21+ 가 필요합니다. 소스에서 설치하거나 [릴리스](https://github.com/xdevplatform/playground/releases)에서 사전 빌드된 바이너리를 다운로드하세요.

<Tabs>
  <Tab title="Go install">
```bash
go install github.com/xdevplatform/playground/cmd/playground@latest
playground start
```
  </Tab>
  <Tab title="소스에서 빌드">
```bash
git clone https://github.com/xdevplatform/playground.git
cd playground
go build -o playground ./cmd/playground
./playground start
```
  </Tab>
</Tabs>

서버는 기본적으로 `http://localhost:8080`에서 시작됩니다.

## 빠른 시작

실제 API에 요청하는 것과 동일하게 요청을 보내세요. bearer 토큰으로 `test_token`을 사용하세요:

```bash title="me" lines wrap icon="terminal"
# Look up a user
curl -H "Authorization: Bearer test_token" \
  http://localhost:8080/2/users/me

# Create a post
curl -X POST -H "Authorization: Bearer test_token" \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello from the playground!"}' \
  http://localhost:8080/2/tweets

# Search posts
curl -H "Authorization: Bearer test_token" \
  "http://localhost:8080/2/tweets/search/recent?query=hello"
```

인터랙티브 UI를 사용하려면 브라우저에서 `http://localhost:8080/playground`를 여세요.

## 포함된 내용

| 기능 | 설명 |
|:--------|:------------|
| **요청 검증** | OpenAPI 스펙에 따라 요청을 검증 |
| **실제와 유사한 오류** | 적절한 오류 코드와 메시지를 반환 |
| **스트리밍 지원** | 시뮬레이션된 스트리밍 엔드포인트 |
| **Rate limit** | 구성 가능한 rate limit 시뮬레이션 |
| **CORS 지원** | 브라우저 기반 애플리케이션에서 작동 |
| **사용량 추적** | 시뮬레이션된 결제 및 크레딧 추적 엔드포인트 |
| **상태 지속성** | `~/.playground/`에서의 선택적 파일 지속성 |
