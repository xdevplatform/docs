List lookup 엔드포인트를 사용하면 List에 대한 정보를 조회할 수 있습니다. ID로 특정 List를 조회하거나 사용자가 소유한 모든 List를 가져올 수 있습니다.

## 엔드포인트

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/lists/:id`](/x-api/lists/get-list-by-id) | ID로 List 가져오기 |
| GET | [`/2/users/:id/owned_lists`](/x-api/users/get-owned-lists) | 사용자가 소유한 List 가져오기 |

---

## 응답 필드

기본적으로 응답에는 `id`와 `name`이 포함됩니다. 추가 필드를 요청하세요:

| Field | Description |
|:------|:------------|
| `description` | List 설명 |
| `owner_id` | 소유자의 사용자 ID |
| `private` | List가 비공개인지 여부 |
| `follower_count` | 팔로워 수 |
| `member_count` | 멤버 수 |
| `created_at` | List 생성 날짜 |

### 요청 예시

```bash
curl "https://api.x.com/2/lists/1234567890?\
list.fields=description,owner_id,member_count,follower_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
