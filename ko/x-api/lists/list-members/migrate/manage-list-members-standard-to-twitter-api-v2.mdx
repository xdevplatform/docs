### Manage List members: standard v1.1과 X API v2 비교

standard v1.1의 [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create) 및 [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy) 엔드포인트를 사용해 왔다면, 이 가이드는 standard v1.1과 X API v2의 manage List members 엔드포인트 사이의 유사점과 차이점을 이해하는 데 도움이 될 것입니다.

* **유사점**
    * 인증
* **차이점**
    * 엔드포인트 URL
    * App 및 Project 요구사항
    * HTTP 메서드
    * Rate limit
    * 요청 매개변수

#### 유사점

**인증**

두 엔드포인트 버전 모두 [OAuth 1.0a User Context](https://developer.x.com/content/developer-twitter/resources/fundamentals/authentication)를 지원합니다. 따라서 이전에 standard v1.1 manage List member 엔드포인트 중 하나를 사용했다면 X API v2 버전으로 마이그레이션할 때도 동일한 인증 방식을 계속 사용할 수 있습니다.

#### 차이점

**엔드포인트 URL**

* Standard v1.1 엔드포인트:
    * POST https://api.x.com/1.1/lists/members/create.json
        (지정된 List에 멤버 추가)
    * POST https://api.x.com/1.1/lists/members/destroy.json
        (지정된 List에서 멤버 제거)
* X API v2 엔드포인트:
    * POST https://api.x.com/2/lists/:id/members
        (지정된 List에 멤버 추가)

    * DELETE https://api.x.com/2/lists/:id/members/:user_id
        (지정된 List에서 멤버 제거)

**Rate limit**

| **Standard v1.1** | **X API v2** |
| :--- | :--- |
| /1.1/lists/members/create.json<br/><br/>없음 | /2/lists/:id/members<br/><br/>OAuth 1.0a User Context로 15분 창당 300회 요청<br/><br/>OAuth 2.0 Authorization Code with PKCE로 15분 창당 300회 요청 |
| /1.1/lists/members/destroy.json<br/><br/>없음 | /2/lists/:id/members/:user_id<br/><br/>OAuth 1.0a User Context로 15분 창당 300회 요청<br/><br/>OAuth 2.0 Authorization Code with PKCE로 15분 창당 300회 요청 |

**App 및 Project 요구사항**

X API v2 엔드포인트는 요청을 인증할 때 [Project](/resources/fundamentals/developer-apps)와 연결된 [developer App](/resources/fundamentals/developer-apps)의 자격 증명을 사용해야 합니다. 모든 X API v1.1 엔드포인트는 App 또는 project와 관련된 App의 자격 증명을 사용할 수 있습니다.

**요청 매개변수**

다음 standard v1.1 요청 매개변수는 X API v2에서 대응되는 매개변수를 가집니다:

| **Standard v1.1** | **X API v2** |
| :--- | :--- |
| list_id | id  |
| slug | 대응되는 매개변수 없음 |
| screen_name | 대응되는 매개변수 없음 |
| owner\_screen\_name | 대응되는 매개변수 없음 |
| owner_id | 대응되는 매개변수 없음 |
