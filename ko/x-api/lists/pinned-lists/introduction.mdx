Pinned Lists 엔드포인트를 사용하면 인증된 사용자에 대한 List를 조회, 고정, 고정 해제할 수 있습니다. 고정된 List는 사용자의 X 인터페이스에 눈에 띄게 표시됩니다.

## 엔드포인트

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/pinned_lists`](/x-api/users/get-pinned-lists) | 고정된 List 가져오기 |
| POST | [`/2/users/:id/pinned_lists`](/x-api/users/pin-list) | List 고정 |
| DELETE | [`/2/users/:id/pinned_lists/:list_id`](/x-api/users/unpin-list) | List 고정 해제 |

---

## 예시: 고정된 List 가져오기

```bash
curl "https://api.x.com/2/users/123456789/pinned_lists?\
list.fields=name,description,member_count" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

## 예시: List 고정하기

```bash
curl -X POST "https://api.x.com/2/users/123456789/pinned_lists" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"list_id": "9876543210"}'
```
