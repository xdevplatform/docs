이 가이드는 List를 고정하고 고정 해제하는 방법을 안내합니다.

<Note>
**사전 요구사항**

시작하기 전에 다음이 필요합니다:
- 승인된 App이 포함된 [developer account](https://developer.x.com/en/portal/petition/essential/basic-info)
- User Access Token (OAuth 1.0a 또는 OAuth 2.0 PKCE)
</Note>

## List 고정

<Steps>
  <Step title="사용자 ID와 List ID 가져오기">
    인증된 사용자의 ID와 고정하려는 List의 ID가 필요합니다. List를 볼 때 URL에서 List ID를 찾을 수 있습니다.
  </Step>

  <Step title="List 고정">

<CodeGroup dropdown>

```bash cURL
curl -X POST "https://api.x.com/2/users/2244994945/pinned_lists" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"list_id": "1454155907651158017"}'
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# List 고정
response = client.lists.pin(
    user_id="2244994945",
    list_id="1454155907651158017"
)

print(f"Pinned: {response.data.pinned}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// List 고정
const response = await client.lists.pin("2244994945", {
  listId: "1454155907651158017",
});

console.log(`Pinned: ${response.data?.pinned}`);
```

</CodeGroup>

  </Step>

  <Step title="응답 확인">
    ```json
    {
      "data": {
        "pinned": true
      }
    }
    ```
  </Step>
</Steps>

## List 고정 해제

<CodeGroup dropdown>

```bash cURL
curl -X DELETE "https://api.x.com/2/users/2244994945/pinned_lists/1454155907651158017" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# List 고정 해제
response = client.lists.unpin(
    user_id="2244994945",
    list_id="1454155907651158017"
)

print(f"Pinned: {response.data.pinned}")
```

