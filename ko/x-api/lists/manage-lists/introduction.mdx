## 엔드포인트

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| POST | [`/2/lists`](/x-api/lists/create-list) | 새 List 생성 |
| PUT | [`/2/lists/:id`](/x-api/lists/update-list) | List 업데이트 |
| DELETE | [`/2/lists/:id`](/x-api/lists/delete-list) | List 삭제 |

---

## 예시: List 생성

```bash
curl -X POST "https://api.x.com/2/lists" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Tech News",
    "description": "My favorite tech journalists",
    "private": false
  }'
```

## 응답 예시

```json
{
  "data": {
    "id": "1234567890",
    "name": "Tech News"
  }
}
```
