## 엔드포인트

| Method | Endpoint | 설명 |
|:-------|:---------|:------------|
| GET | [`/2/spaces/search`](/x-api/spaces/search-spaces) | Spaces 검색 |

---

## 매개변수

| 매개변수 | 설명 |
|:----------|:------------|
| `query` | 검색 쿼리 (필수) |
| `state` | `live` 또는 `scheduled`로 필터링 |
| `space.fields` | 추가 Space 필드 |
| `expansions` | 포함할 관련 객체 |

---

## 예제 요청

```bash
curl "https://api.x.com/2/spaces/search?\
query=AI&\
state=live&\
space.fields=title,host_ids,participant_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
