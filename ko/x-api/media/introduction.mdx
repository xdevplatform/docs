media 객체는 단일 사진, 비디오 또는 애니메이션 GIF를 나타냅니다. media 객체는 X API 내의 많은 endpoint에서 사용되며 Post, Direct Message, 사용자 프로필, 광고 크리에이티브 등에 포함될 수 있습니다. 각 media 객체는 서로 다른 해상도나 형식의 여러 표시 또는 재생 변형을 가질 수 있습니다.

## 미디어 유형 및 크기 제한

API를 통한 업로드 크기 제한

- **이미지**: `5 MB`
- **GIF**: `15 MB`
- **비디오**: `512 MB` (`media_category=amplify_video` 사용 시)

## 생성

Post, Direct Message, 사용자 프로필 사진, 호스팅된 Ads 카드 등의 객체는 하나 이상의 미디어 객체를 포함할 수 있습니다. 이러한 최상위 객체들을 통틀어 엔티티라고 합니다. 관련 엔티티 생성 API(예: [`POST /2/tweets`](/x-api/posts/creation-of-a-post))에는 고유한 `media_id`를 사용하여 하나 이상의 미디어 객체를 전달할 수 있습니다.

미디어 객체를 포함하는 엔티티는 다음 단계에 따라 생성할 수 있습니다:

1. 권장되는 [청크형](/x-api/media/quickstart/media-upload-chunked) 업로드(이미지/GIF/비디오) 또는 이전 [심플](/x-api/media/upload-media) 업로드(이미지만)로 미디어 파일을 업로드합니다.
1. 1단계에서 `media_id`를 수신합니다. 엔티티가 여러 `media_id` 파라미터 전달을 허용하는 경우 이 단계를 다른 미디어로 여러 번 반복할 수 있습니다.
1. `media_id`와 기타 필수 파라미터를 포함해 적절한 endpoint를 호출하여 엔티티를 생성합니다. 예를 들어 [`POST /2/tweets`](/x-api/posts/creation-of-a-post) endpoint를 사용해 Post에 `media_id`를 첨부합니다.
