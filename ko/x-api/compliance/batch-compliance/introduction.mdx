Batch Compliance 엔드포인트를 사용하면 Post ID 또는 user ID 데이터세트를 업로드하고 현재 규정 준수 상태를 받을 수 있습니다. 이를 사용하여 삭제된 Post, 정지된 계정 및 기타 규정 준수 이벤트를 식별할 수 있습니다.

## 작동 방식

1. **작업 생성** — 유형(Posts 또는 users)과 업로드 URL 지정
2. **ID 업로드** — 제공된 URL로 데이터세트 업로드
3. **처리 대기** — 작업이 비동기적으로 처리됨
4. **결과 다운로드** — 각 ID의 규정 준수 상태 확인

---

## 엔드포인트

| Method | Endpoint | 설명 |
|:-------|:---------|:------------|
| POST | [`/2/compliance/jobs`](/x-api/compliance/create-compliance-job) | 새 compliance 작업 생성 |
| GET | [`/2/compliance/jobs/:id`](/x-api/compliance/get-compliance-job-by-id) | 작업 상태 가져오기 |
| GET | [`/2/compliance/jobs`](/x-api/compliance/get-compliance-jobs) | 모든 작업 나열 |

---

## 작업 유형

| 유형 | 설명 |
|:-----|:------------|
| `tweets` | Post 규정 준수 상태 확인 |
| `users` | 사용자 규정 준수 상태 확인 |

---

## 규정 준수 이벤트

### Post 이벤트

| 이벤트 | 설명 |
|:------|:------------|
| `deleted` | 사용자가 Post 삭제 |
| `bounced` | Post가 규정 준수 검사에 실패 |
| `protected` | 계정이 보호됨 |
| `suspended` | 계정이 정지됨 |
| `scrub_geo` | 지리 데이터 제거됨 |

### 사용자 이벤트

| 이벤트 | 설명 |
|:------|:------------|
| `deleted` | 계정이 삭제됨 |
| `suspended` | 계정이 정지됨 |
| `protected` | 계정이 보호됨 |
| `deactivated` | 계정이 비활성화됨 |

---

## 예제: 작업 생성

```bash
curl -X POST "https://api.x.com/2/compliance/jobs" \
  -H "Authorization: Bearer $BEARER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "tweets",
    "name": "my-compliance-job"
  }'
```
