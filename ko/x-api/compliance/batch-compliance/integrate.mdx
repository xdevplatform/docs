## 재개 가능한 업로드 다루기

Batch compliance 엔드포인트를 사용하면 개발자는 대량의 X 데이터를 배치 업로드하여, 데이터 세트가 사용자 의도 및 X의 현재 콘텐츠 상태를 반영하기 위해 어떤 조치가 필요한지 파악할 수 있습니다. 시스템과 연결이 안정적이고 신뢰할 수 있을 때, 대량의 데이터를 원격 서버에 업로드하는 것은 비교적 간단한 작업입니다. 그러나 항상 그렇지는 않을 수 있습니다. 일부 환경에서는 연결 타임아웃이 있어 일정 시간 후 앱과 업로드 서버 간의 연결이 끊길 수 있으며, 예를 들어 노트북에서 wi-fi 연결을 통해 대용량 파일을 업로드하려 할 때 연결 문제가 발생할 수 있습니다. 이러한 상황에서는 하나의 연속 연결로 업로드하는 것보다, 파일을 여러 개의 작은 부분으로 나누어 업로드하는 것이 바람직합니다.

X의 batch compliance 엔드포인트는 대용량 파일을 처리하기 위해 Google Cloud Storage에 의존합니다. 이 유형의 스토리지는 다양한 애플리케이션에 최적화되어 있으며, Cloud Storage는 대용량 파일을 관리하기 위해 재개 가능한 업로드(resumable uploads)라는 기법을 지원합니다.

업로드가 어느 시점에서 실패하더라도 Google Cloud Storage는 중단된 지점에서 작업을 재개할 수 있습니다.
