## X API v2란 무엇인가요?

X API v2는 이제 주요 X API이며, 제품 투자와 혁신이 집중되는 곳입니다. 우리는 개발자들과 협력하여 다양한 개발자 커뮤니티를 더 잘 지원하기 위해 차세대 X API를 구축했습니다. 개발자 피드백을 바탕으로, 더 광범위한 요구사항에 부응하기 위해 API를 재구축하고, 새로운 기능과 엔드포인트를 도입했으며, 개발자 경험을 개선했습니다.

X API v2는 이제 주요 X API이며, 제품 투자와 혁신이 집중되는 곳입니다. 지난 몇 년간 우리는 개발자와 협력하여 더 폭넓은 요구를 지원하고 새로운 기능과 엔드포인트를 도입하며 개발자 경험을 개선하기 위해 API를 재구축했습니다. 우리는 개방적인 개발자 플랫폼 구축을 지속하기 위해 헌신하며, 여러분이 X API v2로 무엇을 만들어낼지 기대합니다.

## 왜 마이그레이션해야 하나요?

X API v2는 현대적이고 지속 가능한 기반 위에 구축되었으며, standard v1.1 및 enterprise 제품을 대체하는 개선된 엔드포인트뿐만 아니라, 완전히 새로운 기능도 포함합니다. 결국에는 레거시 API(v1.1 및 enterprise)를 사용 중단할 예정이므로, 레거시 API 고객은 v2로 마이그레이션하기 시작할 것을 강력히 권장합니다. X API를 사용해 공개적인 대화를 청취하고 분석하며, X에서 사람들과 소통하고, 혁신하세요.

이 섹션에서는 엔드포인트와 기능에 대해 논의합니다.

X API v2의 대부분의 엔드포인트는 대체용이지만, 몇 가지 새로운 엔드포인트를 도입했습니다. 다음은 v2에 출시된 새로운 엔드포인트의 몇 가지 예시입니다:

- 사람들이 X Spaces를 더 잘 활용하고, 개발자가 오디오 대화의 미래를 형성하는 데 도움이 되도록 [Spaces 엔드포인트](/x-api/spaces/introduction).
- 대규모로 학대적이거나 산만하거나 오해의 소지가 있는 답글의 영향을 제한하는 도구를 구축할 수 있는 [Hide replies](/x-api/posts/hide-replies/introduction).
- [List를 pin 및 unpin](/x-api/lists/pinned-lists/introduction)하거나 다른 사람의 pinned List를 조회할 수 있는 새로운 Lists 엔드포인트.
- 저장된 사용자 및 Tweet 데이터가 규정을 준수하는지 확인할 수 있는 새로운 [batch compliance 엔드포인트](/x-api/compliance/batch-compliance/introduction).
