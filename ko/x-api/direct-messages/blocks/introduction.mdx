Manage DM blocks endpoint를 사용하면 인증된 사용자를 대신해 특정 계정을 차단하거나 차단 해제할 수 있습니다. 이 endpoint에는 두 가지 POST 메서드를 사용할 수 있습니다:

* **/2/users/:id/dm/block**: 계정을 차단합니다
* **/2/users/:id/dm/unblock**: 계정 차단을 해제합니다


### 시작하기
### 인증

사용자를 대신해 요청을 수행하므로, 이 endpoint는 [OAuth 1.0a User Context](/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow) 또는 [OAuth 2.0 Authorization Code with PKCE](/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2)로 인증해야 하며, 요청을 대신 수행할 사용자와 연결된 사용자 Access Token을 사용해야 합니다. 이 사용자 Access Token은 [3-legged OAuth flow](https://developer.x.com/resources/fundamentals/authentication/obtaining-user-access-tokens) (OAuth 1.0a) 또는 [Authorization Code with PKCE grant flow](/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) (OAuth 2.0)를 사용하여 생성할 수 있습니다.

### 요청하기

Block

사용자가 앱으로 인증한 후에는 아래와 같이 사용자를 대신해 Block endpoint를 호출할 수 있습니다:

      ```
      curl --request POST 'https://api.x.com/2/users/:id/dm/block' --header 'Authorization: ••••••'
      ```




요청이 성공하면 아래와 같은 JSON 응답을 확인할 수 있습니다:

```json
{
   "data": {
       "blocked": true
   }
}
```




**Unblock**

사용자가 앱으로 인증한 후에는 아래와 같이 사용자를 대신해 Unblock endpoint를 호출할 수 있습니다:

      ```
      curl --request POST 'https://api.x.com/2/users/:id/dm/unblock' --header 'Authorization: ••••••'
      ```




요청이 성공하면 아래와 같은 JSON 응답을 확인할 수 있습니다:

```json
{
   "data": {
       "blocked": false
   }
}
```
