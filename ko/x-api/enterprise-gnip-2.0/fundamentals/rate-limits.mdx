## 개요


매일 수천 명의 개발자가 X API에 요청을 보냅니다. 이러한 요청의 방대한 양을 관리하기 위해 만들 수 있는 요청 수에 제한이 부과됩니다. 이 제한은 개발자 커뮤니티가 의존하는 안정적이고 확장 가능한 API를 제공하는 데 도움이 됩니다.

허용되는 최대 요청 수는 시간 간격, 즉 지정된 기간이나 시간 창에 기반합니다. Endpoint의 rate limit이 15분당 900 요청이라면 임의의 15분 간격에 대해 최대 900 요청이 허용됩니다.
