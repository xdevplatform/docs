Follows 엔드포인트를 사용하면 사용자를 팔로우 및 언팔로우하고, 임의의 사용자에 대한 팔로워 및 팔로잉 목록을 조회할 수 있습니다.

## 엔드포인트

### Follows lookup

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/followers`](/x-api/users/get-followers) | 사용자의 팔로워 가져오기 |
| GET | [`/2/users/:id/following`](/x-api/users/get-following) | 사용자가 팔로우하는 계정 가져오기 |

### Manage follows

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| POST | [`/2/users/:id/following`](/x-api/users/follow-user) | 사용자 팔로우 |
| DELETE | [`/2/users/:source_user_id/following/:target_user_id`](/x-api/users/unfollow-user) | 사용자 언팔로우 |

---

## 예시: 팔로워 가져오기

```bash
curl "https://api.x.com/2/users/2244994945/followers?\
user.fields=username,verified,public_metrics" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

## 예시: 사용자 팔로우하기

```bash
curl -X POST "https://api.x.com/2/users/123456789/following" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "2244994945"}'
```
