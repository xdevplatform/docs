## 엔드포인트

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/muting`](/x-api/users/get-muting) | 뮤트된 사용자 가져오기 |
| POST | [`/2/users/:id/muting`](/x-api/users/mute-user) | 사용자 뮤트 |
| DELETE | [`/2/users/:source_user_id/muting/:target_user_id`](/x-api/users/unmute-user) | 사용자 뮤트 해제 |

---

## 예시: 뮤트된 사용자 가져오기

```bash
curl "https://api.x.com/2/users/123456789/muting?\
user.fields=username,description" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

## 예시: 사용자 뮤트하기

```bash
curl -X POST "https://api.x.com/2/users/123456789/muting" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "9876543210"}'
```
