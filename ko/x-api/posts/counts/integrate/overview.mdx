이 페이지는 Post counts 엔드포인트 통합을 위한 도구와 핵심 개념을 다룹니다.

## 유용한 도구

몇 가지 핵심 개념을 살펴보기 전에, 다음 도구나 코드 샘플 중 하나를 사용해 이 엔드포인트의 기능을 테스트하는 것을 권장합니다.

### 코드 샘플

원하는 프로그래밍 언어의 코드로 이 엔드포인트 사용을 시작하고 싶으신가요? 시작점으로 활용할 수 있는 다양한 코드 샘플을 [GitHub 페이지](https://github.com/xdevplatform/Twitter-API-v2-sample-code)에서 제공하며, [Python 클라이언트](https://github.com/xdevplatform/search-tweets-python)도 포함되어 있습니다.

### 라이브러리

시작에 도움이 되도록 여러 [커뮤니티 서드파티 라이브러리](/tools-and-libraries)를 활용해 보세요. 적절한 버전 태그를 확인하여 v2 엔드포인트와 호환되는 라이브러리를 찾을 수 있습니다.

### Postman

Postman은 이 엔드포인트를 테스트할 때 사용할 수 있는 훌륭한 도구입니다. 각 Postman 요청에는 해당 엔드포인트의 모든 파라미터가 포함되어 있어, 사용 가능한 옵션을 빠르게 파악할 수 있습니다. Postman 컬렉션에 대해 자세히 알아보려면 [Using Postman](/tutorials/postman-getting-started) 페이지를 참고하세요.

## 핵심 개념

### 인증

모든 X API v2 엔드포인트는 keys and tokens라고도 부르는 자격 증명 세트로 요청을 [인증](/resources/fundamentals/authentication)해야 합니다. 이 엔드포인트는 [OAuth 2.0 Bearer Token](/resources/fundamentals/authentication#oauth-2-0) 사용을 요구하며, 요청을 성공적으로 보내려면 [Bearer Token](/resources/fundamentals/authentication#bearer-token-also-known-as-app-only)을 전달해야 합니다. Bearer Token은 developer App에서 직접 생성하거나, [POST oauth2/token](/resources/fundamentals/authentication#post-oauth2-token) 엔드포인트를 사용해 생성할 수 있습니다.

### Developer Console, Projects, developer Apps

X API v2 엔드포인트를 사용하려면 [developer account](/resources/fundamentals/developer-portal)를 보유하고, 해당 계정 내에서 [Project](/resources/fundamentals/developer-apps)를 설정하고, 그 Project 내에서 [developer App](/resources/fundamentals/developer-apps)을 생성해야 합니다. 해당 developer App의 keys and tokens는 recent Post counts 엔드포인트에서 동작합니다. full-archive Post counts 엔드포인트를 사용하거나, advanced operators와 확장된 쿼리 길이를 사용하려면 enterprise 액세스 승인을 받아야 합니다.

자세한 내용은 enterprise 액세스 관련 섹션을 참조하세요.

### Rate limit

매일 수천 명의 개발자가 X API에 요청을 보냅니다. 이러한 대량의 요청을 관리하기 위해 각 엔드포인트에 [rate limit](/x-api/fundamentals/rate-limits)이 설정되어 있으며, 이는 개발자가 App 또는 인증된 사용자를 대신하여 만들 수 있는 요청 수를 제한합니다.

이 엔드포인트는 App 수준에서 rate limit이 설정되어 있으므로, 개발자는 지정된 App(사용 중인 자격 증명 기준)에서 일정 기간 동안 정해진 횟수의 요청만 이 엔드포인트에 보낼 수 있습니다.

### 쿼리 작성

이 엔드포인트의 핵심 기능은 게시물을 필터링하여 카운트로 전달할 때 단일 쿼리를 사용한다는 점입니다. 이 쿼리들은 메시지 키워드, 해시태그, URL 등 게시물 및 사용자 속성에 매칭되는 연산자로 구성됩니다. 연산자를 boolean 로직과 괄호로 조합하여 쿼리의 매칭 동작을 세밀하게 다듬을 수 있습니다.

자세한 내용은 [쿼리 작성 방법](/x-api/posts/counts/integrate/build-a-query) 가이드를 참고하세요.

### 페이지네이션

recent Post counts에는 next_token이 반환되지 않으므로, granularity에 관계없이 지난 7일간의 게시물 볼륨을 한 번의 API 호출로 얻을 수 있습니다.

full-archive Post counts에서는 지난 30일간의 데이터를 얻을 수 있습니다. 30일보다 이전의 데이터가 필요할 경우 next_token이 반환되며, 이를 사용해 페이지네이션으로 추가 데이터를 가져올 수 있습니다.
