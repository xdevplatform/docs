## X API의 filtered stream 엔드포인트 비교

v2 filtered stream 엔드포인트 그룹은 [standard v1.1 statuses/filter](https://developer.x.com/en/docs/x-api/v1/tweets/filter-realtime/api-reference/post-statuses-filter) 및 [PowerTrack API](/x-api/enterprise-gnip-2.0/powertrack-api)를 대체하고 있습니다. 이전 버전의 filtered stream 엔드포인트를 사용하는 코드, 앱 또는 도구를 새로운 X API v2 엔드포인트로 마이그레이션하는 것을 고려 중이라면, 이 비교표가 시작에 도움이 될 것입니다.

보다 자세한 마이그레이션 가이드는 다음을 참고하세요:

[Standard v1.1과 X API v2 비교 마이그레이션](x-api/posts/filtered-stream#standard-v1-1-compared-to-x-api-v2)

[PowerTrack API에서 X API v2로 마이그레이션](/x-api/enterprise-gnip-2.0/powertrack-api#powertrack-operators)

다음 표는 X가 제공하는 filtered streaming 엔드포인트를 비교합니다:
