### Likes lookup: Standard v1.1과 X API v2 비교

standard v1.1 [GET favorites/list](https://developer.x.com/en/docs/x-api/v1/tweets/post-and-engage/api-reference/get-favorites-list) 엔드포인트를 사용해 왔다면, 이 가이드의 목표는 standard v1.1과 X API v2 Likes lookup 엔드포인트의 공통점과 차이점을 이해하도록 돕는 것입니다.

v2에서는 게시물에 좋아요를 누른 사용자에 대한 정보를 가져올 수 있는 새로운 liked users 엔드포인트도 도입했습니다.

* **공통점**
    * 인증
    * Rate limit
* **차이점**
    * 엔드포인트 URL

    * 요청 제한
    * App 및 Project 요구사항

    * 요청 파라미터
    * 새로운 JSON 형식

#### 공통점

**인증**

standard v1.1과 X API v2 Likes lookup 엔드포인트 모두 [OAuth 1.0a User Context](/resources/fundamentals/authentication#oauth-1-0a-2) 또는 [OAuth 2.0 Bearer Token](/resources/fundamentals/authentication#bearer-token-also-known-as-app-only)을 사용합니다. 따라서 이전에 [GET favorites/list 엔드포인트](https://developer.x.com/en/docs/x-api/v1/tweets/post-and-engage/api-reference/get-favorites-list) standard v1.1 엔드포인트를 사용하고 있었다면, X API v2 버전으로 마이그레이션하더라도 원한다면 동일한 인증 방식을 계속 사용할 수 있습니다.

선택한 인증 라이브러리/패키지에 따라 다르지만, Bearer Token 인증이 시작하기 가장 쉬운 방법이며 간단한 요청 헤더로 설정할 수 있습니다. Bearer Token 생성 방법은 [이 OAuth 2.0 Bearer Token 가이드](/resources/fundamentals/authentication#bearer-token-also-known-as-app-only)를 참고하세요.
 

**Rate limit**

standard v1.1 GET favorites/list 엔드포인트에는 사용자당 15분당 75 요청의 rate limit이 있습니다. v2의 대응 liked Posts 엔드포인트도 동일한
