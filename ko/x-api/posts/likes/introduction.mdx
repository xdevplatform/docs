## 엔드포인트

### Likes 조회

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/tweets/:id/liking_users`](/x-api/posts/get-liking-users) | 게시물에 좋아요를 누른 사용자 가져오기 |
| GET | [`/2/users/:id/liked_tweets`](/x-api/users/get-liked-posts) | 사용자가 좋아요한 게시물 가져오기 |

### Likes 관리

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| POST | [`/2/users/:id/likes`](/x-api/users/like-post) | 게시물에 좋아요 |
| DELETE | [`/2/users/:id/likes/:tweet_id`](/x-api/users/unlike-post) | 게시물 좋아요 취소 |

## 중요 참고사항

<Note>
liking users 엔드포인트는 실제 좋아요 수와 상관없이 게시물당 최대 **100명의 사용자**를 반환합니다.
</Note>

---

## 예시: 좋아요를 누른 사용자 가져오기

```bash
curl "https://api.x.com/2/tweets/1234567890/liking_users?\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

## 예시: 게시물에 좋아요

```bash
curl -X POST "https://api.x.com/2/users/123456789/likes" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
