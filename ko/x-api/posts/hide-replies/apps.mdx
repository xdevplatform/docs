## hide replies 엔드포인트를 사용하는 앱

hide replies 엔드포인트를 통합한 개발자들이 만든 주목할 만한 앱 모음입니다. 자신들의 기술을 X API와 결합해, 모든 사용자가 공개 대화를 더 나은 방향으로 이끄는 데 도움이 되는 유용한 경험을 만들어냈습니다.

 ![Clarabridge](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/clarabridge.jpg.twimg.1920.jpg)

**Clarabridge**

Clarabridge는 기업이 X 피드를 깨끗하고 흥미롭게 유지할 수 있도록 hide replies를 통합했습니다. 답글은 수동으로 숨길 수 있으며, 에이전트는 Clarabridge의 텍스트 분석을 사용해 브랜드 정책에 부합하지 않는 욕설과 기타 표현을 자동으로 감지할 수도 있습니다.

[웹사이트 이동 ▸](https://www.clarabridge.com/ "웹사이트 이동 ▸")

[X의 Clarabridge](https://x.com/Clarabridge "X의 Clarabridge")

 ![Perspective API template app](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/perspective-logo.png.twimg.1920.png)

**Perspective API template app**

Perspective는 유해한 댓글을 감지하도록 Jigsaw(Alphabet 산하 조직)가 학습시킨 인공지능입니다. 이 앱은 수신되는 답글을 감지하고, Perspective가 과거에 본 유해 댓글과 얼마나 유사하다고 보는지를 나타내는 "점수"를 기반으로 답글을 자동으로 숨깁니다. 이는 X가 개발한 오픈 소스 템플릿 앱입니다. 여러분이 자신에게 맞게 개인화하여 사용자를 위한 도구를 만들어 보시길 권장합니다.

[앱 사용 ▸](https://quintessential-yoke.glitch.me "앱 사용 ▸")

[X의 Jigsaw](https://x.com/jigsaw "X의 Jigsaw")

 ![Reshuffle](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 150 150%22%3E%3C/svg%3E)

**Reshuffle**

Reshuffle은 유연한 스크립트로 비즈니스 애플리케이션을 연결하는 플랫폼입니다. 여러분이 정의한 키워드가 포함된 답글을 감지하고 숨기는 통합 스크립트를 구축했습니다. 사용해 보려면 Hide replies가 활성화된 유효한 앱이 있는지 확인한 뒤, 리포지토리의 지침을 따르세요.

[X의 Reshuffle](https://x.com/reshufflehq "X의 Reshuffle")

**Hide unwanted replies**

 ![Pandaflow](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 94 94%22%3E%3C/svg%3E)

**Pandaflow**

Pandaflow는 워크플로를 자동화하는 노코드 플랫폼입니다. 사용자가 정의한 사용자 지정 플로에 따라 답글을 프로그래밍 방식으로 숨길 수 있도록 이 엔드포인트를 통합합니다.
