X API는 endpoint 경로에 버전 번호를 사용하여 진화를 허용하면서도 안정성을 제공합니다. 버전 관리 전략을 이해하면 통합을 계획하고 최신 상태를 유지하는 데 도움이 됩니다.

---

## 현재 버전

| 버전 | 상태 | 설명 |
|:--------|:-------|:------------|
| **v2** | 현재 | 최신 endpoint, 유연한 가격, 모든 신규 기능 |
| **v1.1** | 레거시 | 제한된 지원, 최소한의 업데이트 |
| **Enterprise** | 사용 가능 | 전용 지원과 함께 대용량 액세스 |

<Tip>
모든 신규 프로젝트에는 **X API v2**를 사용하세요. 여기서 모든 새로운 기능이 출시됩니다.
</Tip>

---

## URL의 버전

버전 번호는 endpoint 경로에 나타납니다:

```
https://api.x.com/2/tweets
                   ^
                   version
```

## Breaking vs. non-breaking 변경

### Breaking 변경(코드 업데이트 필요)

이러한 변경은 주요 버전 업그레이드에서만 발생합니다:

- Endpoint 제거
- 응답 field 제거
- 쿼리 파라미터 제거
- 새로운 필수 파라미터 추가
- field의 데이터 유형 변경
- field 또는 리소스 이름 변경
- 응답 코드나 오류 유형 변경
- 인증 scope 수정

### Non-breaking 변경(추가)

버전 변경 없이 언제든지 발생할 수 있습니다:

- 새 endpoint 추가
- 새 선택적 파라미터 추가
- 새 응답 field 추가
- 새 OAuth scope 추가
- 오류 메시지 텍스트 변경
- 프라이버시/보안 이유로 field null 처리

## 릴리스 일정

| 유형 | 빈도 | 공지 |
|:-----|:----------|:-------|
| **주요 버전** | 연 1회 이하 | 마이그레이션 가이드 제공 |
| **Non-breaking 변경** | 지속적 | Changelog 업데이트 |
| **보안 패치** | 필요 시 | 현재 버전에 적용될 수 있음 |

---

## 지원 중단 정책

새로운 주요 버전을 릴리스할 때:

1. **지원 중단**: 이전 버전이 지원 중단됨으로 표시됨
2. **지원 기간**: 지원 중단된 버전은 정의된 기간 동안 계속 작동
3. **은퇴**: 지원 중단된 버전이 제거됨

### 정의

| 상태 | 의미 |
|:-------|:--------|
| **활성** | 새 기능과 수정으로 완전 지원 |
| **지원 중단** | 새 기능 없음, 중요 버그만 수정, 사용 권장하지 않음 |
| **은퇴** | 더 이상 접근 불가 |
