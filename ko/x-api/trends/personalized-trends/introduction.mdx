## 엔드포인트

| Method | Endpoint | 설명 |
|:-------|:---------|:------------|
| GET | `/2/users/personalized_trends` | 개인화된 트렌드 가져오기 |

---

## 예제 요청

```bash
curl "https://api.x.com/2/users/personalized_trends" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

## 예시 응답

```json title="예시 응답" lines wrap icon="/icons/xds/icon-brackets.svg"
{
  "data": [
    {
      "trend_name": "#AI",
      "tweet_count": 125000
    },
    {
      "trend_name": "Machine Learning",
      "tweet_count": 85000
    }
  ]
}
```
