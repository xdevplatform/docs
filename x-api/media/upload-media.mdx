Simple (non-chunked) upload for images and small files. For video or any file that needs async processing, use the [chunked upload](/x-api/media/quickstart/media-upload-chunked) flow instead (`/initialize`, `/{id}/append`, `/{id}/finalize`).

Images are limited to **5 MB**. Animated GIFs are limited to **15 MB**. Video should not use this endpoint.

Attaching the returned `media_id` to [`POST /2/tweets`](/x-api/posts/create-post) applies a second size check. See [size and duration limits](/x-api/media/introduction#size-and-duration-limits).
