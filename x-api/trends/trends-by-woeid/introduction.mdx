The Trends by WOEID endpoint returns trending topics for a specific geographic location, identified by a Yahoo! Where On Earth ID (WOEID).

## Example request

```bash
curl "https://api.x.com/2/trends/by/woeid/2459115" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

## Example response

```json title="Example response" lines wrap icon="/icons/xds/icon-brackets.svg"
{
  "data": [
    {
      "trend_name": "#AI"
    },
    {
      "trend_name": "Breaking News"
    }
  ],
  "meta": {
    "location": {
      "woeid": 2459115,
      "name": "New York",
      "country": "United States",
      "country_code": "US",
      "place_type": "town",
      "parent_id": 23424977
    }
  }
}
```

---

## Location

`meta.location` describes the place the trends are for. It is returned by default, so there is no field to ask for.

| Field | Type | Description |
|:------|:-----|:------------|
| `woeid` | integer | The WOEID of the place. Always present. |
| `name` | string | The name of the place. Always present. |
| `country` | string | The country the place is in. For a country, this is its own name. |
| `country_code` | string | The two-letter code of that country, such as `US` or `GB`. |
| `place_type` | string | The kind of place: `town`, `country`, or `supername` (Worldwide). |
| `parent_id` | integer | The WOEID of the place that contains this one. The parent of a town is its country, and the parent of a country is Worldwide (`1`). |

`country`, `country_code`, `place_type`, and `parent_id` are present when they are known. Worldwide has no country and no parent:

```json title="Location for Worldwide (WOEID 1)" lines wrap icon="/icons/xds/icon-brackets.svg"
"meta": {
  "location": {
    "woeid": 1,
    "name": "Worldwide",
    "place_type": "supername"
  }
}
```
