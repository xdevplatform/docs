The Usage endpoint lets you monitor your API usage, including the number of Posts consumed. Track your usage programmatically to manage costs and stay within limits.

<Note>
Pay-per-usage plans are subject to a monthly cap of 3 million Post reads. If you need higher volume, consider an [Enterprise plan](/forms/enterprise-api-interest).
</Note>

## Endpoints

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/usage/tweets`](/x-api/usage/get-usage) | Get Post usage data |
| GET | [`/2/usage/credits`](/x-api/usage/get-usage-credits) | Get your Pay-per-use (PPU) credit balance in USD |

---

## Response data

By default, `GET /2/usage/tweets` returns your Project's current billing-cycle Post usage (`project_usage`), monthly cap (`project_cap`), cap reset day (`cap_reset_day`), and `project_id`. Pass `usage.fields=daily_project_usage,daily_client_app_usage` (and optional `days`, from `1` to `90`, default `7`) to include daily breakdowns:

```json title="Example response" lines wrap icon="/icons/xds/icon-brackets.svg"
{
  "data": {
    "cap_reset_day": 10,
    "project_cap": "10000000",
    "project_id": "1234567890",
    "project_usage": "30840",
    "daily_project_usage": {
      "project_id": "1234567890",
      "usage": [
        {
          "date": "2026-01-14T00:00:00.000Z",
          "usage": "15420"
        },
        {
          "date": "2026-01-15T00:00:00.000Z",
          "usage": "15420"
        }
      ]
    },
    "daily_client_app_usage": [
      {
        "client_app_id": "12345678",
        "usage_result_count": 2,
        "usage": [
          {
            "date": "2026-01-14T00:00:00.000Z",
            "usage": "15420"
          },
          {
            "date": "2026-01-15T00:00:00.000Z",
            "usage": "15420"
          }
        ]
      }
    ]
  }
}
```

### Fields

| Field | Description |
|:------|:------------|
| `project_id` | Your Project's ID |
| `project_usage` | Total deduplicated Posts consumed by the Project in the current billing cycle |
| `project_cap` | Your Project's monthly Post cap |
| `cap_reset_day` | Day of the month when your monthly Post cap resets |
| `daily_project_usage` | Daily UTC deduplicated Post usage for the Project (`project_id` and `usage` array of `{ date, usage }`). Requires `usage.fields=daily_project_usage`. |
| `daily_client_app_usage` | Daily UTC deduplicated Post usage per App (`client_app_id`, `usage_result_count`, and `usage` array of `{ date, usage }`). Requires `usage.fields=daily_client_app_usage`. |
| `date` | UTC day of the usage entry in ISO 8601 format (`YYYY-MM-DDT00:00:00.000Z`) |
| `usage` | Number of deduplicated Posts consumed on that UTC day (string) |

---

## Example request

```bash
curl "https://api.x.com/2/usage/tweets?days=7&usage.fields=daily_project_usage,daily_client_app_usage" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

## Use cases

- **Cost monitoring** — Track consumption against your budget
- **Alerting** — Set up alerts when approaching limits
- **Optimization** — Identify high-consumption endpoints
- **Reporting** — Generate usage reports

<Tip>
Resources are deduplicated within a 24-hour UTC window, so requesting the same resource multiple times in a day only counts as one charge. [Learn more about pricing →](/x-api/getting-started/pricing)
</Tip>
