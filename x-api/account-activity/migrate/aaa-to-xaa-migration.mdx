## Summary

We have set January 1, 2027 as the target date for AAA to reach end of life. All customers should plan to migrate to the new X Activity API (XAA) before that time. See the [X Activity API (XAA) documentation](/x-api/activity/introduction) for details.

## Benefits of XAA

XAA offers several advantages over AAA:

- A full superset of all AAA features
- Granular event-based subscription model, rather than all-or-nothing for a user subscription
- Full OAuth2.0 support
- Supports webhook delivery and persistent HTTP stream. You can use the same webhook you currently use for AAA if you so choose
- Several additional event families that AAA did not serve including support for the new XChat service, live broadcast chat and lifecycle events, profile updates, and more
- Non-user specific events such as platform news
- OAuth revocation events
- Uses the same replay mechanisms that AAA did
