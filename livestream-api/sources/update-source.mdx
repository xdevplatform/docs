<Warning>
**This route is deprecated and will be removed on January 1, 2027**, after which it returns `404`. Use [Update Source by ID](/livestream-api/sources/update-source-by-id) (`PUT /2/sources/:id`) instead, which takes the source id rather than the stream key. See the [migration guide](/livestream-api/migration-guide).
</Warning>

Only the `name` can be updated.


**Endpoint:** `PUT /2/users/:user_id/sources/:source_id`

`:source_id` is the source's stream key (its `id` on the deprecated routes).

## Request body

```json
{
  "name": "Updated Encoder Name"
}
```

## Response

The updated source object (wrapped in `"source"`).
