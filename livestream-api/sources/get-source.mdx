Returns a single source (must be owned by the authenticated user).

<Note>
  This endpoint is available by whitelist only. To request access, fill out the [Livestream API Access Form](/forms/livestream-api-access).
</Note>

**Endpoint:** `GET /2/users/:user_id/sources/:source_id`

## Response

Same shape as an item inside the [list response](/livestream-api/sources/list-sources), wrapped:

```json
{
  "source": { ... }
}
```

A source that doesn't exist, or that belongs to another user, returns `404`.

<Tip>
Poll this endpoint after starting your encoder to check that video is arriving: `is_stream_active` becomes `true` within a few seconds of your encoder connecting. A source doesn't need to be receiving video to [create](/livestream-api/broadcasts/create-broadcast) or [publish](/livestream-api/broadcasts/publish-or-end-broadcast) a broadcast.
</Tip>
