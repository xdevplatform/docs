<Warning>
**This route is deprecated and will be removed on January 1, 2027**, after which it returns `404`. Use [Get Source by ID](/livestream-api/sources/get-source-by-id) (`GET /2/sources/:id`) instead, which takes the source id rather than the stream key. See the [migration guide](/livestream-api/migration-guide).
</Warning>

Returns a single source (must be owned by the authenticated user).


**Endpoint:** `GET /2/users/:user_id/sources/:source_id`

`:source_id` is the source's stream key (its `id` on the deprecated routes).

## Response

Same shape as an item inside the [list response](/livestream-api/sources/list-sources), wrapped:

```json
{
  "source": { ... }
}
```

A source that doesn't exist, or that belongs to another user, returns `404`.

<Tip>
Poll this endpoint after starting your encoder to check that video is arriving: `is_stream_active` becomes `true` within a few seconds of your encoder connecting.
</Tip>
