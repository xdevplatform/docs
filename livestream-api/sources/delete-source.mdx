<Warning>
**This route is deprecated and will be removed on January 1, 2027**, after which it returns `404`. Use [Delete Source by ID](/livestream-api/sources/delete-source-by-id) (`DELETE /2/sources/:id`) instead, which takes the source id rather than the stream key. See the [migration guide](/livestream-api/migration-guide).
</Warning>

Permanently deletes a source. No active broadcast may be using it.

<Note>
  This endpoint is available by whitelist only. To request access, fill out the [Livestream API Access Form](/forms/livestream-api-access).
</Note>

**Endpoint:** `DELETE /2/users/:user_id/sources/:source_id`

`:source_id` is the source's stream key (its `id` on the deprecated routes).

## Response

HTTP `200` with an empty JSON object (`{}`). Deleting a source that doesn't exist returns `404`.

<Note>
Don't depend on the exact body shape of delete responses — treat any 2xx as success.
</Note>
