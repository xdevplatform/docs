Returns all of the authenticated user's stream sources in `data`, and their number in `meta.result_count`. This route replaces the deprecated [List Stream Sources](/livestream-api/sources/list-sources) (`GET /2/users/:user_id/sources`); see the [migration guide](/livestream-api/migration-guide).


Each source's `id` is the `source_id` that [Go Live](/livestream-api/broadcasts/go-live) and [scheduled broadcasts](/livestream-api/scheduled-broadcasts/create-scheduled-broadcast) take. Use this route to look up the source ids of sources you created with the deprecated routes.

Stream keys aren't included. To configure an encoder, read a source's key with [Get Source Stream Key](/livestream-api/sources/get-source-stream-key). `is_stream_active` shows whether the source is receiving video right now.
