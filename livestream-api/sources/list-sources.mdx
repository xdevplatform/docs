Returns all sources owned by the user (empty array if none).

<Note>
  This endpoint is available by whitelist only. To request access, fill out the [Livestream API Access Form](/forms/livestream-api-access).
</Note>

**Endpoint:** `GET /2/users/:user_id/sources`

## Response shape

```json
{
  "sources": [ { ...source object... }, ... ]
}
```

Each item is a source object with the same fields as the [Create Stream Source](/livestream-api/sources/create-source) response. `is_stream_active` shows whether the source is receiving video right now.
