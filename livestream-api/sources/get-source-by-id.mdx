Returns one of the authenticated user's stream sources. `:id` is the source id (19 digits) from [Get Sources](/livestream-api/sources/get-sources) or [Create a Source](/livestream-api/sources/create-a-source). This route replaces the deprecated [Get Stream Source](/livestream-api/sources/get-source) (`GET /2/users/:user_id/sources/:source_id`); see the [migration guide](/livestream-api/migration-guide).

<Note>
  This endpoint is available by whitelist only. To request access, fill out the [Livestream API Access Form](/forms/livestream-api-access).
</Note>

The stream key isn't included; read it with [Get Source Stream Key](/livestream-api/sources/get-source-stream-key).

<Tip>
Poll this endpoint after starting your encoder to check that video is arriving: `is_stream_active` becomes `true` within a few seconds of your encoder connecting.
</Tip>

## Errors

| Status | Problem `type` | When |
|:-------|:---------------|:-----|
| `400` | `https://api.x.com/2/problems/invalid-request` | `:id` isn't a source id, for example a stream key: `` The `id` value is not a source id. `` The value isn't echoed back. |
| `404` | `https://api.x.com/2/problems/resource-not-found` | The source doesn't exist or belongs to another user. |
