Permanently deletes one of the authenticated user's stream sources. `:id` is the source id (19 digits) from [Get Sources](/livestream-api/sources/get-sources). No active broadcast may be using the source. This route replaces the deprecated [Delete Stream Source](/livestream-api/sources/delete-source) (`DELETE /2/users/:user_id/sources/:source_id`); see the [migration guide](/livestream-api/migration-guide).

<Note>
  This endpoint is available by whitelist only. To request access, fill out the [Livestream API Access Form](/forms/livestream-api-access).
</Note>

On success, the response is `{ "data": { "deleted": true } }`. Broadcasts that used the source are kept; their `source_id` is omitted once the source is deleted.

## Errors

| Status | Problem `type` | When |
|:-------|:---------------|:-----|
| `400` | `https://api.x.com/2/problems/invalid-request` | `:id` isn't a source id, for example a stream key: `` The `id` value is not a source id. `` The value isn't echoed back. |
| `404` | `https://api.x.com/2/problems/resource-not-found` | The source doesn't exist or belongs to another user. |
