Renames one of the authenticated user's stream sources and returns the updated source. `:id` is the source id (19 digits) from [Get Sources](/livestream-api/sources/get-sources). Only `name` can be updated; any other body field returns `400`. This route replaces the deprecated [Update Stream Source](/livestream-api/sources/update-source) (`PUT /2/users/:user_id/sources/:source_id`); see the [migration guide](/livestream-api/migration-guide).

<Note>
  This endpoint is available by whitelist only. To request access, fill out the [Livestream API Access Form](/forms/livestream-api-access).
</Note>

## Errors

| Status | Problem `type` | When |
|:-------|:---------------|:-----|
| `400` | `https://api.x.com/2/problems/invalid-request` | The body is invalid, or `:id` isn't a source id, for example a stream key: `` The `id` value is not a source id. `` The value isn't echoed back. |
| `404` | `https://api.x.com/2/problems/resource-not-found` | The source doesn't exist or belongs to another user. |
