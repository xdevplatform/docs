Returns the recommended AWS region for stream ingest.

<Note>
  This endpoint is available by whitelist only. To request access, fill out the [Livestream API Access Form](/forms/livestream-api-access).
</Note>

**Endpoint:** `GET /2/region`

**Auth:** User context only: OAuth 2.0 with the `broadcast.read` scope, or OAuth 1.0a. App-only authentication isn't supported. See [Authentication](/livestream-api/authentication).

**Rate limit:** 100 requests per user per 15 minutes.

## Behavior

The endpoint returns HTTP `200 OK` with a JSON body containing a single `region` field. The body has no `data` wrapper.

The value is either `us-east-1` or `us-west-2`. X chooses it based on the X data center that handles the request.

## Response

```json
{
  "region": "us-west-2"
}
```

Pass the `region` value unchanged as `region` when you create a source with [`POST /2/users/:id/sources`](/livestream-api/sources/create-source) or `POST /2/sources`.
