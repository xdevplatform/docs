Returns the recommended ingest region: the X ingest location nearest the server handling your request.

<Note>
  This endpoint is available by whitelist only. To request access, fill out the [Livestream API Access Form](/forms/livestream-api-access).
</Note>

**Endpoint:** `GET /2/region`

**Auth:** User context — OAuth 2.0 (with `broadcast.read` scope) recommended, or OAuth 1.0a 3-legged. See [Authentication](/livestream-api/authentication).

## Response

```json
{
  "region": "us-east-1"
}
```

`region` is `us-east-1` or `us-west-2`. Pass it as `region` when [creating a stream source](/livestream-api/sources/create-source).
