Creates a persistent RTMPS ingest point for the authenticated user. Returns `201` with the new source in `data`. This route replaces the deprecated [Create Stream Source](/livestream-api/sources/create-source) (`POST /2/users/:user_id/sources`); see the [migration guide](/livestream-api/migration-guide).


## Request body

`name` and `region` are both required. Use the `region` from [Get Recommended Region](/livestream-api/sources/get-recommended-region). AWS-style region codes are accepted and mapped to the nearest X ingest location: `us-west-1` and `us-west-2` to US West; `us-east-1`, `us-east-2`, `ca-central-1`, `sa-east-1`, `eu-west-1`, `eu-west-2`, `eu-west-3`, `eu-central-1`, `eu-north-1`, `ap-south-1`, `ap-northeast-1`, `ap-northeast-2`, `ap-southeast-1` and `ap-southeast-2` to US East. Any other value, or any field other than `name` and `region`, returns `400`.

## Response

The response includes the source's `id` and its `stream_key`:

```json
{
  "data": {
    "id": "9123456789012345678",
    "name": "My Primary Encoder",
    "region": "us-east-1",
    "rtmp_url": "rtmps://a.live.x.com/x",
    "rtmps_url": "rtmps://a.live.x.com:443/x",
    "stream_key": "YOUR_STREAM_KEY",
    "is_stream_active": false,
    "created_at_ms": "1772029802844"
  }
}
```

- `id` is the source id. Use it as `source_id` when you [go live](/livestream-api/broadcasts/go-live) and in the other `/2/sources/:id` routes.
- `stream_key` is a credential. Configure your encoder with `rtmps_url` and `stream_key`, and store the key securely. This is the only response that includes it; read it again later with [Get Source Stream Key](/livestream-api/sources/get-source-stream-key).
- `region` is the X ingest location serving the source (`us-east-1` or `us-west-2`), which can differ from the `region` you requested.

See the [source object](/livestream-api/sources/overview#source-object) for all fields.
