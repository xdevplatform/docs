Returns the stream key of one of the authenticated user's stream sources. `:id` is the source id (19 digits) from [Get Sources](/livestream-api/sources/get-sources). Configure your encoder with the source's `rtmps_url` and this stream key. With OAuth 2.0, this read requires both the `broadcast.read` and `broadcast.write` scopes.


```json
{
  "data": {
    "id": "9123456789012345678",
    "stream_key": "YOUR_STREAM_KEY"
  }
}
```

<Warning>
The stream key is a credential: anyone with it can stream to the source. Fetch it only when you need to configure an encoder, and keep it out of logs, URLs, analytics and client-side code.
</Warning>

## Errors

| Status | Problem `type` | When |
|:-------|:---------------|:-----|
| `400` | `https://api.x.com/2/problems/invalid-request` | `:id` isn't a source id, for example a stream key: `` The `id` value is not a source id. `` The value isn't echoed back. |
| `404` | `https://api.x.com/2/problems/resource-not-found` | The source doesn't exist or belongs to another user. |
