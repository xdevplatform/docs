---
title: Delete a Scheduled Broadcast
sidebarTitle: Delete Scheduled Broadcast
description: "DELETE /2/broadcasts/scheduled/:id deletes a scheduled broadcast that isn't live."
keywords: ["delete scheduled broadcast", "DELETE broadcasts scheduled"]
openapi: "delete /2/broadcasts/scheduled/{id}"
---

Deletes a scheduled broadcast. `:id` is the alphanumeric `broadcast_id`.

A broadcast that is live can't be deleted, and the request returns `400`. Wait for the broadcast to end, then delete it.

<Note>
Recurring schedules are retired. A request with `roll_forward=true` returns `400`.
</Note>
