Allows a muted user to post chat messages in a broadcaster's chat again. The unmute applies to every broadcast the broadcaster hosts.

`:user_id` is the numeric id of the user to unmute.

Without the `broadcast_id` query parameter, you unmute the user in your own chats. You don't need a live broadcast to do this.

Chat moderators pass `broadcast_id` to unmute the user in that broadcast host's chats. The broadcast must be live. See [List Broadcast Moderators](/livestream-api/chat/list-moderators) for how moderators are managed.

<Note>
To mute a user, use [Mute a Chat User](/livestream-api/chat/mute-user). To see who you have muted, use [List Muted Chat Users](/livestream-api/chat/list-muted-chat-users).
</Note>
