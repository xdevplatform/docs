Returns the users muted in the authenticated broadcaster's chat. Mutes are scoped to the broadcaster, not to an individual broadcast, and apply across every broadcast that user hosts.

This endpoint lists only the authenticated user's own mutes. A chat moderator can't use it to list the mutes of a broadcaster they moderate for.

Timed mutes include their expiry time. Expired timed mutes are omitted from the response.

Pass `expansions=user_id` to include the muted users' user objects in the response.

## Pagination

The response includes `meta.next_token` whenever a page is full, even if no more results remain. As a result, the last page of results can be followed by an empty page. To fetch the next page, pass the `next_token` value as `pagination_token`. Keep paging until the response has no `next_token` or returns an empty page.

<Note>
To mute or unmute a user, use [Mute a Chat User](/livestream-api/chat/mute-user) or [Unmute a Chat User](/livestream-api/chat/unmute-user).
</Note>
