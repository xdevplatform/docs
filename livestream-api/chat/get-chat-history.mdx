Gets a paginated list of timestamped chat messages for a broadcast. Only accessible after the broadcast has finished. `:id` is the alphanumeric `broadcast_id`, and the authenticated user must own the broadcast.

Messages are returned newest-first. Use `max_results` (1–200, default 100) to page, and `pagination_token` to continue from the `meta.next_token` returned by the previous response.

<Note>
For live chat ingestion while a broadcast is running, use the [X Activity API](/x-api/activity/introduction) `broadcast.chat` event instead. This endpoint is for retrieving the message history after the broadcast ends.
</Note>
