Prevents a user from posting chat messages in a broadcaster's chat. Mutes belong to the broadcaster and apply to every broadcast they host.

Pass the numeric id of the user to mute as `user_id` in the request body. `user_id` is the only required field.

Without `broadcast_id`, you mute the user in your own chats. You don't need a live broadcast to do this.

Chat moderators pass `broadcast_id` to mute the user in that broadcast host's chats. The broadcast must be live. See [List Broadcast Moderators](/livestream-api/chat/list-moderators) for how moderators are managed.

Pass an optional `message_id` to remove that chat message at the same time. This is useful when muting is in response to a particular message. `message_id` requires `broadcast_id`.

Pass an optional `end_at_ms` to time the mute out at a specific Unix timestamp in milliseconds. Omit `end_at_ms` to mute the user indefinitely.

You can't mute the broadcast owner.

<Note>
To reverse this, use [Unmute a Chat User](/livestream-api/chat/unmute-user). To see who you have muted, use [List Muted Chat Users](/livestream-api/chat/list-muted-chat-users). To remove an individual message without muting its author, use [Delete a Chat Message](/livestream-api/chat/delete-chat-message).
</Note>
