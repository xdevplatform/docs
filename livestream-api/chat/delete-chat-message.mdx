Deletes a single message from a live broadcast's chat. Once deleted, the message is no longer visible to viewers.

The broadcast must be currently live, and the authenticated user must be the host of the broadcast (or otherwise have moderation permission on it). `:id` is the alphanumeric `broadcast_id`, and `:message_id` is the `timestamp` returned when the message was originally sent.

## Path parameters

| Name | Type | Required | Description |
|:-----|:-----|:---------|:------------|
| `id` | string | Yes | The alphanumeric `broadcast_id` of the live broadcast. |
| `message_id` | string | Yes | The id of the chat message to delete — the `timestamp` returned by [Send a Chat Message](/livestream-api/chat/send-chat-message). |

## Example

```bash
curl --request DELETE \
  --url 'https://api.x.com/2/broadcasts/1DxLddgepQbxm/chat/1772032100000000000' \
  --header 'Authorization: Bearer YOUR_ACCESS_TOKEN'
```

```json
{
  "data": {
    "success": true
  }
}
```

## Errors

- A request returns `400 Bad Request` if the broadcast cannot be found or is not currently live.
- It returns `403 Forbidden` if the authenticated user is not permitted to moderate chat in the broadcast.
- It returns `404 Not Found` if the referenced `message_id` cannot be found in the broadcast's chat.

<Note>
To also prevent a user from posting further messages, use [Mute a Chat User](/livestream-api/chat/mute-chat-user), which supports deleting the prompting message in the same call.
</Note>
