---

Allows a muted user to post chat messages in the broadcaster's chat again. The unmute applies to all of the broadcaster's broadcasts, not only the broadcast in the request.

`:id` is the alphanumeric `broadcast_id` of a live broadcast. It identifies whose chat you are moderating: the broadcast owner's. `:user_id` is the numeric id of the user to unmute.

The authenticated user must be the broadcast owner or a chat moderator for the broadcast owner. When a moderator calls this endpoint, the unmute applies to the chat of the owner they moderate for. See [List Broadcast Moderators](/livestream-api/chat/list-moderators) for how moderators are managed.

<Note>
To mute a user, use [Mute a Chat User](/livestream-api/chat/mute-chat-user).
</Note>
