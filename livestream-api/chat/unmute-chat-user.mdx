Unmutes a user who was previously muted in a live broadcast's chat, allowing them to send messages again.

The broadcast must be currently live, and the authenticated user must be the host of the broadcast (or otherwise have moderation permission on it). `:id` is the alphanumeric `broadcast_id`, and `:user_id` is the numeric id of the user to unmute.

## Path parameters

| Name | Type | Required | Description |
|:-----|:-----|:---------|:------------|
| `id` | string | Yes | The alphanumeric `broadcast_id` of the live broadcast. |
| `user_id` | string | Yes | The numeric id of the user to unmute. |

## Example

```bash
curl --request DELETE \
  --url 'https://api.x.com/2/broadcasts/1DxLddgepQbxm/chat/mutes/2244994945' \
  --header 'Authorization: Bearer YOUR_ACCESS_TOKEN'
```

```json
{
  "data": {
    "success": true
  }
}
```

## Errors

- A request returns `400 Bad Request` if the broadcast cannot be found or is not currently live.
- It returns `403 Forbidden` if the authenticated user is not permitted to moderate chat in the broadcast.
- It returns `404 Not Found` if the target user is not currently muted in the broadcast's chat.

<Note>
To mute a user, use [Mute a Chat User](/livestream-api/chat/mute-chat-user).
</Note>
