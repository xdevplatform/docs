Mutes a user from chatting in a live broadcast. Once muted, the user cannot send further messages in the broadcast's chat. Optionally, a specific message that prompted the mute can be deleted in the same call.

The broadcast must be currently live, and the authenticated user must be the host of the broadcast (or otherwise have moderation permission on it). `:id` is the alphanumeric `broadcast_id`.

## Path parameters

| Name | Type | Required | Description |
|:-----|:-----|:---------|:------------|
| `id` | string | Yes | The alphanumeric `broadcast_id` of the live broadcast. |

## Request body

| Field | Type | Required | Description |
|:------|:-----|:---------|:------------|
| `user_id` | string | Yes | The numeric id of the user to mute. |
| `message_id` | string | No | The id of a chat message (the `timestamp` returned when the message was sent) to delete as part of the mute. |

## Example

```bash
curl --request POST \
  --url 'https://api.x.com/2/broadcasts/1DxLddgepQbxm/chat/mutes' \
  --header 'Authorization: Bearer YOUR_ACCESS_TOKEN' \
  --header 'Content-Type: application/json' \
  --data '{
    "user_id": "2244994945",
    "message_id": "1772032100000000000"
  }'
```

```json
{
  "data": {
    "success": true
  }
}
```

## Errors

- A request returns `400 Bad Request` if the broadcast cannot be found, is not currently live, or the request body is invalid.
- It returns `403 Forbidden` if the authenticated user is not permitted to moderate chat in the broadcast.
- It returns `404 Not Found` if the target user or referenced `message_id` cannot be found in the broadcast's chat.

<Note>
To unmute a user, use [Unmute a Chat User](/livestream-api/chat/unmute-chat-user). To delete an individual message without muting its author, use [Delete a Chat Message](/livestream-api/chat/delete-chat-message).
</Note>
