Deletes one of the authenticated user's broadcasts, scheduled or ended, including its replay. `:id` is the alphanumeric broadcast ID. This route replaces the deprecated [Delete Broadcast](/livestream-api/broadcasts/delete-broadcast) (`DELETE /2/users/:user_id/broadcasts/:broadcast_id`); see the [migration guide](/livestream-api/migration-guide).

<Note>
  This endpoint is available by whitelist only. To request access, fill out the [Livestream API Access Form](/forms/livestream-api-access).
</Note>

A running broadcast must be ended first: call [End Broadcast](/livestream-api/broadcasts/end-broadcast), then delete it. This endpoint has no request body. On success, the response is `{ "data": { "deleted": true } }`.

## Errors

Errors use the standard X API problem format.

| Status | Problem `type` | When | What to do |
|:-------|:---------------|:-----|:-----------|
| `400` | `https://api.x.com/2/problems/invalid-request` | The broadcast can't be deleted as requested. | If it's running, [end it](/livestream-api/broadcasts/end-broadcast) first. |
| `403` | `about:blank` | The broadcast belongs to another user, the account can't manage it, or the broadcast was moderated. | Don't retry. |
| `403` | `https://api.x.com/2/problems/missing-scopes` | The OAuth 2.0 token lacks `broadcast.write`. | Re-authorize the user with the `broadcast.read` and `broadcast.write` scopes. |
| `404` | `https://api.x.com/2/problems/resource-not-found` | The broadcast doesn't exist. It may already have been deleted. | Check the broadcast ID. |
| `503` | `about:blank` | Temporary failure. | Retry with backoff. |
