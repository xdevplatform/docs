## Educadores

Traga a API para a sua sala de aula para ensinar aos alunos os fundamentos da programação e
valiosas habilidades de processamento de dados.

**Recursos:**

Você é um educador querendo usar a X API em seu curso? Este
[guia para ensinar com a X API](https://dev.to/suhemparack/a-guide-to-teaching-with-the-twitter-api-v2-3n08)
ajudará você a entender a X API, por que ela é usada por educadores, que tipos
de aulas são ministradas com a API e tudo mais que você precisa saber para
começar.

**Destaque:**

Os currículos abaixo são construídos e executados usando a X API v2:

- [Social Media Data Mining and Analysis](https://canvas.uw.edu/courses/1434897)
  pela Dra. Tanu Mitra

- [Data Science & Society](https://dssoc.github.io/) pelo Dr. Chris Bail

- [Introduction to Cultural Analytics & Python](https://melaniewalsh.github.io/Intro-Cultural-Analytics/welcome.html)
  pela Dra. Melanie Walsh

- [Oxford Spring School in Advanced Research Methods, Analysing X Data](https://github.com/cjbarrie/oxspsch)
  pelo Dr. Chris Barrie
