## Introdução

 Enquanto o [endpoint de recent search](/x-api/posts/search/introduction) permite que você obtenha apenas Posts publicados nos últimos 7 dias, os endpoints de user Post timeline e user mention timeline permitem obter Posts e menções mais antigos que os últimos 7 dias, para um usuário autorizado (usando o user ID). Os desenvolvedores podem usar esses endpoints para estudar tópicos, entidades e sentimento dos Posts da timeline de um usuário ou das menções. Neste tutorial, mostraremos como explorar os Posts e menções de um usuário usando os endpoints de user Tweet timeline e user mention timeline.
 

## Pré-requisitos

*   Para usar os endpoints de user Tweet timeline e user mention timeline, você precisará de uma conta de desenvolvedor válida.
*   Você também precisará de um [Project](/resources/fundamentals/developer-apps) criado.
*   Você deve ter [se inscrito](https://developer.x.com/en/portal/petition/essential/basic-info) para uma conta de desenvolvedor e ter ativado a [nova experiência do Developer Console](https://developer.x.com/en/portal/opt-in.html).
*   O acesso está disponível com chaves e tokens ativos para um App de desenvolvedor conectado a um [Project](/resources/fundamentals/developer-apps) criado no [Developer Console](/resources/fundamentals/developer-portal).
*   Um Bearer Token do seu App no [X Developer Console](/resources/fundamentals/developer-portal).
*   Se você não tem uma conta de desenvolvedor aprovada, pode [solicitar uma](https://developer.x.com/en/apply-for-access).

## Como obter o user ID de um usuário para usar nos endpoints user Tweet timeline e user mention timeline

Os endpoints de user Tweet timeline e user mention timeline permitem obter Posts usando o user ID. Para obter o user ID a partir de um username, você pode usar o novo [endpoint user lookup v2](/x-api/users/lookup/quickstart/user-lookup). Substitua USER\_NAME pelo username de sua escolha e XXXX pelo seu próprio bearer token obtido acima

```bash
  curl --request GET 'https://api.x.com/2/users/by/username/USER_NAME --header 'Authorization: Bearer XXXXXX'
```

Você verá o user ID na resposta como mostrado abaixo:

```json
{
   "data": {
       "id": "2244994945",
       "name": "Developers",
       "username": "XDevelopers"
   }
}
```


## Conectando-se aos endpoints user Tweet timeline e user mention timeline

Para obter a user Tweet timeline de um usuário, execute o seguinte comando curl no seu terminal (certifique-se de substituir USER\_ID pelo user ID de sua escolha e XXXX pelo seu próprio bearer token obtido acima)

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/tweets' --header 'Authorization: Bearer XXXXXX'
```


Você verá que a resposta JSON dessas requisições contém o ID e o texto dos Posts por padrão (exemplo abaixo).

```yaml
{
   "id": "1334200897081987072",
   "text": "👀 If you are new to the X API v2, check out this step-by-step guide to making your first request https://t.co/4rZqThpSbp"
}
```

Se você quiser campos adicionais retornados como parte da resposta (como informações do usuário, campos adicionais do Tweet como context annotations, etc.), precisará especificar esses campos explicitamente na sua resposta. Aprenda como fazer isso no [guia sobre uso de fields e expansions](/x-api/fundamentals/data-dictionary/reference#how-to-use-fields-and-expansions).

Você também pode obter esses Posts usando linguagens de programação de sua escolha. Confira nosso código de exemplo em Python, Node (JavaScript), Java e Ruby para os endpoints user Tweet timeline e user mention timeline no nosso [repositório do GitHub](https://github.com/xdevplatform/Twitter-API-v2-sample-code).
 

## Explorando os Posts do usuário

Uma vez que saiba como obter Posts usando os endpoints user Tweet timeline e user mention timeline, você pode começar a explorar seus Posts. Por exemplo, se quiser identificar entidades nomeadas comuns presentes nas menções de um usuário, pode fazer o seguinte:

Na requisição da API, especifique que deseja o objeto context\_annotations retornado nas respostas do Tweet:

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/mentions?tweet.fields=context_annotations' --header 'Authorization: Bearer XXXXXX'
```

Na resposta, você verá se há entidades nomeadas presentes nas menções. Aqui está um exemplo:

```json
{
   "domain": {
       "id": "47",
       "name": "Brand",
       "description": "Brands and Companies"
   },
   "entity": {
       "id": "783214",
       "name": "X"
   }
}
```

Se quisesse ver quais entidades populares aparecem em suas menções, você poderia manter uma contagem das entidades populares analisando cada Tweet nas menções.

Se você quiser explorar a URL de imagem de preview de todos os Posts em sua timeline que contêm mídia, pode fazer o seguinte:

Na requisição da API, especifique que deseja o preview\_image\_url nos campos tweet.media, e as expansions attachments.media\_keys
```bash
curl --request GET 'https://api.x.com/2/users/2244994945/mentions?max_results=100&media.fields=preview_image_url&expansions=attachments.media_keys' --header 'Authorization: Bearer XXXXXX'
```

Na resposta, você verá o preview\_image\_url no objeto includes como mostrado abaixo:

```json
{
   "includes": {
       "media": [
           {
               "media_key": "16_1334657439640121344",
               "preview_image_url": "https://pbs.twimg.com/tweet_video_thumb/EoWn3rqU8AAtFWL.jpg",
               "type": "animated_gif"
           }
       ]
   }
}
```
