Este guia mostra como obter Post counts (volume) para os últimos 7 dias.

<Note>
**Pré-requisitos**

Antes de começar, você precisará de:
- Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info) com um App aprovado
- O Bearer Token do seu App
</Note>

## Obter Post counts recentes

<Steps>
  <Step title="Crie uma query">
    Use a mesma sintaxe de query do recent search. Por exemplo, para contar Posts de @XDevelopers:

    ```
    from:XDevelopers
    ```
  </Step>

  <Step title="Faça a requisição">

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/tweets/counts/recent?\
query=from%3AXDevelopers&\
granularity=day" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obter Post counts recentes
response = client.posts.count_recent(
    query="from:XDevelopers",
    granularity="day"
)

for bucket in response.data:
    print(f"{bucket.start}: {bucket.tweet_count} Posts")

print(f"Total: {response.meta.total_tweet_count}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Obter Post counts recentes
const response = await client.posts.countRecent({
  query: "from:XDevelopers",
  granularity: "day",
});

response.data?.forEach((bucket) => {
  console.log(`${bucket.start}: ${bucket.tweet_count} Posts`);
});

console.log(`Total: ${response.meta?.total_tweet_count}`);
```

</CodeGroup>

  </Step>

## Opções de granularidade

Controle como as contagens são agrupadas:

| Granularidade | Descrição |
|:------------|:------------|
| `minute` | Contagens por minuto |
| `hour` | Contagens por hora (padrão) |
| `day` | Contagens por dia |

<CodeGroup dropdown>

```bash cURL
# Obter contagens por hora
curl "https://api.x.com/2/tweets/counts/recent?\
query=python%20lang%3Aen&\
granularity=hour" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obter contagens por hora
response = client.posts.count_recent(
    query="python lang:en",
    granularity="hour"
)

for bucket in response.data:
    print(f"{bucket.start}: {bucket.tweet_count}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Obter contagens por hora
const response = await client.posts.countRecent({
  query: "python lang:en",
  granularity: "hour",
});

response.data?.forEach((bucket) => {
  console.log(`${bucket.start}: ${bucket.tweet_count}`);
});
```

## Filtrar por intervalo de tempo

Limite as contagens a um período específico:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/tweets/counts/recent?\
query=from%3AXDevelopers&\
start_time=2024-01-10T00%3A00%3A00Z&\
end_time=2024-01-15T00%3A00%3A00Z&\
granularity=day" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obter contagens para um intervalo de tempo específico
response = client.posts.count_recent(
    query="from:XDevelopers",
    start_time="2024-01-10T00:00:00Z",
    end_time="2024-01-15T00:00:00Z",
    granularity="day"
)

print(f"Total Posts: {response.meta.total_tweet_count}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Obter contagens para um intervalo de tempo específico
const response = await client.posts.countRecent({
  query: "from:XDevelopers",
  startTime: "2024-01-10T00:00:00Z",
  endTime: "2024-01-15T00:00:00Z",
  granularity: "day",
});

console.log(`Total Posts: ${response.meta?.total_tweet_count}`);
```

</CodeGroup>

## Parâmetros comuns

| Parâmetro | Descrição | Padrão |
|:----------|:------------|:--------|
| `query` | Query de busca (obrigatória) | — |
| `granularity` | Tamanho do bucket de tempo | `hour` |
| `start_time` | Timestamp mais antigo (ISO 8601) | 7 dias atrás |
| `end_time` | Timestamp mais recente (ISO 8601) | Agora |
