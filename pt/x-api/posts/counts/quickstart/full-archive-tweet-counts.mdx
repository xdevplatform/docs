Este guia mostra como obter contagens históricas de Posts desde março de 2006.

<Warning>
O Post counts full-archive requer acesso [Self-serve](/x-api/getting-started/about-x-api) ou [Enterprise](/x-api/getting-started/about-x-api).
</Warning>

<Note>
**Pré-requisitos**

Antes de começar, você precisará de:
- Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info) com acesso Self-serve ou Enterprise
- O Bearer Token do seu App
</Note>

## Obter Post counts full-archive

<Steps>
  <Step title="Crie uma query">
    Use a mesma sintaxe de query do full-archive search. Por exemplo, para contar Posts de @XDevelopers:

    ```
    from:XDevelopers
    ```
  </Step>

  <Step title="Defina um intervalo de tempo">
    Especifique `start_time` e `end_time` para pesquisar períodos históricos específicos:

    | Parâmetro | Formato | Exemplo |
    |:----------|:-------|:--------|
    | `start_time` | ISO 8601 | `2020-01-01T00:00:00Z` |
    | `end_time` | ISO 8601 | `2020-12-31T23:59:59Z` |
  </Step>

  <Step title="Faça a requisição">

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/tweets/counts/all?\
query=from%3AXDevelopers&\
start_time=2020-01-01T00%3A00%3A00Z&\
end_time=2020-12-31T23%3A59%3A59Z&\
granularity=day" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obter Post counts full-archive
response = client.posts.count_all(
    query="from:XDevelopers",
    start_time="2020-01-01T00:00:00Z",
    end_time="2020-12-31T23:59:59Z",
    granularity="day"
)

for bucket in response.data:
    print(f"{bucket.start}: {bucket.tweet_count} Posts")

print(f"Total: {response.meta.total_tweet_count}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Obter Post counts full-archive
const response = await client.posts.countAll({
  query: "from:XDevelopers",
  startTime: "2020-01-01T00:00:00Z",
  endTime: "2020-12-31T23:59:59Z",
  granularity: "day",
});

response.data?.forEach((bucket) => {
  console.log(`${bucket.start}: ${bucket.tweet_count} Posts`);
});

console.log(`Total: ${response.meta?.total_tweet_count}`);
```

## Opções de granularidade

Controle como as contagens são agrupadas:

| Granularidade | Descrição |
|:------------|:------------|
| `minute` | Contagens por minuto |
| `hour` | Contagens por hora (padrão) |
| `day` | Contagens por dia |

## Paginar os resultados

Para intervalos de tempo grandes, use o `next_token` da resposta:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/tweets/counts/all?\
query=from%3AXDevelopers&\
start_time=2015-01-01T00%3A00%3A00Z&\
end_time=2020-12-31T23%3A59%3A59Z&\
granularity=day&\
next_token=abc123" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obter counts com paginação
next_token = None

while True:
    response = client.posts.count_all(
        query="from:XDevelopers",
        start_time="2015-01-01T00:00:00Z",
        end_time="2020-12-31T23:59:59Z",
        granularity="day",
        next_token=next_token
    )
    
    for bucket in response.data:
        print(f"{bucket.start}: {bucket.tweet_count}")
    
    next_token = response.meta.next_token
    if not next_token:
        break
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Obter counts com paginação
let nextToken = undefined;

do {
  const response = await client.posts.countAll({
    query: "from:XDevelopers",
    startTime: "2015-01-01T00:00:00Z",
    endTime: "2020-12-31T23:59:59Z",
    granularity: "day",
    nextToken,
  });

  response.data?.forEach((bucket) => {
    console.log(`${bucket.start}: ${bucket.tweet_count}`);
  });

  nextToken = response.meta?.next_token;
} while (nextToken);
```

## Principais diferenças em relação ao recent counts

| Recurso | Recent Counts | Full-Archive Counts |
|:--------|:--------------|:--------------------|
| Intervalo de tempo | Últimos 7 dias | Março de 2006 até agora |
| Acesso necessário | Todos os desenvolvedores | Pay-per-use, Enterprise |
| Intervalo de tempo padrão | Últimos 7 dias | Últimos 30 dias |

---

## Parâmetros comuns

| Parâmetro | Descrição | Padrão |
|:----------|:------------|:--------|
| `query` | Query de busca (obrigatória) | — |
| `granularity` | Tamanho do bucket de tempo | `hour` |
| `start_time` | Timestamp mais antigo (ISO 8601) | 30 dias atrás |
| `end_time` | Timestamp mais recente (ISO 8601) | Agora |
| `next_token` | Token de paginação | — |
