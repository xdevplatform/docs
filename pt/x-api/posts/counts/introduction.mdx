Os endpoints de Post counts retornam o volume de Posts que correspondem a uma query ao longo do tempo, sem retornar os Posts em si. Use estes endpoints para analisar tendências, entender o tamanho de uma conversa e refinar queries antes de pesquisar.

## Endpoints

| Endpoint | Descrição | Acesso |
|:---------|:------------|:-------|
| GET [`/2/tweets/counts/recent`](/x-api/posts/get-count-of-recent-posts) | Contar Posts dos últimos 7 dias | Todos os desenvolvedores |
| GET [`/2/tweets/counts/all`](/x-api/posts/get-count-of-all-posts) | Contar Posts do arquivo completo | Pay-per-use, Enterprise |

## Opções de granularidade

Especifique como as contagens são agrupadas usando o parâmetro `granularity`:

| Granularidade | Descrição | Caso de uso |
|:------------|:------------|:---------|
| `minute` | Contagens por minuto | Monitoramento em tempo real |
| `hour` | Contagens por hora (padrão) | Análise diária |
| `day` | Contagens por dia | Tendências de longo prazo |

## Recent counts

Conte Posts dos **últimos 7 dias**. Disponível para todos os desenvolvedores.

### Recursos

- Contagens agrupadas por minuto, hora ou dia
- Mesmos operadores de query do recent search
- Query de 512 caracteres

### Exemplo de resposta

```json
{
  "data": [
    { "start": "2024-01-15T00:00:00.000Z", "end": "2024-01-15T01:00:00.000Z", "tweet_count": 1523 },
    { "start": "2024-01-15T01:00:00.000Z", "end": "2024-01-15T02:00:00.000Z", "tweet_count": 1247 },
    { "start": "2024-01-15T02:00:00.000Z", "end": "2024-01-15T03:00:00.000Z", "tweet_count": 892 }
  ],
  "meta": {
    "total_tweet_count": 3662
  }
}
```

## Full-archive counts

Conte Posts do **arquivo completo** desde 2006.

<Note>
Full-archive counts estão disponíveis para clientes pay-per-use e Enterprise.
</Note>

### Recursos

- Conte Posts históricos de qualquer período
- Todos os operadores de query disponíveis
- Query de 1.024 caracteres (4.096 para Enterprise)

### Paginação

Os resultados paginam em 31 dias por resposta:
- **Granularidade day**: 31 dias por página
- **Granularidade hour**: 744 horas (31 dias) por página
- **Granularidade minute**: 44.640 minutos (31 dias) por página

## Operadores de query

Post counts usam a mesma sintaxe de query dos endpoints de busca:

```
python lang:en -is:retweet
```

## Notas importantes

<Note>
**Counts vs. resultados de busca**

As contagens podem não corresponder exatamente aos resultados de busca. Endpoints de busca aplicam filtragem de compliance adicional que os endpoints de counts não executam.
</Note>
