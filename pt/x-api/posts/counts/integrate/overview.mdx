Esta página cobre ferramentas e conceitos-chave para integrar os endpoints de Post counts.

## Ferramentas úteis

Antes de começarmos a explorar alguns conceitos-chave, recomendamos que você use uma das seguintes ferramentas ou amostras de código para começar a testar a funcionalidade destes endpoints.

### Amostras de código

Interessado em começar a usar esses endpoints com código na sua linguagem de programação preferida? Temos várias amostras de código diferentes disponíveis que você pode usar como ponto de partida em nossa [página do GitHub](https://github.com/xdevplatform/Twitter-API-v2-sample-code), incluindo um [cliente Python](https://github.com/xdevplatform/search-tweets-python).

### Bibliotecas

Aproveite uma de nossas várias [bibliotecas de terceiros da comunidade](/tools-and-libraries) para ajudar você a começar. Você pode encontrar uma biblioteca que funcione com os endpoints v2 procurando pela tag de versão apropriada.

### Postman

O Postman é uma ótima ferramenta que você pode usar para testar esses endpoints. Cada requisição do Postman inclui todos os parâmetros do endpoint em questão para ajudar você a entender rapidamente o que está disponível. Para saber mais sobre nossas coleções do Postman, visite a página [Usando o Postman](/tutorials/postman-getting-started).

## Conceitos-chave

### Autenticação

Todos os endpoints da X API v2 exigem que as requisições sejam [autenticadas](/resources/fundamentals/authentication) com um conjunto de credenciais, também conhecidas como chaves e tokens. Este endpoint específico exige o uso de [OAuth 2.0 Bearer Token](/resources/fundamentals/authentication#oauth-2-0), o que significa que você deve passar um [Bearer Token](/resources/fundamentals/authentication#bearer-token-also-known-as-app-only) para fazer uma requisição bem-sucedida. Você pode gerar um Bearer Token diretamente dentro de um App de desenvolvedor ou gerá-lo usando o endpoint [POST oauth2/token](/resources/fundamentals/authentication#post-oauth2-token).

### Developer Console, Projects e Apps de desenvolvedor

Para trabalhar com qualquer endpoint da X API v2, você deve ter uma [conta de desenvolvedor](/resources/fundamentals/developer-portal), configurar um [Project](/resources/fundamentals/developer-apps) dentro dessa conta e criar um [App de desenvolvedor](/resources/fundamentals/developer-apps) dentro desse Project. Suas chaves e tokens dentro desse App de desenvolvedor funcionarão para os endpoints de Post counts recentes. Se você quiser usar o endpoint de Post counts full-archive, ou utilizar os operadores avançados e o comprimento maior de query, será necessário ter sido aprovado para acesso enterprise.

Visite nossa seção sobre acesso enterprise para saber mais.

### Rate limits

Todos os dias, muitos milhares de desenvolvedores fazem requisições à X API. Para ajudar a gerenciar o volume, [rate limits](/x-api/fundamentals/rate-limits) são aplicados em cada endpoint, limitando o número de requisições que cada desenvolvedor pode fazer em nome de um app ou em nome de um usuário autenticado.

Este endpoint tem rate limit no nível do App, ou seja, você, o desenvolvedor, só pode fazer um determinado número de requisições a este endpoint em um determinado período de tempo a partir de qualquer App (identificado pelas credenciais que você está usando).

### Criando queries

O recurso central desses endpoints é o uso de uma única query para filtrar os Posts nas contagens entregues a você. Essas queries são compostas por operadores que correspondem a atributos de Post e de usuário, como palavras-chave da mensagem, hashtags e URLs. Operadores podem ser combinados em queries com lógica booleana e parênteses para ajudar a refinar o comportamento de correspondência da query.

Você pode usar nosso guia sobre [como criar uma query](/x-api/posts/counts/integrate/build-a-query) para saber mais.

### Paginação

Para Post counts recentes, não há next_token retornado, o que significa que, independentemente da granularidade, você obterá o volume de Posts dos últimos 7 dias em uma única chamada de API.

Para Post counts full-archive, você obterá dados dos últimos 30 dias. Para dados de mais de 30 dias, você receberá um next_token que poderá usar para paginar e obter os dados adicionais.
