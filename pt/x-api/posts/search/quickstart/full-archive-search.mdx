Este guia mostra como fazer sua primeira requisição de full-archive search para encontrar Posts do arquivo completo da X, desde março de 2006.

<Warning>
O full-archive search requer acesso [Self-serve](/x-api/getting-started/about-x-api) ou [Enterprise](/x-api/getting-started/about-x-api). [Atualize seu acesso](https://developer.x.com/en/portal/products) para usar este endpoint.
</Warning>

<Note>
**Pré-requisitos**

Antes de começar, você precisará de:
- Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info)
- O Bearer Token do seu App (encontrado no Developer Console em "Keys and tokens")
</Note>

---

## Passo 1: crie uma query

O full-archive search suporta todos os operadores de query. Crie queries da mesma forma que no recent search:

```
from:XDevelopers lang:en
```

<Tip>
O full-archive search suporta queries de até 1.024 caracteres (4.096 para Enterprise).
</Tip>

---

## Passo 2: defina um intervalo de tempo

Por padrão, os resultados retornam Posts dos últimos 30 dias. Use `start_time` e `end_time` para pesquisar períodos específicos:

| Parâmetro | Formato | Exemplo |
|:----------|:-------|:--------|
| `start_time` | ISO 8601 | `2020-01-01T00:00:00Z` |
| `end_time` | ISO 8601 | `2020-12-31T23:59:59Z` |

---

## Passo 3: faça uma requisição

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/tweets/search/all?\
query=from%3AXDevelopers&\
start_time=2020-01-01T00%3A00%3A00Z&\
end_time=2020-12-31T23%3A59%3A59Z&\
max_results=100" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Full-archive search com paginação
for page in client.posts.search_all(
    query="from:XDevelopers",
    start_time="2020-01-01T00:00:00Z",
    end_time="2020-12-31T23:59:59Z",
    max_results=100
):
    for post in page.data:
        print(post.text)
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Full-archive search com paginação
const paginator = client.posts.searchAll({
  query: "from:XDevelopers",
  startTime: "2020-01-01T00:00:00Z",
  endTime: "2020-12-31T23:59:59Z",
  maxResults: 100,
});

for await (const page of paginator) {
  page.data?.forEach((post) => {
    console.log(post.text);
  });
}
```

## Passo 5: adicione fields e expansions

Solicite dados adicionais com query parameters:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/tweets/search/all?\
query=from%3AXDevelopers&\
start_time=2020-01-01T00%3A00%3A00Z&\
end_time=2020-12-31T23%3A59%3A59Z&\
tweet.fields=created_at,public_metrics,author_id&\
expansions=author_id&\
user.fields=username,description&\
max_results=100" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Search com fields e expansions
for page in client.posts.search_all(
    query="from:XDevelopers",
    start_time="2020-01-01T00:00:00Z",
    end_time="2020-12-31T23:59:59Z",
    tweet_fields=["created_at", "public_metrics", "author_id"],
    expansions=["author_id"],
    user_fields=["username", "description"],
    max_results=100
):
    for post in page.data:
        print(f"{post.created_at}: {post.text[:50]}...")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Search com fields e expansions
const paginator = client.posts.searchAll({
  query: "from:XDevelopers",
  startTime: "2020-01-01T00:00:00Z",
  endTime: "2020-12-31T23:59:59Z",
  tweetFields: ["created_at", "public_metrics", "author_id"],
  expansions: ["author_id"],
  userFields: ["username", "description"],
  maxResults: 100,
});

for await (const page of paginator) {
  page.data?.forEach((post) => {
    console.log(`${post.created_at}: ${post.text?.slice(0, 50)}...`);
  });
}
```

## Passo 6: pagine pelos resultados

Os SDKs lidam com a paginação automaticamente. Para cURL, use o `next_token` da resposta:

```bash
curl "https://api.x.com/2/tweets/search/all?\
query=from%3AXDevelopers&\
max_results=500&\
next_token=b26v89c19zqg8o3fo7gesq314yb9l2l4ptqy" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

## Principais diferenças em relação ao recent search

| Recurso | Recent Search | Full-Archive Search |
|:--------|:--------------|:--------------------|
| Intervalo de tempo | Últimos 7 dias | Março de 2006 até agora |
| Acesso necessário | Todos os desenvolvedores | Pay-per-use, Enterprise |
| Máx. de resultados por requisição | 100 | 500 |
| Tamanho da query | 512 chars | 1.024 chars |
| Rate limit | 450 / 15 min | 300 / 15 min, 1 / seg |
| Autenticação | App-Only, User Context | App-Only |

---

## Parâmetros comuns

| Parâmetro | Descrição | Padrão |
|:----------|:------------|:--------|
| `query` | Query de busca (obrigatória) | — |
| `max_results` | Posts por página (10-500) | 10 |
| `start_time` | Timestamp do Post mais antigo | 30 dias atrás |
| `end_time` | Timestamp do Post mais recente | Agora |
| `next_token` | Token de paginação | — |
| `tweet.fields` | Fields adicionais de Post | `id`, `text` |
| `expansions` | Objetos relacionados a incluir | — |
