## Comparando os endpoints Search Posts da X API

O endpoint Search Tweets da v2 acabará por substituir o endpoint [standard v1.1 search/posts](/x-api/posts/search/introduction) e a [enterprise Search API](/x-api/enterprise-gnip-2.0/fundamentals/search-api). Se você tem código, apps ou ferramentas que usam uma versão mais antiga de um endpoint de busca da X e está considerando migrar para os endpoints mais recentes da X API v2, este guia é para você.

---

**Comparação de operadores de filtragem**

As quatro versões diferentes (standard, enterprise e v2) do search Posts diferem em quais operadores estão disponíveis e também têm níveis variados de disponibilidade de operadores dentro de cada versão, que são explicados abaixo.

Enterprise

* Não há subníveis de operadores enterprise

X API v2

* **Self-serve:** Disponível ao usar qualquer Project
* **Enterprise:** Disponível ao usar um Project

Você pode aprender mais sobre cada um desses conjuntos de operadores em seus respectivos guias:

* [Operadores Enterprise](/x-api/enterprise-gnip-2.0/fundamentals/search-api#available-operators)
* [Operadores da X API v2](/x-api/posts/search/integrate/build-a-query#operators)
