## Comparando os endpoints de gerenciar Posts da X API

Os endpoints de gerenciar Posts da v2 substituirão os endpoints standard v1.1 [POST statuses/update](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-update) e [POST statuses/destroy/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-destroy-id). Se você tem código, apps ou ferramentas que usam a versão v1.1 dos endpoints de gerenciar Posts e está considerando migrar para o endpoint mais novo da X API v2, este conjunto de guias é para você.

As tabelas a seguir comparam os endpoints de gerenciar Posts do standard v1.1 e da X API v2:

### Criar um Post

| Descrição | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP suportados | POST | POST |
| Domínio do host | https://api.x.com | https://api.x.com |
| Caminho do endpoint | /1.1/statuses/update.json | /2/tweets |
| [Autenticação](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br/><br/>OAuth 2.0 Authorization Code com PKCE |
| [Rate limits](/x-api/fundamentals/rate-limits) padrão de requisição | Nenhum<br/><br/>300 requisições por janela de 3 horas por usuário, por app. Compartilhado com o endpoint v1.1 POST Retweets. | 200 requisições por 15 min por usuário<br/><br/>300 requisições por janela de 3 horas por usuário, por app. Compartilhado com o endpoint v2 POST Retweets. |
| Requer o uso de credenciais de um [App de desenvolvedor](/resources/fundamentals/developer-apps) associado a um [Project](/resources/fundamentals/developer-apps) |     | ✔   |

### Excluir um Post

| Descrição | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP suportados | POST | DELETE |
| Domínio do host | https://api.x.com | https://api.x.com |
| Caminho do endpoint | /1.1/statuses/destroy/:id.json | /2/tweets/:id |
| [Autenticação](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br/><br/>OAuth 2.0 Authorization Code com PKCE |
| [Rate limits](/x-api/fundamentals/rate-limits) padrão de requisição | Nenhum | 50 requisições por 15 min por usuário |
| Requer o uso de credenciais de um [App de desenvolvedor](/resources/fundamentals/developer-apps) associado a um [Project](/resources/fundamentals/developer-apps) |     | ✔   |
