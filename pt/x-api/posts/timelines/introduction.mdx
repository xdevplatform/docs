Os endpoints Timelines permitem recuperar Posts de timelines de usuário, feeds de menções e home feeds. Obtenha o conteúdo publicado por um usuário, veja quais Posts o mencionam ou visualize a home timeline personalizada.

## Endpoints

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/tweets`](/x-api/users/get-posts) | Obter Posts de um usuário |
| GET | [`/2/users/:id/mentions`](/x-api/users/get-mentions) | Obter Posts mencionando um usuário |
| GET | [`/2/users/:id/timelines/reverse_chronological`](/x-api/users/get-timeline) | Obter home timeline |

## Timeline de Posts do usuário

Obtenha os Posts mais recentes criados por um usuário específico.

### Recursos

- Até 3.200 Posts mais recentes
- Filtre replies e retweets
- Suporte a paginação
- Acesso histórico com filtragem baseada em tempo

## Home timeline em ordem cronológica reversa

Obtenha a home timeline do usuário autenticado em ordem cronológica reversa.

### Recursos

- Posts de contas seguidas
- 3.200 Posts mais recentes (ou 7 dias)
- Exclui ranking algorítmico
- Requer autenticação de usuário

<Note>
Este endpoint requer [OAuth 1.0a User Context](/resources/fundamentals/authentication) ou [OAuth 2.0 Authorization Code com PKCE](/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2).
</Note>

## Opções de filtragem

### Parâmetro exclude

Filtre tipos específicos de Post:

| Valor | Efeito |
|:------|:-------|
| `retweets` | Excluir retweets |
| `replies` | Excluir replies |

```bash
curl "https://api.x.com/2/users/123/tweets?exclude=retweets,replies" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

### Filtragem baseada em tempo

| Parâmetro | Descrição |
|:----------|:------------|
| `start_time` | Timestamp do Post mais antigo (ISO 8601) |
| `end_time` | Timestamp do Post mais recente (ISO 8601) |
| `since_id` | Retornar Posts após este ID |
| `until_id` | Retornar Posts antes deste ID |
