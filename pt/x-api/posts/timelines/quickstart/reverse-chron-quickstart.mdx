Este guia mostra como fazer sua primeira requisição ao endpoint de home timeline em ordem cronológica reversa.

<Note>
**Pré-requisitos**

Antes de começar, você precisará de:
- Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info) com um App aprovado
- User Access Tokens (este endpoint requer autenticação de usuário)
</Note>

---

## Passo 1: obtenha o ID do usuário

Você precisa do ID de usuário da conta cuja home timeline você quer recuperar. Encontre-o usando o endpoint de busca por username:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/by/username/XDevelopers" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python Python SDK
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

response = client.users.get_by_username("XDevelopers")
print(f"User ID: {response.data.id}")
```

```javascript JavaScript SDK
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

const response = await client.users.getByUsername("XDevelopers");
console.log(`User ID: ${response.data?.id}`);
```

</CodeGroup>

A resposta inclui o ID do usuário:

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",
    "username": "XDevelopers"
  }
}
```

## Passo 2: solicite a home timeline

Faça uma requisição GET com o ID do usuário e User Access Token:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/2244994945/timelines/reverse_chronological" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python Python SDK
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# Obter home timeline com paginação
for page in client.posts.get_home_timeline("2244994945"):
    for post in page.data:
        print(post.text)
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// Obter home timeline com paginação
const paginator = client.posts.getHomeTimeline("2244994945");

for await (const page of paginator) {
  page.data?.forEach((post) => {
    console.log(post.text);
  });
}
```

</CodeGroup>

## Passo 4: adicione fields e expansions

Solicite dados adicionais com query parameters:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/2244994945/timelines/reverse_chronological?\
tweet.fields=created_at,public_metrics,author_id&\
expansions=author_id&\
user.fields=username,verified&\
max_results=10" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# Obter home timeline com fields e expansions
for page in client.posts.get_home_timeline(
    "2244994945",
    tweet_fields=["created_at", "public_metrics", "author_id"],
    expansions=["author_id"],
    user_fields=["username", "verified"],
    max_results=10
):
    for post in page.data:
        print(f"{post.text[:50]}... - Likes: {post.public_metrics.like_count}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// Obter home timeline com fields e expansions
const paginator = client.posts.getHomeTimeline("2244994945", {
  tweetFields: ["created_at", "public_metrics", "author_id"],
  expansions: ["author_id"],
  userFields: ["username", "verified"],
  maxResults: 10,
});

for await (const page of paginator) {
  page.data?.forEach((post) => {
    console.log(`${post.text?.slice(0, 50)}... - Likes: ${post.public_metrics?.like_count}`);
  });
}
```

</CodeGroup>

## Passo 5: pagine pelos resultados

Os SDKs lidam com a paginação automaticamente. Para cURL, use o `next_token` da resposta para obter mais resultados:

```bash
curl "https://api.x.com/2/users/2244994945/timelines/reverse_chronological?\
max_results=10&\
pagination_token=7140dibdnow9c7btw421dyz6jism75z99gyxd8egarsc4" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

---

## Parâmetros comuns

| Parâmetro | Descrição | Padrão |
|:----------|:------------|:--------|
| `max_results` | Resultados por página (1-100) | 10 |
| `start_time` | Timestamp do Post mais antigo (ISO 8601) | — |
| `end_time` | Timestamp do Post mais recente (ISO 8601) | — |
| `since_id` | Retornar Posts após este ID | — |
| `until_id` | Retornar Posts antes deste ID | — |
| `exclude` | Excluir `retweets`, `replies` ou ambos | — |
