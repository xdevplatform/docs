## Timelines do Standard v1.1 para timelines da X API v2

Se você tem trabalhado com os endpoints de timelines v1.1 (statuses/user\_timeline e statuses/mentions\_timeline), o objetivo deste guia é ajudar você a entender as similaridades e diferenças entre os endpoints de timelines do standard e da X API v2 para que você possa migrar sua integração atual para a nova versão.

* **Similaridades:**
    * Autenticação:
        * OAuth 1.0a User Context (reverse chronological home timeline, user Post timeline e user mentions timeline)
        * OAuth 2.0 App-Only (user Post timeline)
    * Limite de acesso histórico: A user timeline (user Post timeline) fornece acesso aos 3200 Posts mais recentes; a mentions timeline (user mention timeline) fornece acesso às 800 menções mais recentes.
    * Suporte para histórico de edições e metadados de Post
    * Rate limits (user Post timeline)
    * Polling de atualização: Capacidade de recuperar novos resultados desde o since_id
    * Percorrer timelines por IDs de Post
    * Especificações dos resultados:
        * Ordem dos resultados: Resultados retornados em ordem cronológica reversa
        * Capacidade de excluir replies (apenas user Post timeline)
        * Capacidade de excluir Retweets (apenas user Post timeline)
* **Diferenças**
    * Nova capacidade de autenticação: 
        * OAuth 2.0 App-Only (user mention timeline)
        * OAuth 2.0 Authorization Code Flow com PKCE (reverse chronological home timeline, user Post timeline e user mentions timeline)
    * Requisitos de acesso: Requisitos de App e Project da X API v2
    * Rate limits (user mention timeline e reverse chronological home timeline)
    * Método de paginação adicional
        * Diferente max_results (count) por resposta
    * Formato dos dados de resposta
    * Parâmetros de requisição
        * Personalização
