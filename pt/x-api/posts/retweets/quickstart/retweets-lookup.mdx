Este guia mostra como recuperar os usuários que Retweetaram um Post específico.

<Note>
**Pré-requisitos**

Antes de começar, você precisará de:
- Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info) com um App aprovado
- O Bearer Token do seu App (para dados públicos) ou User Access Token (para métricas privadas)
</Note>

## Obter usuários que Retweetaram um Post

<Steps>
  <Step title="Encontre o ID do Post">
    Obtenha o ID do Post para o qual você quer consultar os Retweets:

    ```
    https://x.com/XDevelopers/status/1354143047324299264
                                    └── Este é o ID do Post
    ```
  </Step>

  <Step title="Faça a requisição">

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/tweets/1354143047324299264/retweeted_by?\
user.fields=created_at,username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python Python SDK
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obter usuários que Retweetaram um Post com paginação
for page in client.posts.get_retweeted_by(
    "1354143047324299264",
    user_fields=["created_at", "username", "verified"]
):
    for user in page.data:
        print(f"{user.username} - Joined: {user.created_at}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Obter usuários que Retweetaram um Post com paginação
const paginator = client.posts.getRetweetedBy("1354143047324299264", {
  userFields: ["created_at", "username", "verified"],
});

for await (const page of paginator) {
  page.data?.forEach((user) => {
    console.log(`${user.username} - Joined: ${user.created_at}`);
  });
}
```

## Inclua dados adicionais

Use expansions para obter dados relacionados, como Posts fixados:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/tweets/1354143047324299264/retweeted_by?\
user.fields=created_at&\
expansions=pinned_tweet_id&\
tweet.fields=created_at" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obter usuários que Retweetaram com expansions
for page in client.posts.get_retweeted_by(
    "1354143047324299264",
    user_fields=["created_at"],
    expansions=["pinned_tweet_id"],
    tweet_fields=["created_at"]
):
    for user in page.data:
        print(f"{user.username}")
    # Posts fixados estão em page.includes.tweets
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Obter usuários que Retweetaram com expansions
const paginator = client.posts.getRetweetedBy("1354143047324299264", {
  userFields: ["created_at"],
  expansions: ["pinned_tweet_id"],
  tweetFields: ["created_at"],
});

for await (const page of paginator) {
  page.data?.forEach((user) => {
    console.log(user.username);
  });
  // Posts fixados estão em page.includes?.tweets
}
```
