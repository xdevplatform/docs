## Comparando os endpoints de Retweets da X API

**Consulta de Retweets**

O endpoint de consulta de Retweets da v2 substituirá os endpoints standard [v1.1 GET statuses/retweets/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/get-statuses-retweets-id) e [v1.1 GET statuses/retweets/:ids](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/get-statuses-retweeters-ids).

As tabelas a seguir comparam os endpoints de Retweets do standard v1.1 e da X API v2:

| Descrição | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP suportados | GET | GET |
| Domínio do host | https://api.x.com | https://api.x.com |
| Caminho do endpoint | /1.1/retweeters/id.json<br/><br/>`/1.1/retweets/ids.json` | /2/users/:id/retweeted_by |
| [Autenticação](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 2.0 Bearer Token<br/><br/>OAuth 1.0a User Context |
| [Rate limits](/resources/fundamentals/rate-limits) padrão de requisição | 75 requisições por 15 min | 75 requisições por 15 min (por App)<br/><br/>75 requisições por 15 min (por usuário) |
| Formato de dados | Formato Standard v1.1 | [Formato X API v2](/x-api/fundamentals/data-dictionary) (determinado pelos parâmetros de requisição fields e expansions, não compatível com versões anteriores do v1.1)<br/><br/>Para saber mais sobre como migrar do formato Standard v1.1 para o formato X API v2, visite nosso [guia de migração de formatos de dados](/x-api/migrate/data-format-migration). |
| Requer o uso de credenciais de um [App de desenvolvedor](/resources/fundamentals/developer-apps) associado a um [Project](/resources/fundamentals/developer-apps) |     | ✔️  |

### Gerenciar Retweets

As tabelas a seguir comparam o endpoint de desfazer Retweet do standard v1.1 e da X API v2:

**Retweetar um Post**

| Descrição | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP suportados | POST | POST |
| Domínio do host | https://api.x.com | https://api.x.com |
| Caminho do endpoint | /1.1/statuses/retweet/:id.json | /2/users/:id/retweets |
| [Autenticação](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| [Rate limits](/resources/fundamentals/rate-limits) padrão de requisição | Nenhum<br/><br/>300 requisições por janela de 3 horas (por usuário, por app). Isso é compartilhado com o endpoint POST Tweet | 50 requisições por 15 min (por usuário)<br/><br/>300 requisições por janela de 3 horas (por usuário, por app). Isso é compartilhado com o endpoint POST Tweet para gerenciar Posts. |
| Requer o uso de credenciais de um [App de desenvolvedor](/resources/fundamentals/developer-apps) associado a um [Project](/resources/fundamentals/developer-apps) |     | ✔️  |
