## Apps que usam o endpoint hide replies

Aqui está uma coleção de apps notáveis criados por desenvolvedores que integraram o endpoint hide replies. Ao combinar sua tecnologia com a X API, eles criaram experiências úteis para ajudar todos os usuários a melhorar a conversa pública.

 ![Clarabridge](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/clarabridge.jpg.twimg.1920.jpg)

**Clarabridge**

A Clarabridge integra o hide replies para que as empresas possam manter seu feed do X limpo e interessante de ler. As replies podem ser ocultadas manualmente e os agentes também podem usar a análise de texto da Clarabridge para detectar automaticamente palavrões e outra linguagem que não esteja alinhada com a política da marca.

[Ir para o site ▸](https://www.clarabridge.com/ "Ir para o site ▸")

[Clarabridge no X](https://x.com/Clarabridge "Clarabridge no X")

 ![App template Perspective API](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/perspective-logo.png.twimg.1920.png)

**App template Perspective API**

O Perspective é uma inteligência artificial treinada pela Jigsaw (uma unidade da Alphabet) para detectar comentários tóxicos. Este app detecta as replies recebidas de uma pessoa e oculta automaticamente uma reply com base na "pontuação" que indica o quão confiante o Perspective está de que um comentário é semelhante a comentários tóxicos que já viu no passado. Este é um app template open source desenvolvido pelo X. Encorajamos você a personalizá-lo para criar ferramentas para seus usuários.

[Usar o app ▸](https://quintessential-yoke.glitch.me "Usar o app ▸")

[Jigsaw no X](https://x.com/jigsaw "Jigsaw no X")

 ![Reshuffle](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 150 150%22%3E%3C/svg%3E)

**Reshuffle**

O Reshuffle é uma plataforma para conectar aplicações de negócios com scripts flexíveis. Eles criaram um script de integração para detectar e ocultar replies que incluem palavras-chave que você define. Para testar, garanta que você tenha um app válido habilitado para Hide replies e depois siga as instruções no repositório.

[Ir para o app ▸](https://github.com/reshufflehq/reshuffle "Ir para o app ▸")

[Reshuffle no X](https://x.com/reshufflehq "Reshuffle no X")

 ![Hide unwanted replies](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 396 397%22%3E%3C/svg%3E)

**Hide unwanted replies**

Dara Oladosu, o desenvolvedor por trás do popular app QuotedReplies, criou um app que oculta automaticamente replies que atendem a alguns dos critérios que ele determinou como mais propensos a exibir comportamento abusivo, incluindo replies que contêm certas palavras-chave que ele silenciou no passado.

[Ir para o app ▸](https://hideunwantedreplies.com/ "Ir para o app ▸")

[Dara Oladosu no X](https://x.com/dara_tobi "Dara Oladosu no X")

 ![Pandaflow](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 94 94%22%3E%3C/svg%3E)

**Pandaflow**

O Pandaflow é uma plataforma no code para automatizar fluxos de trabalho. Eles integram o endpoint para que os usuários possam ocultar replies programaticamente com base em um fluxo personalizado que definirem.
