O endpoint Hide Replies permite ocultar ou reexibir replies a Posts criados pelo usuário autenticado. Replies ocultas ainda são acessíveis, mas exigem um clique extra para serem visualizadas.

## Endpoint

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| PUT | [`/2/tweets/:tweet_id/hidden`](/x-api/posts/hide-reply) | Ocultar ou reexibir uma reply |

---

## Como funciona

Envie uma requisição PUT com `hidden: true` para ocultar uma reply, ou `hidden: false` para reexibi-la:

```json
{
  "hidden": true
}
```

---

## Exemplo: ocultar uma reply

```bash
curl -X PUT "https://api.x.com/2/tweets/1234567890/hidden" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"hidden": true}'
```

## Exemplo de resposta

```json
{
  "data": {
    "hidden": true
  }
}
```
