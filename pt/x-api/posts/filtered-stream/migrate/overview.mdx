## Comparando os endpoints de filtered stream da X API

O grupo de endpoints de filtered stream da v2 está substituindo o [standard v1.1 statuses/filter](https://developer.x.com/en/docs/x-api/v1/tweets/filter-realtime/api-reference/post-statuses-filter) e a [PowerTrack API](/x-api/enterprise-gnip-2.0/powertrack-api). Se você tem código, apps ou ferramentas que usam uma versão mais antiga do endpoint de filtered stream, e está considerando migrar para o endpoint mais novo da X API v2, esta comparação pode ajudar você a começar.

Veja nossos guias de migração mais aprofundados para:

[Migrando do Standard v1.1 em comparação com a X API v2](x-api/posts/filtered-stream#standard-v1-1-compared-to-x-api-v2)

[Migrando da PowerTrack API para a X API v2](/x-api/enterprise-gnip-2.0/powertrack-api#powertrack-operators)

A tabela a seguir compara os endpoints de streaming filtrado que a X oferece:

| Acesso | X App | Requer um contrato e conta enterprise | Requer uma conta de desenvolvedor ([inscreva-se](https://developer.x.com/en/portal/petition/essential/basic-info)) e um [X App](/resources/fundamentals/developer-apps) dentro de um [Project](/resources/fundamentals/developer-apps) |
| :--- | :--- | :--- | :--- |

| [Autenticação](/resources/fundamentals/authentication) | OAuth 1.0a User Context | HTTP Basic Authentication | OAuth 2.0 App-Only |
| Métodos HTTP suportados | POST | GET  <br/>POST | GET  <br/>POST |
| Parâmetros obrigatórios | Regra definida na conexão como parâmetro, pelo menos um de:<br/><br/>* **follow**<br/>* **track**<br/>* **locations** | Sem parâmetros obrigatórios para conexão de streaming, parâmetro backfill opcional.<br/><br/>Regras gerenciadas separadamente | Sem parâmetros obrigatórios para conexão de streaming, parâmetros opcionais para definir o formato de resposta e adicionar o [recurso de recuperação backfill](/x-api/fundamentals/recovery-and-redundancy) para acesso Academic Research.<br/><br/>Regras gerenciadas separadamente |
