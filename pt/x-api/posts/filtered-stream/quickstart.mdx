Este guia mostra como se conectar ao filtered stream para receber Posts em quase tempo real que correspondam às suas regras de filtro.

<Note>
**Pré-requisitos**

Antes de começar, você precisará de:
- Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info)
- O Bearer Token do seu App (encontrado no Developer Console em "Keys and tokens")
</Note>

---

<Steps>
  <Step title="Crie uma regra de filtro" icon="/icons/xds/icon-filter.svg">
    Regras definem quais Posts receber. Use operadores para corresponder a palavras-chave, hashtags, usuários e muito mais.

    **Exemplo de regra:** Corresponde a Posts contendo "cat" com imagens:

    ```
    cat has:images
    ```

    <Card title="Criar uma regra" icon="/icons/xds/icon-filter.svg" href="/x-api/posts/filtered-stream/integrate/build-a-rule">
      Aprenda a sintaxe de regras e os operadores
    </Card>
  </Step>

  <Step title="Adicione a regra ao seu stream" icon="plus">
    Adicione sua regra usando o endpoint de regras. Inclua uma `tag` para identificar qual regra correspondeu a cada Post:

<CodeGroup dropdown>

```bash cURL
curl -X POST "https://api.x.com/2/tweets/search/stream/rules" \
  -H "Authorization: Bearer $BEARER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "add": [
      {"value": "cat has:images", "tag": "cats with images"}
    ]
  }'
```

```python Python SDK
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Adicionar uma regra ao filtered stream
response = client.filtered_stream.add_rules(
    add=[{"value": "cat has:images", "tag": "cats with images"}]
)

for rule in response.data:
    print(f"Rule added: {rule.id} - {rule.value}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Adicionar uma regra ao filtered stream
const response = await client.filteredStream.addRules({
  add: [{ value: "cat has:images", tag: "cats with images" }],
});

response.data?.forEach((rule) => {
  console.log(`Rule added: ${rule.id} - ${rule.value}`);
});
```

</CodeGroup>

    **Resposta:**

    ```json
    {
      "data": [
        {
          "id": "1273026480692322304",
          "value": "cat has:images",
          "tag": "cats with images"
        }
      ],
      "meta": {
        "sent": "2024-01-15T10:30:00.000Z",
        "summary": {
          "created": 1,
          "not_created": 0,
          "valid": 1,
          "invalid": 0
        }
      }
    }
    ```
  </Step>

  <Step title="Verifique suas regras" icon="check">
    Liste todas as regras ativas para confirmar que sua regra foi adicionada:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/tweets/search/stream/rules" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python Python SDK
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obter todas as regras ativas
response = client.filtered_stream.get_rules()

for rule in response.data:
    print(f"Active rule: {rule.id} - {rule.value}")
```

```javascript JavaScript SDK
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Obter todas as regras ativas
const response = await client.filteredStream.getRules();

response.data?.forEach((rule) => {
  console.log(`Active rule: ${rule.id} - ${rule.value}`);
});
```

</CodeGroup>

  </Step>

  <Step title="Conecte-se ao stream" icon="plug">
    Abra uma conexão persistente para receber Posts correspondentes:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/tweets/search/stream?\
tweet.fields=created_at,author_id&\
expansions=author_id&\
user.fields=username" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Conectar ao filtered stream
for post in client.filtered_stream.stream(
    tweet_fields=["created_at", "author_id"],
    expansions=["author_id"],
    user_fields=["username"]
):
    print(f"New post: {post.data.text}")
    print(f"Matching rules: {post.matching_rules}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Conectar ao filtered stream
const stream = client.filteredStream.stream({
  tweetFields: ["created_at", "author_id"],
  expansions: ["author_id"],
  userFields: ["username"],
});

for await (const post of stream) {
  console.log(`New post: ${post.data?.text}`);
  console.log(`Matching rules: ${post.matching_rules}`);
}
```

</CodeGroup>

  </Step>

  <Step title="Processe os Posts recebidos" icon="/icons/xds/icon-chat.svg">
    Posts correspondentes são transmitidos como objetos JSON:

    ```json
    {
      "data": {
        "id": "1234567890",
        "text": "Look at this cute cat! 🐱",
        "author_id": "9876543210",
        "created_at": "2024-01-15T10:35:00.000Z",
        "edit_history_tweet_ids": ["1234567890"]
      },
      "includes": {
        "users": [
          {
            "id": "9876543210",
            "username": "catperson"
          }
        ]
      },
      "matching_rules": [
        {
          "id": "1273026480692322304",
          "tag": "cats with images"
        }
      ]
    }
    ```

    <Tip>
    O array `matching_rules` mostra quais regras corresponderam ao Post, usando as tags que você definiu.
    </Tip>
  </Step>

  <Step title="Excluir regras (opcional)" icon="trash">
    Remova regras pelo ID:

<CodeGroup dropdown>

```bash cURL
curl -X POST "https://api.x.com/2/tweets/search/stream/rules" \
  -H "Authorization: Bearer $BEARER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "delete": {
      "ids": ["1273026480692322304"]
    }
  }'
```

```python Python SDK
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Excluir regras por ID
response = client.filtered_stream.delete_rules(
    delete={"ids": ["1273026480692322304"]}
)
print(f"Deleted: {response.meta.summary.deleted}")
```

```javascript JavaScript SDK
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Excluir regras por ID
const response = await client.filteredStream.deleteRules({
  delete: { ids: ["1273026480692322304"] },
});
console.log(`Deleted: ${response.meta?.summary?.deleted}`);
```

## Gerenciando sua conexão

<AccordionGroup>
  <Accordion title="Sinais keep-alive">
    O stream envia linhas em branco (`\r\n`) a cada 20 segundos. Se você não receber dados ou um keep-alive por 20 segundos, reconecte.
  </Accordion>

  <Accordion title="Desconectando">
    Pressione `Ctrl+C` para fechar a conexão ou feche a janela do terminal.
  </Accordion>

  <Accordion title="Limites de conexão">
    Apenas uma conexão por App é permitida. Abrir uma nova conexão fechará qualquer conexão existente.
  </Accordion>
</AccordionGroup>
