## Comparando os endpoints de Likes da X API


Estes guias focarão nas seguintes áreas:

* **Parâmetros de requisição da API** - O endpoint da X API v2 introduz um novo conjunto de parâmetros de requisição. Embora alguns parâmetros sejam familiares, especialmente para aqueles que integram com o Labs, há muitas diferenças importantes, como a introdução dos parâmetros [fields](/x-api/fundamentals/fields) e [expansions](/x-api/fundamentals/expansions).

* **Requisitos de App e Project** \- Para acessar a X API v2, você precisará usar credenciais de um [App de desenvolvedor](/resources/fundamentals/developer-apps) associado a um [Project](/resources/fundamentals/developer-apps)

#### Consulta de likes
**Usuários que curtiram um Post**

O endpoint de liked users é uma nova funcionalidade da v2, permitindo obter informações sobre os usuários que curtiram um Post.

| Descrição | X API v2 |
| :--- | :--- |
| Métodos HTTP suportados | GET |
| Domínio do host | https://api.x.com |
| Caminho do endpoint | /2/tweets/:id/liking_users |
| [Autenticação](/resources/fundamentals/authentication) | OAuth 2.0 Bearer Token<br/><br/>OAuth 1.0a User Context |
| [Rate limits](/resources/fundamentals/rate-limits) padrão de requisição | 75 requisições por 15 min (por App)<br/><br/>75 requisições por 15 min (por usuário) |

**Posts curtidos por um usuário**

As tabelas a seguir comparam o endpoint standard v1.1 [GET favorites/list](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/get-favorites-list) e o endpoint de Posts curtidos da X API v2:

| Descrição | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP suportados | GET | GET |
| Domínio do host | https://api.x.com | https://api.x.com |
| Caminho do endpoint | /1.1/favorites/list.json | /2/users/:id/liked_tweets |
| [Autenticação](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 2.0 Bearer Token<br/><br/>OAuth 1.0a User Context |
| [Rate limits](/resources/fundamentals/rate-limits) padrão de requisição | 75 requisições por 15 min | 75 requisições por 15 min (por App)<br/><br/>75 requisições por 15 min (por usuário) |
| Formatos de dados | Formato Standard v1.1 | [Formato X API v2](/x-api/fundamentals/data-dictionary) (determinado pelos parâmetros de requisição fields e expansions, não compatível com versões anteriores do v1.1)<br/><br/>Para saber mais sobre como migrar do formato Standard v1.1 para o formato X API v2, visite nosso [guia de migração de formatos de dados](/x-api/migrate/data-format-migration). |


#### Gerenciar Likes

Os endpoints de gerenciamento de Likes da v2 substituem os endpoints v1.1 [POST favorites/create](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-favorites-create) e [POST favorites/destroy](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-favorites-destroy).

As tabelas a seguir comparam os endpoints de gerenciamento de Like do standard v1.1 e da X API v2:

#### Curtir um Post

| Descrição | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP suportados | POST | POST |
| Domínio do host | https://api.x.com | https://api.x.com |
| Caminho do endpoint | /1.1/favorites/create.json | /2/users/:id/likes |
| [Autenticação](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| [Rate limits](/resources/fundamentals/rate-limits) padrão de requisição | 1000 requisições por 24 horas (por usuário)<br/><br/>1000 requisições por 24 horas (por App) | 50 requisições por 15 min (por usuário)<br/><br/>1000 requisições por 24 horas (por usuário, compartilhado com DELETE) |

#### Descurtir um Post

| Descrição | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP suportados | POST | DELETE |
| Domínio do host | https://api.x.com | https://api.x.com |
| Caminho do endpoint | /1.1/favorites/destroy.json | /2/users/:id/likes/:tweet_id |
| [Autenticação](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| [Rate limits](/resources/fundamentals/rate-limits) padrão de requisição | 1000 requisições por 24 horas (por usuário)<br/><br/>1000 requisições por 24 horas (por App) | 50 requisições por 15 min (por usuário)<br/><br/>1000 requisições por 24 horas (por usuário, compartilhado com POST) |
