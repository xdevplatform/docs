Este guia mostra como curtir e descurtir Posts usando a X API.

<Note>
**Pré-requisitos**

Antes de começar, você precisará de:
- Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info) com um App aprovado
- User Access Token (OAuth 1.0a ou OAuth 2.0 PKCE)
</Note>

---

## Curtir um Post

<Steps>
  <Step title="Obtenha seu ID de usuário">
    Você precisa do ID do usuário autenticado. Você pode encontrá-lo usando o [endpoint de user lookup](/x-api/users/lookup/introduction) ou a partir do seu Access Token (a parte numérica é o seu ID de usuário).
  </Step>

  <Step title="Obtenha o ID do Post">
    Encontre o ID do Post na URL ao visualizar um Post:

    ```
    https://x.com/XDevelopers/status/1228393702244134912
                                    └── Este é o ID do Post
    ```
  </Step>

  <Step title="Envie a requisição de curtir">

<CodeGroup dropdown>

```bash cURL
curl -X POST "https://api.x.com/2/users/123456789/likes" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1228393702244134912"}'
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Curtir um Post
response = client.posts.like(
    user_id="123456789",
    tweet_id="1228393702244134912"
)

print(f"Liked: {response.data.liked}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// Curtir um Post
const response = await client.posts.like("123456789", {
  tweetId: "1228393702244134912",
});

console.log(`Liked: ${response.data?.liked}`);
```

</CodeGroup>

  </Step>

  <Step title="Revise a resposta">
    ```json
    {
      "data": {
        "liked": true
      }
    }
    ```
  </Step>
</Steps>

## Descurtir um Post

Remova um like de um Post:

<CodeGroup dropdown>

```bash cURL
curl -X DELETE "https://api.x.com/2/users/123456789/likes/1228393702244134912" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Descurtir um Post
response = client.posts.unlike(
    user_id="123456789",
    tweet_id="1228393702244134912"
)

print(f"Liked: {response.data.liked}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// Descurtir um Post
const response = await client.posts.unlike("123456789", "1228393702244134912");

console.log(`Liked: ${response.data?.liked}`);
```

</CodeGroup>

**Resposta:**

```json
{
  "data": {
    "liked": false
  }
}
```
