<Note>
**Pré-requisitos**

Antes de começar, você precisará de:

## Obter usuários que curtiram um Post

Recupere a lista de usuários que curtiram um Post específico:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/tweets/1354143047324299264/liking_users?\
user.fields=created_at,username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python Python SDK
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obter usuários que curtiram um Post com paginação
for page in client.posts.get_liking_users(
    "1354143047324299264",
    user_fields=["created_at", "username", "verified"]
):
    for user in page.data:
        print(f"{user.username} - Joined: {user.created_at}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Obter usuários que curtiram um Post com paginação
const paginator = client.posts.getLikingUsers("1354143047324299264", {
  userFields: ["created_at", "username", "verified"],
});

for await (const page of paginator) {
  page.data?.forEach((user) => {
    console.log(`${user.username} - Joined: ${user.created_at}`);
  });
}
```

## Obter os Posts curtidos por um usuário

Recupere os Posts que um usuário específico curtiu:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/2244994945/liked_tweets?\
tweet.fields=created_at,public_metrics&\
max_results=10" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obter Posts curtidos por um usuário com paginação
for page in client.users.get_liked_tweets(
    "2244994945",
    tweet_fields=["created_at", "public_metrics"],
    max_results=10
):
    for post in page.data:
        print(f"{post.text[:50]}... - Likes: {post.public_metrics.like_count}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Obter Posts curtidos por um usuário com paginação
const paginator = client.users.getLikedTweets("2244994945", {
  tweetFields: ["created_at", "public_metrics"],
  maxResults: 10,
});

for await (const page of paginator) {
  page.data?.forEach((post) => {
    console.log(`${post.text?.slice(0, 50)}... - Likes: ${post.public_metrics?.like_count}`);
  });
}
```

## Incluir dados adicionais

Use expansions para obter dados relacionados, como Posts fixados:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/tweets/1354143047324299264/liking_users?\
user.fields=created_at&\
expansions=pinned_tweet_id&\
tweet.fields=created_at" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obter usuários que curtiram com expansion de Post fixado
for page in client.posts.get_liking_users(
    "1354143047324299264",
    user_fields=["created_at"],
    expansions=["pinned_tweet_id"],
    tweet_fields=["created_at"]
):
    for user in page.data:
        print(f"{user.username}")
    # Posts fixados estão em page.includes.tweets
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Obter usuários que curtiram com expansion de Post fixado
const paginator = client.posts.getLikingUsers("1354143047324299264", {
  userFields: ["created_at"],
  expansions: ["pinned_tweet_id"],
  tweetFields: ["created_at"],
});

for await (const page of paginator) {
  page.data?.forEach((user) => {
    console.log(user.username);
  });
  // Posts fixados estão em page.includes?.tweets
}
```
