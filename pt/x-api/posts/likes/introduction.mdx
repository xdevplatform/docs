Os endpoints de Likes permitem curtir e descurtir Posts, ver quais usuários curtiram um Post e obter Posts curtidos por um usuário.

## Endpoints

### Consulta de likes

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| GET | [`/2/tweets/:id/liking_users`](/x-api/posts/get-liking-users) | Obter usuários que curtiram um Post |
| GET | [`/2/users/:id/liked_tweets`](/x-api/users/get-liked-posts) | Obter Posts curtidos por um usuário |

### Gerenciar likes

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| POST | [`/2/users/:id/likes`](/x-api/users/like-post) | Curtir um Post |
| DELETE | [`/2/users/:id/likes/:tweet_id`](/x-api/users/unlike-post) | Descurtir um Post |

---

## Notas importantes

<Note>
O endpoint de usuários que curtiram retorna no máximo **100 usuários** por Post, para todo o tempo, independentemente do número real de likes.
</Note>

---

## Exemplo: obter usuários que curtiram

```bash
curl "https://api.x.com/2/tweets/1234567890/liking_users?\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

## Exemplo: curtir um Post

```bash
curl -X POST "https://api.x.com/2/users/123456789/likes" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
