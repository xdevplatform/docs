* 1% sampled stream.
* 10% sampled stream. Comumente referido como "Decahose".

Estes são chamados de "volume streams" porque ambos entregam grandes volumes de dados. Mesmo o stream de 1% pode emitir várias dezenas de Posts a cada segundo. Com esses streams, você pode identificar e acompanhar tendências, monitorar o sentimento geral, monitorar eventos globais e muito mais.

Esses endpoints de streaming entregam [objetos Post](/x-api/fundamentals/data-dictionary/reference#tweet) por meio de uma conexão HTTP GET persistente e usam autenticação [OAuth 2.0 App-Only](/resources/fundamentals/authentication#oauth-2-0). Com acesso Essential, você pode ter uma conexão por vez. Com todos os níveis de acesso, requisições de conexão podem ser feitas até 50 vezes por janela de 15 minutos.

Estes endpoints de volume stream suportam Posts editados. Estes endpoints entregarão Posts editados, junto com seu histórico de edições, incluindo um array de IDs de Post. Para Posts sem histórico de edições, este array conterá um único ID. Para Posts que foram editados, este array contém múltiplos IDs, organizados em ordem crescente refletindo a ordem das edições, com a versão mais recente na última posição do array. Para saber mais sobre como funcionam as edições de Post, veja a página de [fundamentos de edições de Post](/x-api/fundamentals/edit-posts).

_Para usar essas APIs, você deve primeiro configurar uma conta com nossa equipe de vendas enterprise._

<Note>
**Configuração da conta**

Para acessar estes endpoints, você precisará de:

* Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info) aprovada.
* Autenticar usando as chaves e tokens de um [App de desenvolvedor](/resources/fundamentals/developer-apps) localizado dentro de um [Project](/resources/fundamentals/developer-apps). 

Saiba mais sobre como obter acesso aos endpoints da X API v2 em nosso [guia de introdução](/x-api/getting-started/getting-access).
</Note>
