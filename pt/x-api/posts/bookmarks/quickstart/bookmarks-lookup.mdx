Este guia mostra como recuperar seus Posts marcados como favoritos usando a X API.

<Note>
**Pré-requisitos**

Antes de começar, você precisará de:
- Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info) com um App aprovado
- User Access Token com o escopo `bookmark.read` (OAuth 2.0 PKCE)
</Note>

---

## Obtenha seus bookmarks

<Steps>
  <Step title="Obtenha seu ID de usuário">
    Você precisa do ID do usuário autenticado. Você pode encontrá-lo usando o endpoint `/2/users/me` ou pelo [endpoint de user lookup](/x-api/users/lookup/introduction).
  </Step>

  <Step title="Solicite seus bookmarks">

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/2244994945/bookmarks?\
tweet.fields=created_at,public_metrics,author_id&\
max_results=10" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# Obter Posts marcados como favoritos com paginação
for page in client.bookmarks.get(
    "2244994945",
    tweet_fields=["created_at", "public_metrics", "author_id"],
    max_results=10
):
    for post in page.data:
        print(f"{post.text[:50]}... - Likes: {post.public_metrics.like_count}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// Obter Posts marcados como favoritos com paginação
const paginator = client.bookmarks.get("2244994945", {
  tweetFields: ["created_at", "public_metrics", "author_id"],
  maxResults: 10,
});

for await (const page of paginator) {
  page.data?.forEach((post) => {
    console.log(`${post.text?.slice(0, 50)}... - Likes: ${post.public_metrics?.like_count}`);
  });
}
```

## Inclua informações do autor

Use expansions para obter dados sobre os autores dos Posts:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/2244994945/bookmarks?\
tweet.fields=created_at,author_id&\
expansions=author_id&\
user.fields=username,verified" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# Obter bookmarks com informações do autor
for page in client.bookmarks.get(
    "2244994945",
    tweet_fields=["created_at", "author_id"],
    expansions=["author_id"],
    user_fields=["username", "verified"]
):
    for post in page.data:
        print(f"{post.text[:50]}...")
    # As informações do autor estão em page.includes.users
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// Obter bookmarks com informações do autor
const paginator = client.bookmarks.get("2244994945", {
  tweetFields: ["created_at", "author_id"],
  expansions: ["author_id"],
  userFields: ["username", "verified"],
});

for await (const page of paginator) {
  page.data?.forEach((post) => {
    console.log(`${post.text?.slice(0, 50)}...`);
  });
  // As informações do autor estão em page.includes?.users
}
```

## Escopos obrigatórios

Ao usar OAuth 2.0 PKCE, seu access token deve ter estes escopos:

| Escopo | Descrição |
|:------|:------------|
| `bookmark.read` | Ler bookmarks |
| `tweet.read` | Ler dados do Post |
| `users.read` | Ler dados do usuário (para expansions) |
