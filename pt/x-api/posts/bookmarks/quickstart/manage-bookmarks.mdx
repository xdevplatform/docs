Este guia mostra como adicionar e remover bookmarks usando a X API.

<Note>
**Pré-requisitos**

Antes de começar, você precisará de:
- Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info) com um App aprovado
- User Access Token com o escopo `bookmark.write` (OAuth 2.0 PKCE)
</Note>

---

## Adicionar um bookmark

<Steps>
  <Step title="Obtenha seu ID de usuário">
    Você precisa do ID do usuário autenticado. Você pode encontrá-lo usando o endpoint `/2/users/me` ou o [endpoint de user lookup](/x-api/users/lookup/introduction).
  </Step>

  <Step title="Obtenha o ID do Post">
    Encontre o ID do Post na URL ao visualizar um Post:

    ```
    https://x.com/XDevelopers/status/1460323737035677698
                                    └── Este é o ID do Post
    ```
  </Step>

  <Step title="Adicione o bookmark">

<CodeGroup dropdown>

```bash cURL
curl -X POST "https://api.x.com/2/users/2244994945/bookmarks" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1460323737035677698"}'
```

```python Python SDK
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# Adicionar um bookmark
response = client.bookmarks.create(
    user_id="2244994945",
    tweet_id="1460323737035677698"
)

print(f"Bookmarked: {response.data.bookmarked}")
```

```javascript JavaScript SDK
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// Adicionar um bookmark
const response = await client.bookmarks.create("2244994945", {
  tweetId: "1460323737035677698",
});

console.log(`Bookmarked: ${response.data?.bookmarked}`);
```

</CodeGroup>

  </Step>

  <Step title="Revise a resposta">
    ```json
    {
      "data": {
        "bookmarked": true
      }
    }
    ```
  </Step>
</Steps>

## Remover um bookmark

Exclua um Post dos seus bookmarks:

<CodeGroup dropdown>

```bash cURL
curl -X DELETE "https://api.x.com/2/users/2244994945/bookmarks/1460323737035677698" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python Python SDK
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# Remover um bookmark
response = client.bookmarks.delete(
    user_id="2244994945",
    tweet_id="1460323737035677698"
)

print(f"Bookmarked: {response.data.bookmarked}")
```

```javascript JavaScript SDK
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// Remover um bookmark
const response = await client.bookmarks.delete("2244994945", "1460323737035677698");

console.log(`Bookmarked: ${response.data?.bookmarked}`);
```

</CodeGroup>

**Resposta:**

```json
{
  "data": {
    "bookmarked": false
  }
}
```

---

## Escopos obrigatórios

Ao usar OAuth 2.0 PKCE, seu access token deve ter estes escopos:

| Escopo | Descrição |
|:------|:------------|
| `bookmark.write` | Adicionar e remover bookmarks |
| `tweet.read` | Ler dados do Post |
| `users.read` | Ler dados do usuário |
