Os endpoints de Bookmarks permitem que você visualize, adicione e remova Posts marcados como favoritos para o usuário autenticado. Os bookmarks são privados e visíveis apenas para o usuário que os criou.

## Endpoints

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/bookmarks`](/x-api/users/get-bookmarks) | Obter os bookmarks do usuário |
| POST | [`/2/users/:id/bookmarks`](/x-api/users/create-bookmark) | Marcar um Post como favorito |
| DELETE | [`/2/users/:id/bookmarks/:tweet_id`](/x-api/users/delete-bookmark) | Remover um bookmark |
| GET | [`/2/users/:id/bookmarks/folders`](/x-api/users/get-bookmark-folders) | Obter pastas de bookmarks |
| GET | [`/2/users/:id/bookmarks/folders/:folder_id`](/x-api/users/get-bookmarks-by-folder-id) | Obter Posts em uma pasta |

---

## Exemplo: obter bookmarks

```bash
curl "https://api.x.com/2/users/123456789/bookmarks?\
tweet.fields=created_at,author_id,public_metrics" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

## Exemplo: adicionar bookmark

```bash
curl -X POST "https://api.x.com/2/users/123456789/bookmarks" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
