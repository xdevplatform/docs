Os endpoints Likes Streams entregam eventos de like em tempo real por meio de conexões HTTP GET persistentes. Esses streams fornecem acesso à atividade de likes no X, permitindo que você acompanhe padrões de engajamento, monitore o desempenho de conteúdo e analise o comportamento de likes em escala.

Dois streams estão disponíveis:

* **Stream All Likes** — Entrega todos os eventos públicos de like em tempo real (firehose).
* **Stream Sampled Likes** — Entrega uma amostra de 10% dos eventos públicos de like.

Esses endpoints de streaming usam autenticação [OAuth 2.0 App-Only](/resources/fundamentals/authentication#oauth-2-0).

_Para usar essas APIs, você deve primeiro configurar uma conta com nossa equipe de vendas enterprise._

<Note>
**Configuração da conta**

Para acessar esses endpoints, você precisará de:

* Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info) aprovada.
* Autenticar usando as chaves e tokens de um [developer App](/resources/fundamentals/developer-apps) que esteja localizado dentro de um [Project](/resources/fundamentals/developer-apps).

Saiba mais sobre como obter acesso aos endpoints da API do X v2 em nosso [guia de primeiros passos](/x-api/getting-started/getting-access).
</Note>

## Endpoints

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| GET | [`/2/likes/firehose/stream`](/x-api/stream/stream-all-likes) | Faz streaming de todos os eventos de like em tempo real |
| GET | [`/2/likes/sample10/stream`](/x-api/stream/stream-sampled-likes) | Faz streaming de uma amostra de 10% dos eventos de like |
