Um objeto de mídia representa uma única foto, vídeo ou GIF animado. Objetos de mídia são usados por muitos endpoints dentro da API do X e podem ser incluídos em Posts, Direct Messages, perfis de usuário, criativos publicitários e outros locais. Cada objeto de mídia pode ter múltiplas variantes de exibição ou reprodução, com resoluções ou formatos diferentes.

## Tipos de mídia e restrições de tamanho

Restrições de tamanho para upload via API

- **Image**: `5 MB`
- **GIF**: `15 MB`
- **Video**: `512 MB` (ao usar `media_category=amplify_video`)

## Criação

Objetos como Posts, Direct Messages, fotos de perfil de usuário, hosted Ads cards, etc. podem conter um ou mais objetos de mídia. Esses objetos de nível superior são coletivamente conhecidos como entidades. A API de criação de entidade relevante (ex.: [`POST /2/tweets`](/x-api/posts/creation-of-a-post)) pode receber um ou mais objetos de mídia usando um `media_id` único.

Uma entidade que contém objeto(s) de mídia pode ser criada seguindo estes passos:

1. Faça upload do(s) arquivo(s) de mídia usando o upload [chunked](/x-api/media/quickstart/media-upload-chunked) recomendado (imagens/GIF/vídeo) ou o upload [simple](/x-api/media/upload-media) mais antigo (apenas imagens).
1. Receba um `media_id` do passo 1. Esta etapa pode ser repetida várias vezes com mídias diferentes se a entidade permitir que múltiplos parâmetros `media_id` sejam passados.
1. Crie a entidade chamando o endpoint apropriado, incluindo o `media_id` e outros parâmetros obrigatórios. Por exemplo, anexe um `media_id` a um Post usando o endpoint [`POST /2/tweets`](/x-api/posts/creation-of-a-post).
