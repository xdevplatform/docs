Este guia mostra como recuperar listas de seguidores e de quem o usuário segue, além de gerenciar follows.

<Note>
**Pré-requisitos**

Antes de começar, você precisará de:
- Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info) com um App aprovado
- O Bearer Token do seu App (para consultas)
- User Access Token (para gerenciar follows)
</Note>

---

## Obter os seguidores de um usuário

Recupere a lista de usuários que seguem um usuário específico:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/2244994945/followers?\
user.fields=username,verified,public_metrics&\
max_results=100" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obter os seguidores de um usuário com paginação
for page in client.users.get_followers(
    "2244994945",
    user_fields=["username", "verified", "public_metrics"],
    max_results=100
):
    for user in page.data:
        print(f"{user.username} - Followers: {user.public_metrics.followers_count}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Obter os seguidores de um usuário com paginação
const paginator = client.users.getFollowers("2244994945", {
  userFields: ["username", "verified", "public_metrics"],
  maxResults: 100,
});

for await (const page of paginator) {
  page.data?.forEach((user) => {
    console.log(`${user.username} - Followers: ${user.public_metrics?.followers_count}`);
  });
}
```

</CodeGroup>

### Resposta

```json title="Exemplo de resposta" lines wrap icon="/icons/xds/icon-brackets.svg"

  "data": [
    {
      "id": "1234567890",
      "name": "Developer",
      "username": "dev_user",
      "verified": false,
      "public_metrics": {
        "followers_count": 500,
        "following_count": 200,
        "tweet_count": 1500
      }
    }
  ],
  "meta": {
    "result_count": 1,
    "next_token": "abc123"
  }
}
```

## Seguir um usuário

Siga um usuário em nome do usuário autenticado:

<CodeGroup dropdown>

```bash cURL
curl -X POST "https://api.x.com/2/users/123456789/following" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "2244994945"}'
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Seguir um usuário
response = client.users.follow(
    source_user_id="123456789",
    target_user_id="2244994945"
)
print(f"Following: {response.data.following}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// Seguir um usuário
const response = await client.users.follow("123456789", {
  targetUserId: "2244994945",
});
console.log(`Following: ${response.data?.following}`);
```

</CodeGroup>

### Resposta

```json
{
  "data": {
    "following": true,
    "pending_follow": false
  }
}
```

<Note>
Se a conta alvo for protegida, `pending_follow` será `true` até que a solicitação de follow seja aprovada.
</Note>

## Deixar de seguir um usuário

Deixe de seguir um usuário em nome do usuário autenticado:

<CodeGroup dropdown>

```bash cURL
curl -X DELETE "https://api.x.com/2/users/123456789/following/2244994945" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Deixar de seguir um usuário
response = client.users.unfollow(
    source_user_id="123456789",
    target_user_id="2244994945"
)
print(f"Following: {response.data.following}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
```

</CodeGroup>

## Parâmetros comuns

| Parâmetro | Descrição |
|:----------|:------------|
| `max_results` | Resultados por página (1-1000, padrão 100) |
| `pagination_token` | Token para a próxima página |
| `user.fields` | Fields adicionais de usuário |
| `expansions` | Objetos relacionados a incluir |
