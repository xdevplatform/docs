Os endpoints de Follows permitem seguir e deixar de seguir usuários, além de recuperar as listas de seguidores e de quem o usuário segue.

## Endpoints

### Consulta de follows

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/followers`](/x-api/users/get-followers) | Obter os seguidores de um usuário |
| GET | [`/2/users/:id/following`](/x-api/users/get-following) | Obter quem um usuário segue |

### Gerenciar follows

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| POST | [`/2/users/:id/following`](/x-api/users/follow-user) | Seguir um usuário |
| DELETE | [`/2/users/:source_user_id/following/:target_user_id`](/x-api/users/unfollow-user) | Deixar de seguir um usuário |

---

## Exemplo: Obter seguidores

```bash
curl "https://api.x.com/2/users/2244994945/followers?\
user.fields=username,verified,public_metrics" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

## Exemplo: Seguir um usuário

```bash
curl -X POST "https://api.x.com/2/users/123456789/following" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "2244994945"}'
```
