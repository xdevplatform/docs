Os endpoints de Blocks permitem recuperar a lista de usuários bloqueados pelo usuário autenticado, além de bloquear e desbloquear usuários.

<Callout icon="/icons/xds/icon-key.svg" color="#22C55E" iconType="regular">
Os endpoints de bloquear e desbloquear usuários só estão disponíveis no plano Enterprise. Você pode preencher o formulário de interesse Enterprise [aqui](/forms/enterprise-api-interest).
</Callout>

## Endpoints

| Método | Endpoint | Descrição | Disponibilidade |
|:-------|:---------|:------------|:-------------|
| GET | [`/2/users/:id/blocking`](/x-api/users/get-blocking) | Obter usuários bloqueados | <div className="flex items-center gap-1 flex-nowrap whitespace-nowrap"><Badge color="blue" size="xs">Pay-per-use</Badge><Badge color="green" size="xs">Enterprise</Badge></div> |
| POST | `/2/users/:id/blocking` | Bloquear um usuário | <Badge color="green" size="xs">Enterprise</Badge> |
| DELETE | `/2/users/:source_user_id/blocking/:target_user_id` | Desbloquear um usuário | <Badge color="green" size="xs">Enterprise</Badge> |

---

## Exemplo: Obter usuários bloqueados

```bash
curl "https://api.x.com/2/users/123456789/blocking?\
user.fields=username,description" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

## Exemplo: Bloquear um usuário (somente Enterprise)

```bash
curl -X POST "https://api.x.com/2/users/123456789/blocking" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "9876543210"}'
```
