## Autenticação

Os endpoints de blocks exigem autenticação do usuário:

| Método | Descrição |
|:-------|:------------|
| [OAuth 2.0 Authorization Code with PKCE](/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) | Recomendado para novas aplicações |
| [OAuth 1.0a User Context](/resources/fundamentals/authentication) | Suporte legado |

<Warning>
A autenticação App-Only não é suportada. Você deve autenticar em nome de um usuário.
</Warning>

### Escopos obrigatórios (OAuth 2.0)

| Escopo | Necessário para |
|:------|:-------------|
| `block.read` | Obter contas bloqueadas |
| `block.write` | Bloquear e desbloquear contas |
| `users.read` | Necessário junto com os escopos de block |

## Visão geral dos endpoints

|:-------|:---------|:------------|:-------------|
| GET | `/2/users/:id/blocking` | Obter a lista de contas bloqueadas | <div className="flex items-center gap-1 flex-nowrap whitespace-nowrap"><Badge color="blue" size="xs">Pay-per-use</Badge><Badge color="green" size="xs">Enterprise</Badge></div> |

## Paginação

Para usuários com listas grandes de bloqueios, os resultados são paginados:

<CodeGroup dropdown>

```bash cURL
# Primeira requisição
curl "https://api.x.com/2/users/123/blocking?max_results=100" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"

# Requisição subsequente com token de paginação
curl "https://api.x.com/2/users/123/blocking?max_results=100&pagination_token=NEXT_TOKEN" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

# Use um user access token do OAuth 2.0
client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# O SDK trata a paginação automaticamente
all_blocked = []

for page in client.users.get_blocking(user_id="123", max_results=100):
    if page.data:
        all_blocked.extend(page.data)

print(f"Blocked {len(all_blocked)} users")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

async function getAllBlockedUsers(userId) {
  const allBlocked = [];

  // O SDK trata a paginação automaticamente
  const paginator = client.users.getBlocking(userId, { maxResults: 100 });

  for await (const page of paginator) {
    if (page.data) {
      allBlocked.push(...page.data);
    }
  }

  return allBlocked;
}

// Uso
const blocked = await getAllBlockedUsers("123");
console.log(`Blocked ${blocked.length} users`);
```

## Tratamento de erros

| Status | Erro | Solução |
|:-------|:------|:---------|
| 400 | Requisição inválida | Verifique o formato do user ID |
| 401 | Não autorizado | Verifique o access token |
| 403 | Proibido | Verifique escopos e permissões. Bloquear/desbloquear requerem [Enterprise](/forms/enterprise-api-interest) |
| 404 | Não encontrado | O usuário não existe |
| 429 | Muitas requisições | Aguarde e tente novamente |
