### Consulta de mutes: Standard v1.1 comparado com X API v2

Se você tem usado os endpoints standard v1.1 [GET mutes/users/ids](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/get-mutes-users-ids) e [GET mutes/users/list](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/get-mutes-users-list), o objetivo deste guia é ajudar você a entender as semelhanças e diferenças entre os endpoints de consulta de mutes do standard v1.1 e da X API v2.

* **Semelhanças**
    * Autenticação
* **Diferenças**
    * URLs dos endpoints

    * Limites de usuários por requisição
    * Requisitos de App e Project
    * Formatos dos dados de resposta
    * Parâmetros da requisição

#### Semelhanças

**Autenticação**

Tanto os endpoints de consulta de mutes do standard v1.1 quanto da X API v2 utilizam [OAuth 1.0a User Context](/resources/fundamentals/authentication#oauth-1-0a-2). Portanto, se você estava usando um dos endpoints de consulta de mutes do standard v1.1, pode continuar usando o mesmo método de autenticação ao migrar para a versão X API v2.

#### Diferenças

**URLs dos endpoints**

* Endpoints do standard v1.1:
    * GET https://api.x.com/1.1/mutes/users/ids.json
        (lista de IDs de usuários que o usuário especificado silenciou)
    * GET https://api.x.com/1.1/mutes/users/lists.json
        (lista de usuários que estão silenciados pelo usuário especificado)
* Endpoint da X API v2:
    * GET https://api.x.com/2/users/:id/muting
        (lista de usuários que estão silenciados pelo ID de usuário especificado)
