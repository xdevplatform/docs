Os endpoints de Mutes permitem silenciar e reativar usuários, além de recuperar a lista de usuários silenciados pelo usuário autenticado.

## Endpoints

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/muting`](/x-api/users/get-muting) | Obter usuários silenciados |
| POST | [`/2/users/:id/muting`](/x-api/users/mute-user) | Silenciar um usuário |
| DELETE | [`/2/users/:source_user_id/muting/:target_user_id`](/x-api/users/unmute-user) | Reativar um usuário silenciado |

---

## Exemplo: Obter usuários silenciados

```bash
curl "https://api.x.com/2/users/123456789/muting?\
user.fields=username,description" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

## Exemplo: Silenciar um usuário

```bash
curl -X POST "https://api.x.com/2/users/123456789/muting" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "9876543210"}'
```
