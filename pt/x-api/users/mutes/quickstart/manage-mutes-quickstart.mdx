Este guia mostra como silenciar e reativar usuários usando a X API.

<Note>
**Pré-requisitos**

Antes de começar, você precisará de:
- Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info) com um App aprovado
- User Access Token (OAuth 1.0a ou OAuth 2.0 PKCE)
</Note>

## Silenciar um usuário

<Steps>
  <Step title="Obtenha seu user ID">
    Você precisa do ID do usuário autenticado. Encontre-o usando o [endpoint de consulta de usuário](/x-api/users/lookup/introduction) ou a partir do seu Access Token (a parte numérica é o seu user ID).
  </Step>

  <Step title="Obtenha o user ID alvo">
    Encontre o user ID da conta que você quer silenciar usando o [endpoint de consulta de usuário](/x-api/users/lookup/introduction).
  </Step>

  <Step title="Envie a requisição de mute">

<CodeGroup dropdown>

```bash cURL
curl -X POST "https://api.x.com/2/users/123456789/muting" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "9876543210"}'
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Silenciar um usuário
response = client.users.mute(
    source_user_id="123456789",
    target_user_id="9876543210"
)

print(f"Muting: {response.data.muting}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// Silenciar um usuário
const response = await client.users.mute("123456789", {
  targetUserId: "9876543210",
});

console.log(`Muting: ${response.data?.muting}`);
```

</CodeGroup>

  </Step>

  <Step title="Revise a resposta">
    ```json
    {
      "data": {
        "muting": true
      }
    }
    ```
  </Step>
</Steps>

## Reativar um usuário silenciado

Remova o mute de um usuário:

<CodeGroup dropdown>

```bash cURL
curl -X DELETE "https://api.x.com/2/users/123456789/muting/9876543210" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Reativar um usuário silenciado
response = client.users.unmute(
    source_user_id="123456789",
    target_user_id="9876543210"
)

print(f"Muting: {response.data.muting}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// Reativar um usuário silenciado
const response = await client.users.unmute("123456789", "9876543210");

console.log(`Muting: ${response.data?.muting}`);
```

</CodeGroup>

**Resposta:**

```json
{
  "data": {
    "muting": false
  }
}
```

## Silenciar vs Bloquear

| Recurso | Silenciar | Bloquear |
|:--------|:-----|:------|
| Ver os Posts deles | Não | Não |
| Eles veem seus Posts | Sim | Não |
| Eles podem seguir você | Sim | Não |
| Eles podem enviar DM | Sim | Não |
| Eles sabem | Não | Sim |
