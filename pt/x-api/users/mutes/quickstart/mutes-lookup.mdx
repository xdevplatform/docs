Este guia mostra como recuperar sua lista de usuários silenciados usando a X API.

<Note>
**Pré-requisitos**

Antes de começar, você precisará de:
- Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info) com um App aprovado
- User Access Token (OAuth 1.0a ou OAuth 2.0 PKCE)
</Note>

---

## Obter seus usuários silenciados

<Steps>
  <Step title="Obtenha seu user ID">
    Você precisa do ID do usuário autenticado. Encontre-o usando o [endpoint de consulta de usuário](/x-api/users/lookup/introduction) ou a partir do seu Access Token (a parte numérica é o seu user ID).
  </Step>

  <Step title="Solicite seus usuários silenciados">

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/123456789/muting?\
user.fields=created_at,username,verified&\
max_results=100" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# Obter usuários silenciados com paginação
for page in client.users.get_muting(
    "123456789",
    user_fields=["created_at", "username", "verified"],
    max_results=100
):
    for user in page.data:
        print(f"{user.username} - Muted")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// Obter usuários silenciados com paginação
const paginator = client.users.getMuting("123456789", {
  userFields: ["created_at", "username", "verified"],
  maxResults: 100,
});

for await (const page of paginator) {
  page.data?.forEach((user) => {
    console.log(`${user.username} - Muted`);
  });
}
```

</CodeGroup>

  </Step>

## Incluir dados adicionais

Use expansions para obter dados relacionados, como Posts fixados:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/123456789/muting?\
user.fields=created_at&\
expansions=pinned_tweet_id&\
tweet.fields=created_at" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# Obter usuários silenciados com expansions
for page in client.users.get_muting(
    "123456789",
    user_fields=["created_at"],
    expansions=["pinned_tweet_id"],
    tweet_fields=["created_at"]
):
    for user in page.data:
        print(f"{user.username}")
    # Posts fixados estão em page.includes.tweets
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// Obter usuários silenciados com expansions
const paginator = client.users.getMuting("123456789", {
  userFields: ["created_at"],
  expansions: ["pinned_tweet_id"],
  tweetFields: ["created_at"],
});

for await (const page of paginator) {
  page.data?.forEach((user) => {
    console.log(user.username);
  });
  // Posts fixados estão em page.includes?.tweets
}
```

## Paginar pelos resultados

Os SDKs tratam a paginação automaticamente. Para cURL, use o `next_token` da resposta:

```bash
curl "https://api.x.com/2/users/123456789/muting?\
max_results=100&\
pagination_token=1710819323648428707" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```
