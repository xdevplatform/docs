## Autenticação

Os endpoints de mutes exigem autenticação do usuário para acessar listas privadas de silenciados:

| Método | Descrição |
|:-------|:------------|
| [OAuth 2.0 Authorization Code with PKCE](/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) | Recomendado para novas aplicações |
| [OAuth 1.0a User Context](/resources/fundamentals/authentication) | Suporte legado |

<Warning>
A autenticação App-Only não é suportada. Você deve autenticar em nome de um usuário.
</Warning>

### Escopos obrigatórios (OAuth 2.0)

| Escopo | Necessário para |
|:------|:-------------|
| `mute.read` | Obter contas silenciadas |
| `mute.write` | Silenciar e reativar contas |
| `users.read` | Necessário junto com os escopos de mute |

---

## Visão geral dos endpoints

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| GET | `/2/users/:id/muting` | Obter a lista de contas silenciadas |
| POST | `/2/users/:id/muting` | Silenciar uma conta |
| DELETE | `/2/users/:source_user_id/muting/:target_user_id` | Reativar uma conta |

### Exemplo com fields

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/123456789/muting?\
user.fields=username,verified,created_at&\
max_results=100" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# Obter usuários silenciados com fields adicionais
for page in client.users.get_muting(
    user_id="123456789",
    user_fields=["username", "verified", "created_at"],
    max_results=100
):
    for user in page.data:
        print(f"{user.username} - Verified: {user.verified}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

const paginator = client.users.getMuting("123456789", {
  userFields: ["username", "verified", "created_at"],
  maxResults: 100,
});

for await (const page of paginator) {
  page.data?.forEach((user) => {
    console.log(`${user.username} - Verified: ${user.verified}`);
  });
}
```

## Paginação

Para usuários com listas grandes de silenciados, os resultados são paginados:

<CodeGroup dropdown>

```bash cURL
# Primeira requisição
curl "https://api.x.com/2/users/123/muting?max_results=100" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"

# Requisição subsequente com token de paginação
curl "https://api.x.com/2/users/123/muting?max_results=100&pagination_token=NEXT_TOKEN" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# O SDK trata a paginação automaticamente
all_muted = []

for page in client.users.get_muting(user_id="123", max_results=100):
    if page.data:
        all_muted.extend(page.data)

print(f"Muted {len(all_muted)} users")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

async function getAllMutedUsers(userId) {
  const allMuted = [];

  // O SDK trata a paginação automaticamente
  const paginator = client.users.getMuting(userId, { maxResults: 100 });

  for await (const page of paginator) {
    if (page.data) {
      allMuted.push(...page.data);
    }
  }

  return allMuted;
}

// Uso
const muted = await getAllMutedUsers("123");
console.log(`Muted ${muted.length} users`);
```

## Diferenças de comportamento

### Silenciar vs Bloquear

| Recurso | Silenciar | Bloquear |
|:--------|:-----|:------|
| Ver os Posts deles | Não (ocultos) | Não |
| Eles veem seus Posts | Sim | Não |
| Eles seguem você | Sim (podem seguir) | Não (removido) |
| Eles podem enviar DM | Sim | Não |
| Notificação enviada | Não | Não |

<Tip>
Silenciar é privado — o usuário silenciado não é notificado e não tem como saber que foi silenciado.
</Tip>

## Tratamento de erros

| Status | Erro | Solução |
|:-------|:------|:---------|
| 400 | Requisição inválida | Verifique o formato do user ID |
| 401 | Não autorizado | Verifique o access token |
| 403 | Proibido | Verifique escopos e permissões |
| 404 | Não encontrado | O usuário não existe |
| 429 | Muitas requisições | Aguarde e tente novamente |
