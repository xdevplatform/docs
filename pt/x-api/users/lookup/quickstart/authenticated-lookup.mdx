Este guia mostra como recuperar o perfil do usuário atualmente autenticado usando o endpoint `/me`.

<Note>
**Pré-requisitos**

Antes de começar, você precisará de:
- Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info) com um App aprovado
- User Access Token (OAuth 1.0a ou OAuth 2.0 PKCE)
</Note>

---

## Obter o usuário autenticado

Faça uma requisição ao endpoint `/me` com um User Access Token:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/me?\
user.fields=created_at,description,verified,public_metrics,profile_image_url" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# Obter o usuário autenticado
response = client.users.get_me(
    user_fields=["created_at", "description", "verified", "public_metrics", "profile_image_url"]
)

print(f"Username: {response.data.username}")
print(f"ID: {response.data.id}")
print(f"Followers: {response.data.public_metrics.followers_count}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// Obter o usuário autenticado
const response = await client.users.getMe({
  userFields: ["created_at", "description", "verified", "public_metrics", "profile_image_url"],
});

console.log(`Username: ${response.data?.username}`);
console.log(`ID: ${response.data?.id}`);
console.log(`Followers: ${response.data?.public_metrics?.followers_count}`);
```

</CodeGroup>

## Caso de uso

O endpoint `/me` é essencial ao:

- **Verificar a autenticação** — Confirme se o usuário está autenticado corretamente
- **Obter o user ID** — Recupere o ID do usuário autenticado para outras chamadas à API
- **Personalizar experiências** — Exiba o perfil do usuário no seu app
- **Requisições em nome de** — Saiba em nome de quem você está fazendo as requisições

## Incluir o Post fixado

Solicite o Post fixado do usuário:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/me?\
user.fields=pinned_tweet_id&\
expansions=pinned_tweet_id&\
tweet.fields=created_at,text" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# Obter usuário autenticado com o Post fixado
response = client.users.get_me(
    user_fields=["pinned_tweet_id"],
    expansions=["pinned_tweet_id"],
    tweet_fields=["created_at", "text"]
)

print(f"Username: {response.data.username}")
# O Post fixado está em response.includes.tweets
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// Obter usuário autenticado com o Post fixado
const response = await client.users.getMe({
  userFields: ["pinned_tweet_id"],
  expansions: ["pinned_tweet_id"],
  tweetFields: ["created_at", "text"],
});

console.log(`Username: ${response.data?.username}`);
// O Post fixado está em response.includes?.tweets
```

</CodeGroup>

## Fields disponíveis

| Field | Descrição |
|:------|:------------|
| `created_at` | Data de criação da conta |
| `description` | Bio do usuário |
| `profile_image_url` | URL do avatar |
| `verified` | Status de verificação |
| `public_metrics` | Contagens de seguidores/seguindo |
| `location` | Localização definida pelo usuário |
| `url` | Site do usuário |
| `protected` | Status de conta protegida |
| `pinned_tweet_id` | ID do Post fixado |

## Requisito de autenticação

<Warning>
O endpoint `/me` exige autenticação User Context. Autenticação App-Only (Bearer Token) não é suportada.
</Warning>

Use um destes:
- [OAuth 1.0a User Context](/resources/fundamentals/authentication)
- [OAuth 2.0 Authorization Code with PKCE](/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2)
