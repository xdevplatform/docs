## Comparando os endpoints de consulta de usuários da X API

Os endpoints v2 de consulta de usuário substituirão os endpoints standard v1.1 [GET users/lookup](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/get-users-lookup.html) e [GET users/show](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/get-users-show.html). Se você tem código, apps ou ferramentas que utilizam uma dessas versões dos endpoints de consulta de usuário e está considerando migrar para o endpoint mais recente da X API v2, este conjunto de guias é para você.
 

As tabelas a seguir comparam os diversos tipos de endpoints de consulta de usuários:
 

|     |     |     |
| :--- | :--- | :--- |
| **Descrição** | **Standard v1.1** | **X API v2** |
| Métodos HTTP suportados | `GET` | `GET` |
| Domínio do host | `https://api.x.com` | `https://api.x.com` |
| Caminho do endpoint | `/1.1/users/show.json` `/1.1/users/lookup.json` | `/2/users`<br/><br/>`/2/users/:id`<br/><br/>`/2/users/by`<br/><br/>`/2/users/by/:username` |
| [Autenticação](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br/><br/>App only<br/><br/>OAuth 2.0 Authorization Code with PKCE |
| [Limites de requisição](/resources/fundamentals/rate-limits) padrão | 900 requisições por 15 min (por usuário)<br/><br/>/show - 900 requisições por 15 min (por app)  <br/>/lookup - 300 requisições por 15 min (por app) | 900 requisições por 15 min (por usuário)<br/><br/>300 requisições por 15 min (por app) |
| Máximo de usuários por resposta | /show -  1<br/><br/>/lookup - 100 | 100 |
| Formato do objeto JSON de resposta | Formato Standard v1.1 | [Formato X API v2](/x-api/fundamentals/data-dictionary) (determinado pelos parâmetros fields e expansions da requisição, não é retrocompatível com os formatos v1.1)<br/><br/>Para saber mais sobre como migrar do formato Standard v1.1 para o formato X API v2, consulte nosso [guia de migração de formatos de dados](/x-api/migrate/data-format-migration). |
| Suporta selecionar quais [fields](/x-api/fundamentals/data-dictionary) retornam no payload |     | ✔   |
| Suporta os fields de [annotations](/x-api/fundamentals/post-annotations) (no Post fixado) |     | ✔   |
| Suporta solicitar novos fields de [metrics](/x-api/fundamentals/metrics) (no Post fixado) |     | ✔   |
| Suporta o field [conversation_id](/x-api/fundamentals/conversation-id) (no Post fixado) |     | ✔   |
| Exige o uso de credenciais de um [App de desenvolvedor](/resources/fundamentals/developer-apps) associado a um [Project](/resources/fundamentals/developer-apps) |     | ✔   |
