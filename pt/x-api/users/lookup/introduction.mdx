Os endpoints de consulta de usuários permitem recuperar informações de perfil de um ou mais usuários. Consulte usuários pelo ID, pelo username, ou obtenha detalhes do usuário atualmente autenticado.

## Endpoints

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| GET | [`/2/users/:id`](/x-api/users/get-user-by-id) | Obter usuário por ID |
| GET | [`/2/users`](/x-api/users/get-users-by-ids) | Obter usuários por IDs (até 100) |
| GET | [`/2/users/by/username/:username`](/x-api/users/get-user-by-username) | Obter usuário por username |
| GET | [`/2/users/by`](/x-api/users/get-users-by-usernames) | Obter usuários por usernames (até 100) |
| GET | [`/2/users/me`](/x-api/users/get-my-user) | Obter usuário autenticado |

---

## Exemplo de requisição

```bash
curl "https://api.x.com/2/users/by/username/XDevelopers?\
user.fields=created_at,description,public_metrics,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

## Exemplo de resposta

