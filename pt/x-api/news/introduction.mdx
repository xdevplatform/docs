O endpoint de news lookup permite que desenvolvedores obtenham notícias e manchetes em destaque no X.

Este endpoint oferece suporte à autenticação app-auth e user-auth para OAuth1 e OAuth2 PKCE.

## Primeiros passos

Para usar o endpoint, você precisa de um [bearer token](/fundamentals/authentication/oauth-2-0/application-only) do [Developer Console](https://developer.x.com/en/portal/dashboard).

Depois de obter o bearer token, você pode chamar a news API conforme mostrado abaixo:

```bash
curl 'https://api.x.com/2/news/1989418137272422538?news.fields=contexts,cluster_posts_results' --header 'Authorization: Bearer XXXXX'
```
