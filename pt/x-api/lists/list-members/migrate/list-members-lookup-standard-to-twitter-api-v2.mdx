### Consulta de membros da List: Standard v1.1 comparado com X API v2


Se você tem usado os endpoints standard v1.1 [GET lists/members](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-members) e [GET lists/memberships](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-memberships), o objetivo deste guia é ajudar você a entender as semelhanças e diferenças entre os endpoints de membros da List do standard v1.1 e da X API v2.

* **Semelhanças**
    * Métodos de autenticação
* **Diferenças**
    * URLs dos endpoints
    * Rate limits
    * Requisitos de App e Project
    * Limites de objetos de dados por requisição
    * Formatos dos dados de resposta
    * Parâmetros da requisição

#### Semelhanças

**Autenticação**

Ambas as versões de endpoint suportam tanto [OAuth 1.0a User Context](/resources/fundamentals/authentication#oauth-1-0a-2) quanto [App only](/resources/fundamentals/authentication#oauth-2-0). Portanto, se você estava usando um dos endpoints de membros da List do standard v1.1, pode continuar usando o mesmo método de autenticação ao migrar para a versão X API v2.

Dependendo da sua biblioteca/pacote de autenticação, a autenticação App only provavelmente é a maneira mais fácil de começar e pode ser configurada com um simples cabeçalho de requisição. Para saber como gerar um Access Token App only, consulte [este guia sobre App only](/resources/fundamentals/authentication#bearer-token-also-known-as-app-only).

#### Diferenças

**URLs dos endpoints**

* Endpoints do standard v1.1:
    * GET https://api.x.com/1.1/lists/members.json
        (Consultar membros de uma List específica)
    * GET https://api.x.com/1.1/lists/mem
