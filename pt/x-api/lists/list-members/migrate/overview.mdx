## Comparando os endpoints de Membros da List da X API


O grupo de endpoints v2 de Membros da List substituirá os endpoints standard v1.1 [GET lists/members](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-members), [GET lists/memberships](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-memberships), [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create) e [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy). Se você tem código, apps ou ferramentas que utilizam uma dessas versões dos endpoints de membros da List e está considerando migrar para o endpoint mais recente da X API v2, este conjunto de guias é para você.

### Consulta de membros da List

Os endpoints v2 de consulta de membros da List substituirão os endpoints standard [GET lists/members](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-members) e [GET lists/memberships](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-memberships).

As tabelas a seguir comparam os endpoints de List do standard v1.1 e da X API v2:

**Consulta de membro da List**

|     |     |     |
| :--- | :--- | :--- |
| Descrição | Standard v1.1 | X API v2 |
| Métodos HTTP suportados | `GET` | `GET` |
| Domínio do host | `https://api.x.com` | `https://api.x.com` |
| Caminho do endpoint | `/1.1/lists/members.json` | `/2/lists/:id/members` |
| [Autenticação](/resources/fundamentals/authentication) | OAuth 1.0a User Context<br/><br/>App only | OAuth 1.0a User Context<br/><br/>OAuth 2.0 Authorization Code with PKCE<br/><br/>App only |
| [Limites de requisição](/resources/fundamentals/rate-limits) padrão | 900 requisições por 15 min com OAuth 1.0a<br/><br/>75 requisições por 15 min com App only | 900 requisições por 15 min com OAuth 1.0a<br/><br/>900 requisições por 15 min com OAuth 2.0<br/><br/>900 requisições por 15 min com App only |

**Consulta de List membership**

|     |     |     |
| :--- | :--- | :--- |
| Descrição | Standard v1.1 | X API v2 |
| Métodos HTTP suportados | `GET` | `GET` |
| Domínio do host | `https://api.x.com` | `https://api.x.com` |
| Caminho do endpoint | `/1.1/lists/memberships.json` | `/2/users/:id/list_memberships` |
| [Autenticação](/resources/fundamentals/authentication) | OAuth 1.0a User Context<br/><br/>App only | OAuth 1.0a User Context<br/><br/>OAuth 2.0 Authorization Code with PKCE<br/><br/>App only |
| [Limites de requisição](/resources/fundamentals/rate-limits) padrão | 75 requisições por 15 min com OAuth 1.0a<br/><br/>75 requisições por 15 min com App only | 75 requisições por 15 min com OAuth 1.0a<br/><br/>75 requisições por 15 min com OAuth 2.0<br/><br/>75 requisições por 15 min com App only |

### Gerenciar membros da List

Os endpoints v2 de gerenciamento de membros da List substituirão os endpoints standard [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create) e [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy).

As tabelas a seguir comparam os endpoints de List do standard v1.1 e da X API v2:

**Adicionar membro**

| Descrição | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP suportados | POST | POST |
| Domínio do host | https://api.x.com | https://api.x.com |
| Caminho do endpoint | /1.1/lists/members/create.json | /2/lists/:id/members |
| [Autenticação](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br/><br/>OAuth 2.0 Authorization Code with PKCE |
| [Limites de requisição](/resources/fundamentals/rate-limits) padrão | Nenhum | 300 requisições por 15 min (por usuário) |

**Remover membro**

| Descrição | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP suportados | POST | DELETE |
| Domínio do host | https://api.x.com | https://api.x.com |
| Caminho do endpoint | /1.1/lists/members/destroy.json | /2/lists/:id/:user_id |
| [Autenticação](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br/><br/>OAuth 2.0 Authorization Code with PKCE |
| [Limites de requisição](/resources/fundamentals/rate-limits) padrão | Nenhum | 300 requisições por 15 min (por usuário) |

Para acessar os endpoints da X API v2, você precisa [criar uma conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info). Ao autenticar, você deve usar chaves e tokens de um [App de desenvolvedor](/resources/fundamentals/developer-apps) que esteja em um [Project](/resources/fundamentals/developer-apps).

Saiba mais sobre como obter acesso aos endpoints da X API v2 na nossa página de [introdução](/x-api/getting-started/getting-access).
