### Gerenciar membros da List: Standard v1.1 comparado com X API v2

Se você tem usado os endpoints standard v1.1 [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create) e [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy), o objetivo deste guia é ajudar você a entender as semelhanças e diferenças entre os endpoints de gerenciamento de membros da List do standard v1.1 e da X API v2.

* **Semelhanças**
    * Autenticação
* **Diferenças**
    * URLs dos endpoints
    * Requisitos de App e Project
    * Métodos HTTP
    * Rate limits
    * Parâmetros da requisição

#### Semelhanças

**Autenticação**

Ambas as versões de endpoint suportam [OAuth 1.0a User Context](https://developer.x.com/content/developer-twitter/resources/fundamentals/authentication). Portanto, se você estava usando um dos endpoints de gerenciamento de membros da List do standard v1.1, pode continuar usando o mesmo método de autenticação ao migrar para a versão X API v2.

#### Diferenças

**URLs dos endpoints**

* Endpoints do standard v1.1:
    * POST https://api.x.com/1.1/lists/members/create.json
        (Adiciona um membro a uma List específica)
    * POST https://api.x.com/1.1/lists/members/destroy.json
        (Remove um membro de uma List específica)
* Endpoint da X API v2:
    * POST https://api.x.com/2/lists/:id/members
        (Adiciona um membro a uma List específica)

    * DELETE https://api.x.com/2/lists/:id/members/:user_id
        (Remove um membro de uma List específica)

**Rate limits**

| **Standard v1.1** | **X API v2** |
| :--- | :--- |
| /1.1/lists/members/create.json<br/><br/>nenhum | /2/lists/:id/members<br/><br/>300 requisições por janela de 15 minutos com OAuth 1.0a User Context<br/><br/>300 requisições por janela de 15 minutos com OAuth 2.0 Authorization Code with PKCE |
| /1.1/lists/members/destroy.json<br/><br/>nenhum | /2/lists/:id/members/:user_id<br/><br/>300 requisições por janela de 15 minutos com OAuth 1.0a User Context<br/><br/>300 requisições por janela de 15 minutos com OAuth 2.0 Authorization Code with PKCE |

**Requisitos de App e Project**

Os endpoints da X API v2 exigem que você use credenciais de um [App de desenvolvedor](/resources/fundamentals/developer-apps) que esteja associado a um [Project](/resources/fundamentals/developer-apps) ao autenticar suas requisições. Todos os endpoints da X API v1.1 podem usar credenciais de Apps ou de Apps relacionados a um Project.

**Parâmetros da requisição**

Os seguintes parâmetros de requisição do standard v1.1 têm equivalentes na X API v2:

| **Standard v1.1** | **X API v2** |
| :--- | :--- |
| list_id | id  |
| slug | Sem equivalente |
| screen_name | Sem equivalente |
| owner\_screen\_name | Sem equivalente |
| owner_id | Sem equivalente |
