Este guia mostra como adicionar e remover membros de uma List.

<Note>
**Pré-requisitos**

Antes de começar, você precisará de:
- Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info) com um App aprovado
- User Access Token (OAuth 1.0a ou OAuth 2.0 PKCE)
- Uma List da qual você seja proprietário
</Note>

---

## Adicionar um membro a uma List

<Steps>
  <Step title="Obtenha o ID da List e o user ID">
    Você precisa do ID da sua List e do user ID da pessoa que deseja adicionar. Encontre user IDs usando o [endpoint de consulta de usuário](/x-api/users/lookup/introduction).
  </Step>

  <Step title="Adicione o membro">

<CodeGroup dropdown>

```bash cURL
curl -X POST "https://api.x.com/2/lists/1441162269824405510/members" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"user_id": "2244994945"}'
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Adicionar um membro a uma List
response = client.lists.add_member(
    list_id="1441162269824405510",
    user_id="2244994945"
)

print(f"Is member: {response.data.is_member}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// Adicionar um membro a uma List
const response = await client.lists.addMember("1441162269824405510", {
  userId: "2244994945",
});

console.log(`Is member: ${response.data?.is_member}`);
```

</CodeGroup>

  </Step>

  <Step title="Revise a resposta">
    ```json
    {
      "data": {
        "is_member": true
      }
    }
    ```
  </Step>
</Steps>

## Remover um membro de uma List

<CodeGroup dropdown>

```bash cURL
curl -X DELETE "https://api.x.com/2/lists/1441162269824405510/members/2244994945" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Remover um membro de uma List
response = client.lists.remove_member(
    list_id="1441162269824405510",
    user_id="2244994945"
)

print(f"Is member: {response.data.is_member}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// Remover um membro de uma List
const response = await client.lists.removeMember(
  "1441162269824405510",
  "2244994945"
);

console.log(`Is member: ${response.data?.is_member}`);
```

</CodeGroup>

**Resposta:**

```json
{
  "data": {
    "is_member": false
  }
}
```

## Observações importantes

<Note>
- Você só pode gerenciar membros de Lists das quais é proprietário
- Adicionar um usuário a uma List não requer a permissão dele
- Os usuários podem ver em quais Lists públicas foram adicionados
</Note>
