Os endpoints de Membros da List permitem visualizar os membros de uma List, adicionar membros às suas Lists e removê-los. Você também pode ver de quais Lists um usuário é membro.

## Endpoints

### Consulta de membros da List

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| GET | [`/2/lists/:id/members`](/x-api/lists/get-list-members) | Obter membros de uma List |
| GET | [`/2/users/:id/list_memberships`](/x-api/users/get-list-memberships) | Obter Lists nas quais um usuário está |

### Gerenciar membros da List

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| POST | [`/2/lists/:id/members`](/x-api/lists/add-list-member) | Adicionar um membro |
| DELETE | [`/2/lists/:id/members/:user_id`](/x-api/lists/remove-list-member) | Remover um membro |

---

## Exemplo: Obter membros da List

```bash
curl "https://api.x.com/2/lists/1234567890/members?\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

## Exemplo: Adicionar um membro

```bash
curl -X POST "https://api.x.com/2/lists/1234567890/members" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"user_id": "9876543210"}'
```
