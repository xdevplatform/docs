## Comparando os endpoints de Lists da X API

Os endpoints v2 de gerenciamento de Lists eventualmente substituirão [POST lists/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-create), [POST lists/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-destroy) e [POST lists/update](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-update). Se você tem código, apps ou ferramentas que usam uma versão mais antiga desses endpoints e está considerando migrar para a X API v2 mais recente, este guia é para você.

As tabelas a seguir comparam os endpoints de List do standard v1.1 e da X API v2:

**Criar uma List**

| Descrição | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP suportados | POST | POST |
| Domínio do host | https://api.x.com | https://api.x.com |
| Caminho do endpoint | /1.1/lists/create.json | /2/lists |
| [Autenticação](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| [Limites de requisição](/resources/fundamentals/rate-limits) padrão | Nenhum | 300 requisições por 15 min (por usuário) |

**Excluir uma List**

| Descrição | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP suportados | POST | DELETE |
| Domínio do host | https://api.x.com | https://api.x.com |
| Caminho do endpoint | /1.1/lists/destroy.json | /2/lists/:id |
| [Autenticação](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| [Limites de requisição](/resources/fundamentals/rate-limits) padrão | Nenhum | 300 requisições por 15 min (por usuário) |

**Atualizar uma List**

| Descrição | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP suportados | POST | PUT |
| Domínio do host | https://api.x.com | https://api.x.com |
| Caminho do endpoint | /1.1/lists/update.json | /2/lists/:id |
| [Autenticação](/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| [Limites de requisição](/resources/fundamentals/rate-limits) padrão | Nenhum | 300 requisições por 15 min (por usuário) |

Para acessar os endpoints da X API v2, você precisa [criar uma conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info). Ao autenticar, você deve usar chaves e tokens de um [App de desenvolvedor](/resources/fundamentals/developer-apps) que esteja em um [Project](/resources/fundamentals/developer-apps).

Saiba mais sobre como obter acesso aos endpoints da X API v2 na nossa página de [introdução](/x-api/getting-started/getting-access).
