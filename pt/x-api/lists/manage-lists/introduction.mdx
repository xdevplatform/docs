## Endpoints

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| POST | [`/2/lists`](/x-api/lists/create-list) | Criar uma nova List |
| PUT | [`/2/lists/:id`](/x-api/lists/update-list) | Atualizar uma List |
| DELETE | [`/2/lists/:id`](/x-api/lists/delete-list) | Excluir uma List |

---

## Exemplo: Criar uma List

```bash
curl -X POST "https://api.x.com/2/lists" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Tech News",
    "description": "My favorite tech journalists",
    "private": false
  }'
```

## Exemplo de resposta

```json
{
  "data": {
    "id": "1234567890",
    "name": "Tech News"
  }
}
```
