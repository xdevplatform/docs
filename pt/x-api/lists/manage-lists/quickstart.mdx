Este guia mostra como criar, atualizar e excluir Lists.

<Note>
**Pré-requisitos**

Antes de começar, você precisará de:
- Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info) com um App aprovado
- User Access Token (OAuth 1.0a ou OAuth 2.0 PKCE)
</Note>

---

## Criar uma List

<Steps>
  <Step title="Prepare sua requisição">
    Defina o nome da List (obrigatório) e a descrição e configurações de privacidade opcionais:

    ```json
    {
      "name": "Tech News",
      "description": "Top tech journalists and publications",
      "private": false
    }
    ```
  </Step>

  <Step title="Envie a requisição">

<CodeGroup dropdown>

```bash cURL
curl -X POST "https://api.x.com/2/lists" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Tech News",
    "description": "Top tech journalists and publications",
    "private": false
  }'
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Criar uma nova List
response = client.lists.create(
    name="Tech News",
    description="Top tech journalists and publications",
    private=False
)

print(f"List created: {response.data.id} - {response.data.name}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// Criar uma nova List
const response = await client.lists.create({
  name: "Tech News",
  description: "Top tech journalists and publications",
  private: false,
});

console.log(`List created: ${response.data?.id} - ${response.data?.name}`);
```

</CodeGroup>

  </Step>

  <Step title="Revise a resposta">
    ```json
    {
      "data": {
        "id": "1441162269824405510",
        "name": "Tech News"
      }
    }
    ```

    Guarde o `id` para atualizar ou excluir a List depois.
  </Step>
</Steps>

## Atualizar uma List

Modifique o nome, a descrição ou a privacidade de uma List:

<CodeGroup dropdown>

```bash cURL
curl -X PUT "https://api.x.com/2/lists/1441162269824405510" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Tech News & Insights",
    "description": "Updated description"
  }'
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Atualizar uma List
response = client.lists.update(
    "1441162269824405510",
    name="Tech News & Insights",
    description="Updated description"
)

print(f"Updated: {response.data.updated}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// Atualizar uma List
const response = await client.lists.update("1441162269824405510", {
  name: "Tech News & Insights",
  description: "Updated description",
});

console.log(`Updated: ${response.data?.updated}`);
```

</CodeGroup>

**Resposta:**

```json
{
  "data": {
    "updated": true
  }
}
```

## Excluir uma List

<Steps>
  <Step title="Obtenha o ID da List">
    Você precisa do ID da List que deseja excluir.
  </Step>

  <Step title="Envie a requisição de exclusão">

<CodeGroup dropdown>

```bash cURL
curl -X DELETE "https://api.x.com/2/lists/1441162269824405510" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Excluir uma List
response = client.lists.delete("1441162269824405510")
print(f"Deleted: {response.data.deleted}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// Excluir uma List
const response = await client.lists.delete("1441162269824405510");
console.log(`Deleted: ${response.data?.deleted}`);
```

</CodeGroup>

  </Step>

  <Step title="Confirme a exclusão">
    ```json
    {
      "data": {
        "deleted": true
      }
    }
    ```
  </Step>
</Steps>

<Warning>
Você só pode excluir Lists das quais é proprietário.
</Warning>
