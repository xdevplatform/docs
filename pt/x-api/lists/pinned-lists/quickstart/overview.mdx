Os endpoints de Lists fixadas permitem consultar as Lists fixadas de um usuário e gerenciar quais Lists estão fixadas.

<Note>
**Pré-requisitos**

Antes de começar, você precisará de:
- Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info) com um App aprovado
- User Access Token (OAuth 1.0a ou OAuth 2.0 PKCE)
</Note>

## Autenticação

| Operação | Autenticação |
|:----------|:---------------|
| Consultar Lists fixadas | OAuth 1.0a ou OAuth 2.0 PKCE |
| Fixar/desafixar Lists | OAuth 1.0a ou OAuth 2.0 PKCE |

<Warning>
Tanto as operações de consulta quanto as de gerenciamento exigem autenticação com contexto de usuário. Autenticação App-only (Bearer Token) não é suportada.
</Warning>

## Exemplo rápido

<CodeGroup dropdown>

```bash cURL
# Obter Lists fixadas
curl "https://api.x.com/2/users/2244994945/pinned_lists" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python Python SDK
from xdk import Client

client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

# Obter Lists fixadas
response = client.lists.get_pinned("2244994945")

for lst in response.data:
    print(f"{lst.name}")
```

```javascript JavaScript SDK
import { Client } from "@xdevplatform/xdk";

const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

// Obter Lists fixadas
const response = await client.lists.getPinned("2244994945");

response.data?.forEach((lst) => {
  console.log(lst.name);
});
```
