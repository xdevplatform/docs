Este guia mostra como fixar e desafixar Lists.

<Note>
**Pré-requisitos**

Antes de começar, você precisará de:
- Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info) com um App aprovado
- User Access Token (OAuth 1.0a ou OAuth 2.0 PKCE)
</Note>

---

## Fixar uma List

<Steps>
  <Step title="Obtenha seu user ID e o ID da List">
    Você precisa do ID do usuário autenticado e do ID da List que deseja fixar. Encontre os IDs de List na URL ao visualizar uma List.
  </Step>

  <Step title="Fixe a List">

<CodeGroup dropdown>

```bash cURL
curl -X POST "https://api.x.com/2/users/2244994945/pinned_lists" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"list_id": "1454155907651158017"}'
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Fixar uma List
response = client.lists.pin(
    user_id="2244994945",
    list_id="1454155907651158017"
)

print(f"Pinned: {response.data.pinned}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// Fixar uma List
const response = await client.lists.pin("2244994945", {
  listId: "1454155907651158017",
});

console.log(`Pinned: ${response.data?.pinned}`);
```

</CodeGroup>

  </Step>

  <Step title="Revise a resposta">
    ```json
    {
      "data": {
        "pinned": true
      }
    }
    ```
  </Step>
</Steps>

## Desafixar uma List

<CodeGroup dropdown>

```bash cURL
curl -X DELETE "https://api.x.com/2/users/2244994945/pinned_lists/1454155907651158017" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client
from xdk.oauth1_auth import OAuth1

oauth1 = OAuth1(
    api_key="YOUR_API_KEY",
    api_secret="YOUR_API_SECRET",
    access_token="YOUR_ACCESS_TOKEN",
    access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
)

client = Client(auth=oauth1)

# Desafixar uma List
response = client.lists.unpin(
    user_id="2244994945",
    list_id="1454155907651158017"
)

print(f"Pinned: {response.data.pinned}")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client, OAuth1 } from "@xdevplatform/xdk";

const oauth1 = new OAuth1({
  apiKey: "YOUR_API_KEY",
  apiSecret: "YOUR_API_SECRET",
  accessToken: "YOUR_ACCESS_TOKEN",
  accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
});

const client = new Client({ oauth1 });

// Desafixar uma List
const response = await client.lists.unpin("2244994945", "1454155907651158017");

console.log(`Pinned: ${response.data?.pinned}`);
```

</CodeGroup>

**Resposta:**

```json
{
  "data": {
    "pinned": false
  }
}
```

## Observações importantes

<Note>
- Você só pode fixar Lists que segue ou das quais é proprietário
- Lists fixadas aparecem no topo das suas Lists no app do X
- Há um limite para quantas Lists você pode fixar
</Note>
