Os endpoints de Lists fixadas permitem visualizar, fixar e desafixar Lists para o usuário autenticado. Lists fixadas aparecem em destaque na interface do usuário no X.

## Endpoints

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/pinned_lists`](/x-api/users/get-pinned-lists) | Obter Lists fixadas |
| POST | [`/2/users/:id/pinned_lists`](/x-api/users/pin-list) | Fixar uma List |
| DELETE | [`/2/users/:id/pinned_lists/:list_id`](/x-api/users/unpin-list) | Desafixar uma List |

---

## Exemplo: Obter Lists fixadas

```bash
curl "https://api.x.com/2/users/123456789/pinned_lists?\
list.fields=name,description,member_count" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

## Exemplo: Fixar uma List

```bash
curl -X POST "https://api.x.com/2/users/123456789/pinned_lists" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"list_id": "9876543210"}'
```
