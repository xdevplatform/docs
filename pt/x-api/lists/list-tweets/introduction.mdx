O endpoint de Posts da List permite recuperar Posts da timeline de uma List. Obtenha os Posts mais recentes de todos os membros de uma List.

## Endpoint

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| GET | [`/2/lists/:id/tweets`](/x-api/lists/get-list-posts) | Obter Posts de uma List |

---

## Exemplo de requisição

```bash
curl "https://api.x.com/2/lists/1234567890/tweets?\
tweet.fields=created_at,author_id,public_metrics&\
expansions=author_id&\
user.fields=username&\
max_results=100" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
