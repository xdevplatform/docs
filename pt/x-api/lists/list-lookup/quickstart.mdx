## Obter uma List por ID

Recupere os detalhes de uma List específica:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/lists/1234567890?\
list.fields=description,owner_id,member_count,follower_count,private,created_at" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obter uma List por ID
response = client.lists.get(
    "1234567890",
    list_fields=["description", "owner_id", "member_count", "follower_count", "private", "created_at"]
)

print(f"List: {response.data.name}")
print(f"Members: {response.data.member_count}")
```

```javascript JavaScript SDK
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Obter uma List por ID
const response = await client.lists.get("1234567890", {
  listFields: ["description", "owner_id", "member_count", "follower_count", "private", "created_at"],
});

console.log(`List: ${response.data?.name}`);
console.log(`Members: ${response.data?.member_count}`);
```

</CodeGroup>

## Obter Lists de propriedade de um usuário

Recupere todas as Lists de propriedade de um usuário específico:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/users/2244994945/owned_lists?\
list.fields=description,member_count,follower_count&\
max_results=100" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obter Lists de propriedade de um usuário com paginação
for page in client.lists.get_owned_lists(
    "2244994945",
    list_fields=["description", "member_count", "follower_count"],
    max_results=100
):
    for lst in page.data:
        print(f"{lst.name} - {lst.member_count} members")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Obter Lists de propriedade de um usuário com paginação
const paginator = client.lists.getOwnedLists("2244994945", {
  listFields: ["description", "member_count", "follower_count"],
  maxResults: 100,
});

for await (const page of paginator) {
  page.data?.forEach((lst) => {
    console.log(`${lst.name} - ${lst.member_count} members`);
  });
}
```

</CodeGroup>

## Incluir informações do proprietário

Expanda os dados de usuário do proprietário:

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/lists/1234567890?\
list.fields=description,owner_id&\
expansions=owner_id&\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obter List com informações do proprietário
response = client.lists.get(
    "1234567890",
    list_fields=["description", "owner_id"],
    expansions=["owner_id"],
    user_fields=["username", "verified"]
)

print(f"List: {response.data.name}")
# Informações do proprietário estão em response.includes.users
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

// Obter List com informações do proprietário
const response = await client.lists.get("1234567890", {
  listFields: ["description", "owner_id"],
  expansions: ["owner_id"],
  userFields: ["username", "verified"],
});

console.log(`List: ${response.data?.name}`);
// Informações do proprietário estão em response.includes?.users
```

</CodeGroup>

### Resposta com expansion

```json title="Exemplo de resposta" lines wrap icon="/icons/xds/icon-brackets.svg"
{
  "data": {
    "id": "1234567890",
    "name": "Tech News",
    "description": "Top tech journalists",
    "owner_id": "2244994945"
  },
  "includes": {
    "users": [
      {
        "id": "2244994945",
        "username": "XDevelopers",
        "verified": true
      }
    ]
  }
}
```

## Fields disponíveis

| Field | Descrição |
|:------|:------------|
| `description` | Descrição da List |
| `owner_id` | User ID do proprietário |
| `private` | Se a List é privada |
| `member_count` | Número de membros |
| `follower_count` | Número de seguidores |
| `created_at` | Data de criação da List |
