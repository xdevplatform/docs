## Comparando os endpoints de consulta de List da X API

O grupo de endpoints v2 de consulta de List substituirá os endpoints standard v1.1 [GET lists/show](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-show) e [GET lists/ownership](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-ownerships). Se você tem código, apps ou ferramentas que utilizam uma dessas versões dos endpoints de consulta de List e está considerando migrar para o endpoint mais recente da X API v2, este conjunto de guias é para você.

As tabelas a seguir comparam os endpoints de List do standard v1.1 e da X API v2:

**Consulta de List por ID**

|     |     |     |
| :--- | :--- | :--- |
| Descrição | Standard v1.1 | X API v2 |
| Métodos HTTP suportados | `GET` | `GET` |
| Domínio do host | `https://api.x.com` | `https://api.x.com` |
| Caminho do endpoint | `/1.1/lists/show.json` | `/2/lists/:id` |
| [Autenticação](/resources/fundamentals/authentication) | OAuth 1.0a User Context<br/><br/>App only | OAuth 1.0a User Context<br/><br/>OAuth 2.0 Authorization Code with PKCE<br/><br/>App only |
| [Limites de requisição](/resources/fundamentals/rate-limits) padrão | 75 requisições por 15 min com OAuth 1.0a<br/><br/>75 requisições por 15 min com OAuth 2.0<br/><br/>75 requisições por 15 min com App only | 75 requisições por 15 min com OAuth 1.0a<br/><br/>75 requisições por 15 min com OAuth 2.0<br/><br/>75 requisições por 15 min com App only |

**Consulta de Lists de propriedade de um usuário**

|     |     |     |
| :--- | :--- | :--- |
| Descrição | Standard v1.1 | X API v2 |
| Métodos HTTP suportados | `GET` | `GET` |
| Domínio do host | `https://api.x.com` | `https://api.x.com` |
| Caminho do endpoint | `/1.1/lists/ownerships.json` | `/2/users/:id/owned_lists` |
| [Autenticação](/resources/fundamentals/authentication) | OAuth 1.0a User Context<br/><br/>App only | OAuth 1.0a User Context<br/><br/>OAuth 2.0 Authorization Code with PKCE<br/><br/>App only |
| [Limites de requisição](/resources/fundamentals/rate-limits) padrão | 15 requisições por 15 min com OAuth 1.0a<br/><br/>15 requisições por 15 min com App only | 15 requisições por 15 min com OAuth 1.0a<br/><br/>15 requisições por 15 min com OAuth 2.0<br/><br/>15 requisições por 15 min com App only |

Para acessar os endpoints da X API v2, você precisa [criar uma conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info). Ao autenticar, você deve usar chaves e tokens de um [App de desenvolvedor](/resources/fundamentals/developer-apps) que esteja em um [Project](/resources/fundamentals/developer-apps).

Saiba mais sobre como obter acesso aos endpoints da X API v2 na nossa página de [introdução](/x-api/getting-started/getting-access).
