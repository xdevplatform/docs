Os endpoints de consulta de List permitem recuperar informações sobre Lists. Consulte uma List específica pelo ID ou obtenha todas as Lists de propriedade de um usuário.

## Endpoints

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| GET | [`/2/lists/:id`](/x-api/lists/get-list-by-id) | Obter List por ID |
| GET | [`/2/users/:id/owned_lists`](/x-api/users/get-owned-lists) | Obter Lists de propriedade de um usuário |

---

## Fields de resposta

Por padrão, a resposta inclui `id` e `name`. Solicite fields adicionais:

| Field | Descrição |
|:------|:------------|
| `description` | Descrição da List |
| `owner_id` | User ID do proprietário |
| `private` | Se a List é privada |
| `follower_count` | Número de seguidores |
| `member_count` | Número de membros |
| `created_at` | Data de criação da List |

### Exemplo de requisição

```bash
curl "https://api.x.com/2/lists/1234567890?\
list.fields=description,owner_id,member_count,follower_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
