## Autenticação

Os endpoints de consulta de List suportam vários métodos de autenticação:

| Método | Melhor para | Acesso a Lists privadas? |
|:-------|:---------|:-------------------------|
| [OAuth 2.0 App-Only](/resources/fundamentals/authentication#oauth-2-0) | Dados públicos de List | Não |
| [OAuth 2.0 Authorization Code with PKCE](/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) | Apps voltados ao usuário | Sim (próprias/seguidas) |
| [OAuth 1.0a User Context](/resources/fundamentals/authentication) | Integrações legadas | Sim (próprias/seguidas) |

### Exemplo de requisição

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/lists/84839422?\
list.fields=description,member_count,follower_count,private" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python Python SDK
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obter uma List por ID
response = client.lists.get(
    list_id="84839422",
    list_fields=["description", "member_count", "follower_count", "private"]
)
print(response.data)
```

```javascript JavaScript SDK
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

const response = await client.lists.get("84839422", {
  listFields: ["description", "member_count", "follower_count", "private"],
});
console.log(response.data);
```

</CodeGroup>

## Fields e expansions

### Resposta padrão

```json
{
  "data": {
    "id": "84839422",
    "name": "Tech News"
  }
}
```

### Fields disponíveis

<Accordion title="list.fields">
| Field | Descrição |
|:------|:------------|
| `created_at` | Timestamp de criação da List |
| `description` | Descrição da List |
| `follower_count` | Número de seguidores |
| `member_count` | Número de membros |
| `owner_id` | User ID do proprietário |
| `private` | Se a List é privada |
</Accordion>

<Accordion title="user.fields (requer expansion owner_id)">
| Field | Descrição |
|:------|:------------|
| `username` | @handle do proprietário |
| `name` | Nome de exibição do proprietário |
| `verified` | Status de verificação do proprietário |
| `profile_image_url` | URL do avatar do proprietário |
</Accordion>

### Exemplo com expansions

<CodeGroup dropdown>

```bash cURL
curl "https://api.x.com/2/lists/84839422?\
list.fields=description,member_count,follower_count,owner_id&\
expansions=owner_id&\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# Obter List com expansion de proprietário
response = client.lists.get(
    list_id="84839422",
    list_fields=["description", "member_count", "follower_count", "owner_id"],
    expansions=["owner_id"],
    user_fields=["username", "verified"]
)

print(response.data)
print(response.includes)  # Contém o objeto de usuário do proprietário
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

const response = await client.lists.get("84839422", {
  listFields: ["description", "member_count", "follower_count", "owner_id"],
  expansions: ["owner_id"],
  userFields: ["username", "verified"],
});

console.log(response.data);
console.log(response.includes); // Contém o objeto de usuário do proprietário
```

</CodeGroup>

## Paginação

Ao recuperar Lists de propriedade, os resultados são paginados:

<CodeGroup dropdown>

```bash cURL
# Primeira requisição
curl "https://api.x.com/2/users/123/owned_lists?max_results=100" \
  -H "Authorization: Bearer $BEARER_TOKEN"

# Requisição subsequente com token de paginação
curl "https://api.x.com/2/users/123/owned_lists?max_results=100&pagination_token=NEXT_TOKEN" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

```python title="Python SDK" lines wrap icon="python"
from xdk import Client

client = Client(bearer_token="YOUR_BEARER_TOKEN")

# O SDK trata a paginação automaticamente
all_lists = []

for page in client.lists.get_user_owned_lists(user_id="123", max_results=100):
    if page.data:
        all_lists.extend(page.data)

print(f"Found {len(all_lists)} lists")
```

```javascript title="JavaScript SDK" lines wrap icon="square-js"
import { Client } from "@xdevplatform/xdk";

const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

async function getAllOwnedLists(userId) {
  const allLists = [];

  // O SDK trata a paginação automaticamente
  const paginator = client.lists.getUserOwnedLists(userId, { maxResults: 100 });

  for await (const page of paginator) {
    if (page.data) {
      allLists.push(...page.data);
    }
  }

  return allLists;
}

// Uso
const lists = await getAllOwnedLists("123");
console.log(`Found ${lists.length} lists`);
```

## Lists privadas

- Lists privadas só são visíveis para o proprietário
- Você deve se autenticar como proprietário para recuperar os detalhes de uma List privada
- O field `private` indica se uma List é privada

---

## Tratamento de erros

| Status | Erro | Solução |
|:-------|:------|:---------|
| 400 | Requisição inválida | Verifique o formato do ID da List |
| 401 | Não autorizado | Verifique a autenticação |
| 403 | Proibido | A List pode ser privada |
| 404 | Não encontrado | A List não existe |
| 429 | Muitas requisições | Aguarde e tente novamente |
