## Endpoint

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| GET | [`/2/communities/search`](/x-api/communities/search-communities) | Buscar Communities |

---

## Parâmetros

| Parâmetro | Descrição |
|:----------|:------------|
| `query` | Consulta de busca (obrigatório) |
| `max_results` | Resultados por página (máx. 100) |
| `community.fields` | Campos adicionais de Community |

---

## Exemplo de requisição

```bash
curl "https://api.x.com/2/communities/search?\
query=Python&\
max_results=10&\
community.fields=name,description,member_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
