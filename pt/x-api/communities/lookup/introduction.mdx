O endpoint de consulta de Communities permite recuperar informações sobre Communities do X pelo ID.

## Visão geral

Communities são grupos públicos ou privados no X onde os membros podem compartilhar Posts, discutir tópicos e se conectar em torno de interesses em comum.

## Endpoint

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| GET | [`/2/communities/:id`](/x-api/communities/get-community-by-id) | Obter Community por ID |

---

## Campos de resposta

| Campo | Descrição |
|:------|:------------|
| `id` | ID da Community |
| `name` | Nome da Community |
| `description` | Descrição da Community |
| `created_at` | Data de criação |
| `member_count` | Número de membros |
| `is_private` | Se a Community é privada |

---

## Exemplo de requisição

```bash
curl "https://api.x.com/2/communities/1234567890?\
community.fields=name,description,member_count,created_at" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
