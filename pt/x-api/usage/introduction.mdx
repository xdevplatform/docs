O endpoint Usage permite monitorar o uso da sua API, incluindo o número de Posts consumidos. Acompanhe seu uso programaticamente para gerenciar custos e permanecer dentro dos limites.

<Note>
Os planos pay-per-usage estão sujeitos a um limite mensal de 2 milhões de leituras de Post. Se você precisar de maior volume, considere um [plano Enterprise](/forms/enterprise-api-interest).
</Note>

## Endpoint

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| GET | [`/2/usage/tweets`](/x-api/usage/get-usage) | Obter dados de uso de Posts |

---

## Dados de resposta

A resposta inclui contagens diárias de consumo de Posts:

```json title="Exemplo de resposta" lines wrap icon="/icons/xds/icon-brackets.svg"
{
  "data": {
    "daily_project_usage": [
      {
        "date": "2024-01-15",
        "usage": [
          {
            "app_id": "12345678",
            "tweets_consumed": 15420
          }
        ]
      }
    ],
    "project_id": "1234567890",
    "project_cap": 10000000
  }
}
```

### Campos

| Campo | Descrição |
|:------|:------------|
| `daily_project_usage` | Array de dados de uso diário |
| `date` | Data no formato YYYY-MM-DD |
| `app_id` | ID do seu App |
| `tweets_consumed` | Posts consumidos no dia |
| `project_cap` | Seu limite mensal de Posts |

---

## Exemplo de requisição

```bash
curl "https://api.x.com/2/usage/tweets" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

## Casos de uso

- **Monitoramento de custos** — Acompanhe o consumo em relação ao seu orçamento
- **Alertas** — Configure alertas ao se aproximar dos limites
- **Otimização** — Identifique endpoints de alto consumo
- **Relatórios** — Gere relatórios de uso

<Tip>
Os recursos são desduplicados dentro de uma janela de 24 horas em UTC, então solicitar o mesmo recurso várias vezes em um dia conta apenas como uma cobrança. [Saiba mais sobre preços →](/x-api/getting-started/pricing)
</Tip>
