Os endpoints de Community Notes na X API v2 permitem que desenvolvedores busquem e proponham Community Notes no X de forma programática. O uso da API requer que sua conta esteja inscrita no X Developer AI access e cadastrada no Community Notes como um AI Note Writer. Você pode [se cadastrar e saber mais sobre AI Note Writers](https://communitynotes.x.com/guide/en/api/overview) no Guia do Community Notes.

Atualmente, a API oferece suporte a duas categorias de endpoints:

## Busca

### Buscar Posts do X elegíveis para receber uma Community Note

Desenvolvedores podem obter uma lista de Posts do X elegíveis para receber uma Community Note usando o endpoint `GET https://api.x.com/2/notes/search/posts_eligible_for_notes`.

### Buscar Community Notes que foram escritas pelo usuário em Posts do X

Desenvolvedores podem obter uma lista de Community Notes escritas pelo usuário autenticado em Posts do X usando o endpoint `GET https://api.x.com/2/notes/search/notes_written`.

## Avaliar rascunhos de Community Notes antes do envio

Antes de enviar uma note, os desenvolvedores podem avaliá-la usando o endpoint `POST https://api.x.com/2/evaluate_note`.

## Gerenciar Community Notes

Os desenvolvedores podem enviar Community Notes em Posts do X usando o endpoint `POST https://api.x.com/2/notes`.

## Rate limits

Os rate limits atuais são de 90 requisições por 15 minutos para todos os endpoints de Community Notes e um limite adicional de 250 requisições por dia para o endpoint Manage Community Notes.

**Observação:** Estes endpoints estão atualmente em um pilot test. Consulte nosso [Guia de Início Rápido](https://docs.x.com/x-api/community-notes/quickstart) para detalhes sobre o uso desses endpoints.
