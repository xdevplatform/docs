## Endpoint

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| GET | [`/2/spaces/search`](/x-api/spaces/search-spaces) | Buscar Spaces |

---

## Parâmetros

| Parâmetro | Descrição |
|:----------|:------------|
| `query` | Consulta de busca (obrigatório) |
| `state` | Filtrar por `live` ou `scheduled` |
| `space.fields` | Campos adicionais de Space |
| `expansions` | Objetos relacionados a incluir |

---

## Exemplo de requisição

```bash
curl "https://api.x.com/2/spaces/search?\
query=AI&\
state=live&\
space.fields=title,host_ids,participant_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
