Os endpoints de consulta de Spaces permitem obter informações sobre Spaces ao vivo ou agendados. Consulte Spaces pelo ID ou encontre Spaces criados por usuários específicos.

## Endpoints

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| GET | [`/2/spaces/:id`](/x-api/spaces/get-space-by-id) | Obter Space por ID |
| GET | [`/2/spaces`](/x-api/spaces/get-spaces-by-ids) | Obter Spaces por IDs |
| GET | [`/2/spaces/by/creator_ids`](/x-api/spaces/get-spaces-by-creator-ids) | Obter Spaces pelos user IDs dos criadores |
| GET | [`/2/spaces/:id/buyers`](/x-api/spaces/get-space-ticket-buyers) | Obter compradores de ingressos de um Space |
| GET | [`/2/spaces/:id/tweets`](/x-api/spaces/get-space-posts) | Obter Posts compartilhados em um Space |

## Campos de resposta

Por padrão, a resposta inclui `id` e `state`. Solicite campos adicionais:

| Campo | Descrição |
|:------|:------------|
| `title` | Título do Space |
| `host_ids` | IDs de usuários host |
| `speaker_ids` | IDs de usuários speaker |
| `participant_count` | Número de participantes |
| `scheduled_start` | Horário de início agendado |
| `started_at` | Horário de início real |
| `ended_at` | Horário de término |
| `is_ticketed` | Se o Space tem ingressos |

### Estados do Space

| Estado | Descrição |
|:------|:------------|
| `live` | Ativo no momento |
| `scheduled` | Agendado para o futuro |
| `ended` | Encerrado |

## Exemplo de requisição

```bash
curl "https://api.x.com/2/spaces/1DXxyRYNejbKM?\
space.fields=title,host_ids,participant_count,scheduled_start,state" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
