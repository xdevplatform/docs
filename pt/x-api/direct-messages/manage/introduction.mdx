## Endpoints

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| POST | `/2/dm_conversations` | Cria uma nova conversa |
| POST | `/2/dm_conversations/with/:participant_id/messages` | Envia para conversa individual |
| POST | `/2/dm_conversations/:dm_conversation_id/messages` | Envia para conversa existente |
| DELETE | `/2/dm_events/:id` | Exclui um evento de DM |

---

## Exemplo: enviar uma mensagem

```bash
curl -X POST "https://api.x.com/2/dm_conversations/with/1234567890/messages" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello! How are you?"}'
```

## Exemplo de resposta

```json
{
  "data": {
    "dm_conversation_id": "1234567890-0987654321",
    "dm_event_id": "1122334455667788990"
  }
}
```

---

## Tipos de mensagem

Você pode enviar mensagens de texto e anexar mídia:

```json
{
  "text": "Check out this photo!",
  "attachments": [{
    "media_id": "1234567890123456789"
  }]
}
```
