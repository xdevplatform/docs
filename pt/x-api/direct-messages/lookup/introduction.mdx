Os endpoints de consulta de Mensagens Diretas permitem que você recupere eventos de DM para o usuário autenticado, incluindo mensagens de conversas individuais e em grupo.

## Endpoints

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| GET | [`/2/dm_events`](/x-api/direct-messages/get-dm-events) | Obtém todos os eventos de DM para o usuário |
| GET | [`/2/dm_conversations/with/:participant_id/dm_events`](/x-api/direct-messages/get-dm-events-for-a-dm-conversation) | Obtém eventos de conversa individual |
| GET | [`/2/dm_conversations/:dm_conversation_id/dm_events`](/x-api/direct-messages/get-dm-events-for-a-dm-conversation-1) | Obtém eventos por ID de conversa |

---

## Tipos de eventos

| Evento | Descrição |
|:------|:------------|
| `MessageCreate` | Uma mensagem foi enviada na conversa |
| `ParticipantsJoin` | Um usuário entrou na conversa |
| `ParticipantsLeave` | Um usuário saiu da conversa |

---

## Retenção de dados

<Note>
Eventos de até **30 dias atrás** estão disponíveis por meio destes endpoints.
</Note>
