Os endpoints de gerenciamento de bloqueios de DM permitem que você bloqueie ou desbloqueie uma conta especificada em nome de um usuário autenticado. Para esses endpoints, há dois métodos POST disponíveis:

* **/2/users/:id/dm/block**: Permite bloquear uma conta
* **/2/users/:id/dm/unblock**: Permite desbloquear uma conta


### Primeiros passos
### Autenticação

Como você está fazendo solicitações em nome de um usuário, deve autenticar esses endpoints com [OAuth 1.0a User Context](/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow) ou [OAuth 2.0 Authorization Code with PKCE](/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2), e utilizar os user Access Tokens associados ao usuário em cujo nome você está fazendo a solicitação. Você pode gerar esse user Access Token usando o [3-legged OAuth flow](https://developer.x.com/resources/fundamentals/authentication/obtaining-user-access-tokens) (OAuth 1.0a) ou usando o [Authorization Code with PKCE grant flow](/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) (OAuth 2.0).

### Fazendo uma solicitação

Bloquear

Depois que um usuário se autenticar com seu app, você pode chamar o endpoint Block em nome do usuário, conforme mostrado abaixo:

      ```
      curl --request POST 'https://api.x.com/2/users/:id/dm/block' --header 'Authorization: ••••••'
      ```




Se a solicitação for bem-sucedida, você deverá ver a resposta JSON conforme mostrado abaixo:

```json
{
   "data": {
       "blocked": true
   }
}
```




**Desbloquear**

Depois que um usuário se autenticar com seu app, você pode chamar o endpoint Unblock em nome do usuário, conforme mostrado abaixo:

      ```
      curl --request POST 'https://api.x.com/2/users/:id/dm/unblock' --header 'Authorization: ••••••'
      ```




Se a solicitação for bem-sucedida, você deverá ver a resposta JSON conforme mostrado abaixo:

```json
{
   "data": {
       "blocked": false
   }
}
```
