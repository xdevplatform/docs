Esta página aborda o tratamento de desconexões específico do Powerstream. Para orientação abrangente sobre como lidar com desconexões em todos os endpoints de streaming, consulte o [guia de fundamentos sobre lidar com desconexões](/x-api/fundamentals/handling-disconnections).

## Tratamento de desconexões no Powerstream

Os conceitos centrais para lidar com desconexões aplicam-se a todos os endpoints de streaming. Consulte o guia de fundamentos para:

- Por que as conexões são desconectadas
- Erros comuns de desconexão
- Detectando desconexões
- Estratégias de reconexão e backoff
- Melhores práticas

## Recuperando dados perdidos

Se você tiver uma desconexão, consulte [Recuperação e redundância](/x-api/fundamentals/recovery-and-redundancy) para estratégias de recuperação de dados perdidos, incluindo:

- **Backfill** — Use o parâmetro `backfillMinutes` para desconexões de 5 minutos ou menos
- **Recovery** — Use os parâmetros `startTime` e `endTime` para desconexões mais longas (até 24 horas)

### Exemplo de backfill do Powerstream

```bash
curl 'https://api.x.com/2/powerstream?backfillMinutes=5' \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

### Exemplo de recovery do Powerstream

```bash
curl 'https://api.x.com/2/powerstream?startTime=2022-07-12T15:10:00Z&endTime=2022-07-12T15:20:00Z' \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```
