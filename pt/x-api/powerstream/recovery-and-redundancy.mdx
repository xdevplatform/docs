Esta página aborda recursos de recuperação e redundância específicos do Powerstream. Para orientação abrangente sobre recuperação e redundância em todos os endpoints de streaming, consulte o [guia de fundamentos de recuperação e redundância](/x-api/fundamentals/recovery-and-redundancy).

## Recursos de recuperação do Powerstream

Os conceitos centrais de recuperação e redundância aplicam-se a todos os endpoints de streaming. Consulte o guia de fundamentos para:

- Conexões redundantes
- Árvore de decisão Backfill vs. Recovery
- Melhores práticas

## Backfill

Para desconexões de **5 minutos ou menos**, use o parâmetro `backfillMinutes`:

```bash
curl 'https://api.x.com/2/powerstream?backfillMinutes=5' \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

<Note>
Posts mais antigos são entregues primeiro. Os Posts **não** são desduplicados — seu sistema deve tolerar duplicatas.
</Note>

## Recovery

Para desconexões **superiores a 5 minutos** (até 24 horas), use os parâmetros `startTime` e `endTime`:

| Parâmetro | Tipo | Descrição |
|:----------|:-----|:------------|
| `startTime` | Data ISO 8601 | Hora de início para recuperar (UTC) |
| `endTime` | Data ISO 8601 | Hora de término para recuperar (UTC) |

```bash
curl 'https://api.x.com/2/powerstream?startTime=2022-07-12T15:10:00Z&endTime=2022-07-12T15:20:00Z' \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

Uma vez conectado, o Recovery irá retransmitir o período de tempo especificado e, em seguida, desconectar.
