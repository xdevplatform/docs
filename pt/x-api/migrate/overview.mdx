## O que é a X API v2?

A X API v2 agora é a X API principal e é onde o investimento em produto e a inovação estão concentrados. Fizemos parceria com desenvolvedores para construir a próxima geração da X API, atendendo melhor à nossa diversificada comunidade de desenvolvedores. Com base no feedback dos desenvolvedores, reconstruímos a API para atender a uma gama mais ampla de necessidades, introduzimos novos recursos e endpoints e aprimoramos a experiência do desenvolvedor.

Nos últimos anos, fizemos parceria com desenvolvedores e reconstruímos a API para atender melhor a uma coleção mais ampla de necessidades, introduzir novos recursos e endpoints e aprimorar a experiência do desenvolvedor. Estamos comprometidos em continuar a construir uma plataforma de desenvolvedores aberta e ansiosos para ver o que você construirá com a X API v2.

## Por que migrar?

A X API v2 é construída sobre uma base moderna e mais sustentável e inclui endpoints substitutos aprimorados para os produtos standard v1.1 e enterprise, além de funcionalidades totalmente novas. Recomendamos fortemente que os clientes das APIs legadas (v1.1 e enterprise) comecem a migrar para a v2, pois pretendemos descontinuá-las eventualmente. Use a X API para ouvir e analisar a conversa pública, engajar-se com pessoas no X e inovar.

Nesta seção, discutiremos os endpoints e funcionalidades.

Embora a maioria dos endpoints na X API v2 sejam substituições, introduzimos vários novos endpoints. Aqui estão vários exemplos de novos endpoints que lançamos na v2:

- [Endpoints de Spaces](/x-api/spaces/introduction) para ajudar as pessoas a aproveitar mais o X Spaces e permitir que os desenvolvedores ajudem a moldar o futuro das conversas em áudio.
- [Hide replies](/x-api/posts/hide-replies/introduction), que permite construir ferramentas que ajudam a limitar o impacto de respostas abusivas, que distraem ou enganosas em escala.
- Novos endpoints de Lists que permitem [fixar e desafixar Lists](/x-api/lists/pinned-lists/introduction) ou consultar as Lists fixadas de alguém.
- Novos [endpoints de batch compliance](/x-api/compliance/batch-compliance/introduction) que permitem garantir que os dados de usuários e Tweets armazenados estejam em conformidade.

## Novas funcionalidades

A X API v2 também inclui novos recursos que ajudarão você a obter mais valor com a X API. Muitas das novidades foram impulsionadas pelo seu feedback e incluem certos recursos que eram reservados anteriormente para clientes enterprise.

Algumas das melhorias na API incluem:

- [Design consistente entre endpoints](/x-api/fundamentals/consistency)
- [Capacidade de especificar quais fields e objetos são retornados no payload da resposta](/x-api/fundamentals/data-dictionary/reference#how-to-use-fields-and-expansions)
- [Objetos de dados novos e mais detalhados](/x-api/fundamentals/data-dictionary)
- [Recebimento e filtragem de dados com novas informações contextuais fornecidas por annotations de Tweets](/x-api/fundamentals/post-annotations)
- [Acesso a novas métricas](/x-api/fundamentals/metrics)
- [Identificação e filtragem simples de conversas que pertencem a uma thread de resposta](/x-api/fundamentals/conversation-id)
- [Funcionalidade avançada e maior acesso a dados para pesquisadores acadêmicos](https://developer.x.com/content/developer-twitter/en/products/twitter-api/academic-research)
- [Funcionalidade de recuperação e redundância para endpoints de streaming](/x-api/fundamentals/recovery-and-redundancy)
- [Retorno fácil de contagens de Tweets que correspondem a uma consulta](/x-api/posts/counts/introduction)
- [Suporte a Edit Tweets](/x-api/fundamentals/edit-posts)
- Filtragem de spam com alta confiança
- URLs encurtadas são totalmente expandidas para filtragem e análise mais eficazes
- Objetos JSON de resposta simplificados, removendo campos descontinuados e modernizando rótulos
- Retorno de 100% dos Tweets públicos e disponíveis correspondentes em consultas de busca
- "Rules" de streaming para você fazer alterações sem interromper conexões
- Linguagem de consulta mais expressiva para busca de Tweets, contagens de Tweets e filtered stream
- Especificação OpenAPI para construir novas bibliotecas e rastrear mudanças de forma mais transparente
