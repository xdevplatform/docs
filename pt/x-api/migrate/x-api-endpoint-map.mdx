A tabela a seguir mapeia os endpoints da X API v2 para os correspondentes endpoints standard v1.1 e enterprise. Para saber mais sobre cada uma dessas versões e tiers, visite nosso [guia de introdução da X API](/x-api/getting-started/about-x-api).

Você notará que ainda temos vários itens marcados como **\[Em breve]**. Se você notar algo nesta tabela marcado como **\[Substituição em consideração]** ou **\[Sem substituição planejada]** e gostaria que lançássemos uma versão v2 desse endpoint, avise-nos através de nosso [fórum da comunidade](https://devcommunity.x.com/) ou de seu gerente de conta enterprise.
