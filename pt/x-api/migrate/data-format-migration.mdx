## Introdução

Com o lançamento da versão v2 da X API, adotamos um novo formato de resposta de dados e método para solicitar diferentes objetos e campos, que estamos simplesmente chamando de formato X API v2.

Na seção de diferenças gerais, você pode aprender sobre algumas mudanças relevantes para usuários standard e enterprise. No entanto, também elaboramos um guia específico para o [formato Native standard v1.1](https://developer.x.com/en/docs/x-api/v1/data-dictionary/overview), o [formato Native Enriched](/x-api/enterprise-gnip-2.0/fundamentals/data-dictionary#native-enriched-tweet-object) enterprise e o [formato Activity Streams](/x-api/enterprise-gnip-2.0/fundamentals/data-dictionary#activity-object) enterprise, que ajudam a mapear campos e explicam quais fields e expansions você deve usar para solicitar os novos campos da v2.

* [Formato Native para X API v2 (standard v1.1)](/x-api/migrate/data-format-migration#migrating-from-standard-v1-1s-data-format-to-v2)
* [Native Enriched para X API v2 (enterprise)](/x-api/migrate/data-format-migration#migrating-from-native-enriched-data-format-to-v2)
* [Activity Streams para X API v2 (enterprise)](/x-api/migrate/data-format-migration#migrating-from-activity-streams-data-format-to-v2)

Você também pode se interessar por nossa [ferramenta visual de migração de formato de dados](/x-api/migrate/data-format-migration#visual-data-format-migration-tool) para ajudá-lo a ver rapidamente as diferenças entre o [formato de dados X API v1.1](https://developer.x.com/en/docs/x-api/v1/data-dictionary/overview) e o [formato X API v2](/x-api/introduction).
