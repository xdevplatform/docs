Os endpoints de Batch Compliance permitem que você faça upload de conjuntos de dados de Post IDs ou user IDs e receba o status atual de compliance de cada um. Use isso para identificar Posts excluídos, contas suspensas e outros eventos de compliance.

## Como funciona

1. **Crie um job** — Especifique o tipo (Posts ou usuários) e a URL de upload
2. **Envie os IDs** — Faça upload do seu conjunto de dados para a URL fornecida
3. **Aguarde o processamento** — O job é processado de forma assíncrona
4. **Baixe os resultados** — Obtenha o status de compliance de cada ID

## Endpoints

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| POST | [`/2/compliance/jobs`](/x-api/compliance/create-compliance-job) | Criar um novo compliance job |
| GET | [`/2/compliance/jobs/:id`](/x-api/compliance/get-compliance-job-by-id) | Obter status do job |
| GET | [`/2/compliance/jobs`](/x-api/compliance/get-compliance-jobs) | Listar todos os jobs |

---

## Tipos de job

| Tipo | Descrição |
|:-----|:------------|
| `tweets` | Verificar status de compliance de Posts |
| `users` | Verificar status de compliance de usuários |

---

## Eventos de compliance

### Eventos de Post

| Evento | Descrição |
|:------|:------------|
| `deleted` | Post foi excluído pelo usuário |
| `bounced` | Post falhou na verificação de compliance |
| `protected` | Conta se tornou protegida |
| `suspended` | Conta foi suspensa |
| `scrub_geo` | Dados de geolocalização foram removidos |

### Eventos de usuário

| Evento | Descrição |
|:------|:------------|
| `deleted` | Conta foi excluída |
| `suspended` | Conta foi suspensa |
| `protected` | Conta se tornou protegida |
| `deactivated` | Conta foi desativada |

---

## Exemplo: Criar um job

```bash
curl -X POST "https://api.x.com/2/compliance/jobs" \
  -H "Authorization: Bearer $BEARER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "tweets",
    "name": "my-compliance-job"
  }'
```
