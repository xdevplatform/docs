## Trabalhando com uploads retomáveis (resumable uploads)

Ao usar os endpoints de Batch compliance, desenvolvedores podem fazer upload em lote de grandes volumes de dados do X e entender qual ação é necessária para garantir que seus conjuntos de dados reflitam a intenção do usuário e o estado atual do conteúdo no X. Fazer upload de grandes volumes de dados para um servidor remoto é uma operação relativamente simples quando os sistemas e a conectividade são estáveis e confiáveis. No entanto, nem sempre é esse o caso. Alguns ambientes podem impor um timeout de conexão, efetivamente cortando a conexão entre seu app e o servidor de upload após um determinado tempo; você também pode encontrar problemas de conexão, por exemplo, ao tentar enviar um arquivo grande do seu laptop por uma conexão wi-fi. Nessas circunstâncias, é desejável enviar partes menores do arquivo por vez, em vez de manter uma única conexão contínua.

Os endpoints de batch compliance do X dependem do Google Cloud Storage para processar arquivos grandes. Esse tipo de armazenamento é otimizado para diversas aplicações; o Cloud Storage oferece suporte a uma técnica de gerenciamento de arquivos grandes chamada resumable uploads.

Se o upload apresentar algum problema em qualquer ponto, o Google Cloud Storage é capaz de retomar a operação de onde parou.
