O X tem compromisso com sua comunidade de desenvolvedores que constroem com a X API. Como parte desse compromisso, buscamos tornar nossa API aberta e justa para desenvolvedores, segura para as pessoas no X e benéfica para a plataforma X como um todo. É fundamental que qualquer desenvolvedor que armazene conteúdo do X offline garanta que os dados reflitam a intenção do usuário e o estado atual do conteúdo no X. Por exemplo, quando alguém no X exclui um Post ou sua conta, protege seus Posts ou edita um Post, é essencial que tanto o X quanto nossos desenvolvedores respeitem as expectativas e a intenção dessa pessoa.

Os streams quase em tempo real de eventos de compliance fornecem aos desenvolvedores as ferramentas para manter os dados do X em conformidade com o [X Developer Agreement and Policy](https://developer.x.com/en/developer-terms/policy).

Existem dois streams de eventos de compliance, um para eventos de _Post compliance_ e outro para eventos de _User compliance_. Esses streams estão disponíveis com acesso Enterprise e foram projetados para ajudar parceiros que ingerem grandes volumes de dados a "ouvir" eventos de compliance, como eventos de edição de Post.

Esses streams fornecem os seguintes eventos:

**Post compliance stream:**

* **delete** \- indica que o Post foi excluído.

* **tweet_edit** \- indica que um Post foi editado e fornece o ID do Post atualizado.

* **withheld** \- indica que o Post foi retido em um ou mais países.

* **drop** \- indica que o Post deve ser removido da visualização pública.

* **undrop** \- indica que o Post pode ser exibido novamente e tratado como público.


**User compliance stream:**

* **user_delete** \- indica que a conta de usuário foi excluída

* **user_undelete** \- indica que a conta de usuário foi restaurada

* **user_protect** \- indica que a conta de usuário se tornou privada

* **user_unprotect** \- indica que a conta de usuário se tornou pública

* **user_withheld** \- indica que a conta de usuário foi retida em um ou mais países.

* **user_suspend** \- indica que a conta de usuário foi suspensa
* **user_unsuspend** \- indica que a conta de usuário teve sua suspensão removida
* **user\_profile\_modification** \- indica que o perfil do usuário foi atualizado. Isso inclui uma descrição, nome, localização e URL atualizados.

**Configuração da conta**

Para acessar esses endpoints, você precisará de:

* Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info) aprovada.
* Autenticar-se usando as chaves e tokens de um [developer App](/resources/fundamentals/developer-apps) que esteja localizado dentro de um [Projeto](/resources/fundamentals/developer-apps).

Saiba mais sobre como obter acesso aos endpoints da X API v2 em nosso [guia de introdução](/x-api/getting-started/getting-access).
