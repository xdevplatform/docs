Os endpoints de Stream Connections permitem recuperar o histórico das conexões de streaming da sua aplicação e encerrar conexões ativas ou múltiplas. Use-os para monitorar o status da conexão, resolver problemas como conexões duplicadas e gerenciar sessões de streaming para endpoints como Filtered Stream e Sampled Stream.

<Note>
Esses endpoints exigem [autenticação com Bearer Token](/fundamentals/authentication/oauth-2-0/application-only) e estão disponíveis para apps com acesso aos endpoints de streaming.
</Note>

## Endpoints

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| GET | [`/2/connections`](/x-api/connections/get-connection-history) | Obter conexões de streaming ativas e históricas |
| DELETE | [`/2/connections/all`](/x-api/connections/terminate-all-connections) | Encerrar todas as conexões ativas |
| DELETE | [`/2/connections/{endpoint_id}`](/x-api/connections/terminate-connections-by-endpoint) | Encerrar conexões de um endpoint específico |
| DELETE | [`/2/connections`](/x-api/connections/terminate-multiple-connections) | Encerrar múltiplas conexões por UUIDs |

---

## Casos de uso

- **Solucionar desconexões** — Verifique o histórico para diagnosticar problemas ([consulte lidando com desconexões](/x-api/fundamentals/handling-disconnections))
- **Aplicar limites de conexão** — Encerre conexões duplicadas ou em excesso
- **Limpar sessões** — Interrompa todos os streams antes de manutenção ou redeploy
- **Monitorar uso** — Acompanhe padrões de conexão em endpoints como filtered_stream, sample_stream
