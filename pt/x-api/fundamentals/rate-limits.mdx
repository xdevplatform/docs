Rate limits controlam o número de solicitações que você pode fazer a cada endpoint. Exceder os limites resulta em um erro 429 até que a janela seja redefinida.

---

## Como os rate limits funcionam

| Conceito | Descrição |
|:--------|:------------|
| **Janela de tempo** | Geralmente 15 minutos ou 24 horas |
| **Limites por usuário** | Aplicam-se com OAuth 1.0a ou OAuth 2.0 user tokens |
| **Limites por app** | Aplicam-se com Bearer Token (app-only) |
| **Por endpoint** | Cada endpoint tem seus próprios limites |

---

## Verificando seus limites

Os cabeçalhos da resposta mostram seu status atual de rate limit:

```
x-rate-limit-limit: 900
x-rate-limit-remaining: 847
x-rate-limit-reset: 1705420800
```

| Cabeçalho | Descrição |
|:-------|:------------|
| `x-rate-limit-limit` | Máximo de solicitações permitidas |
| `x-rate-limit-remaining` | Solicitações restantes na janela |
| `x-rate-limit-reset` | Timestamp Unix quando a janela é redefinida |

## Lidando com rate limits

Quando você atinge um rate limit, receberá uma resposta 429:

```json
{
  "errors": [{
    "code": 88,
    "message": "Rate limit exceeded"
  }]
}
```

### Estratégia de recuperação

1. Verifique `x-rate-limit-reset` para saber quando a janela é redefinida
2. Aguarde até esse momento antes de tentar novamente
3. Use backoff exponencial, se necessário

```python title="Exemplo" lines wrap icon="python"
import time

def make_request_with_backoff(url, headers):
    response = requests.get(url, headers=headers)
    
    if response.status_code == 429:
        reset_time = int(response.headers.get('x-rate-limit-reset', 0))
        wait_time = max(reset_time - time.time(), 60)
        time.sleep(wait_time)
        return make_request_with_backoff(url, headers)
    
    return response
```

## Rate limits vs. faturamento

Rate limits e faturamento são separados:

| Conceito | Propósito |
|:--------|:--------|
| **Rate limits** | Controlar a frequência de solicitações para a estabilidade do sistema |
| **Cobrança de uso** | Cobrar pelos dados recuperados (pagamento por uso) |

Você pode estar dentro dos rate limits mas ainda incorrer em custos de uso, ou atingir os rate limits sem custo adicional.
