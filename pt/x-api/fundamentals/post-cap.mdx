A API do X v2 usa preços de **pagamento por uso**. Você é cobrado com base no consumo real da API, rastreado no nível do app.

---

## Como o faturamento funciona

| Conceito | Descrição |
|:--------|:------------|
| **Baseado em créditos** | Compre créditos antecipadamente, deduzidos conforme você usa a API |
| **Preço por solicitação** | Endpoints diferentes têm custos diferentes |
| **Rastreamento em tempo real** | Monitore o uso no Developer Console |

<Note>
Planos de pagamento por uso estão sujeitos a um limite mensal de 2 milhões de leituras de Posts. Se você precisa de maior volume, considere um [plano Enterprise](/forms/enterprise-api-interest).
</Note>

## Deduplicação

<Note>
**Deduplicação diária**: Se o mesmo post for retornado por várias consultas em um dia, ele conta apenas uma vez para o faturamento.
</Note>

Isso significa:

- Recuperar o mesmo post várias vezes em um dia = 1 cobrança
- Recuperar um post novamente no dia seguinte = 1 cobrança adicional
- Posts diferentes na mesma solicitação = cada um conta separadamente

## Monitorando o uso

Rastreie seu uso no [Developer Console](https://console.x.com):

| Métrica | Descrição |
|:-------|:------------|
| **Uso total** | Posts recuperados no período de faturamento |
| **Por endpoint** | Divisão por tipo de endpoint |
| **Por app** | Uso por developer app |
| **Rastreamento de custos** | Cálculos de custo em tempo real |
| **Saldo de créditos** | Créditos pré-pagos restantes |

## Detalhes de preços

Para preços atuais por endpoint e operação, visite o [Developer Console](https://console.x.com).

Os preços podem variar conforme:

- Tipo de endpoint (search vs. lookup vs. stream)
- Operação (leitura vs. gravação)
- Escopo dos dados (recente vs. full-archive)

## Perguntas frequentes

<Accordion title="O que acontece se meus créditos acabarem?">
As solicitações da API falharão até que você compre mais créditos. Configure alertas de saldo para evitar interrupção.
</Accordion>

<Accordion title="Existem valores mínimos mensais?">
Não. Pague apenas pelo que usar. Você pode ter meses com zero uso e zero custo.
</Accordion>

<Accordion title="Como o streaming é cobrado?">
Cada post único entregue via filtered stream conta para o uso, sujeito à deduplicação diária.
</Accordion>

<Accordion title="Solicitações com falha contam?">
Não. Apenas respostas bem-sucedidas que retornam dados são cobradas.
</Accordion>
