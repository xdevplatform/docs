A API do X v2 retorna dados mínimos por padrão. Use **parâmetros fields** para solicitar dados adicionais para cada tipo de objeto.

---

## Como os fields funcionam

Por padrão, uma consulta de post retorna apenas `id`, `text` e `edit_history_tweet_ids`. Para obter mais dados, adicione parâmetros de field à sua solicitação:

```bash
# Default response - minimal fields
curl "https://api.x.com/2/tweets/1234567890" \
  -H "Authorization: Bearer $TOKEN"

# With additional fields
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=created_at,public_metrics,author_id" \
  -H "Authorization: Bearer $TOKEN"
```

---

## Parâmetros de field disponíveis

Cada tipo de objeto tem seu próprio parâmetro fields:

| Objeto | Parâmetro | Documentação |
|:-------|:----------|:--------------|
| Post (Tweet) | `tweet.fields` | [Fields de Post](/x-api/fundamentals/data-dictionary/reference#tweet) |
| User | `user.fields` | [Fields de User](/x-api/fundamentals/data-dictionary/reference#user) |
| Media | `media.fields` | [Fields de Media](/x-api/fundamentals/data-dictionary/reference#media) |
| Poll | `poll.fields` | [Fields de Poll](/x-api/fundamentals/data-dictionary/reference#poll) |
| Place | `place.fields` | [Fields de Place](/x-api/fundamentals/data-dictionary/reference#place) |

## Exemplo: fields de Post

Solicite fields específicos de post com `tweet.fields`:

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=created_at,public_metrics,lang" \
  -H "Authorization: Bearer $TOKEN"
```

Resposta:

```json title="Exemplo de resposta" lines wrap icon="/icons/xds/icon-brackets.svg"
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "edit_history_tweet_ids": ["1234567890"],
    "created_at": "2024-01-15T12:00:00.000Z",
    "lang": "en",
    "public_metrics": {
      "retweet_count": 10,
      "reply_count": 5,
      "like_count": 100,
      "quote_count": 2,
      "bookmark_count": 3,
      "impression_count": 1500
    }
  }
}
```

## Exemplo: fields de User

Solicite fields específicos de user com `user.fields`:

```bash
curl "https://api.x.com/2/users/by/username/xdevelopers?user.fields=created_at,description,public_metrics" \
  -H "Authorization: Bearer $TOKEN"
```

```json title="Exemplo de resposta" lines wrap icon="/icons/xds/icon-brackets.svg"
      "followers_count": 570842,
      "following_count": 2048,
      "tweet_count": 14052,
      "listed_count": 1672

}
```

## Fields para objetos relacionados

Para obter fields em objetos relacionados (como o autor de um post), você precisa de duas coisas:

1. Uma **expansion** para incluir o objeto relacionado
2. O **parâmetro fields** para esse tipo de objeto

```bash
# Get post with author details
curl "https://api.x.com/2/tweets/1234567890?expansions=author_id&user.fields=description,public_metrics" \
  -H "Authorization: Bearer $TOKEN"
```

Resposta:

```json title="Exemplo de resposta" lines wrap icon="/icons/xds/icon-brackets.svg"
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "author_id": "2244994945"
  },
  "includes": {
    "users": [{
      "id": "2244994945",
      "name": "X Developers",
      "username": "xdevelopers",
      "description": "The voice of the X Developer Platform",
      "public_metrics": {
        "followers_count": 570842,
        "following_count": 2048
      }
    }]
  }
}
```

[Saiba mais sobre expansions →](/x-api/fundamentals/expansions)

## Observações importantes

<Warning>
**Você não pode solicitar subfields.** Ao solicitar `public_metrics`, você obtém todas as métricas (likes, reposts, replies, quotes, bookmarks, impressions). Não é possível solicitar apenas `public_metrics.like_count`.
</Warning>

- A ordem dos fields nas respostas pode diferir da ordem da solicitação
- Fields ausentes nas respostas significam que o valor é `null` ou vazio
- Alguns fields exigem autenticação específica (ex.: métricas privadas precisam de user context)
- Consulte a referência da API de cada endpoint para os fields disponíveis
