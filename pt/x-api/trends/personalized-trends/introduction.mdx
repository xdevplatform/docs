## Endpoint

| Método | Endpoint | Descrição |
|:-------|:---------|:------------|
| GET | `/2/users/personalized_trends` | Obter tendências personalizadas |

---

## Exemplo de requisição

```bash
curl "https://api.x.com/2/users/personalized_trends" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

## Exemplo de resposta

```json title="Exemplo de resposta" lines wrap icon="/icons/xds/icon-brackets.svg"
{
  "data": [
    {
      "trend_name": "#AI",
      "tweet_count": 125000
    },
    {
      "trend_name": "Machine Learning",
      "tweet_count": 85000
    }
  ]
}
```

## Primeiros passos

<Note>
**Pré-requisitos**

- Uma [conta de desenvolvedor](https://developer.x.com/en/portal/petition/essential/basic-info) aprovada
- Um [Projeto e App](/resources/fundamentals/developer-apps) no Developer Console
- User Access Tokens via [OAuth 2.0 PKCE](/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2)
- Premium User Subscription
</Note>
