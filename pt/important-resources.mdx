## Referência rápida

### Estrutura de resposta

Todas as respostas v2 seguem esta estrutura:

```json
{
  "data": { ... },      // Objeto(s) principal(is)
  "includes": { ... },  // Objetos expandidos (se solicitados)
  "meta": { ... },      // Informações de paginação
  "errors": [ ... ]     // Erros parciais (se houver)
}
```

### Parâmetros comuns

| Parâmetro | Uso |
|:----------|:----|
| `tweet.fields` | Solicitar campos específicos do post |
| `user.fields` | Solicitar campos específicos do usuário |
| `expansions` | Incluir objetos relacionados |
| `max_results` | Limitar resultados por página |
| `pagination_token` | Obter próxima/página anterior |

### Métodos de autenticação

| Método | Caso de uso |
|:-------|:---------|
| Bearer Token | Dados públicos somente leitura |
| OAuth 2.0 | Ações do usuário com escopos granulares |
| OAuth 1.0a | Ações do usuário (legado, permissões completas) |

[Guia completo de autenticação →](/resources/fundamentals/authentication/overview)
