O SDK XDK Python está disponível diretamente do repositório do GitHub e pode ser instalado via `pip`.
## Pré-requisitos
- Python 3.8 ou superior.
- `pip` e `venv` para ambientes virtuais (recomendado).
## Instalação rápida
Instale o XDK a partir do subdiretório do GitHub:
```bash
pip install xdk
```
Isso obtém a versão mais recente gerada a partir da branch `main`.
## Instalação para desenvolvimento
Para desenvolvimento ou contribuição:
1. Clone o repositório:
   ```bash
   git clone https://github.com/xdevplatform/xdk.git
   cd xdk/python
   ```
2. Instale as dependências em modo editável:
   ```bash
   pip install -e .
   ```
   Isso instala o SDK e suas dependências de runtime.
3. (Opcional) Instale as dependências de desenvolvimento para testes/linting:
   ```bash
   pip install -e .[dev]
   ```
## Verificação
Teste a instalação:
```python
import xdk
print(xdk.__version__)  # Should print the XDK version
```
**Nota:** Como o XDK é gerado usando a spec OpenAPI, sempre confira o [changelog da X API](https://docs.x.com/changelog) e as notas de versão do XDK no repositório para verificar quaisquer alterações.
Para exemplos de código detalhados usando o XDK Python, confira nosso [repositório de exemplos de código no GitHub](https://github.com/xdevplatform/samples/tree/main/python).
