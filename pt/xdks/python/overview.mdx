O XDK Python (X Developer Kit) é nossa biblioteca cliente oficial para interagir com a X API v2 usando Python. Ele permite que os desenvolvedores comecem a usar nossa API rapidamente e criem aplicações com ela. É gerado com base em nossa [especificação OpenAPI](https://api.x.com/2/openapi.json) oficial. Ele abstrai detalhes de baixo nível de HTTP, oferecendo controle refinado quando necessário.
## Recursos principais
- 🔐 **Suporte a OAuth**: Suporte completo para autenticação por Bearer Token (apenas de app), OAuth 2.0 com PKCE (contexto de usuário) e OAuth 1.0.
- 🔄 **Paginação**: Paginação automática de resultados grandes. O XDK cuida da paginação sem exigir que você faça múltiplas chamadas de API usando o `next_token`.
- 📡 **Streaming**: Oferece suporte a streaming de dados em tempo real para endpoints como o filtered stream, que exigem uma conexão HTTP persistente.
- 🎯 **Cobertura abrangente**: Suporta todos os endpoints da X API v2, incluindo pesquisa, timelines, filtered stream e muito mais.
**Compatibilidade de versão**: Python 3.8+. Testado em CPython e PyPy.
