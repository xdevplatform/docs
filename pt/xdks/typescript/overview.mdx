Um SDK TypeScript abrangente para a X API (anteriormente Twitter API) com recursos avançados, incluindo paginação inteligente, múltiplos métodos de autenticação, streaming em tempo real e segurança de tipos completa.

## Recursos principais

- **🔐 Autenticação**: Contexto de usuário (OAuth 1.0a, OAuth 2.0) e apenas de app (Bearer Token)
- **🔄 Paginação**: Paginação automática com suporte a iteração assíncrona
- **📡 Streaming**: Streaming orientado a eventos com reconexão automática
- **📚 Segurança de tipos**: Definições TypeScript completas para todos os endpoints e parâmetros
- **🎯 Suporte completo à X API**: Users, Posts, Lists, Bookmarks, Communities e muito mais

## Início rápido

<CodeGroup dropdown>

```typescript title="quickstart.ts" lines wrap icon="square-js" theme={null}
import { 
    Client, 
    type ClientConfig,
    type Users
} from '@xdevplatform/xdk';

const config: ClientConfig = { bearerToken: 'your-bearer-token' };

const client: Client = new Client(config);

async function main(): Promise<void> {
  const userResponse: Users.GetByUsernameResponse = await client.users.getByUsername('XDevelopers');
  const username: string = userResponse.data?.username!;
  console.log(username);
}

main();
```

```javascript quickstart.js theme={null}
import { Client } from '@xdevplatform/xdk';

const client = new Client({ bearerToken: 'your-bearer-token' });

const userResponse = await client.users.getByUsername('XDevelopers');
const username = userResponse.data.username;
console.log(username);
```
