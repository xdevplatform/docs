Comece a usar o SDK TypeScript para a X API no seu projeto.

## Instalar

<CodeGroup>

```bash npm theme={null}
npm install @xdevplatform/xdk
```

```bash yarn theme={null}
yarn add @xdevplatform/xdk
```

```bash pnpm theme={null}
pnpm add @xdevplatform/xdk
```

</CodeGroup>

## Suporte a TypeScript

O SDK é escrito em TypeScript e inclui definições de tipos completas. Nenhum pacote de tipos adicional é necessário.

## Requisitos

- Node.js 16+ 
- TypeScript 4.5+ (se estiver usando TypeScript)
