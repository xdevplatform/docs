Interface de resposta paginada

Representa a estrutura de uma resposta de API paginada da X API.

## Parâmetros de tipo

| Nome | Descrição |
| :------ | :------ |
| `T` | O tipo dos itens na resposta |

## Propriedades

<ResponseField name="data" type="T[]" required>
Array de itens na página atual

</ResponseField>

<ResponseField name="meta" type="Object">
Metadados de paginação

<Expandable title="propriedades">
<ResponseField name="Name" type="Type | Description" required>
</ResponseField>

<ResponseField name="resultCount" type="number | Número de resultados na página atual">
</ResponseField>

<ResponseField name="nextToken" type="string | Token para buscar a próxima página">
</ResponseField>

<ResponseField name="previousToken" type="string | Token para buscar a página anterior">
</ResponseField>
</Expandable>
</ResponseField>

<ResponseField name="includes" type="Record&lt;string, any&gt;">
Objetos adicionais incluídos (usuários, tweets, etc.)

</ResponseField>

<ResponseField name="errors" type="any[]">
Quaisquer erros na resposta

</ResponseField>
