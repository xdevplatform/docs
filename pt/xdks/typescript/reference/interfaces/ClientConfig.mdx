Opções de configuração para o cliente X API

## Propriedades

<ResponseField name="baseUrl" type="string">
URL base para requisições da API

</ResponseField>

<ResponseField name="bearerToken" type="string">
Bearer Token para autenticação

</ResponseField>

<ResponseField name="accessToken" type="string">
Token de acesso OAuth 2.0

</ResponseField>

<ResponseField name="oauth1" type="any">
Instância OAuth1 para autenticação

</ResponseField>

<ResponseField name="headers" type="Record&lt;string, string&gt;">
Cabeçalhos personalizados para incluir nas requisições

</ResponseField>

<ResponseField name="timeout" type="number">
Timeout de requisição em milissegundos

</ResponseField>

<ResponseField name="retry" type="boolean">
Se deve tentar novamente automaticamente requisições que falharam

</ResponseField>

<ResponseField name="maxRetries" type="number">
Número máximo de tentativas de repetição

</ResponseField>
