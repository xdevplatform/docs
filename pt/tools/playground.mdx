O [API Playground](https://github.com/xdevplatform/playground) é um servidor mock local que simula toda a X API v2. Teste endpoints, construa protótipos e explore a API sem consumir créditos reais.

## Instalação

Requer Go 1.21+. Instale a partir do código-fonte ou baixe um binário pré-compilado dos [releases](https://github.com/xdevplatform/playground/releases).

<Tabs>
  <Tab title="Go install">
```bash
go install github.com/xdevplatform/playground/cmd/playground@latest
playground start
```
  </Tab>
  <Tab title="Build a partir do código-fonte">
```bash
git clone https://github.com/xdevplatform/playground.git
cd playground
go build -o playground ./cmd/playground
./playground start
```
  </Tab>
</Tabs>

O servidor inicia em `http://localhost:8080` por padrão.

## Início rápido

Faça requisições como faria para a API real — use `test_token` como seu bearer token:

```bash title="me" lines wrap icon="terminal"
# Fazer lookup de um usuário
curl -H "Authorization: Bearer test_token" \
  http://localhost:8080/2/users/me

# Criar um post
curl -X POST -H "Authorization: Bearer test_token" \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello from the playground!"}' \
  http://localhost:8080/2/tweets

# Buscar posts
curl -H "Authorization: Bearer test_token" \
  "http://localhost:8080/2/tweets/search/recent?query=hello"
```

Abra `http://localhost:8080/playground` no seu navegador para a interface interativa.

## O que está incluído

| Recurso | Descrição |
|:--------|:------------|
| **Validação de requisições** | Valida requisições conforme a spec OpenAPI |
| **Erros realistas** | Retorna códigos e mensagens de erro adequados |
| **Suporte a streaming** | Endpoints de streaming simulados |
| **Rate limiting** | Simulação configurável de rate limits |
| **Suporte a CORS** | Funciona com aplicações baseadas em navegador |
| **Rastreamento de uso** | Endpoints simulados de faturamento e rastreamento de créditos |
| **Persistência de estado** | Persistência opcional em arquivo em `~/.playground/` |
