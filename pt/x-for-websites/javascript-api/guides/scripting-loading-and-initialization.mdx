## Inicializando conteúdo incorporado depois que uma página é carregada

A maioria das integrações do X for Websites será bem atendida pelo código embed recomendado encontrado na [documentação de configuração](/x-for-websites/javascript-api/guides/set-up-x-for-websites), mas você pode querer otimizar como e quando o JavaScript de widgets do Twitter for Websites escaneia o DOM da página para descobrir novos elementos HTML elegíveis para serem transformados em botões ou widgets.

Se o conteúdo é inserido dinamicamente em uma página (como conteúdo com lazy-loading ou usando uma técnica `pushState` para navegar entre artigos), é necessário processar novos botões e widgets usando a função `twttr.widgets.load()`.

```javascript
twttr.widgets.load()
```

Chamado sem argumento, `widgets-js` pesquisará em toda a árvore DOM `document.body` por widgets não inicializados. Para melhor desempenho, passe um objeto `HTMLElement` para restringir a busca apenas aos filhos do elemento.

Exemplo:

```javascript
twttr.widgets.load(
  document.getElementById("container")
);
```
