A forma mais fácil de criar um widget do X for Websites — um Post button, Follow button, Post ou timeline incorporado — é usar nossas ferramentas de configuração em [publish.x.com](https://publish.x.com) e depois copiar e colar o código HTML gerado no template ou área de widget do seu site.

- [Gerar marcação para um Post ou Follow button](https://publish.x.com)
- [Gerar marcação para um Post ou timeline incorporado](https://publish.x.com)

## Para melhor desempenho e confiabilidade, inclua o script widgets.js em seu template

Inclua o JavaScript do X for Websites uma vez em seu template de página para desempenho ideal e para permitir o rastreamento de [eventos JavaScript de widget do X](/x-for-websites/javascript-api/guides/javascript-api).

Se seu site usa vários widgets, você pode configurar os widgets do X em suas páginas uma vez, o que tornará seu site mais rápido, e widgets como Posts incorporados serão mais confiáveis para autores ao usar sistemas de gerenciamento de conteúdo.

```html title="Exemplo" lines wrap icon="/icons/xds/icon-code.svg"
<script>window.twttr = (function(d, s, id) {
  var js, fjs = d.getElementsByTagName(s)[0],
    t = window.twttr || {};
  if (d.getElementById(id)) return t;
  js = d.createElement(s);
  js.id = id;
  js.src = "https://platform.x.com/widgets.js";
  fjs.parentNode.insertBefore(js, fjs);

  t._e = [];
  t.ready = function(f) {
    t._e.push(f);
  };

  return t;
}(document, "script", "twitter-wjs"));</script>
```

O snippet acima otimiza o carregamento por:

1. Atribuir um ID de elemento HTML `twitter-wjs` para identificar facilmente se o arquivo JavaScript já existe na página. Sair cedo se o ID já existir.
2. Carregar o JavaScript do Twitter for Websites de forma assíncrona.
3. Inicializar uma fila de funções assíncronas para armazenar funções dependentes até que o script esteja disponível.

Inclua este snippet antes de qualquer outro JavaScript em sua página que possa depender da fila de funções assíncronas `twttr.ready`.

## Ignore tags de script dos embeds

Se você incluir o carregador JavaScript do X em cada página, não precisa incluir o elemento `<script>` gerado por um configurador de botão, Post incorporado ou ferramenta de Timeline incorporada. Você pode excluir o HTML `<script>` extra da marcação gerada.

Se você usar a [oEmbed API](/x-for-websites/oembed-api) para incluir Posts em seu conteúdo, pode gerar códigos embed que não incluem o elemento `<script>` passando `omit_script=true` na query string.
