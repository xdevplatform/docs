A biblioteca JavaScript do X for Websites suporta inserção dinâmica de um Post button usando a função `twttr.widgets.createShareButton`. Passe uma URL de compartilhamento, elemento pai alvo e quaisquer opções personalizadas.

Os snippets de código nesta página assumem que `widgets.js` foi carregado com sucesso na sua página. Inclua um carregador de script assíncrono em sua página, inicializando `window.twttr` conforme descrito em nossa [documentação do carregador JavaScript](/x-for-websites/javascript-api/guides/set-up-x-for-websites). Todo código JavaScript que depende de `widgets.js` deve ser executado em ou após `twttr.ready`.

## Argumentos

| Parâmetro  | Descrição                                                                 | Valor de exemplo                              |
|------------|-----------------------------------------------------------------------------|--------------------------------------------|
| `url`      | Uma URL de compartilhamento, ou uma string vazia se você não quiser incluir um componente de URL no Post composer | `https://dev.x.com/`                 |
| `targetEl` | Nó DOM do elemento pai desejado                                      | `document.getElementById('container')`     |
| `options`  | Sobrescreve as opções padrão de widget. Consulte a [referência de parâmetros do Post button](/x-for-websites/post-button/guides/parameter-reference) para detalhes | `{ text: 'Hello world' }`                  |

## Exemplo

Um elemento com o ID DOM `container` existe na página.

```html
<div id="container"></div>
```

O snippet de código abaixo criará um novo Post button com texto de compartilhamento pré-selecionado "Hello world" e uma URL compartilhada de "/" inserido em uma página dentro de um elemento com um ID único `container`.

```javascript
twttr.widgets.createShareButton(
  '/',
  document.getElementById('container'),
  {
    text: 'Hello World'
  }
);
```

## Promises

A função `twttr.widgets.createShareButton` retorna uma [Promise](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise). Você pode executar código depois que um widget é inserido na sua página passando um callback para a função `then` da promise resultante.

```javascript
twttr.widgets.createShareButton(...)
.then( function( el ) {
  console.log('Post button added.');
});
```

## Botões de hashtag, mention

Crie um hashtag ou mention button usando as funções [twttr.widgets.createHashtagButton](/x-for-websites/post-button/guides/hashtag-button) e [twttr.widgets.createMentionButton](/x-for-websites/post-button/guides/mention-button) respectivamente. O mesmo objeto se aplica.
