Um Post button suporta pré-preenchimento de texto de compartilhamento, hashtags e referência de conta do X. Associe contas relacionadas do X para gerar seguidores.

## Parâmetros de conteúdo do Post

| Parâmetro  | Descrição                                                                 | Exemplo                              |
|------------|-----------------------------------------------------------------------------|--------------------------------------|
| `text`     | Texto pré-preenchido destacado no Post composer.                       | `custom share text`                  |
| `url`      | URL incluída com o Post.                                                | `https://dev.x.com/web/post-button` |
| `hashtags` | Uma lista separada por vírgulas de hashtags a serem adicionadas ao texto padrão do Post.    | `example,demo`                       |
| `via`      | Atribuir a origem de um Post a um username do X.                      | `xdevelopers`                         |
| `related`  | Uma lista separada por vírgulas de contas relacionadas ao conteúdo do URI compartilhado.| `xapi,x`                 |

## Parâmetros de exibição do botão

Personalize o tamanho do Post Button exibido, alinhamento do botão e mais.

Esses parâmetros visuais não se aplicam aos Web Intents, que são estilizados separadamente pelos sites que implementam.

| Parâmetro | Descrição                                                                 | Exemplo |
|-----------|-----------------------------------------------------------------------------|---------|
| `size`    | Quando definido como `large`, exibe uma versão maior do botão. Defina como `l` para iframe. | `large` |
| `lang`    | Um [código de idioma suportado pelo X](/x-for-websites/supported-languages). | `es`    |
| `dnt`     | Quando definido como `true`, o botão e sua página incorporada em seu site não são usados para fins que incluem [sugestões personalizadas](https://support.x.com/articles/20169421) e [anúncios personalizados](https://support.x.com/articles/20170405). | `true`  |

### Exemplo HTML `data-*`

```html
<a class="twitter-share-button"
  href="https://x.com/intent/tweet"
  data-size="large"
  data-text="custom share text"
  data-url="https://dev.x.com/web/tweet-button"
  data-hashtags="example,demo"
  data-via="xdevelopers"
  data-related="xapi,x">
Post
</a>
```

### Exemplo de factory JavaScript

```javascript
twttr.widgets.createShareButton(
  "https:\/\/dev.x.com\/web\/tweet-button",
  document.getElementById("tweet-container"),
  {
    size: "large",
    text: "custom share text",
    hashtags: "example,demo",
    via: "xdevelopers",
    related: "xapi,x"
  }
);
```
