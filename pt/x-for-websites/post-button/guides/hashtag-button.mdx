Um Hashtag button é um tipo especial de [Post button](/x-for-websites/post-button/overview) para incentivar a participação em uma conversa agrupada por keyword. [Leia mais sobre hashtags no X](https://support.x.com/articles/49309).

## Como adicionar um Hashtag Button ao seu site

1. Crie um novo elemento âncora com uma classe `twitter-hashtag-button` para permitir que o JavaScript do X for Websites descubra o elemento e aprimore o link em um Hashtag button. Defina um valor de atributo `href` como `https://x.com/intent/tweet` para criar um link para o compositor de web intent do X.

```html
<a class="twitter-hashtag-button"
  href="https://x.com/intent/tweet">
Post</a>
```

2. Adicione sua hashtag de interesse como um valor de parâmetro de query `button_hashtag` e um componente do texto interno do elemento âncora.

```html
<a class="twitter-hashtag-button"
  href="https://x.com/intent/tweet?button_hashtag=XStories">
Post #XStories</a>
```

3. Carregue de forma assíncrona [o JavaScript do X for Websites usando nosso snippet de carregamento](/x-for-websites/javascript-api/guides/set-up-x-for-websites). O snippet JavaScript verificará se existe uma versão existente na página, inicializará uma fila de funções para serem executadas quando o JavaScript de widgets tiver carregado, e carregará o JavaScript de widgets de forma assíncrona do CDN do X.

## Definir hashtags secundárias

Inclua hashtags adicionais no texto pré-preenchido do Post usando o [parâmetro de query hashtags do web intent](/x-for-websites/post-button/guides/web-intent). Uma hashtag definida no parâmetro `button_hashtag` e exibida no botão aparecerá antes das hashtags definidas no parâmetro `hashtags`.

## Função factory JavaScript

A biblioteca JavaScript de widget do X suporta inserção dinâmica de um hashtag button usando a função `twttr.widgets.createHashtagButton`. Passe uma hashtag, elemento de container alvo e as mesmas opções suportadas pela [função factory JavaScript do Post button](/x-for-websites/post-button/guides/javascript-factory-function).

```javascript
twttr.widgets.createHashtagButton(
  "XStories",
  document.getElementById("container"),
  {
    size:"large"
  }
);
```
