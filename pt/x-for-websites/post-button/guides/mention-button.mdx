Um Mention button é um tipo especial de [Post button](/x-for-websites/post-button/overview) para incentivar um novo Post focado em uma interação entre o usuário e uma conta mencionada. Um Post que começa com `@username` não aparece na timeline do autor na visualização padrão; o Post só aparecerá na home timeline dos seguidores do autor se o visualizador seguir tanto o autor quanto o usuário mencionado. [Leia mais sobre @replies e @mentions](https://support.x.com/articles/14023).

## Como adicionar um Mention Button ao seu site

1. Crie um novo elemento âncora com uma classe `twitter-mention-button` para permitir que o JavaScript do X for Websites descubra o elemento e aprimore o link em um Mention button. Defina um valor de atributo `href` como `https://x.com/intent/tweet` para criar um link para o compositor de web intent do X.

```html
<a class="twitter-mention-button"
  href="https://x.com/intent/tweet">
Post</a>
```

2. Adicione o username da conta mencionada como um valor de parâmetro de query `screen_name` e um componente do texto interno do elemento âncora.

```html
<a class="twitter-mention-button"
  href="https://x.com/intent/tweet?screen_name=XDevelopers">
Post to @XDevelopers</a>
```

3. Carregue de forma assíncrona [o X for Websites usando nosso snippet de carregamento](/x-for-websites/javascript-api/guides/set-up-x-for-websites). O snippet JavaScript verificará se existe uma versão existente na página, inicializará uma fila de funções para serem executadas quando o JavaScript de widgets tiver carregado, e carregará o JavaScript de widgets de forma assíncrona do CDN do X.

## Função factory JavaScript

A biblioteca JavaScript de widget do X suporta inserção dinâmica de um Mention button usando a função `twttr.widgets.createMentionButton`. Passe um username, elemento de container alvo e as mesmas opções suportadas pela [função factory JavaScript do Post button](/x-for-websites/post-button/guides/javascript-factory-function).

```html
twttr.widgets.createMentionButton(
  "XDevelopers",
  document.getElementById("container"),
  {
    size:"large"
  }
);
```
