Um Post Web Intent facilita para os visitantes do seu site compor e publicar um Post para sua audiência a partir de um link na sua página web. Sites podem configurar texto e hashtags do Post, passar uma URL e identificar contas do X relacionadas à página.

## URL do Web Intent

```
https://x.com/intent/tweet
```

## Parâmetros de query

| Parâmetro     | Descrição                                                                 | Valor de exemplo                                      |
|---------------|-----------------------------------------------------------------------------|----------------------------------------------------|
| `text`        | Texto do Post pré-preenchido em UTF-8 e codificado em URL. O texto passado aparecerá pré-selecionado para um usuário do X deletar ou editar antes de publicar. O comprimento do texto do Post passado não deve exceder 280 caracteres quando combinado com quaisquer hashtags, via ou parâmetros url passados. Texto passado que faça o Post exceder 280 caracteres exigirá edição adicional por um usuário do X antes que ele possa publicar com sucesso. | `Hello%20World`                                    |
| `url`         | Uma URL totalmente qualificada com esquema HTTP ou HTTPS, [codificada em URL](http://en.wikipedia.org/wiki/Percent-encoding). A URL fornecida será encurtada pelo t.co do X para o número de caracteres especificado por short_url_length. | `https%3A%2F%2Fexample.com%2F`                     |
| `hashtags`    | Permita fácil descoberta de Posts por tópico incluindo uma lista separada por vírgulas de valores de hashtag sem o caractere # precedente. | `nature,sunset`                                    |
| `via`         | Um username do X para associar com o Post, como a conta do X do seu site. O username fornecido será adicionado ao final do Post com o texto "via @username". Um usuário do X deslogado será incentivado a fazer sign-in ou entrar no X para interagir com os Posts da conta via. A conta pode ser sugerida como conta a seguir depois que o usuário publica um Post. | `xdevelopers`                                       |
| `related`     | Sugira usernames adicionais do X relacionados ao Post como valores separados por vírgulas. O X pode sugerir essas contas para seguir depois que o usuário publica seu Post. Você pode fornecer uma breve descrição de como a conta se relaciona ao Post com uma vírgula codificada em URL e texto após o username. | `x%3AX%20News,xapi%3AX%20API%20News` |
| `in_reply_to` | O ID do Post pai em uma conversa, como o Post inicial do seu site ou conta de autor. | `525001166233403393`                               |
