## O Post Button suporta outros idiomas?

Sim. Inclua um parâmetro `lang` para definir explicitamente o idioma do Post button. Consulte a lista de [idiomas suportados pelo X for Websites](/x-for-websites/supported-languages) para saber mais sobre os idiomas suportados.

## Quais são as dimensões do Post Button?

O Post button tem 55 pixels de largura e 20 pixels de altura.

### Post Button internacionalizado

Post buttons internacionalizados têm dimensões ligeiramente diferentes.

| Idioma | Código lang | Dimensões   |
|----------|-----------|--------------|
| Inglês  | `en`      | 55px por 20px |
| Japonês | `ja`      | 80px por 20px |
| Espanhol  | `es`      | 64px por 20px |

## Quero usar vários Post Buttons na minha página. Há algo que eu deva saber?

Se você quer usar mais de um Post Button em uma página, há algumas coisas que você deve verificar.

1. Se estiver usando o Post Button JavaScript, certifique-se de incluir o JavaScript `widgets.js` apenas uma vez. O melhor lugar para colocar o JavaScript é antes do fechamento de `</body>`.
2. Para evitar duplicação de conteúdo em sua página, considere usar as tags `rel="me"` e `rel="canonical"` no lugar dos data points via e url em cada Post Button.

## Posso controlar a ordem das contas recomendadas?

Apenas duas contas são exibidas e, por padrão, o usuário via é exibido primeiro, com a primeira conta relacionada mostrada em seguida. Se o usuário for seguidor do usuário via, a Share Box exibirá as duas primeiras contas relacionadas das quais o usuário não é seguidor. Nenhuma conta é exibida se o usuário seguir todas as contas sugeridas (via e relacionadas).

Saiba mais sobre [contas relacionadas](/x-for-websites/post-button/overview).

## O Post Button funciona sobre HTTPS?

Sim, o Post Button funciona sobre HTTPS.
