Posts incorporados trazem sua escolha de conteúdo do X para os artigos do seu site. Um Post incorporado inclui fotos, vídeo e mídia de cards criados para exibição no X, e pode até transmitir vídeo ao vivo do Periscope. Todos os aspectos dos requisitos de exibição do X são tratados para você ao usar nossas ferramentas; atribuição de autor, ações do Post, hashtags, menções e outros componentes-chave da experiência do X.

Um Post incorporado consiste em duas partes: um snippet HTML hospedado em sua página web, e o JavaScript do X for Websites para transformar esse código em um Post totalmente renderizado. Você pode copiar a marcação do Post incorporado gerada pelo menu do Post em x.com, colar uma URL em um CMS compatível ou adicionar um Post à página programaticamente usando uma função factory JavaScript.

## Incorporar a partir do x.com

Todo Post exibido em x.com inclui um código de incorporação para copiar e colar facilmente em sua página web. Ative o menu do Post e selecione "Embed Post" para gerar a marcação para incluir em sua página:

## Converter URLs de Post usando oEmbed

Converta programaticamente uma URL de Post em marcação de Post incorporado usando a oEmbed API. Torne a incorporação de um Post no seu CMS ou app tão simples quanto colar uma URL de Post.

```bash
https://publish.x.com/oembed?
  url=https://x.com/Interior/status/463440424141459456
```

Nosso [guia de melhores práticas para CMS](/x-for-websites/embedded-posts/guides/cms-best-practices) descreve padrões comuns para sites que adicionam suporte de software a Posts incorporados.

## Personalizar a exibição do Post

Personalize um Post incorporado para o design visual e preferências de exibição do seu site incluindo parâmetros extras em seu HTML de Post incorporado.

### Combine com o esquema de cores do seu site

Um Post incorporado suporta temas de cor claro e escuro. Personalize os widgets do X [em nível de página com elementos `<meta>`](/x-for-websites/webpage-properties) ou adicione atributos `data-*` a elementos `<blockquote>` gerados individualmente.

Consulte nossa [documentação de referência de Post incorporado](/x-for-websites/embedded-posts/guides/embedded-tweet-parameter-reference) para uma lista completa de opções de Post incorporado.

### Não mostrar Post anterior na thread de conversa

Um Post pode ser em resposta a outro Post. Por padrão, incluímos um resumo do Post anterior na conversa para fornecer contexto.

Defina um parâmetro de query oEmbed como `hide_thread=true` ou adicione um atributo `data-conversation="none"` ao elemento `<blockquote>` resultante para impedir a exibição de um Post pai.

### Ocultar fotos, vídeos e Cards

Um Post pode incluir uma foto, vídeo ou link para outro conteúdo que suporte um [Card](https://dev.x.com/cards/overview). Por padrão, essa mídia é exibida em Posts incorporados. Você pode ocultar essa mídia se editorialmente desejado.

Defina um parâmetro de query oEmbed como `hide_media=true` ou adicione um atributo `data-cards="hidden"` ao elemento `<blockquote>` resultante para impedir a exibição de conteúdo expandido.

### Personalizar alinhamento

Um Post incorporado é alinhado à esquerda por padrão. O Post pode ser centralizado ou alinhado à direita, se preferir, usando a personalização de alinhamento. Embora historicamente o CSS forneça numerosos hacks para centralizar conteúdo em uma página web, este é o método oficial recomendado e suportado.

## Renderizar um Post com JavaScript

Nosso JavaScript de widget escaneia o DOM em execução, convertendo elementos `blockquote.twitter-tweet` em Posts incorporados totalmente renderizados com base no conteúdo do elemento.

Se estiver inserindo dinamicamente novo conteúdo em uma página, passe o novo fragmento de documento para [twttr.widgets.load()](/x-for-websites/javascript-api/guides/scripting-loading-and-initialization) para inicializar o conteúdo do Post incorporado.

Para renderizar diretamente um Post incorporado em runtime, use a função [twttr.widgets.createTweet()](/x-for-websites/embedded-posts/guides/embedded-post-javascript-factory-function).
