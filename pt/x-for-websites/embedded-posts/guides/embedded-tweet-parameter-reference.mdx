Um Post incorporado suporta personalização em atributos `data-*` e funções factory JavaScript. Este documento de referência descreve os parâmetros usados em todos os formatos.

Consulte a [oEmbed API](/x-for-websites/oembed-api) para definir esses parâmetros como parte de uma resposta HTML para um ID ou URL de Post.

## Parâmetros

| Parâmetro     | Descrição                                                                 | Exemplo    |
|---------------|-----------------------------------------------------------------------------|------------|
| `id`          | O ID numérico do Post desejado.                                      | `20`       |
| `cards`       | Quando definido como `hidden`, links em um Post não são expandidos para prévias de foto, vídeo ou link. | `hidden`   |
| `conversation`| Quando definido como `none`, apenas o Post citado será exibido, mesmo que seja em resposta a outro Post. | `none`     |
| `theme`       | Quando definido como `dark`, exibe o Post com texto claro sobre fundo escuro.  | `dark`     |
| `width`       | A largura máxima do Post renderizado em pixels inteiros. Este valor deve estar entre 250 e 550 pixels. | `325`      |
| `align`       | Alinhar o Post à `left`, `right` ou `center` em relação ao seu contêiner. Normalmente definido para permitir que texto ou outro conteúdo se envolva em torno do Post. | `right`    |
| `lang`        | Um [código de idioma suportado pelo X](/x-for-websites/supported-languages). Carrega componentes de texto no idioma especificado. Nota: não afeta o texto do Post citado. | `es`       |
| `dnt`         | Quando definido como `true`, o Post e sua página incorporada em seu site não são usados para fins que incluem [sugestões personalizadas](https://support.x.com/articles/20169421) e [anúncios personalizados](https://support.x.com/articles/20170405). | `true`     |

### Exemplo HTML

```html
<blockquote class="twitter-tweet" data-lang="en">
  <p lang="en" dir="ltr">just setting up my twttr</p>&mdash; Jack (@jack) <a href="https://x.com/jack/status/20">March 21, 2006</a>
</blockquote>
```

### Exemplo de factory JavaScript

```javascript
twttr.widgets.createTweet(
  "20",
  document.getElementById("tweet-container"),
  {
    theme: "dark"
  }
);
```

<Note>
O ID numérico do Post deve ser passado como string.
</Note>
