A biblioteca JavaScript do X for Websites suporta a inserção dinâmica de Posts incorporados usando a função `twttr.widgets.createTweet`. Passe um ID do Post, elemento pai alvo e quaisquer opções personalizadas.

Os snippets de código nesta página assumem que o `widgets.js` foi carregado com sucesso na sua página. Inclua um carregador de script assíncrono em sua página, inicializando `window.twttr` conforme descrito em nossa [documentação do carregador JavaScript](/x-for-websites/javascript-api/guides/set-up-x-for-websites). Todo código JavaScript que depende de `widgets.js` deve ser executado em ou após `twttr.ready`.

| Parâmetro  | Descrição                                                                 | Valor de exemplo                              |
|------------|-----------------------------------------------------------------------------|--------------------------------------------|
| `tweetID`  | O ID numérico do Post desejado.                                      | `'20'`                                     |
| `targetEl` | Nó DOM do elemento pai desejado.                                     | `document.getElementById('container')`     |
| `options`  | Sobrescreve as opções padrão de widget. Consulte a [Referência de parâmetros de Post incorporado](/x-for-websites/embedded-posts/guides/embedded-tweet-parameter-reference) para detalhes. | `{ theme: 'dark' }`                        |

## Exemplo

Um elemento com o ID DOM `container` existe na página.

```html
<div id="container"></div>
```

O snippet de código abaixo inserirá o [Post ID 20](https://x.com/jack/status/20) em uma página dentro de um elemento com um ID único `container`. O objeto de opções especifica uma personalização de tema escuro.

```javascript
twttr.widgets.createTweet(
  '20',
  document.getElementById('container'),
  {
    theme: 'dark'
  }
);
```

## Promises

A função `twttr.widgets.createTweet` retorna uma [Promise](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise). Você pode executar código depois que um widget é inserido na sua página passando um callback para a função `then` da promise resultante.

```javascript
twttr.widgets.createTweet(...)
.then( function( el ) {
  console.log('Post added.');
});
```
