O botão Follow é um pequeno botão exibido em seus sites para ajudar os usuários a seguirem facilmente uma conta do X. Um botão Follow consiste em duas partes: um link para uma [página de follow web intent](/x-for-websites/follow-button/overview) no x.com e o JavaScript do X for Websites para transformar o link em nosso reconhecível botão Follow.

## Como adicionar um botão Follow ao seu site

O site [publish.x.com](https://publish.x.com) inclui uma ferramenta simples para gerar o embed de um botão Follow para copiar e colar no modelo do seu site. Basta inserir um @screenName para começar.

### Manualmente

1. Crie um elemento âncora com o nome de classe `twitter-follow-button`. Defina o valor do atributo `href` apontando para uma URL de perfil do X.

```html
<a class="twitter-follow-button"
  href="https://x.com/XDevelopers">
Follow @XDevelopers</a>
```

2. Personalize os parâmetros do botão Follow usando atributos `data-*`.

```html
<a class="twitter-follow-button"
  href="https://x.com/XDevelopers"
  data-size="large">
Follow @XDevelopers</a>
```

3. Carregue de forma assíncrona o JavaScript do X for Websites usando nosso snippet de carregamento. O script inicializará o botão Follow após o carregamento do conteúdo da página.


## Personalização do botão

### Ocultar username

Oculte o username do botão Follow exibido definindo um valor de atributo `data-show-screen-name` como `false`.

### Estilo de botão grande

Adicione um valor de atributo `data-size` como `large` para exibir um botão Follow maior.
