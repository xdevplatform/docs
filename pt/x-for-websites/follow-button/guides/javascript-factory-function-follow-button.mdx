A biblioteca JavaScript do X for Websites suporta inserção dinâmica de um follow button usando a função `twttr.widgets.createFollowButton`. Passe o username do X, elemento pai alvo e quaisquer opções personalizadas.

Os snippets de código nesta página assumem que `widgets.js` foi carregado com sucesso na sua página. Inclua um carregador de script assíncrono em sua página, inicializando `window.twttr` conforme descrito em nossa [documentação do carregador JavaScript](/x-for-websites/javascript-api/guides/set-up-x-for-websites). Todo código JavaScript que depende de `widgets.js` deve ser executado em ou após `twttr.ready`.

## Argumentos

| Parâmetro    | Descrição                                      | Valor de exemplo                              |
|--------------|--------------------------------------------------|--------------------------------------------|
| `username`   | Um username do X                              | `'XDevelopers'`                             |
| `targetEl`   | Nó DOM do elemento pai desejado           | `document.getElementById('container')`     |
| `options`    | Sobrescreve as opções padrão de widget                  | `{ size: 'large' }`                        |

## Exemplo

Um elemento com o ID DOM `container` existe na página.

```html
<div id="container"></div>
```

O snippet de código abaixo criará um novo Follow button para o username do X "XDevelopers" inserido em uma página dentro de um elemento com um ID único `container`.

```javascript
twttr.widgets.createFollowButton(
  'XDevelopers',
  document.getElementById('container'),
  {
    size: 'large'
  }
);
```

## Promises

A função `twttr.widgets.createFollowButton` retorna uma [Promise](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise). Você pode executar código depois que um widget é inserido na sua página passando um callback para a função `then` da promise resultante.

```javascript
twttr.widgets.createFollowButton(...)
.then( function( el ) {
  console.log('Follow button added.');
});
```
