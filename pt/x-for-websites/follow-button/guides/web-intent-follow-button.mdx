[Web Intents](/x-for-websites/web-intents/overview) exibem ações do X otimizadas para exibição em uma pequena janela do navegador. Um site pode se conectar a um follow web intent por meio de um simples link em qualquer site. Os widgets JavaScript do X for Websites usam o follow web intent para solicitar aos visualizadores que sigam uma conta.

Uma janela de Web Intent de follow apresenta um formulário de login inline para usuários do X deslogados.

O usuário seguirá a conta ao efetuar login com sucesso por meio do formulário de login inline do follow web intent. O status de follow é confirmado pelo botão "Following" exibido na janela do web intent.

Recomendamos renderizar uma janela filha de Web Intent com dimensões de pelo menos 550 pixels de largura e 420 pixels de altura.

## URL do Web Intent

```
https://x.com/intent/follow
```

## Parâmetros de query

Um follow Web Intent deve referenciar uma conta do X por `screen_name` ou `user_id`. Um `screen_name` pode mudar; recomendamos usar `user_id` sempre que possível.

| Parâmetro     | Descrição                                                  | Valor de exemplo     |
|---------------|--------------------------------------------------------------|-------------------|
| `screen_name` | O username do X da conta que você gostaria que o visualizador seguisse | `xdevelopers`      |
| `user_id`     | O identificador de usuário do X da conta que você gostaria que o visualizador seguisse | `2244994945`      |
