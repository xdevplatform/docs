## Quais são as dimensões do botão de follow?

O botão de follow tem 20 pixels de altura. Sua largura variará dependendo do idioma escolhido (ou do idioma do visualizador), do comprimento do `screen_name` especificado, do número de seguidores quando `show_count` está ativo, etc. Recomendamos que você reserve espaço para o valor de `screen_name` e o valor de `show_count`, caso escolha exibi-lo.

Note que, se você usar a versão JavaScript do Follow Button, poderá especificar a largura usando o atributo `data-width`. Se estiver usando a versão iframe, você pode usar a propriedade `style`.
