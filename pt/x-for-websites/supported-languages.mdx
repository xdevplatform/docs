## Suporte de idiomas

```html
<a
  class="twitter-share-button"
  href="https://x.com/share"
  data-lang="es">
X
</a>
```

O X for Websites extrairá o idioma mais apropriado de sua posição na árvore DOM, se nenhum idioma for fornecido na marcação do widget. Páginas que definem um script ou região não suportados serão mapeadas para o idioma disponível mais próximo: por exemplo, `pt-BR` usará `pt` se o português estiver disponível, mas uma localização regional brasileira não estiver.

O inglês dos Estados Unidos é o padrão se o código de idioma de uma página não corresponder a nenhuma tradução disponível.

<Note>
Definir o idioma afeta apenas o idioma dos elementos do X, como texto de ação e exibição de timestamp; o texto do Tweet é sempre exibido no idioma em que foi originalmente escrito.
</Note>

## Suporte a navegadores

Suportamos todos os navegadores e webviews que suportam [ECMAScript Level 5](https://en.wikipedia.org/wiki/ECMAScript#5th_Edition) e superior — isso deve incluir todos os navegadores e webviews modernos. Construímos e testamos nossos widgets em todos os navegadores desktop e móveis modernos, bem como webviews móveis.

As únicas exceções onde não renderizamos são navegadores que não suportam ECMAScript level 5 e Internet Explorer 11 e inferiores.
