O botão Message é um pequeno botão para ajudar seus clientes a enviar facilmente uma Direct Message para você no X. Permita que seus clientes entrem em contato para fazer perguntas e obter suporte diretamente do seu site.

Um botão Message consiste em duas partes: um link para o compositor de direct message em X.com, e o JavaScript do X for Websites para aprimorar o link com o botão Message reconhecível.

## Fluxo de criação de mensagem

Clicar no botão levará o usuário ao compositor de Direct Message, pré-preenchido com os valores que você definir na marcação do botão.

## Como adicionar um botão de mensagem ao seu site

O [publish.x.com](https://publish.x.com) é uma ferramenta de configuração simples para criar um botão de mensagem. Basta inserir seu @screenName para começar.

### Manualmente

1. Crie um elemento âncora com o nome de classe `twitter-dm-button`. Defina um valor de atributo `href` como `https://x.com/messages/compose` para criar um link para a visualização de direct message do X. O parâmetro de query `recipient_id` é o ID do @username que deve receber as mensagens.

```html
<a href="https://x.com/messages/compose?recipient_id=3805104374"
  class="twitter-dm-button" data-screen-name="@furni">
Message @furni</a>
```

2. Opcionalmente, pré-preencha o texto da mensagem personalizando o parâmetro de query `text`.

```html
<a href="https://x.com/messages/compose?recipient_id=3805104374&text=Hello%20world"
  class="twitter-dm-button" data-screen-name="@furni">
Message @furni</a>
```

3. Carregue de forma assíncrona o JavaScript do X for Websites usando nosso snippet de carregamento. O script inicializará o botão de mensagem após o carregamento do conteúdo da página.

### Parâmetros de query

| Parâmetro      | Descrição                                                                 |
|----------------|-----------------------------------------------------------------------------|
| `recipient_id` | **Obrigatório**. O user ID do usuário do X que receberá as mensagens. |
| `text`         | **Opcional**. O texto pré-preenchido na mensagem. O texto deve estar codificado em URL. |

### Personalização do botão

#### Tamanho

Adicione um valor de atributo `data-size` como `large` para exibir um botão de mensagem maior.
