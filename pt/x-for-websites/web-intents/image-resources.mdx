Os recursos estão disponíveis para dar suporte a uma experiência de usuário consistente em aplicações que utilizam o Twitter e sites que usam Web Intents. Recomenda-se que você armazene esses recursos dentro de sua própria aplicação. Para mais informações sobre o uso dessas marcas, consulte nossos Display Requirements.

## Logo do X

Baixe os assets atuais do logo do X (incluindo vários tamanhos e cores) diretamente do [brand toolkit oficial](https://about.x.com/en/who-we-are/brand-toolkit).

## Tweet Actions

Uma Tweet action representa uma possível ação em um Tweet com um estado "ativo" se o visualizador já concluiu a ação.

Todas as Tweet actions são exibidas com um preenchimento cinza médio (#AAB8C2) em seu estado padrão. Todas as Tweet actions devem definir 50% de opacidade quando a ação está sendo ativada pelo visualizador (por exemplo, pseudo CSS `:active`). A ação mantém a cor de preenchimento anterior durante seu estado pressionado / de ativação, mudando para o estado "ativo" depois que a ação é ativada.

Ações de retweet e like aparecem em um estado "ativo" se o visualizador atual executou a ação. Uma propriedade `retweeted` ou `favorited` do [objeto Tweet](/x-api/fundamentals/data-dictionary/reference#post-tweet) definida como true comunica o estado de exibição "ativo" esperado.

Uma retweet action é desativada se o visualizador atual for o autor do Tweet. Uma ação desativada tem 30% de opacidade.

A opacidade do ícone retweet deve ser ajustada durante a ativação do ícone. O ícone retweet deve aparecer no estado "ativo" se a resposta do objeto Tweet para o visualizador atual tiver a propriedade `retweeted` definida como `true`. Um estado inativo da Tweet action pode existir quando o visualizador atual for o mesmo que o autor do Tweet.
