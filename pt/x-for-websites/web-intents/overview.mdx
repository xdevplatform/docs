Web Intents fornecem fluxos para trabalhar com Tweets e usuários do X: Tweet, Reply, Retweet, Like e Follow. Eles possibilitam que os usuários interajam com o conteúdo do X no contexto do seu site, sem sair da página ou ter que autorizar um novo app apenas para a interação. Web intents são compatíveis com a web mobile, incluem handlers de app nativo no iOS e Android quando o app do X está instalado, e são super fáceis de implementar.

## Trabalhando com Web Intents

Web Intents são a forma mais simples de permitir que as pessoas façam Tweet ou sigam contas do X diretamente do seu site. Web Intents automaticamente trazem um visualizador para a melhor experiência logada para concluir sua ação especificada, incluindo compositores de Tweet ou visualizações de perfil do X dentro dos apps X for iOS e X for Android. Se um visualizador não tiver uma conta do X, ele terá a oportunidade de fazer login no X ou criar uma conta antes de concluir a ação originalmente especificada. Web Intents não exigem configurar uma aplicação do X, armazenar credenciais de app ou solicitar permissões de app a um visualizador antes de publicar.

[O JavaScript do X for Websites](/x-for-websites/javascript-api/guides/set-up-x-for-websites) disparará automaticamente [eventos JavaScript](/x-for-websites/javascript-api/guides/javascript-api) apropriados quando incluído em uma página web.

Web Intents não podem ser carregados dentro de um iframe. Um autor do X deve visualizar a página web completa antes de decidir criar um novo Tweet ou uma Tweet action pré-preenchida pelo seu Web Intent especificado ou seguir uma conta do X especificada.

Imagens para ícones de likes, replies e reposts estão todas disponíveis em nossa página de [Recursos de imagem](/x-for-websites/web-intents/image-resources). Consulte nossos [Display Requirements](https://about.x.com/company/display-requirements) para dicas sobre como renderizar Tweets e outros recursos do X.

Se sua audiência falar um idioma diferente do inglês, recomendamos que você use intents localizados.

### Começar

Web Intents podem ser invocados de forma flexível por meio de uma combinação leve de JavaScript e HTML e destinam-se a ser abertos em uma nova janela.

A forma mais fácil de usar intents é incluir o JavaScript do X for Websites em qualquer página web onde você queira invocar um intent. Se você já configurou o [Tweet button](/x-for-websites/post-button/overview), já está preparado para Web Intents.

Quando combinado com tags âncora padrão e [iconografia familiar](https://dev.x.com/basics/image-resources) como os exemplos abaixo, este JavaScript abrirá automaticamente uma janela do tamanho apropriado quando clicado. Você só precisa carregar `platform.x.com/widgets.js` uma vez.

```html
<script type="text/javascript" async src="https://platform.twitter.com/widgets.js"></script>
<a href="https://twitter.com/intent/tweet?in_reply_to=463440424141459456">Reply</a>
<a href="https://twitter.com/intent/retweet?tweet_id=463440424141459456">Retweet</a>
<a href="https://twitter.com/intent/like?tweet_id=463440424141459456">Like</a>
```

## Lista de Web Intents

### Tweet ou Reply a um Tweet

- [https://x.com/intent/tweet](https://x.com/intent/tweet?in_reply_to=463440424141459456&related=xdevelopers)


Consulte a [documentação do Tweet Web Intent](/x-for-websites/post-button/overview) para mais informações sobre o Tweet intent.

### Retweet a um Tweet

- [https://x.com/intent/retweet](https://x.com/intent/retweet?tweet_id=463440424141459456&related=xdevelopers,x,support)

[Retweets](https://support.x.com/articles/77606-what-is-retweet-rt) são uma forma poderosa de permitir que seus usuários compartilhem seu conteúdo com seus seguidores.

#### Parâmetros suportados

- `tweet_id`

Todo Tweet é identificado por um ID. Você pode encontrar esse valor na API ou visualizando a página de permalink de qualquer Tweet, geralmente acessível ao clicar na data de "publicação" de um tweet.

### Like a um Tweet


- [https://twitter.com/intent/like](https://x.com/intent/like?tweet_id=463440424141459456)


Os usuários [curtem](https://support.x.com/articles/20169874) por várias razões: quando amam um Tweet, quando querem salvá-lo para depois ou para oferecer um sinal de agradecimento. O like intent permite fornecer essa Tweet action e fazer follow-up com contas relevantes sugeridas para o usuário seguir.

#### Parâmetros suportados

- `tweet_id`

Todo Tweet é identificado por um ID. Você pode encontrar esse valor na API ou visualizando a página de permalink de qualquer Tweet, geralmente acessível ao clicar no timestamp exibido ao lado de um Tweet.

### Mini-Perfil

- [https://x.com/intent/user](https://x.com/intent/user?screen_name=NASA)

Este Intent oferece uma maneira discreta de vincular nomes de pessoas, empresas e serviços às suas contas do X. A nova aba apresenta em destaque a foto de perfil da conta, bio, tweets recentes e um botão Follow fácil de usar.

Mais recursos de imagem.

#### Parâmetros suportados

- `screen_name`

Todo usuário do X tem um screen name, mas eles estão sujeitos a mudanças. Recomendamos usar user_id sempre que possível.

- `user_id`

Os X User IDs estão disponíveis na API e identificam um usuário de forma única.

### Follow


- [https://twitter.com/intent/follow](https://x.com/intent/follow?screen_name=NASA)

Um [follow Web Intent](/x-for-websites/follow-button/guides/web-intent-follow-button) exibe um formulário inline de sign in para usuários deslogados e segue a conta X alvo em caso de login bem-sucedido.


## Localização

Você pode passar um parâmetro de query `lang` como parte de qualquer web intent para sobrescrever a exibição de idioma de um usuário logado ou os idiomas aceitos por um navegador. Consulte [idiomas do X for Websites](/x-for-websites/supported-languages) para uma lista de valores `lang` suportados.

## Otimização

### Dependências limitadas

Alguns sites podem preferir incorporar o JavaScript de web intents discretos inline ou sem uma dependência do `platform.twitter.com`. O snippet abaixo oferecerá a funcionalidade equivalente sem a dependência externa.

```javascript title="Exemplo" expandable lines wrap icon="square-js"
(function() {
  if (window.__twitterIntentHandler) return;
  var intentRegex = /twitter\.com\/intent\/(\w+)/,
      windowOptions = 'scrollbars=yes,resizable=yes,toolbar=no,location=yes',
      width = 550,
      height = 420,
      winHeight = screen.height,
      winWidth = screen.width;

  function handleIntent(e) {
    e = e || window.event;
    var target = e.target || e.srcElement,
        m, left, top;

    while (target && target.nodeName.toLowerCase() !== 'a') {
      target = target.parentNode;
    }

    if (target && target.nodeName.toLowerCase() === 'a' && target.href) {
      m = target.href.match(intentRegex);
      if (m) {
        left = Math.round((winWidth / 2) - (width / 2));
        top = 0;

        if (winHeight > height) {
          top = Math.round((winHeight / 2) - (height / 2));
        }

        window.open(target.href, 'intent', windowOptions + ',width=' + width +
                                           ',height=' + height + ',left=' + left + ',top=' + top);
        e.returnValue = false;
        e.preventDefault && e.preventDefault();
      }
    }
  }

  if (document.addEventListener) {
    document.addEventListener('click', handleIntent, false);
  } else if (document.attachEvent) {
    document.attachEvent('onclick', handleIntent);
  }
  window.__twitterIntentHandler = true;
}());
```
