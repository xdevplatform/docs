Defina preferências de widget em todo um site incluindo elementos `<meta>` e `<link>` em suas páginas.

Configurações de widget especificadas em um `<meta>` podem ser sobrescritas em nível de widget individual. Ordem de precedência:

1. parâmetro de query do link do web intent
2. atributo do widget
3. elemento meta ou link

## Desativar varredura do DOM para widgets e botões

O JavaScript do X for Websites escaneia o `document.body` após a inicialização para localizar botões, widgets e web intents para aprimoramento. Desative esta varredura se o conteúdo do X for carregado apenas via [funções factory JavaScript](/x-for-websites/javascript-api/guides/set-up-x-for-websites) ou se você preferir [chamar load diretamente](/x-for-websites/javascript-api/guides/scripting-loading-and-initialization) em um fragmento menor da página.

```html
<meta
  name="twitter:widgets:autoload"
  content="off">
```

## Link canonical

O [Post button](/x-for-websites/post-button/overview) usa a [relação de link canonical da página](http://tools.ietf.org/html/rfc6596) expressa em um `<link>` como a URL compartilhada se a propriedade URL não estiver definida na marcação do botão.

Adicione um link canonical na seção `<head>` da sua página web.

```html
<link
  rel="canonical"
  href="/">
```

## Identifique o perfil do X da página

Preencha a propriedade `via` de um Tweet button vinculando à sua página de perfil do X com um token de relação de link me.

Defina uma relação de link `me` na seção `<head>` da sua página web.

```xml
<link
  rel="me"
  href="https://x.com/XDevelopers">
```

Você também pode definir uma relação `me` a partir de um elemento âncora em sua página, como um botão Follow.

```html
<a
  class="x-follow-button"
  rel="me"
  href="https://x.com/XDevelopers">
Follow @XDevelopers
</a>
```

## Tema

Sobrescreva a preferência de tema `light` padrão para um [Post incorporado](/x-for-websites/embedded-posts/overview) ou uma [Timeline incorporada](/x-for-websites/timelines/overview).

```html
<meta
  name="twitter:widgets:theme"
  content="dark">
```

## Parâmetro do not track

Você pode escolher se os widgets do X em seu site ajudam a personalizar conteúdo e sugestões para usuários do X, incluindo anúncios. Você pode optar por não ter informações do seu site usadas para personalização seguindo as instruções abaixo. Inclua o seguinte snippet dentro dos elementos `<meta>` e `<link>` em suas páginas que incluem widgets do X for Websites:

```html
<meta name="twitter:dnt" content="on">
```

Você também pode optar por sair desse uso de dados para um widget específico, e pode fazer isso definindo o parâmetro opcional `data-dnt` como true, como mostrado no exemplo abaixo:

```html
<a
  class="twitter-share-button"
  href="https://x.com/share"
  data-dnt="true">
Tweet</a>
<script async defer
  src="//platform.x.com/widgets.js"
  charset="utf-8">
</script>
```

## Desativar funcionalidades que podem disparar avisos de Content Security Policy

Um Tweet ou Timeline incorporado pode ser exibido com capacidades restritas quando uma [Content Security Policy](http://en.wikipedia.org/wiki/Content_Security_Policy) restringe o carregamento inline do X. Defina `csp=on` para desativar funcionalidades que poderiam exibir avisos de Content Security Policy em seu site.

```html
<meta
  name="twitter:widgets:csp"
  content="on">
```
