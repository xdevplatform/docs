Uma profile timeline exibe os Posts mais recentes ordenados do mais novo para o mais antigo de uma conta pública específica do X.

## Marcação HTML

Uma profile timeline responsiva pode ser adicionada a uma página web através de um template HTML comum. Gere marcação para uma profile timeline incorporada em [publish.x.com](https://publish.x.com).

Um exemplo de template:

```html
<a class="twitter-timeline"
  href="https://x.com/{screen_name}">
Posts by @{screen_name}
</a>
```

```html
<a class="twitter-timeline"
  href="https://x.com/XDevelopers">
Posts by @XDevelopers
</a>
```

## Função factory JavaScript

A biblioteca JavaScript de widget do X suporta inserção dinâmica de uma profile timeline incorporada usando a função `twttr.widgets.createTimeline`. Passe uma definição de fonte de dados, elemento de container alvo e objeto de opções opcional para inserir uma timeline incorporada em sua página.

Parâmetros HTML `data-*` são convertidos para camelCase quando passados como uma propriedade do objeto de opções.

```javascript
twttr.widgets.createTimeline(
  {
    sourceType: "profile",
    screenName: "XDevelopers"
  },
  document.getElementById("container")
);
```
