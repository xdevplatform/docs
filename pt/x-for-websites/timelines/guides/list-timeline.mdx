Uma list timeline exibe os Posts mais recentes ordenados do mais novo para o mais antigo de uma list pública curada de contas do X. A timeline inclui um cabeçalho exibindo o nome, descrição e curador da list. [Leia mais sobre X lists](https://support.x.com/articles/76460).

## Marcação HTML

Uma timeline responsiva alimentada por uma X list pode ser adicionada a uma página web através de um template HTML comum.

Um exemplo de template:

```html
<a class="twitter-timeline"
  href="https://x.com/{screen_name}/lists/{slug}">
Posts from https://x.com/{screen_name}/lists/{slug}
</a>
```

```html
<a class="twitter-timeline"
  href="https://x.com/x/lists/official-twitter-accts">
Posts from https://x.com/x/lists/official-twitter-accts
</a>
```

## Função factory JavaScript

A biblioteca JavaScript do X for Websites suporta inserção dinâmica de uma list timeline incorporada usando a função `twttr.widgets.createTimeline`. Passe uma definição de fonte de dados, elemento de container alvo e objeto de opções opcional para inserir uma timeline incorporada em sua página.

Parâmetros HTML `data-*` são convertidos para camelCase quando passados como uma propriedade do objeto de opções.

```javascript
twttr.widgets.createTimeline(
  {
    sourceType: "list",
    ownerScreenName: "XDevelopers",
    slug: "national-parks"
  },
  document.getElementById("container")
);
```
