## Referência da API

<Note>
  Esta é a referência técnica completa. Para uma visão geral de criativos, cards e vídeos promovidos, consulte a{" "}
  <a href="/x-ads-api/creatives">Visão Geral de Creatives</a>.
</Note>

Esta referência técnica cobre todos os endpoints da X Ads Creatives API, incluindo Account Media, Cards (Image App Download Card, Video App Download Card, Image Conversation Card, Video Conversation Card, Image Direct Message Card, Video Direct Message Card, Poll Card, Website Card, Video Website Card), Draft Tweets, Media Library, Preroll Call to Actions, Promoted Accounts, Promoted Tweets, Scheduled Promoted Tweets, Scheduled Tweets e Tweets.

Devido ao tamanho da referência técnica original, para consultar os detalhes específicos de cada endpoint (URLs de recursos, parâmetros de requisição, exemplos de resposta em JSON), consulte a documentação em inglês em [/x-ads-api/creatives/reference](/x-ads-api/creatives/reference). Todos os nomes de endpoint, parâmetros, valores enum e estruturas JSON são idênticos.
