O tipo de moeda é identificado usando [ISO-4217](http://en.wikipedia.org/wiki/ISO_4217). É uma string de três letras como `USD` ou `EUR`. O valor de uma moeda é representado em micros. Para USD, $5,50 é codificado como 5,50*1e6, ou 5.500.000. Para representar um "valor inteiro", é preciso multiplicar o local micro por 1e6 (1\_000\_000) para todas as moedas.

A Ads API reconhece as moedas oficiais de todos os países onde o produto X SMB Ads está disponível. Para uma lista completa desses países, clique [aqui](https://business.x.com/en/help/overview/about-eligibility-for-twitter-ads.html).

A maioria das moedas tem uma "precisão" de dois (como USD: $1,23).

* `AED`, `VEF`, `PKR`, `IDR`, `HKD`, `QAR`, `PHP`, `NZD`, `INR`, `EUR`, `ARS`, `THB`, `MXN`, `EGP`, `DZD`, `SAR`, `LBP`, `COP`, `TRY`, `SGD`, `MAD`, `AUD`, `USD`, `MYR`, `CAD`, `BRL`, `GBP`.

As seguintes moedas não usam decimal:

* `VND`, `KRW`, `CLP`, `JPY`

E estas usam três casas decimais:

* `KWD`, `IQD`, `BHD`, `TND`

O uso da moeda é realizado através de [funding instruments](/x-ads-api/introduction).
