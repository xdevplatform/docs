O sandbox é um ambiente para você testar e construir sua implementação da Ads API.

Campanhas criadas via sandbox não serão exibidas aos usuários e registros de teste para objetos como Funding Instruments podem ser criados dinamicamente.

Usar o sandbox é tão simples quanto chamar o hostname apropriado ads-api-sandbox.x.com, mas ele também contém algumas funcionalidades únicas encontradas apenas no sandbox.

Faça uma requisição inicial para [POST accounts](/x-ads-api/campaign-management/reference#post-accounts) para criar uma nova conta de anunciante. A resposta desta chamada conterá um account_id que pode ser usado para requisições subsequentes. Esses endpoints permitem que os consumidores criem e testem contra múltiplas contas de anunciante.

### Lista de endpoints exclusivos do Sandbox:

* [POST accounts](/x-ads-api/campaign-management/reference#post-accounts) Criar uma conta no sandbox
* [POST accounts/:account_id/features](/x-ads-api/campaign-management/reference#post-accounts-account-id-features) Adicionar uma feature de conta a uma conta no sandbox
* [POST accounts/:account\_id/funding\_instruments](/x-ads-api/campaign-management/reference#post-accounts-account-id-funding-instruments) Adicionar um funding instrument a uma conta no sandbox
* [DELETE accounts/:account_id](/x-ads-api/campaign-management/reference#delete-accounts-account-id) Excluir uma conta no sandbox
* [DELETE accounts/:account_id/features](/x-ads-api/campaign-management/reference#delete-accounts-account-id-features) Excluir uma feature de conta de uma conta no sandbox
* [DELETE accounts/:account\_id/funding\_instruments/:funding\_instrument\_id](/x-ads-api/campaign-management/reference#delete-accounts-account-id-funding-instruments-funding-instrument-id) Excluir um funding instrument de uma conta no sandbox
