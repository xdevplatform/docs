## Referência da API

<Note>
  Esta é a referência técnica completa. Para uma visão geral de campanhas, line items, orçamento, conceitos de segmentação e um guia passo a passo, consulte a{" "}
  <a href="/x-ads-api/campaign-management">Visão Geral de Gerenciamento de Campanhas</a>.
</Note>

Esta referência técnica extensa cobre todos os endpoints da X Ads Campaign Management API, incluindo Accounts, Account Apps, Account History, Advertiser Business Categories, Audience Estimate, Authenticated User Access, Bidding Rules, Campaigns, Content Categories, Curated Categories, Features, Funding Instruments, IAB Categories, Line Items, Line Item Placements, Media Creatives, Preroll Call to Actions, Promotable Users, Promoted Accounts, Promoted Tweets, Publishers, Reach Estimate, Recommendations, Targeting Criteria, Targeting Options (Locations, Events, Interests, TV Markets, TV Shows, Behaviors, Behavior Taxonomies, App Store Categories, Conversation Types, Devices, Languages, Network Operators, Platform Versions, Platforms) e Tracking Tags.

Devido ao tamanho da referência técnica original, o conteúdo permanece disponível na documentação em inglês em [/x-ads-api/campaign-management/reference](/x-ads-api/campaign-management/reference). Todos os nomes de endpoints, parâmetros, exemplos de código JSON, valores de resposta e estruturas técnicas são idênticos entre as versões, uma vez que descrevem uma API real. As traduções em português preservam campos técnicos como `campaign_id`, `line_item_id`, `funding_instrument_id`, `entity_status`, `bid_strategy`, `objective`, `placements`, etc. no formato original.

Para consultar a referência técnica em português com traduções detalhadas das descrições, entre em contato com o time da X Developer Platform ou consulte a versão em inglês.
