## Configuração da Conversion API

### Pré-requisitos

#### **Acesso à Ads API - Novas aplicações**

* O requisito principal da Conversion API é ter uma [conta de desenvolvedor](https://developer.x.com/en/portal/dashboard) e [acesso à Ads API](https://developer.x.com/en/docs/twitter-ads-api/getting-started). O processo está descrito no guia [Ads API Getting Started](https://developer.x.com/en/docs/twitter-ads-api/getting-started). Observe o seguinte:

**Passo 1: Conta de desenvolvedor**

* Ao solicitar uma [conta de desenvolvedor](https://developer.x.com/en/portal/dashboard), inscreva-se em um dos nossos [planos](https://developer.x.com/en/portal/products/) de assinatura para aprovação instantânea.
* **Nota**: Como melhor prática, recomendamos fortemente usar o handle oficial da sua empresa no X para criar uma conta de desenvolvedor e solicitar acesso à Ads API. Se a conta de desenvolvedor estiver associada a um handle de desenvolvedor, não há como transferir essas credenciais, se necessário. É melhor abrigar sob uma conta de empresa para gerenciamento contínuo e utilizar [multi-user login](https://business.x.com/en/help/troubleshooting/multi-user-login-faq.html), conforme necessário. Caso contrário, no mínimo, a conta deve ser configurada com configurações não padrão (imagem de cabeçalho, avatar, descrição da bio e URL da bio) e usar autenticação de dois fatores.

**Passo 2: Aplicação da Ads API**

* Certifique-se de ter o **App ID** correto pronto para sua aplicação da Ads API. O App ID pode ser encontrado no [Developer Console](https://developer.x.com/en/portal/dashboard) em Projects & Apps. Exemplo: 16489123
* Solicite acesso à Ads API usando o [Formulário de acesso à Ads API](/forms/ads-api-access).

#### **Acesso à Ads API - Aplicações existentes**

* Se você já tem uma aplicação da Ads API ativamente usada, tanto a aplicação quanto os access tokens existentes podem ser usados para a Conversion API.

Esta é uma referência técnica extensa que cobre configuração completa da Conversion API, incluindo detalhes de OAuth de 3 etapas, geração de access tokens, exemplos de código para vários casos de uso e todos os endpoints da Web Conversion API. Para os detalhes completos, consulte a versão em inglês em [/x-ads-api/measurement/web-conversions](/x-ads-api/measurement/web-conversions).
