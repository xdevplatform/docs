## Visão geral do MACT

A medição de [mobile app promotion](https://biz.x.com/mobile-app-promotion) do X permite que os anunciantes acompanhem o sucesso das campanhas publicitárias no X projetadas para gerar instalações ou outras conversões dentro do app. Um parceiro de medição mobile do X oferece a capacidade de um anunciante gerenciar quais conversões deseja acompanhar dos apps que está promovendo no X. Uma vez que o anunciante tenha configurado o tipo e as janelas de tempo dos eventos que deseja acompanhar, o parceiro de medição mobile enviará todos esses eventos ao X e receberá imediatamente dados de atribuição indicando a campanha e o criativo com o qual o usuário interagiu para gerar a conversão.

### Eventos de conversão

Para reportar um [evento de conversão](https://developer.x.com/en/docs/x-ads-api/measurement/api-reference/conversion-event) ao X e obter dados de atribuição, o parceiro deve enviar o mobile app ID, tipo e timestamp da conversão, bem como um valor com hash do advertising/device ID. Fornecer esses dados registrará o evento de conversão na plataforma do X e retornará a atribuição quando aplicável. Além disso, o anunciante pode optar por fornecer metadados extras sobre o evento de conversão, como valor de uma compra, ID de um produto ou método de registro.

Esta é uma referência técnica extensa que cobre o endpoint POST conversion_event com todos os seus parâmetros. Para os detalhes completos incluindo parâmetros opcionais, exemplos de requisição e resposta, consulte a versão em inglês em [/x-ads-api/measurement/mobile-conversions](/x-ads-api/measurement/mobile-conversions).
