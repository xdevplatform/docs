## Visão geral

A Catalog API é uma solução de commerce que dá aos anunciantes a capacidade de configurar feeds de produtos, agrupar produtos em conjuntos e gerenciar produtos de catálogo de forma holística. A Catalog API permite o gerenciamento programático de catálogos e concede aos anunciantes mais controle sobre como seus catálogos são ingeridos e atualizados.

Um catálogo armazena tudo relacionado aos produtos e product set do usuário e está associado ao handle do usuário. **Atualmente, um usuário só pode criar um catálogo.**

A Catalog API suporta duas formas de ingerir produtos:

1. **Scheduled Feed**: Adicione uma URL de feed (CSV, TSV ou XML) que será buscada periodicamente. O X suporta arquivos de até 8GB.
2. **Batch Products API**: Visualize, crie, atualize e exclua atributos de produto com requisições em lote (JSON).

Comerciantes do X podem criar product sets baseados em regras de filtragem. Isso permite anexar metadados adicionais aos produtos e criar product sets especiais para recursos de commerce orgânico ou Dynamic Product Ads. A Catalog API e o X Shopping Manager suportam dois tipos de product sets:

1. **Manual**: Selecione até 50 produtos e defina um nome e descrição.
2. **Filter**: Adicione até 30 filtros para gerar sets automaticamente (preço, categoria de produto do Google, tipo de produto, inventário, preço promocional, campos personalizados, etc.).

### Pré-requisitos

Os endpoints da Catalog API estão atualmente disponíveis apenas por **acesso antecipado**. Para solicitar acesso, entre em contato com seu representante do X ou preencha o formulário apropriado.

Você deve aceitar os termos de serviço no [X Shopping Manager](https://ads.x.com/shopping_manager).

Para especificações de produtos e detalhes do Shopping Manager, consulte o [Guia de especificações de produtos](https://business.x.com/en/help/shopping-specs.html).
