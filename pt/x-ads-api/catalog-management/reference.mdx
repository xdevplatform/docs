#### GET product_catalogs

Recupera detalhes de alguns ou todos os catálogos de produtos associados ao usuário autenticado (padrão) ou ao usuário especificado no parâmetro `user_id`.

**URL do recurso**

`https://ads-api.x.com/12/product_catalogs`

<ParamField query="user_id" type="long" optional>
  Uma referência ao usuário com o qual você está operando na requisição. Use GET users/lookup para recuperar um user ID a partir de um screen name.
</ParamField>

**Exemplo de requisição**

```json
GET https://ads-api.x.com/12/product_catalogs
```

**Exemplo de resposta**
```json title="Exemplo de resposta" lines wrap icon="/icons/xds/icon-brackets.svg"
{
  "request": {
    "params": {}
  },
  "next_cursor": null,
  "data": [
    {
      "id": "1547080201384865792",
      "name": "Catalog Name"
    }
  ]
}
```

#### POST product_catalogs

Cria um catálogo de produtos. Um usuário só pode criar um catálogo que armazena todos os produtos. Comerciantes do X precisam criar um catálogo antes de fazer upload de produtos.

**URL do recurso**

`https://ads-api.x.com/12/product_catalogs`

<ParamField query="name" type="string" required>
  Nome do seu catálogo de produtos.
</ParamField>

<ParamField query="user_id" type="long" optional>
  Uma referência ao usuário com o qual você está operando na requisição. Use GET users/lookup para recuperar um user ID a partir de um screen name.
</ParamField>

**Exemplo de requisição**

```json
POST https://ads-api.x.com/12/product_catalogs?name=catalog_123_abc_def
```

**Exemplo de resposta**
```json
{
  "request": {
    "params": {
      "name": "catalog_123_abc_def"
    }
  },
  "data": {
    "id": "1559934724822351872",
    "name": "catalog_123_abc_def"
  }
}
```

Esta referência técnica também cobre os endpoints PUT, DELETE para product_catalogs, todos os endpoints de Products (GET, PUT, DELETE), Product Sets (GET, POST, PUT, DELETE) e Scheduled Feeds (GET, POST, PUT, DELETE). Para todos os detalhes técnicos, tabelas de parâmetros, atributos de request body em JSON e exemplos de respostas, consulte a versão em inglês em [/x-ads-api/catalog-management/reference](/x-ads-api/catalog-management/reference). Todos os nomes de parâmetros, endpoints, valores enum e estruturas JSON permanecem inalterados.
