## API Reference Guide

The 23 tools are backed by the following Ads API endpoints (23 routes, served through the x-api gateway at major version `/12`):

| Method | Path | Used by tool |
| :---- | :---- | :---- |
| GET | [`/12/accounts`](/x-ads-api/campaign-management/reference#get-accounts) | `list_ads_accounts` |
